# email-marketing

## ใช้ตอนไหน
ต้องวางระบบอีเมลทั้งหมดของแบรนด์ ไม่ใช่ฉบับเดียว

## ขั้นตอน
1. แบ่ง segment ตามพฤติกรรม/ความสนใจ
2. กำหนดประเภทอีเมล: broadcast vs automation
3. ตั้ง KPI: open/click/conversion/unsubscribe
4. วางปฏิทินส่ง + แผนทดสอบ subject line

## เทมเพลต / โครงผลลัพธ์
```
Segments / ปฏิทินอีเมล / ประเภท(broadcast,flow) / KPI เป้าหมาย / แผน A/B
```

## เคล็ดลับ
- ลิสต์ที่ engage ดีกว่าลิสต์ใหญ่แต่เงียบ
- ทำความสะอาดลิสต์ที่ไม่เปิดเป็นระยะ
