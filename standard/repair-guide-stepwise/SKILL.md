# คู่มือซ่อมทีละขั้น (Step-by-step Repair Guide)

## ใช้ตอนไหน
เมื่อต้องสอนงานซ่อม/ติดตั้งให้ทีม หรือทำ SOP งานซ่อมที่ทำซ้ำบ่อย

## ถามผู้ใช้ก่อน
1. ซ่อม/ติดตั้งอะไร รุ่นไหน
2. อาการ/ปัญหาที่ต้องแก้
3. เครื่องมือที่ต้องใช้
4. ขั้นตอนคร่าวๆ ที่ช่างทำ (เล่ามาแบบพูด)

## ขั้นตอน
1. เรียงขั้นตอนเป็นลำดับ 1-2-3 ที่ทำตามได้จริง
2. แต่ละขั้นบอก: ทำอะไร / ใช้เครื่องมือไหน / จุดสังเกตว่าทำถูก
3. แทรก ⚠️ คำเตือนความปลอดภัยตรงจุดเสี่ยง
4. ปิดท้ายด้วยวิธีทดสอบว่าซ่อมสำเร็จ

## เทมเพลตผลลัพธ์
```
คู่มือ: [งาน] รุ่น [..]
เครื่องมือที่ต้องเตรียม: ...
⚠️ ความปลอดภัยก่อนเริ่ม: ...
ขั้นตอน:
1. ... (จุดสังเกต: ...)
2. ...
การทดสอบหลังซ่อม: ...
อาการเสียที่พบบ่อย + วิธีแก้: ...
```

## เคล็ดลับ
- เขียนให้ "ช่างใหม่" ทำตามได้ ไม่ใช้ศัพท์ลัดที่เฉพาะคนเก่าเข้าใจ
- ทุกขั้นที่มีโอกาสพังของ/บาดเจ็บ ต้องมีคำเตือน
