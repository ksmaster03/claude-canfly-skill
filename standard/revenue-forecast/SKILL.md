# revenue-forecast

## ใช้ตอนไหน
ต้องคาดการณ์ยอดขายข้างหน้า

## ขั้นตอน
1. เลือกวิธี (bottom-up จาก pipeline / top-down จากตลาด)
2. อิงข้อมูลในอดีต + ปัจจัยฤดูกาล
3. แตกตาม channel/product
4. ระบุช่วง (เป้า/ต่ำ/สูง) + สมมติฐาน

## เทมเพลต / โครงผลลัพธ์
```
วิธีพยากรณ์ / ฐานข้อมูลอดีต / แยก channel / ตัวเลข base-low-high / สมมติฐาน
```

## เคล็ดลับ
- bottom-up น่าเชื่อกว่าเดาเปอร์เซ็นต์โตลอยๆ
- ระบุสมมติฐานให้คนตรวจสอบได้
