# viral-content-formula

## ใช้ตอนไหน
อยากทำคอนเทนต์ให้คนแชร์เยอะ

## ขั้นตอน
1. เลือก trigger อารมณ์ (ทึ่ง/ขำ/โกรธ/อิน)
2. Hook แรงใน 3 วินาที
3. ทำให้ 'แชร์แล้วดูดี' (social currency)
4. จบด้วยเหตุผลให้แชร์/แท็กเพื่อน

## เทมเพลต / โครงผลลัพธ์
```
Emotion trigger / Hook / เนื้อหา relatable / เหตุผลให้แชร์
```

## เคล็ดลับ
- คนแชร์สิ่งที่ทำให้ 'ตัวเขา' ดูดี
- relatable ชนะ 'สวยงาม' เสมอบนโซเชียล
