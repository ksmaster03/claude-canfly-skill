# ถอดปริมาณวัสดุ + BOQ (Material Take-off)

## ใช้ตอนไหน
เมื่อต้องประเมินว่างานหนึ่งใช้วัสดุอะไรเท่าไหร่ เพื่อสั่งซื้อหรือทำราคา

## ถามผู้ใช้ก่อน
1. ประเภทงาน (เทพื้น / ก่อผนัง / ฉาบ / มุงหลังคา ฯลฯ)
2. ขนาดพื้นที่หรือมิติ (กว้าง x ยาว x สูง / ตร.ม. / ลบ.ม.)
3. สเปกวัสดุ (เช่น คอนกรีตกำลังอัด, ความหนา, ชนิดอิฐ)

## ขั้นตอน
1. คำนวณปริมาณงานหลัก (พื้นที่/ปริมาตร)
2. แปลงเป็นวัสดุตามอัตราส่วนมาตรฐาน (เช่น ก่ออิฐมอญ ~130 ก้อน/ตร.ม., ปูนก่อ 1:3)
3. บวก waste factor 3-7% ตามชนิดงาน
4. จัดเป็นตาราง BOQ: รายการ / หน่วย / ปริมาณ / หมายเหตุ
5. **แจ้งสมมติฐานที่ใช้** ให้ผู้ใช้ตรวจสอบเสมอ

## เทมเพลตผลลัพธ์
```
BOQ งาน: [..]   พื้นที่/ปริมาตร: [..]
| รายการวัสดุ | หน่วย | ปริมาณ (รวม waste) | สมมติฐาน |
สมมติฐานที่ใช้: 1) ... 2) ...
⚠️ ตัวเลขนี้เป็นค่าประมาณ ต้องให้วิศวกรผู้ออกแบบยืนยันก่อนสั่งซื้อจริง
```

## เคล็ดลับ
- อย่าให้ตัวเลขลอยๆ — ระบุสูตร/อัตราส่วนที่ใช้เสมอ เพื่อให้คนตรวจสอบย้อนได้
- งานโครงสร้างสำคัญ ให้เตือนผู้ใช้ยืนยันกับแบบ/วิศวกรจริง
