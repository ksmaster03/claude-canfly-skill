# sales-funnel-builder

## ใช้ตอนไหน
ต้องวางกรวยการขายทั้งระบบ

## ขั้นตอน
1. วาง stage: ดึงดูด → ให้คุณค่า → ข้อเสนอ → ปิด → ต่อยอด
2. กำหนด lead magnet ดึงคนเข้ากรวย
3. ออกแบบข้อเสนอแต่ละชั้น (front/core/upsell)
4. ตั้งตัวชี้วัด conversion แต่ละ stage

## เทมเพลต / โครงผลลัพธ์
```
TOFU(lead magnet) / MOFU(nurture) / BOFU(offer) / ปิด / upsell
Conversion เป้าแต่ละชั้น
```

## เคล็ดลับ
- อุดรอยรั่ว stage ที่คนหลุดเยอะสุดก่อน
- แต่ละ stage มีหนึ่ง next action ชัดเจน
