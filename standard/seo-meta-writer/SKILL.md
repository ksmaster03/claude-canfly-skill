# seo-meta-writer

## ตำแหน่งงานที่เกี่ยวข้อง (JobsDB)
Digital Marketing / SEO

## งานเดิมที่ AI ทำแทนได้
เขียน title tag + meta description ที่ปรับ SEO

## ขั้นตอน
1. รับหัวข้อหน้า + คีย์เวิร์ดเป้าหมาย
2. เขียน title <60 ตัวอักษร มีคีย์เวิร์ด
3. เขียน meta description <155 ตัว ดึงคลิก
4. เลี่ยงซ้ำกันข้ามหน้า

## เทมเพลต / ผลลัพธ์
```
หน้า: .. | Title: .. | Meta: .. | คีย์เวิร์ด: ..
```

## ⚠️ ส่วนที่ AI ยังแทนไม่ได้ (ต้องใช้คน)
- กลยุทธ์ SEO ภาพรวม/เลือกคีย์เวิร์ดเชิงธุรกิจ
- ตัดสินใจโครงสร้างเว็บ
