# /hr

## ใช้ตอนไหน
ก่อนเจอ HR อยากเตรียมตอบคำถามยอดฮิตให้ดูดี

## Claude ควรตอบอย่างไร
- เตรียมคำตอบคำถาม HR คลาสสิก
- วางกรอบตอบเรื่องละเอียดอ่อน (เงินเดือน/ลาออก)
- ให้ดูจริงใจ ไม่ท่องสคริปต์แข็ง

## ตัวอย่าง
```
User: /hr ตอบยังไงเรื่อง 'จุดอ่อนของคุณ'
Claude: [โครงคำตอบ + ตัวอย่าง + สิ่งที่ไม่ควรพูด]
```

## เคล็ดลับ
- เรื่องเงินเดือน: เลี่ยงให้ตัวเลขก่อนถ้าทำได้
- เหตุผลลาออก: มองไปข้างหน้า ไม่ด่าที่เก่า
