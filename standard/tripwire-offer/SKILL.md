# tripwire-offer

## ใช้ตอนไหน
อยากให้คนยอมจ่ายครั้งแรกด้วยข้อเสนอเล็กๆ

## ขั้นตอน
1. เลือกของมูลค่าสูงแต่ราคาต่ำ (เช่น 99-299)
2. ทำให้ปฏิเสธยาก (irresistible)
3. ตั้งเป็นบันไดสู่สินค้าหลัก
4. ใส่ upsell ทันทีหลังซื้อ

## เทมเพลต / โครงผลลัพธ์
```
Tripwire: [ของ] ราคา.. / ทำไมคุ้ม / ต่อยอดไปสินค้าหลัก / OTO upsell
```

## เคล็ดลับ
- เป้าไม่ใช่กำไรจาก tripwire แต่คือเปลี่ยนเป็น 'ลูกค้า'
- ราคาต่ำพอให้ตัดสินใจไว
