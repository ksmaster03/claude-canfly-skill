# cohort-program

## ใช้ตอนไหน
อยากทำคอร์สแบบเรียนพร้อมกันเป็นรุ่น

## ขั้นตอน
1. วางปฏิทินรายสัปดาห์ (live + งาน)
2. ออกแบบกิจกรรมกลุ่ม/peer learning
3. กำหนดจังหวะ live + office hours
4. วางระบบ accountability + จบรุ่น

## เทมเพลต / โครงผลลัพธ์
```
ระยะเวลา / ตารางสัปดาห์ / live sessions / งานกลุ่ม / community / demo day
```

## เคล็ดลับ
- พลังของ cohort คือ community + ความรับผิดชอบร่วม
- จังหวะ live สม่ำเสมอกัน drop-off
