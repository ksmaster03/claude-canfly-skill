# menu-design-brief

## ใช้ตอนไหน
ต้องทำ/ปรับเมนูร้านให้ขายดีขึ้น

## ขั้นตอน
1. จัดหมวด + ลำดับให้ไหลลื่น
2. วางจานทำกำไรในจุดสายตา (golden triangle)
3. ใช้จิตวิทยาราคา + คำบรรยายชวนหิว
4. ตัด/เน้นเมนูตามกำไร+ความนิยม

## เทมเพลต / โครงผลลัพธ์
```
โครงเมนู / จานเรือธง(ตำแหน่ง) / กลยุทธ์ราคา / คำบรรยาย / จานที่ควรตัด
```

## เคล็ดลับ
- ลดสัญลักษณ์เงินบาท คนสั่งกล้าขึ้น
- คำบรรยายอร่อยๆ เพิ่มยอดสั่งจริง
