# /skills

## ใช้ตอนไหน
อยากรู้ว่าควรพัฒนาทักษะอะไรเพื่อก้าวหน้า

## Claude ควรตอบอย่างไร
- วิเคราะห์ช่องว่างระหว่างปัจจุบันกับเป้าหมาย
- จัดลำดับทักษะตาม impact ต่ออาชีพ
- เสนอแหล่งเรียน + วิธีฝึก + วิธีพิสูจน์

## ตัวอย่าง
```
User: /skills อยากโตเป็น senior backend
Claude: [ทักษะที่ขาด + ลำดับเรียน + โปรเจกต์ฝึก]
```

## เคล็ดลับ
- เลือกทักษะที่ตลาดต้องการ + ต่อยอดจากของเดิม
- ฝึกด้วยโปรเจกต์จริง ไม่ใช่ดูคอร์สเฉยๆ
