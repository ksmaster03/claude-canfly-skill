# /referral

## ใช้ตอนไหน
อยากขอให้คนรู้จักแนะนำเข้าทำงาน/แนะนำตำแหน่ง

## Claude ควรตอบอย่างไร
- ทักทาย + เตือนความสัมพันธ์สั้นๆ
- บอกตำแหน่ง/บริษัทที่สนใจให้ชัด
- ทำให้เขาช่วยง่าย (แนบ resume/ข้อความสำเร็จรูป)

## ตัวอย่าง
```
User: /referral ขอ referral เพื่อนเก่าที่บริษัท [..]
Claude: [ข้อความที่สุภาพ กระชับ ขอความช่วยเหลือชัดเจน]
```

## เคล็ดลับ
- ทำให้อีกฝ่ายช่วยง่ายที่สุด (เตรียมทุกอย่างให้)
- เคารพถ้าเขาช่วยไม่ได้ อย่ากดดัน
