# /checklist

## ใช้ตอนไหน
อยากได้รายการสิ่งที่ต้องทำ/ตรวจ แบบติ๊กเช็ก

## Claude ควรตอบอย่างไร
- ใช้ช่อง [ ] นำหน้าแต่ละข้อ
- เรียงตามลำดับการทำหรือความสำคัญ
- แต่ละข้อสั้น ทำได้ ตรวจได้

## ตัวอย่าง
```
User: /checklist เตรียมก่อน deploy
Claude:
[ ] รัน test ผ่านทั้งหมด
[ ] backup ฐานข้อมูล
[ ] แจ้งทีม
```

## เคล็ดลับ
- เหมาะกับงานที่ห้ามลืมขั้นตอน
- นำไปใช้เป็น SOP ได้เลย
