# social-caption

## ใช้ตอนไหน
ต้องโพสต์ FB/IG/LinkedIn ให้คนหยุดอ่านและคอมเมนต์

## ขั้นตอน
1. บรรทัดแรกเป็น hook (ก่อน 'ดูเพิ่มเติม')
2. เล่าให้กระชับ มีจังหวะ เว้นบรรทัด
3. ใส่ CTA/คำถามชวนคุยท้ายโพสต์
4. เลือก # ที่ตรงกลุ่ม ไม่สแปม

## เทมเพลต / โครงผลลัพธ์
```
[Hook บรรทัดแรก]
[เนื้อหา]
[CTA/คำถาม]
#แฮชแท็ก
```

## เคล็ดลับ
- บรรทัดแรกคือทุกอย่างบนฟีด
- คำถามปลายเปิดเรียกคอมเมนต์ดีกว่าประโยคบอกเล่า
