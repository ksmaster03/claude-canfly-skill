# blog-post

## ใช้ตอนไหน
ต้องเขียนบทความให้เว็บ/บล็อกที่ทั้งคนและ Google ชอบ

## ขั้นตอน
1. ตั้งพาดหัวที่มีคีย์เวิร์ด + ดึงคลิก
2. เปิดด้วย hook ตอกปัญหาผู้อ่าน
3. วางโครง H2/H3 ตามที่ผู้อ่านอยากรู้
4. ปิดด้วยสรุป + CTA

## เทมเพลต / โครงผลลัพธ์
```
พาดหัว / meta description / [hook] / ## หัวข้อย่อย.. / สรุป + CTA
```

## เคล็ดลับ
- เขียนเพื่อคนก่อน แล้วค่อยปรับ SEO
- ย่อหน้าสั้น เว้นวรรคเยอะ อ่านบนมือถือง่าย
