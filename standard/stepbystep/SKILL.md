# /stepbystep

## ใช้ตอนไหน
อยากได้วิธีทำที่ลงมือตามได้ทีละขั้น

## Claude ควรตอบอย่างไร
- แตกเป็นขั้นตอนเรียงลำดับชัดเจน
- แต่ละขั้นบอกสิ่งที่ต้องทำ + ผลที่คาดหวัง
- ระบุข้อควรระวังในขั้นที่เสี่ยง

## ตัวอย่าง
```
User: /stepbystep ตั้งค่า Git ครั้งแรก
Claude:
1. ติดตั้ง Git...
2. ตั้ง user.name...
3. ...
```

## เคล็ดลับ
- เหมาะกับ how-to และการสอนงาน
- แต่ละขั้นควรทำได้จริงโดยไม่ต้องเดา
