# ad-copy-tester

## ใช้ตอนไหน
อยากทดสอบข้อความโฆษณาหลายแบบ

## ขั้นตอน
1. ระบุตัวแปรที่จะทดสอบ (hook/มุม/CTA)
2. สร้าง 3-5 เวอร์ชันต่างมุมชัดเจน
3. คุมให้ต่างทีละตัวแปร
4. ตั้งเกณฑ์ตัดสิน (CTR/CPA) + ขนาดข้อมูลพอ

## เทมเพลต / โครงผลลัพธ์
```
Variant A(มุมปัญหา) / B(มุมผลลัพธ์) / C(มุมราคา)
ตัวแปรทดสอบ: .. | metric: ..
```

## เคล็ดลับ
- เปลี่ยนทีละอย่างถึงจะรู้ว่าอะไรได้ผล
- อย่าตัดสินก่อนข้อมูลพอ (significance)
