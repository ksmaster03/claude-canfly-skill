# competitor-analysis

## ใช้ตอนไหน
อยากรู้ว่าคู่แข่งทำอะไร เราต่างยังไง

## ขั้นตอน
1. เลือกคู่แข่ง 3-5 ราย (ตรง+ทางอ้อม)
2. เทียบมิติ: สินค้า/ราคา/จุดขาย/การตลาด/รีวิว
3. หาจุดแข็ง-อ่อนแต่ละราย
4. ชี้ช่องว่างที่เราเข้าไปชนะได้

## เทมเพลต / โครงผลลัพธ์
```
| คู่แข่ง | สินค้า | ราคา | จุดขาย | จุดอ่อน |
ช่องว่าง+โอกาสของเรา
```

## เคล็ดลับ
- อ่านรีวิว 1-2 ดาวของคู่แข่ง = เจอช่องว่างทอง
- อย่าแค่ลอก — หา 'ที่เขายังไม่ทำ'
