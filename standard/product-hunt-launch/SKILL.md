# product-hunt-launch

## ใช้ตอนไหน
อยากเปิดตัวบน Product Hunt

## ขั้นตอน
1. เตรียม assets: tagline, gallery, first comment
2. วางแผนวัน/เวลา (เริ่ม 00:01 PST)
3. ระดม hunter/supporters ล่วงหน้า
4. ตอบคอมเมนต์ทั้งวัน + ปั้น engagement

## เทมเพลต / โครงผลลัพธ์
```
Tagline / Gallery / Maker comment / รายชื่อ supporters / ตารางตอบคอมเมนต์
```

## เคล็ดลับ
- อย่าขอ upvote ตรงๆ ผิดกฎ — ให้ขอ 'support/feedback'
- วันอังคาร-พฤหัสมักแข่งสูง เลือกวันให้ดี
