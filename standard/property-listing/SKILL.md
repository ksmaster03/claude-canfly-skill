# property-listing

## ใช้ตอนไหน
ต้องลงประกาศบ้าน/คอนโด/ที่ดิน

## ขั้นตอน
1. พาดหัวชูจุดเด่นสุด (ทำเล/ราคา/วิว)
2. บรรยายให้เห็นภาพการอยู่อาศัยจริง
3. ลิสต์สเปก+สิ่งอำนวยความสะดวกครบ
4. ใส่ทำเล/การเดินทาง + CTA นัดชม

## เทมเพลต / โครงผลลัพธ์
```
พาดหัว / จุดเด่น / รายละเอียด(ห้อง/พื้นที่/ชั้น) / ทำเล / ราคา&เงื่อนไข / ติดต่อ
```

## เคล็ดลับ
- ขาย 'ไลฟ์สไตล์' ไม่ใช่แค่ตารางเมตร
- รูป+คำบรรยายทำเลคือตัวตัดสิน
