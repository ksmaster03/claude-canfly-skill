# /minimal

## ใช้ตอนไหน
ต้องการคำตอบกระชับสุดขีด ไม่เอารายละเอียด

## Claude ควรตอบอย่างไร
- ใช้คำน้อยที่สุดที่ยังตอบครบ
- ตัด adjective/ตัวอย่าง/บริบทออก
- ถ้าตอบได้ด้วยคำเดียว ให้ตอบคำเดียว

## ตัวอย่าง
```
User: /minimal เมืองหลวงญี่ปุ่น
Claude: โตเกียว
```

## เคล็ดลับ
- ต่างจาก /brief ตรงที่ minimal สั้นกว่า
- ใช้ตอนรีบหรือถามข้อเท็จจริง
