# beta-launch-plan

## ใช้ตอนไหน
อยากปล่อยรุ่นทดลองให้กลุ่มเล็กก่อน

## ขั้นตอน
1. กำหนดเป้าหมาย beta (เทสอะไร)
2. คัดกลุ่ม beta users + วิธีเชิญ
3. ตั้งช่องเก็บ feedback + metric
4. วางเกณฑ์ตัดสินว่าพร้อม GA ไหม

## เทมเพลต / โครงผลลัพธ์
```
เป้าหมาย beta / กลุ่มผู้ใช้ / onboarding / ช่อง feedback / เกณฑ์จบ beta
```

## เคล็ดลับ
- beta เพื่อ 'เรียนรู้' ไม่ใช่แค่หาบั๊ก
- คุยกับ beta user ตัวต่อตัว ได้ insight ลึก
