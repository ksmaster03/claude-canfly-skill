# twitter-thread

## ใช้ตอนไหน
อยากเล่าเรื่อง/ให้ความรู้เป็นเธรดที่ไวรัล

## ขั้นตอน
1. ทวีตแรก (hook) ต้องหยุดนิ้วคนเลื่อน
2. หนึ่งทวีต หนึ่งไอเดีย เรียงเป็นจังหวะ
3. ใส่ตัวอย่าง/ตัวเลขให้จับต้องได้
4. ปิดด้วยสรุป + ชวนติดตาม/รีโพสต์

## เทมเพลต / โครงผลลัพธ์
```
1/ [hook]
2/ ..
.../ สรุป + CTA
```

## เคล็ดลับ
- ทวีตแรกสำคัญ 80% ทุ่มเวลาตรงนี้
- ลงท้ายแต่ละทวีตให้อยากอ่านทวีตถัดไป
