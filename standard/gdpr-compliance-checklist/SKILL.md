# gdpr-compliance-checklist

## ใช้ตอนไหน
ต้องเช็กว่าระบบทำตามกฎคุ้มครองข้อมูลไหม

## ขั้นตอน
1. ระบุข้อมูลส่วนบุคคลที่เก็บ + ฐานทางกฎหมาย
2. ตรวจ consent + นโยบายความเป็นส่วนตัว
3. สิทธิเจ้าของข้อมูล (เข้าถึง/ลบ/ย้าย)
4. มาตรการความปลอดภัย + แผนรับมือข้อมูลรั่ว

## เทมเพลต / โครงผลลัพธ์
```
[ ] ทำ data inventory / [ ] consent / [ ] privacy policy / [ ] สิทธิ DSR / [ ] security / [ ] breach plan
```

## เคล็ดลับ
- ⚠️ เป็นแนวทางเบื้องต้น ตรวจกับที่ปรึกษากฎหมายจริง
- ไทยใช้ PDPA — หลักคล้าย GDPR แต่รายละเอียดต่าง
