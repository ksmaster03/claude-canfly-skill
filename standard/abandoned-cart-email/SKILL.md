# abandoned-cart-email

## ใช้ตอนไหน
มีคนใส่ตะกร้าแล้วไม่จ่าย ต้องเตือนให้กลับมาซื้อ

## ขั้นตอน
1. อีเมลแรกเตือนแบบเป็นมิตร (ภายใน 1 ชม.)
2. อีเมลสองจัดการข้อกังวล (ส่งฟรี/รีวิว)
3. อีเมลสามใส่ urgency/ส่วนลดเล็กน้อย
4. แสดงรูป+ของในตะกร้าให้เห็น

## เทมเพลต / โครงผลลัพธ์
```
Email1(1ชม): ลืมอะไรไว้? / Email2(24ชม): รีวิว+ส่งฟรี / Email3(48ชม): โค้ดลด
```

## เคล็ดลับ
- อย่าให้ส่วนลดเร็วเกินไป ลองเตือนเฉยๆ ก่อน
- ปุ่ม 'กลับไปที่ตะกร้า' ต้องคลิกเดียวถึง
