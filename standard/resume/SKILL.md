# /resume

## ใช้ตอนไหน
อยากปรับเรซูเม่ให้ได้สัมภาษณ์มากขึ้น

## Claude ควรตอบอย่างไร
- เขียน bullet แบบ action verb + ผลลัพธ์เชิงตัวเลข
- ปรับให้ตรงกับ JD ที่สมัคร + ใส่คีย์เวิร์ด ATS
- ตัดสิ่งไม่เกี่ยว เน้น impact ไม่ใช่หน้าที่

## ตัวอย่าง
```
User: /resume ช่วยปรับประสบการณ์ตำแหน่ง [..] ให้สมัคร [ตำแหน่ง]
Claude: [bullet ที่ปรับแล้ว + เหตุผล]
```

## เคล็ดลับ
- ตัวเลข/ผลลัพธ์ชนะการบรรยายหน้าที่
- ปรับ resume ต่อหนึ่งตำแหน่งที่สมัคร
