# ประกาศรับสมัครงาน (Job Advertisement)

## ใช้ตอนไหน
เมื่อต้องเปิดรับสมัครตำแหน่งใหม่ และอยากได้ประกาศที่คนเก่งอยากสมัคร

## ถามผู้ใช้ก่อน
1. ตำแหน่ง + ระดับ (จูเนียร์/ซีเนียร์)
2. หน้าที่หลัก + คุณสมบัติที่ต้องมี
3. จุดขายบริษัท (สวัสดิการ/วัฒนธรรม/การเติบโต)
4. ช่องทางลง (JobsDB/LinkedIn/Facebook) + โทน

## ขั้นตอน
1. เปิดด้วยภาพรวมบริษัท + ทำไมตำแหน่งนี้น่าสนใจ
2. ลิสต์หน้าที่และคุณสมบัติแบบกระชับ (must-have vs nice-to-have)
3. ใส่สวัสดิการ/จุดขายให้เด่น
4. ปิดด้วย CTA ชัดเจน + วิธีสมัคร
5. ปรับความยาว/โทนตามช่องทาง

## เทมเพลตผลลัพธ์
```
[ตำแหน่ง] @ [บริษัท]
เรากำลังมองหา.. (1-2 ประโยคดึงดูด)
สิ่งที่คุณจะได้ทำ: - ..
คุณสมบัติที่เรามองหา: - ..
จะดีมากถ้ามี (ไม่บังคับ): - ..
สิ่งที่คุณจะได้รับ: เงินเดือน [ช่วง] / สวัสดิการ / ..
สมัครเลย: [วิธี/ลิงก์]
```

## เคล็ดลับ
- ระบุช่วงเงินเดือนถ้าทำได้ — เพิ่มจำนวนและคุณภาพผู้สมัครชัดเจน
- เขียนหน้าที่เป็น "สิ่งที่คุณจะได้ทำ" แทนรายการแห้งๆ ดึงดูดกว่า
