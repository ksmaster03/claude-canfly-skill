# industry-deep-dive

## ใช้ตอนไหน
อยากเข้าใจอุตสาหกรรมหนึ่งแบบลึกก่อนเข้า/ลงทุน

## ขั้นตอน
1. สรุปขนาดตลาด + อัตราโต + โครงสร้าง
2. ระบุผู้เล่นหลัก + ส่วนแบ่ง
3. วิเคราะห์เทรนด์ + แรงขับเคลื่อน + ความเสี่ยง
4. ชี้โอกาส/ช่องว่างเข้าตลาด

## เทมเพลต / โครงผลลัพธ์
```
ขนาดตลาด&โต / ผู้เล่นหลัก / เทรนด์ / ปัจจัยขับเคลื่อน / ความเสี่ยง / โอกาส
```

## เคล็ดลับ
- อ้างอิงแหล่งข้อมูลจริง ระบุปีของตัวเลข
- ความเสี่ยง+อุปสรรคเข้าตลาด สำคัญพอๆ กับโอกาส
