# ชุดคำถามสัมภาษณ์ (Interview Questions)

## ใช้ตอนไหน
ก่อนสัมภาษณ์ผู้สมัคร เพื่อให้ถามอย่างมีโครงสร้าง ประเมินได้เป็นธรรม เทียบผู้สมัครได้

## ถามผู้ใช้ก่อน
1. ตำแหน่ง + ระดับ
2. competency/ทักษะที่อยากวัด (เทคนิค + soft skill)
3. รูปแบบ (behavioral / technical / case)

## ขั้นตอน
1. แตกคำถามตาม competency ที่ต้องวัด ใช้แนว behavioral (STAR)
2. แต่ละข้อใส่ "สิ่งที่ฟังหา" (good answer vs red flag)
3. เพิ่มเกณฑ์ให้คะแนน 1-5 ต่อด้าน
4. ปิดด้วยคำถามให้ผู้สมัครถามกลับ

## เทมเพลตผลลัพธ์
```
ตำแหน่ง: ..  ด้านที่ประเมิน: ..
[ด้าน A]
Q: เล่าตอนที่คุณ.. (STAR)
   ✅ คำตอบดี: .. | 🚩 สัญญาณระวัง: ..
[ด้าน B] ..
เกณฑ์คะแนน (1-5): | ด้าน | คะแนน | บันทึก |
คำถามทิ้งท้าย: คุณอยากถามอะไรเราไหม?
```

## เคล็ดลับ
- ใช้คำถามเชิงพฤติกรรม ("เล่าตอนที่..") ทำนายผลงานจริงได้ดีกว่าคำถามสมมติ
- ถามชุดเดียวกันกับผู้สมัครทุกคน เพื่อเปรียบเทียบอย่างเป็นธรรม
