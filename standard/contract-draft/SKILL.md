# ร่างสัญญา (Contract Draft)

## ใช้ตอนไหน
เมื่อต้องร่างสัญญาฉบับใหม่ หรือทำโครงสัญญาเพื่อให้ทนายตรวจต่อ

## ถามผู้ใช้ก่อน
1. ประเภทสัญญา (จ้างทำของ / บริการ / ซื้อขาย / เช่า / ร่วมทุน)
2. คู่สัญญาทั้งสองฝ่าย (ชื่อ/สถานะ)
3. สาระสำคัญ: ขอบเขตงาน, ราคา/ค่าตอบแทน, ระยะเวลา, การชำระเงิน
4. เงื่อนไขพิเศษ (ค่าปรับ, การบอกเลิก, ความลับ)

## ขั้นตอน
1. วางโครงมาตรฐาน: คู่สัญญา → คำนิยาม → ขอบเขต → ค่าตอบแทน → ระยะเวลา → สิทธิหน้าที่ → การบอกเลิก → ความรับผิด → กฎหมายที่ใช้บังคับ → ระงับข้อพิพาท
2. เติมเนื้อหาตามที่ผู้ใช้ให้ ระบุช่องที่ยังต้องเติม [.....]
3. แทรกข้อควรระวัง/จุดที่ควรให้ทนายตรวจเป็นคอมเมนต์

## เทมเพลตผลลัพธ์
```
สัญญา[ประเภท]
ทำที่ .. วันที่ ..  ระหว่าง [ฝ่าย ก] และ [ฝ่าย ข]
ข้อ 1 คำนิยาม / ข้อ 2 ขอบเขต / ข้อ 3 ค่าตอบแทนและการชำระ
ข้อ 4 ระยะเวลา / ข้อ 5 สิทธิและหน้าที่ / ข้อ 6 การรักษาความลับ
ข้อ 7 การบอกเลิกและค่าปรับ / ข้อ 8 ความรับผิด / ข้อ 9 เหตุสุดวิสัย
ข้อ 10 กฎหมายที่ใช้บังคับและการระงับข้อพิพาท
ลงชื่อ ทั้งสองฝ่าย + พยาน
[หมายเหตุจุดที่ต้องให้ทนายตรวจ: ...]
```

## เคล็ดลับ
- ⚠️ ร่างนี้เป็นโครงเบื้องต้น **ต้องให้ทนายความตรวจก่อนลงนามจริงเสมอ** ไม่ใช่คำแนะนำทางกฎหมาย
- นิยามศัพท์ให้ชัดตั้งแต่ต้น ลดข้อพิพาทตีความภายหลัง
