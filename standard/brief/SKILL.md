# /brief

## ใช้ตอนไหน
อยากได้คำตอบที่ครบแต่ไม่ยืดยาว

## Claude ควรตอบอย่างไร
- จำกัดความยาว ~3-5 บรรทัด
- เก็บแต่ประเด็นหลัก ตัดส่วนขยาย
- ใช้ bullet ได้ถ้าช่วยให้กระชับ

## ตัวอย่าง
```
User: /brief สรุปข้อดีของการ work from home
Claude: - ประหยัดเวลาเดินทาง
- ยืดหยุ่นเวลา
- โฟกัสงานลึกได้ดีขึ้น
```

## เคล็ดลับ
- ค่าเริ่มต้นที่ดีสำหรับคำถามทั่วไป
- ถ้ายังยาวไป ใช้ /minimal
