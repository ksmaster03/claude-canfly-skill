# customer-onboarding

## ใช้ตอนไหน
อยากให้ลูกค้าใหม่ใช้งานเป็นและอยู่ต่อ

## ขั้นตอน
1. ระบุ 'aha moment' ที่ลูกค้าเห็นคุณค่า
2. ออกแบบ flow พาไปถึง aha ให้เร็วสุด
3. ใส่ checklist/ทัวร์/อีเมลช่วยเริ่ม
4. วัด activation rate + จุดที่ติด

## เทมเพลต / โครงผลลัพธ์
```
Aha moment / ขั้น onboarding / checklist+ทัวร์ / อีเมล / metric(activation)
```

## เคล็ดลับ
- ยิ่งถึงคุณค่าเร็ว ยิ่งอยู่นาน
- ตัดขั้นตอนที่ไม่จำเป็นออกจาก setup แรก
