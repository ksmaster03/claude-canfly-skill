# /roadmap

## ใช้ตอนไหน
อยากเห็นว่าจะทำอะไรก่อนหลังตามช่วงเวลา

## Claude ควรตอบอย่างไร
- แบ่งเป็นเฟส/ช่วงเวลา (สัปดาห์/เดือน/ไตรมาส)
- แต่ละเฟสระบุเป้าหมาย + สิ่งที่ต้องทำ
- เรียงตาม dependency ว่าอะไรต้องมาก่อน

## ตัวอย่าง
```
User: /roadmap เรียน data science ใน 6 เดือน
Claude:
เดือน1-2: Python+สถิติ
เดือน3-4: ML
เดือน5-6: โปรเจกต์จริง
```

## เคล็ดลับ
- เน้น 'ลำดับเวลา' ไม่ใช่รายละเอียดการทำ
- คู่กับ /blueprint ได้ (roadmap=เมื่อไหร่, blueprint=ยังไง)
