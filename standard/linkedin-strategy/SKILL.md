# linkedin-strategy

## ใช้ตอนไหน
อยากใช้ LinkedIn สร้าง authority/หาโอกาส

## ขั้นตอน
1. ปรับโปรไฟล์ให้สื่อ value (headline/about)
2. กำหนดธีมโพสต์ + จังหวะลง
3. เขียนโพสต์ที่ hook + เล่า + insight
4. engage กลุ่มเป้าหมายสม่ำเสมอ

## เทมเพลต / โครงผลลัพธ์
```
โปรไฟล์(headline/about) / เสาคอนเทนต์ / ฟอร์แมตโพสต์ / แผน engage / network
```

## เคล็ดลับ
- บรรทัดแรกโพสต์ (ก่อน see more) ชี้ขาด
- ให้ value มากกว่าอวดตัว
