# upsell-flow

## ใช้ตอนไหน
ลูกค้าซื้อแล้ว อยากเพิ่มมูลค่าต่อออเดอร์

## ขั้นตอน
1. ระบุของที่เสริมกับสิ่งที่เพิ่งซื้อ
2. เสนอ upsell ทันทีหลังจ่าย (one-click)
3. ใช้ตรรกะ 'เพิ่มอีกนิดได้มากกว่าเดิม'
4. มี downsell เผื่อปฏิเสธ upsell

## เทมเพลต / โครงผลลัพธ์
```
ซื้อหลัก → OTO1(upsell) → ถ้าปฏิเสธ → downsell → ขอบคุณ+cross-sell
```

## เคล็ดลับ
- upsell ต้องเกี่ยวกับของที่เพิ่งซื้อ
- อย่าเสนอเยอะชั้นจนน่ารำคาญ
