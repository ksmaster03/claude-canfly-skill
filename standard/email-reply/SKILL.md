# ร่างอีเมลตอบกลับ (Professional Email Reply)

## ใช้ตอนไหน
เมื่อต้องตอบอีเมลลูกค้า/คู่ค้า/เจ้านาย ให้สุภาพ ชัดเจน และได้ผลลัพธ์ที่ต้องการ

## ถามผู้ใช้ก่อน
1. วางอีเมลต้นทาง (ที่ต้องตอบ)
2. ใจความที่อยากสื่อ (ตอบรับ / ปฏิเสธ / ขอข้อมูล / ขอโทษ)
3. ความสัมพันธ์กับผู้รับ + โทน (ทางการ/เป็นกันเอง) + ภาษา

## ขั้นตอน
1. จับประเด็นจากอีเมลต้นทางว่าเขาถาม/ขออะไร
2. ร่างตอบครบทุกประเด็น เรียงจากสำคัญสุด
3. ปรับโทนตามผู้รับ ขึ้นต้น-ลงท้ายให้เหมาะ
4. ถ้าเป็นข่าวไม่ดี: ใช้โครง "ขอบคุณ → เหตุผล → ทางออก"

## เทมเพลตผลลัพธ์
```
เรียน [คุณ..],
[ขอบคุณ/อ้างถึงอีเมลก่อน]
[ตอบประเด็นหลัก เป็นข้อๆ ถ้าหลายเรื่อง]
[ขั้นต่อไป / สิ่งที่ต้องการจากผู้รับ + กำหนดเวลา]
ขอแสดงความนับถือ,
[ชื่อ / ตำแหน่ง / ติดต่อ]
```

## เคล็ดลับ
- หนึ่งอีเมล หนึ่งจุดประสงค์หลัก ชัดกว่ารวมหลายเรื่องปนกัน
- ข่าวร้าย/ปฏิเสธ ให้เสนอทางเลือกเสมอ อย่าปฏิเสธลอยๆ
