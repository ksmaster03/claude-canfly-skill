# email-sequence

## ใช้ตอนไหน
ต้องวางชุดอีเมลต้อนรับ/ดูแลลีดแบบหลายฉบับ

## ขั้นตอน
1. กำหนดเป้าหมายปลายทางของซีเควนซ์
2. วางจำนวนอีเมล + ระยะห่าง + ใจความแต่ละฉบับ
3. อีเมลแรกสร้างความสัมพันธ์ ไม่ขายทันที
4. ค่อยๆ เพิ่มข้อเสนอ + ใส่ CTA ทุกฉบับ

## เทมเพลต / โครงผลลัพธ์
```
Email 1 (วันที่0): welcome.. / Email 2 (วัน2): value.. / Email 3: ข้อเสนอ..
```

## เคล็ดลับ
- ให้คุณค่าก่อนขอขาย ~3:1
- หนึ่งอีเมล หนึ่งเป้าหมาย หนึ่ง CTA
