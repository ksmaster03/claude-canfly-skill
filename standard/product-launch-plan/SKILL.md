# product-launch-plan

## ใช้ตอนไหน
ต้องเปิดตัวของใหม่ให้เป็นระบบ

## ขั้นตอน
1. กำหนดเป้าหมาย launch + กลุ่มเป้าหมาย
2. แบ่งเฟส pre/launch/post
3. วางช่องทาง + ข้อความแต่ละช่อง
4. ตั้ง KPI + แผนเก็บ feedback

## เทมเพลต / โครงผลลัพธ์
```
เป้าหมาย / Pre-launch(teaser) / Launch day / Post(retarget) / ช่องทาง / KPI
```

## เคล็ดลับ
- สร้างกระแสก่อนวันเปิดจริง อย่าเปิดเงียบๆ
- เตรียม asset ทุกช่องก่อนวัน launch
