# ticket-triage-summary

## ตำแหน่งงานที่เกี่ยวข้อง (JobsDB)
Support Agent / Helpdesk

## งานเดิมที่ AI ทำแทนได้
สรุปและจัดประเภท/จัดลำดับความสำคัญของ ticket

## ขั้นตอน
1. สรุปปัญหาของ ticket เป็น 1-2 บรรทัด
2. จัดหมวด (เทคนิค/บิล/ทั่วไป) + priority
3. แนะนำทีม/คนที่ควรรับเรื่อง
4. ดึงข้อมูลที่ยังขาดเพื่อถามลูกค้า

## เทมเพลต / ผลลัพธ์
```
Ticket #.. สรุป: .. | หมวด: .. | priority: .. | มอบหมาย: .. | ข้อมูลที่ขาด: ..
```

## ⚠️ ส่วนที่ AI ยังแทนไม่ได้ (ต้องใช้คน)
- ตัดสินใจเคสที่ priority ก้ำกึ่ง/การเมืองภายใน
- ปิดเคสที่ต้องดุลยพินิจ
