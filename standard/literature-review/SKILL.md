# สังเคราะห์ทบทวนวรรณกรรม (Literature Review)

## ใช้ตอนไหน
เมื่อมีเปเปอร์หลายชิ้นและต้องเขียนส่วน literature review / related work ที่เชื่อมโยงกัน

## ถามผู้ใช้ก่อน
1. หัวข้อวิจัย / คำถามวิจัย
2. รายการเปเปอร์ + สรุปย่อแต่ละชิ้น (หรือใช้ skill นักวิจัย_สรุปเปเปอร์ ก่อน)
3. รูปแบบที่ต้องการ (ตามธีม / ตามเวลา / ตามวิธีการ)

## ขั้นตอน
1. จัดกลุ่มเปเปอร์ตามธีม/แนวคิด ไม่ใช่เล่าทีละชิ้น
2. ในแต่ละธีม: สังเคราะห์ว่างานเห็นพ้อง/ขัดแย้งกันตรงไหน
3. ชี้ "ช่องว่างงานวิจัย" ที่นำไปสู่คำถามวิจัยของเรา
4. ทำตารางเปรียบเทียบ (เปเปอร์ × มิติ) ประกอบ

## เทมเพลตผลลัพธ์
```
ธีม 1: [..]
  - งานที่เห็นพ้อง: A, B พบว่า..
  - งานที่ขัดแย้ง: C โต้แย้งว่า..
ธีม 2: ..
ตารางเปรียบเทียบ: | เปเปอร์ | วิธีการ | dataset | ผล | ข้อจำกัด |
ช่องว่างที่พบ → คำถามวิจัยของเรา: ..
```

## เคล็ดลับ
- สังเคราะห์ ≠ สรุปทีละชิ้น — ต้องเห็น "บทสนทนา" ระหว่างงานวิจัย
- ทุกข้อความต้องอ้างอิงได้ ห้ามแต่งผลงานวิจัยที่ไม่มีจริง
