# course-outline

## ใช้ตอนไหน
ต้องวางหลักสูตร/คอร์สออนไลน์

## ขั้นตอน
1. กำหนดผลลัพธ์ปลายทาง (จบแล้วทำอะไรได้)
2. แตกเป็นโมดูล/บทเรียงตามลำดับการเรียนรู้
3. แต่ละบทมี: เป้าหมาย/เนื้อหา/แบบฝึก
4. ใส่ milestone + โปรเจกต์จบ

## เทมเพลต / โครงผลลัพธ์
```
ผลลัพธ์คอร์ส / Module1..n(บทเรียน) / แบบฝึกแต่ละบท / โปรเจกต์จบ
```

## เคล็ดลับ
- ออกแบบจาก 'ผลลัพธ์' ย้อนกลับมาเนื้อหา
- ให้ลงมือทำทุกบท ไม่ใช่ดูอย่างเดียว
