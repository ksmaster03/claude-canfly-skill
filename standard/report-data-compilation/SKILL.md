# report-data-compilation

## ตำแหน่งงานที่เกี่ยวข้อง (JobsDB)
ธุรการ / Coordinator

## งานเดิมที่ AI ทำแทนได้
รวบรวมข้อมูลกระจัดกระจายเป็นตารางสรุปพร้อมใช้

## ขั้นตอน
1. รับข้อมูลดิบจากหลายแหล่ง
2. จัดให้อยู่ในโครงตารางเดียวกัน
3. คำนวณยอดรวม/เฉลี่ย/สัดส่วน
4. ชี้รายการผิดปกติ/ข้อมูลขาด

## เทมเพลต / ผลลัพธ์
```
| รายการ | ค่า | สัดส่วน | หมายเหตุ |
สรุป: .. | ข้อมูลที่ยังขาด: ..
```

## ⚠️ ส่วนที่ AI ยังแทนไม่ได้ (ต้องใช้คน)
- ตรวจความถูกต้องของข้อมูลต้นทาง
