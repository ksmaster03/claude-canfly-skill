# invoice-generator

## ใช้ตอนไหน
ต้องวางบิลลูกค้าให้ดูเป็นมืออาชีพ

## ขั้นตอน
1. ใส่ข้อมูลผู้ขาย-ผู้ซื้อ + เลขผู้เสียภาษี
2. ลงรายการ + จำนวน + ราคา + รวม
3. คำนวณ VAT 7% + หัก ณ ที่จ่าย (ถ้ามี)
4. ระบุเงื่อนไข/วันครบกำหนด/ช่องทางจ่าย

## เทมเพลต / โครงผลลัพธ์
```
ใบแจ้งหนี้ เลขที่.. วันที่.. / ผู้ขาย-ผู้ซื้อ+เลขภาษี / รายการ | รวม / VAT / สุทธิ / ครบกำหนด
```

## เคล็ดลับ
- ใส่เลขใบกำกับเรียงลำดับ ตามรอบบัญชีได้
- ระบุวันครบกำหนดชัด ช่วยให้เก็บเงินตรงเวลา
