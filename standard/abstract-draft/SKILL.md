# ร่างบทคัดย่อ (Abstract Draft)

## ใช้ตอนไหน
เมื่อทำวิจัยเสร็จและต้องเขียน abstract สำหรับวารสาร/conference ตามจำนวนคำจำกัด

## ถามผู้ใช้ก่อน
1. หัวข้อ + ปัญหาที่ศึกษา
2. วิธีการ / ข้อมูลที่ใช้
3. ผลลัพธ์หลัก (ตัวเลขถ้ามี)
4. จำนวนคำที่จำกัด + ภาษา (ไทย/อังกฤษ/ทั้งสอง)

## ขั้นตอน
1. เขียนตามโครง: Background → Objective → Method → Results → Conclusion
2. คุมจำนวนคำตามที่กำหนด ตัดคำฟุ่มเฟือย
3. ใส่ผลลัพธ์เชิงตัวเลขให้ชัด ไม่พูดลอย
4. ลงท้ายด้วย keywords 3-5 คำ

## เทมเพลตผลลัพธ์
```
[Background 1-2 ประโยค]
[Objective 1 ประโยค]
[Methods 1-2 ประโยค]
[Results พร้อมตัวเลข 2-3 ประโยค]
[Conclusion 1 ประโยค]
Keywords: .., .., ..
(จำนวนคำ: XX / จำกัด YY)
```

## เคล็ดลับ
- ผลลัพธ์คือหัวใจ — ให้พื้นที่มากที่สุด
- ใช้เฉพาะข้อมูลที่อยู่ในงานจริง ห้ามเพิ่มผลที่ไม่ได้ทำ
