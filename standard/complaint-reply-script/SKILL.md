# complaint-reply-script

## ตำแหน่งงานที่เกี่ยวข้อง (JobsDB)
Customer Service / CX

## งานเดิมที่ AI ทำแทนได้
สคริปต์ตอบเรื่องร้องเรียนที่ลดอุณหภูมิและแก้ปัญหา

## ขั้นตอน
1. จับใจความปัญหา + อารมณ์ลูกค้า
2. ใช้โครง: รับรู้ → ขอโทษ → ทางแก้ → ติดตาม
3. เสนอทางออกที่ทำได้จริง
4. ปรับโทนให้จริงใจ ไม่กลไก

## เทมเพลต / ผลลัพธ์
```
[รับรู้ปัญหา] / [ขอโทษจริงใจ] / [สิ่งที่จะทำแก้ไข + เมื่อไหร่] / [ช่องทางติดตาม]
```

## ⚠️ ส่วนที่ AI ยังแทนไม่ได้ (ต้องใช้คน)
- ความเห็นอกเห็นใจจริงในเคสรุนแรง
- อำนาจตัดสินใจชดเชย/ยกระดับเคส
