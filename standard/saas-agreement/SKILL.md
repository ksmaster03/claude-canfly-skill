# saas-agreement

## ใช้ตอนไหน
มีซอฟต์แวร์/บริการออนไลน์ ต้องมีข้อตกลงใช้งาน

## ขั้นตอน
1. กำหนดขอบเขตบริการ + สิทธิการใช้
2. ระบุ SLA (uptime, support) + ข้อจำกัดความรับผิด
3. เงื่อนไขค่าบริการ/ต่ออายุ/ยกเลิก
4. ข้อมูลส่วนบุคคล + การยุติบริการ

## เทมเพลต / โครงผลลัพธ์
```
บริการ&สิทธิใช้ / SLA / ค่าบริการ&ต่ออายุ / ความรับผิด / ข้อมูล / ยกเลิก / กฎหมาย
```

## เคล็ดลับ
- ⚠️ ให้ทนายตรวจ โดยเฉพาะ liability cap และ data
- SLA ที่สัญญาไว้ต้องทำได้จริง
