# youtube-strategy

## ใช้ตอนไหน
อยากโตช่อง YouTube อย่างเป็นระบบ

## ขั้นตอน
1. กำหนด niche + กลุ่มผู้ชม + พิลลาร์คอนเทนต์
2. ออกแบบ title/thumbnail ที่ CTR สูง
3. วาง hook 30 วินาทีแรกกัน drop-off
4. แผนความถี่ + เชื่อมคลิปต่อเนื่อง

## เทมเพลต / โครงผลลัพธ์
```
Niche / พิลลาร์ / สูตร title+thumbnail / hook 30วิ / ปฏิทินลง / playlist
```

## เคล็ดลับ
- thumbnail + title คือ 90% ของยอดคลิก
- คลิปแรก 30 วินาทีตัดสิน watch time
