# สรุปเปเปอร์วิชาการ (Paper Summary)

## ใช้ตอนไหน
เมื่ออ่านเปเปอร์จำนวนมาก และต้องการบันทึกย่อที่กลับมาอ่านแล้วเข้าใจทันที

## ถามผู้ใช้ก่อน
1. วางเนื้อหาเปเปอร์ / abstract / ลิงก์
2. สาขา และระดับความลึกที่ต้องการ

## ขั้นตอน
1. ดึง: ปัญหาที่แก้ / contribution หลัก / วิธีการ / ผลลัพธ์ / ข้อจำกัด
2. สรุปด้วยภาษาตัวเอง ไม่ลอกประโยค abstract
3. เพิ่ม "เชื่อมกับงานเราอย่างไร" + คำถามที่ยังเปิดอยู่

## เทมเพลตผลลัพธ์
```
อ้างอิง: ผู้แต่ง (ปี) ชื่อเรื่อง, วารสาร
ปัญหา/ช่องว่าง: ..
Contribution หลัก: ..
วิธีการ (dataset/model/วิธีทดลอง): ..
ผลลัพธ์เด่น: ..
ข้อจำกัด: ..
เกี่ยวกับงานเรา / ไอเดียต่อยอด: ..
```

## เคล็ดลับ
- ใส่หมายเลขหน้า/รูปที่อ้างถึง เพื่อกลับไปดูต้นฉบับได้เร็ว
- แยก "ที่เปเปอร์อ้าง" กับ "ที่เราคิดเอง" ให้ชัด อย่าปนกัน
