# สร้างควิซ/แบบทดสอบ (Quiz Generator)

## ใช้ตอนไหน
เมื่อต้องออกข้อสอบ ควิซท้ายบท หรือแบบฝึกหัด จากเนื้อหาที่สอน

## ถามผู้ใช้ก่อน
1. วางเนื้อหา/หัวข้อที่จะออกข้อสอบ
2. จำนวนข้อ + รูปแบบ (ปรนัย/ถูกผิด/เติมคำ/อัตนัย)
3. ระดับความยาก + กลุ่มผู้เรียน

## ขั้นตอน
1. กระจายข้อสอบตามระดับ Bloom (จำ → เข้าใจ → ประยุกต์ → วิเคราะห์)
2. ออกข้อ + ตัวเลือกลวงที่สมเหตุผล (ไม่ใช่ตัวเลือกตลกๆ)
3. ให้เฉลย + คำอธิบายว่าทำไมข้อนั้นถูก
4. แท็กระดับความยาก/จุดประสงค์การเรียนรู้แต่ละข้อ

## เทมเพลตผลลัพธ์
```
ชุดข้อสอบ: [หัวข้อ]  จำนวน [N] ข้อ
ข้อ 1 (ระดับ: เข้าใจ) ..
   ก. ..  ข. ..  ค. ..  ง. ..
...
เฉลย:
1. ตอบ ข — เพราะ ..
สรุปการกระจายระดับ: จำ X / เข้าใจ Y / ประยุกต์ Z
```

## เคล็ดลับ
- ตัวเลือกลวงควรเป็นความเข้าใจผิดที่พบจริง จะวัดได้ว่าผู้เรียนพลาดตรงไหน
- อย่าออกแต่ข้อ "จำ" — ใส่ข้อวิเคราะห์/ประยุกต์ด้วยถึงจะวัดความเข้าใจจริง
