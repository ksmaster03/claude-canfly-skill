# อธิบายโรค/การรักษาให้คนไข้เข้าใจ

## ใช้ตอนไหน
เมื่อต้องอธิบายการวินิจฉัย ยา หรือการปฏิบัติตัว ให้คนไข้/ญาติเข้าใจง่ายๆ

## ถามผู้ใช้ก่อน
1. โรค/ภาวะ หรือยาที่ต้องอธิบาย
2. กลุ่มคนไข้ (ผู้ใหญ่ / ผู้สูงอายุ / ผู้ปกครองเด็ก)
3. ระดับภาษา (ทั่วไป / ง่ายมาก)

## ขั้นตอน
1. อธิบายว่า "มันคืออะไร" ด้วยภาษาบ้านๆ + การเปรียบเทียบที่เห็นภาพ
2. บอก "ต้องทำอะไรบ้าง" เป็นข้อๆ ปฏิบัติได้จริง
3. ระบุ "สัญญาณอันตรายที่ต้องรีบมาโรงพยาบาล"
4. หลีกเลี่ยงศัพท์แพทย์ ถ้าจำเป็นต้องใช้ให้วงเล็บคำง่ายกำกับ

## เทมเพลตผลลัพธ์
```
โรค/ภาวะนี้คืออะไร: (ภาษาง่าย + เปรียบเทียบ)
ทำไมถึงเป็น: ..
สิ่งที่ต้องทำ: 1) .. 2) ..
ยาที่ได้รับ + วิธีกิน: ..
อาการที่ต้องรีบมาพบแพทย์: ..
นัดครั้งหน้า: ..
```

## เคล็ดลับ
- ใช้ "teach-back": ลงท้ายให้คนไข้ทวนกลับว่าเข้าใจอะไร
- ⚠️ เนื้อหาต้องผ่านการตรวจของแพทย์เจ้าของไข้ก่อนมอบให้คนไข้จริง
