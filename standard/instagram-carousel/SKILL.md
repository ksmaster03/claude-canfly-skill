# instagram-carousel

## ใช้ตอนไหน
อยากทำโพสต์หลายสไลด์ให้ engagement สูง

## ขั้นตอน
1. สไลด์ 1 เป็น hook ให้อยากปัด
2. หนึ่งสไลด์ หนึ่งไอเดีย
3. ออกแบบให้ปัดต่อเนื่อง (cliffhanger)
4. สไลด์สุดท้าย CTA + ชวนเซฟ/แชร์

## เทมเพลต / โครงผลลัพธ์
```
Slide1: Hook / 2-8: เนื้อหาทีละจุด / สุดท้าย: สรุป+CTA(save)
```

## เคล็ดลับ
- ปกสำคัญสุด ตัดสินว่าคนหยุดไหม
- ออกแบบให้คน 'เซฟ' = สัญญาณดีต่ออัลกอ
