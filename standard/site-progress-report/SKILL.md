# รายงานความคืบหน้าหน้างาน (Site Progress Report)

## ใช้ตอนไหน
เมื่อต้องส่งรายงานความคืบหน้างานก่อสร้างประจำวัน/สัปดาห์ ให้เจ้าของงานหรือผู้จัดการโครงการ

## ถามผู้ใช้ก่อน
1. ชื่อโครงการ / วันที่ / ช่วงรายงาน
2. งานที่ทำเสร็จในช่วงนี้ (บันทึกสั้นๆ ก็ได้)
3. % ความคืบหน้ารวม / เทียบแผน (ช้า-เร็วกว่าแผนไหม)
4. ปัญหา-อุปสรรค / สภาพอากาศ / จำนวนคนงาน
5. แผนงานช่วงถัดไป

## ขั้นตอน
1. จัดข้อมูลดิบให้เป็นหมวด: สรุปผู้บริหาร → งานที่ทำ → ปัญหา → แผนถัดไป
2. แปลงภาษาพูดเป็นภาษาทางการกระชับ ใส่ตัวเลข/เปอร์เซ็นต์ให้ชัด
3. ระบุ action item พร้อมผู้รับผิดชอบและกำหนดเวลา

## เทมเพลตผลลัพธ์
```
รายงานความคืบหน้าโครงการ: [ชื่อ]   วันที่: [..]   ช่วง: [..]
1) สรุปภาพรวม: คืบหน้า X% (ตามแผน/ช้ากว่าแผน Y วัน)
2) งานที่แล้วเสร็จช่วงนี้: - ...
3) ปัญหา/อุปสรรค + แนวทางแก้: - ...
4) ความปลอดภัย: เหตุการณ์ [ไม่มี/มี..]
5) แผนงานช่วงถัดไป: - ...
6) สิ่งที่ต้องการการตัดสินใจ/สนับสนุน: - ...
```

## เคล็ดลับ
- ขึ้นต้นด้วย "สรุปผู้บริหาร" 2-3 บรรทัด ผู้บริหารอ่านแค่ตรงนี้ก็เข้าใจ
- ปัญหาทุกข้อต้องมี "แนวทางแก้" ตามเสมอ ไม่ใช่แจ้งปัญหาลอยๆ
