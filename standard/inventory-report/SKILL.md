# รายงานสต็อกสินค้า (Inventory Report)

## ใช้ตอนไหน
เมื่อต้องสรุปสถานะสต็อกประจำงวด เพื่อวางแผนสั่งซื้อ/ระบายของ

## ถามผู้ใช้ก่อน
1. วางข้อมูลสต็อก (SKU / ชื่อ / คงเหลือ / จุดสั่งซื้อ / ยอดขายเฉลี่ย)
2. งวดที่ต้องการ + เกณฑ์ (เช่น safety stock, lead time)

## ขั้นตอน
1. แบ่งสถานะ: ปกติ / ใกล้หมด (ต่ำกว่าจุดสั่งซื้อ) / ค้างนาน (dead stock) / เกิน
2. คำนวณ "ควรสั่งเพิ่มเท่าไหร่" จากยอดขายเฉลี่ย + lead time
3. ชี้ของค้างที่ควรเร่งระบาย (จัดโปร/คืน supplier)
4. จัด ABC analysis ถ้าข้อมูลพอ (ของกลุ่ม A คุมเข้ม)

## เทมเพลตผลลัพธ์
```
รายงานสต็อก งวด [..]
🔴 ต้องสั่งด่วน (ต่ำกว่าจุดสั่งซื้อ): | SKU | คงเหลือ | ควรสั่ง |
🟡 ค้างนาน/ขายช้า: | SKU | คงเหลือ | ค้าง..วัน | ข้อเสนอ |
🟢 ปกติ: .. รายการ
สรุป: มูลค่าสต็อกรวม .. | รายการต้องสั่ง .. | dead stock มูลค่า ..
```

## เคล็ดลับ
- เน้น exception (ของมีปัญหา) ไม่ต้องลิสต์ทุก SKU ที่ปกติ
- Dead stock = เงินจม เตือนให้จัดการก่อนหมดอายุ/ตกรุ่น
