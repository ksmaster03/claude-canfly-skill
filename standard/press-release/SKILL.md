# ข่าวประชาสัมพันธ์ (Press Release)

## ใช้ตอนไหน
เมื่อมีข่าวเปิดตัวสินค้า/กิจกรรม/ความร่วมมือ และต้องการส่งให้สื่อนำไปเผยแพร่

## ถามผู้ใช้ก่อน
1. ข่าวอะไร (ใคร ทำอะไร ที่ไหน เมื่อไหร่ ทำไม)
2. ประเด็นที่อยากให้คนจดจำ
3. quote จากผู้บริหาร (หรือให้ช่วยร่าง)
4. ข้อมูลบริษัท + ช่องทางติดต่อสื่อ

## ขั้นตอน
1. พาดหัวกระชับ น่าหยิบ + พาดหัวรอง
2. ย่อหน้าแรกตอบ 5W1H ครบ (สำคัญสุดอยู่บน = พีระมิดกลับหัว)
3. ขยายรายละเอียด + ใส่ quote ผู้บริหาร
4. ปิดด้วย boilerplate (เกี่ยวกับบริษัท) + ติดต่อสื่อ

## เทมเพลตผลลัพธ์
```
ข่าวประชาสัมพันธ์ — เผยแพร่ทันที
[พาดหัวข่าว]
[พาดหัวรอง]
[เมือง, วันที่] — [ย่อหน้านำ 5W1H]
[รายละเอียด 1-2 ย่อหน้า]
"[quote ผู้บริหาร]" กล่าวโดย [ชื่อ ตำแหน่ง]
เกี่ยวกับ [บริษัท]: ..
ติดต่อสื่อมวลชน: [ชื่อ/โทร/อีเมล]
```

## เคล็ดลับ
- พาดหัวต้องเป็น "ข่าว" ไม่ใช่ "โฆษณา" สื่อถึงจะหยิบ
- ข้อมูลสำคัญสุดอยู่ย่อหน้าแรก เผื่อสื่อตัดท้ายทิ้ง
