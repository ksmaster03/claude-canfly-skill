# BRIEF — <ชื่อเล่ม> (แหล่งความจริงเดียวสำหรับ writer agents)

## ตัวตนของหนังสือ
- **ชื่อ:** <title>
- **ชื่อรอง:** <subtitle>
- **กลุ่มเป้าหมาย:** <ใคร ระดับไหน อยากได้อะไร>
- **สัญญาของหนังสือ:** อ่านจบแล้วทำ <ผลลัพธ์> ได้จริง เป็นระบบ ทำซ้ำได้

## โทนและสไตล์การเขียน (บังคับ)
- ภาษาไทยล้วน คำเทคนิค/ชื่อเครื่องมือคงอังกฤษได้
- โทน: เพื่อนผู้เชี่ยวชาญ กระชับ มีพลัง ตัวอย่างจริง ไม่วิชาการจ๋า
- เชิงลึก + ลงมือได้จริง: ทุกบทมี "ทำยังไง" ชัด (checklist/สูตร/ตัวเลข/ตัวอย่าง/โค้ดเมื่อเกี่ยว)
- ~1,600–2,400 คำ/บท; ใส่กล่อง ❌พลาดบ่อย/✅ทำแบบนี้ + กล่อง "จำ 3 ข้อ" ท้ายบท
- โค้ด/คำสั่งใน code fence เสมอ; **ห้ามแต่งสถิติเกินจริง**

## รูปแบบไฟล์ (สำคัญต่อ build)
เขียนแต่ละบทเป็น `raw/chNN.md`:
- บรรทัดแรก = ชื่อบท (ใส่ `# ` ได้), ห้ามเขียน "บทที่ X", ห้ามใส่ภาพเอง (build แทรกให้)
- หัวข้อย่อย `## ` / `### `; เขียนจบในตัว แต่โยงถึงบทอื่นได้

## คลังข้อเท็จจริง (อ้างอิงได้เลย ไม่ต้อง search เพิ่ม)
<วางผลresearch + สูตร + โค้ด + ตัวเลขจริงทั้งหมดที่ writer จะต้องใช้ แยกเป็นหัวข้อ A, B, C...>
