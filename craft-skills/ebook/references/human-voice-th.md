# ปรับภาษาไทยให้ "เหมือนคนเขียน" ไม่ใช่ "เหมือน AI เขียน"

ใช้เป็นขั้นตอนหลังเขียนบทเสร็จและผ่าน QC โครงสร้างแล้ว (ขั้น 4.5 ของสกิล `/ebook`)
เป้าหมายคือ **เปลี่ยนน้ำเสียง ไม่ใช่เปลี่ยนข้อเท็จจริง**

---

## 1. ทำไมงานเขียนของโมเดลถึง "รู้สึกออก"

ไม่ใช่เพราะคำศัพท์ผิด แต่เพราะ **จังหวะสม่ำเสมอเกินไป** โมเดลเขียนย่อหน้ายาวเท่ากันหมด ประโยคยาวเท่ากันหมด ทุกหัวข้อมีสามข้อย่อย ทุกย่อหน้าขึ้นต้นด้วยประโยคใจความ ไม่มีการหยุด ไม่มีการแทรก ไม่มีการเปลี่ยนใจกลางทาง

คนเขียนจริงจะมีจังหวะไม่เท่ากัน บางประโยคยาวสามบรรทัด บางประโยคสองคำ

---

## 2. คลังตัวเชื่อมภาษาพูด (ใช้ได้จริงในงานเขียน)

**กลุ่มเปิดประเด็น / อธิบายซ้ำ**
`คือว่า` · `คืออย่างนี้` · `คือแบบนี้` · `พูดง่าย ๆ ก็คือ` · `จะเรียกว่า...ก็ได้` · `เอาแบบนี้`

**กลุ่มเน้นความจริง / แก้ความเข้าใจผิด**
`จริง ๆ แล้ว` · `เอาจริง ๆ` · `ความจริงคือ` · `ที่จริง` · `พูดตรง ๆ` · `ไม่ใช่ว่า...แต่...`

**กลุ่มเปลี่ยนฉาก / พาไปต่อ**
`ทีนี้` · `ทีนี้พอ...` · `ถัดมา` · `แล้วทีนี้` · `กลับมาที่...` · `ย้อนกลับไปนิดหนึ่ง`

**กลุ่มสรุป / เชื่อมเหตุผล** (สลับกัน อย่าใช้ตัวเดียวรัว)
`เพราะฉะนั้น` · `ดังนั้น` · `เลย...` · `ก็เลยกลายเป็นว่า` · `สรุปคือ` · `แปลว่า`

**กลุ่มชี้ / ขยายความ — ตัวแทนของขีดยาว (ดูข้อ 3.5)**
`ก็คือ` · `นั่นคือ` · `ซึ่ง` · `แบบนี้` · `แบบนั้น` · `เพราะว่า`
> คำกลุ่มนี้ใช้แทนตำแหน่งที่เคยใส่ ` — ` ได้เกือบทั้งหมด และอ่านเป็นภาษาพูดมากกว่า

**กลุ่มปิดคำถามให้เป็นภาษาพูด**
`...หรือเปล่า` · `...ไหม` · `...รึเปล่า`
> `หรือเปล่า` ทำให้คำถามฟังเหมือนคนถามจริง ต่างจาก `?` เฉย ๆ ที่ฟังเป็นแบบทดสอบ

**กลุ่มไม่เป็นทางการ (ใช้ประปราย)**
`แบบว่า` · `ประมาณว่า` · `อะไรทำนองนี้` · `ทำนองนั้น`

**กลุ่มเสียงลังเล — ใช้น้อยมาก**
`เอ่อ` · `เอิ่ม`
> ใช้ได้เฉพาะตอนแทรกความคิดกลางประโยคจริง ๆ เช่น *"ค่าคอมสูงสุด 60% ฟังดูดี — เอ่อ แต่เดี๋ยวก่อน มันมีเพดาน 225 บาท"*
> **โควตาที่แนะนำ: ทั้งบทไม่เกิน 1–2 ครั้ง** เกินกว่านั้นอ่านเหมือนถอดเทป ไม่ใช่เหมือนคนเขียน

## 3. เทคนิคจังหวะ (สำคัญกว่าคำเชื่อม)

1. **สลับความยาวประโยค** — หลังประโยคยาว ๆ สองสามบรรทัด ให้ตบด้วยประโยคสั้น
   > *"...ทั้งหมดนี้ใช้เวลาสองถึงสี่เดือน กว่าจะเห็นทราฟฟิกจริง **นานครับ**"*
2. **ใช้ประโยคไม่สมบูรณ์บ้าง** — `ไม่ใช่ทุกคน` / `แค่นั้นจริง ๆ` / `ยังไม่พอ`
3. **ถามผู้อ่าน** แล้วตอบเอง — `แล้วเท่าไหร่ถึงจะพอ? คำตอบคือ...`
4. **แทรกความคิดกลางประโยค** ด้วยขีดยาวหรือวงเล็บ — `— ตรงนี้แหละที่คนพลาดกันเยอะ —`
5. **ยอมรับว่าไม่รู้** — `ตรงนี้ไม่มีใครตอบได้ชัด` / `ผมยังหาตัวเลขที่ยืนยันได้ไม่เจอ`
6. **ขึ้นย่อหน้าด้วยตัวเชื่อม** บ้าง ไม่ต้องขึ้นด้วยประโยคใจความทุกครั้ง
7. **เล่าฉากสั้น ๆ** แทนการอธิบายลอย ๆ — `สมมติคุณเพิ่งเขียนบทความแรกเสร็จเมื่อคืน...`
8. **ทิ้งความเห็นบ้าง** — `ส่วนตัวผมว่าอันนี้ไม่คุ้ม` (ถ้าโทนของเล่มอนุญาต)

## 3.5 ขีดยาว ` — ` คือกับดัก — ใช้ได้ไม่เกิน 10–12 จุดต่อบท

**นี่คือบทเรียนที่จ่ายมาแล้วสองรอบ** ข้อ 3.4 ข้างบนบอกให้ "แทรกความคิดด้วยขีดยาว" ซึ่งถูก — แต่พอสั่ง agent ให้ทำ มันจะใส่จนล้น รอบจริงกับหนังสือ 16 บทได้ **31–76 จุดต่อบท** อ่านแล้วสะดุดทุกสองบรรทัด และกลายเป็นลายเซ็น AI ที่ชัดกว่าคำศัพท์ใด ๆ

คนไทยเขียนจริงไม่ใช้ขีดยาวถี่ขนาดนั้น เขาตัดประโยคเอา

**เพดานที่ใช้ได้ผล: ≤10 จุดต่อบทปกติ · ≤12 จุดต่อบทยาว (40 KB+)**
`check-voice.sh` บังคับเพดานนี้แล้ว บทที่เกินจะขึ้นสถานะ "ขีดยาวเยอะไป"

**วิธีแทน เรียงตามความนิยม:**

| เดิม | แก้เป็น |
|---|---|
| `A — B` (B ขยาย A) | ตัดเป็นสองประโยค **← ใช้บ่อยที่สุด ได้ผลดีที่สุด** |
| `A — เพราะ B` | `A เพราะว่า B` |
| `A — ก็เลย B` | `A ดังนั้น B` |
| `A — คือ B` | `A ก็คือ B` / `A นั่นคือ B` |
| `A — (ข้อมูลเสริม) — B` | `A (ข้อมูลเสริม) B` ใช้วงเล็บ |
| `A — B — C` ในประโยคเดียว | เลือกเก็บขีดเดียว ที่เหลือใช้จุลภาค |

**ตัวอย่างจริง**
> ❌ `SAST มองไม่เห็น runtime config — มันอ่านแค่ซอร์สโค้ด — เพราะฉะนั้นต้องมี DAST คู่ด้วย`
> ✅ `SAST มองไม่เห็น runtime config เพราะมันอ่านแค่ซอร์สโค้ด ดังนั้นต้องมี DAST คู่ด้วย`

**ขีดยาวในบล็อกโค้ด ตาราง และรายการแหล่งอ้างอิง ไม่ต้องนับและห้ามแก้**

## 3.6 รูปทรงย่อหน้า — อย่าให้ข้อความ "ตกเป็นเศษ"

ข้อ 3.1–3.2 บอกให้ใส่ประโยคห้วน ๆ ซึ่งถูก แต่ agent มักตีความเป็น "แยกประโยคสั้นออกมาเป็นย่อหน้าเดี่ยว" หลาย ๆ อันติดกัน ผลคือหน้ากระดาษเต็มไปด้วยเศษบรรทัดลอย อ่านเหมือนสไลด์ ไม่ใช่หนังสือ

**กฎที่ใช้ได้:**
- ย่อหน้าปกติยาว **2–6 บรรทัด**
- ประโยคห้วนที่ยืนเป็นย่อหน้าเดี่ยวได้ (`"มันก็เงียบ"` `"แค่นั้นเอง"`) — **ไม่เกิน 2 จุดต่อบท** ที่เหลือให้กลืนเข้าไปท้ายย่อหน้าก่อนหน้า
- ห้ามให้หัวข้อ `##` / `###` ตามด้วยย่อหน้า 1 บรรทัดแล้วขึ้นหัวข้อใหม่ทันที
- ห้ามมีย่อหน้าเดี่ยวสั้นสองอันติดกัน

**ฝั่ง layout ต้องช่วยด้วย** — ใส่ใน `@media print` ของ `build-book.mjs` เพื่อกันบรรทัดโดดตกหน้า:
```css
p,li{orphans:3;widows:3;}
h2,h3{page-break-after:avoid;}
```

## 4. ลายเซ็น AI ที่ต้องล่าออกให้หมด

| อาการ | แก้เป็น |
|---|---|
| ทุกหัวข้อมีข้อย่อยสามข้อพอดี | สลับเป็น 2, 4, 5 ข้อ หรือเขียนเป็นย่อหน้าไปเลย |
| `ไม่ว่าจะเป็น...หรือ...` | ยกตัวอย่างตรง ๆ |
| `สิ่งสำคัญคือ` / `สิ่งที่ต้องจำไว้คือ` | ตัดทิ้ง แล้วพูดสิ่งนั้นเลย |
| `โดยสรุปแล้ว` / `กล่าวโดยสรุป` | `สรุปคือ` หรือตัดทิ้ง |
| `ในโลกปัจจุบัน` / `ในยุคที่` | ตัดทิ้งทั้งประโยค |
| `อย่างไรก็ตาม` ทุกย่อหน้า | สลับ `แต่` `เอาจริง ๆ` `ทีนี้` |
| ย่อหน้ายาวเท่ากันหมดทั้งบท | ตัดบางย่อหน้าให้เหลือบรรทัดเดียว |
| `เป็นอย่างยิ่ง` / `เป็นอย่างมาก` ถี่ | ตัดออก คำกริยาแบกน้ำหนักเอง |
| ขึ้นต้นย่อหน้าด้วยคำเดิมซ้ำ ๆ | ไล่ดูคำแรกของทุกย่อหน้าในบท แล้วสลับ |
| ทุกประโยคสมบูรณ์ประธาน-กริยา-กรรม | ใส่ประโยคห้วน ๆ แทรก |

## 5. ห้ามแตะ

- **ตัวเลข ข้อเท็จจริง ชื่อแหล่งอ้างอิง** — ห้ามเปลี่ยนแม้แต่หลักเดียว
- **ตาราง** — ในเซลล์ตารางต้องกระชับ ห้ามใส่คำเชื่อมภาษาพูด
- **บล็อกโค้ด และ prompt template** — ห้ามแตะเด็ดขาด
- **`> **จำ 3 ข้อ**`** — คงรูปแบบเป๊ะ ๆ (ปรับถ้อยคำข้างในได้ ให้เป็นภาษาพูดขึ้นได้ แต่ห้ามเปลี่ยนโครง)
- **บรรทัดแรก `# ชื่อบท`** และหัวข้อ `##` / `###` ทั้งหมด
- **รายการแหล่งอ้างอิงท้ายเล่ม** — ห้ามแตะ URL
- **หัวข้อบังคับ** เช่น `### มุมคนเขียนโค้ด` ห้ามเปลี่ยนชื่อ

## 6. โควตาที่ใช้ได้ผล (ต่อบท ~20,000 ตัวอักษร)

| อย่าง | จำนวน |
|---|---|
| ตัวเชื่อมภาษาพูดรวมทุกกลุ่ม | 15–29 จุด (เกิน 30 = เลี่ยน) |
| `เอ่อ` / `เอิ่ม` | 0–2 จุด |
| ประโยคสั้นห้วน (ต่ำกว่า 8 คำ) | อย่างน้อย 8–12 ประโยค **แต่ยืนเป็นย่อหน้าเดี่ยวได้ไม่เกิน 2** |
| คำถามถึงผู้อ่าน (`?` / `ไหม` / `หรือเปล่า`) | 10–20 จุด |
| **ขีดยาว ` — `** | **≤10 จุด (บทยาว ≤12) — ดูข้อ 3.5** |
| การแทรกความคิดด้วยวงเล็บ | 4–8 จุด |
| ฉากสมมติสั้น ๆ | 1–3 จุด |

**อย่าโรยให้ทั่วเท่า ๆ กัน** — นั่นคือความสม่ำเสมอแบบเดิมในคราบใหม่ ให้กระจุกตรงช่วงอธิบายแนวคิด และเบามือตรงช่วงข้อมูลหนัก ๆ

## 6.5 สั่งเป็นยอดรวมอย่างเดียว "ไม่ได้ผล" — ต้องสั่งรายคำ

จากการรันจริงกับหนังสือ 16 บท: สั่งว่า "ใส่ตัวเชื่อม 15–25 จุด" แล้ววัดผล **มีแค่ 1 ใน 3 บทที่ถึงเป้า** ที่เหลือได้ 11–13 จุด เพราะ agent ตีความว่าให้ "แตะเบา ๆ พอมีกลิ่น" และบางตัวไปกองที่คำกลาง ๆ อย่าง `แปลว่า` ซึ่งแทบไม่ให้ความรู้สึกภาษาพูด

**สั่งแบบนี้แทน — ระบุขั้นต่ำรายคำ:**

```text
ต้องมีอย่างน้อย: จริง ๆ แล้ว ×4 · ดังนั้น ×4 · แบบนี้/แบบนั้น ×4 · หรือเปล่า ×3 ·
คือว่า ×3 · ทีนี้ ×3 · เอาจริง ๆ ×2 · พูดง่าย ๆ ก็คือ ×2 · พูดตรง ๆ ×1 ·
เอ่อ หรือ เอิ่ม ×1  (รวมทุกตัวต้องอยู่ 15–29 จุด ห้ามเกิน 30)
และ: ขีดยาว " — " ต้องเหลือไม่เกิน 10 จุดทั้งบท (บทยาว 40 KB+ ไม่เกิน 12)
(คำว่า "แปลว่า" ไม่นับเข้าโควตา เพราะเป็นคำกลาง ๆ)
```

> **`ดังนั้น` `แบบนี้` `หรือเปล่า` คือสามคำที่ให้ผลเร็วที่สุด** — เพราะมันคือคำที่คนไทยใช้จริงตอนอธิบายให้เพื่อนฟัง
> และ `ดังนั้น` ยังใช้แทนตำแหน่งขีดยาวได้ตรง ๆ ยิงปืนนัดเดียวได้นกสองตัว

**และให้ agent ตรวจตัวเองก่อนส่งงาน:**

```text
ก่อนตอบกลับ ให้รัน:
  bash ~/.claude/skills/ebook/scripts/check-voice.sh <proj>
ถ้าบทของคุณยังขึ้นว่า "ต่ำกว่าเกณฑ์" ให้แก้เพิ่มแล้ววัดซ้ำจนผ่าน แล้วค่อยตอบ
```

## 7. วิธีรันขั้นนี้

- **1 บทต่อ 1 subagent** (ไม่ใช่ 3 บท) เพราะเป็นงานอ่านทั้งไฟล์แล้วเขียนใหม่ทั้งไฟล์ — 3 บทมักชนกำแพง 600 วินาที
- สั่งให้ agent **อ่านไฟล์เดิม → เขียนทับด้วย Write** และ **ห้าม paste กลับ**
- สั่งย้ำว่า **ห้ามลดความยาว** ขนาดไฟล์หลังปรับต้องไม่ต่ำกว่าเดิมเกิน 5%
- หลังรันเสร็จ **ตรวจขนาดไฟล์ก่อน/หลัง** และรัน `qc-chapters.sh` ซ้ำ — เคสที่เจอบ่อยคือ agent เผลอตัดตารางหรือย่อบทให้สั้นลง

```bash
# เทียบขนาดก่อน/หลัง
for i in $(seq -w 1 16); do printf "ch%s %6d\n" "$i" $(stat -c%s raw/ch$i.md); done
```
