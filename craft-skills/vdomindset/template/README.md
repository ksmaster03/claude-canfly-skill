## กติกาของฟอร์แมต

- **ซ้าย–ขวา บนเส้นพื้นเดียวกัน** ไม่ใช่บน–ล่าง (คลิป 12 ล้าน กับ 11 ล้านของเพจอ้างอิงใช้แบบนี้ทั้งคู่
  ส่วนคลิปบน–ล่างที่เราถอดมาตอนแรกได้ 2.1 แสน) — ยกเว้นคลิป `Hill` ที่เป็นเส้นทาง จึงต้องซ้อนบน–ล่าง
- **ป้ายคำสั้น ๆ ใต้ตัวละคร** ไม่ใช่ประโยคกลางจอ · คำเป้าหมายลอยบนสุดคำเดียว
- **props เป็นสีเหล็กเทาทั้งสองฝั่ง** มีแต่ "คน" กับ "AI" ที่มีสี
- **ไม่มี CTA** ยกเว้นตัวปิดซีรีส์ (คลิปท็อปของเพจอ้างอิงไม่มี CTA เลยสักตัว)
- **ไม่มี fade เข้า–ออก** เพราะคลิปต้องวนลูป fade จะทิ้งรอยดำตรงรอยต่อ

## การวนลูป

คลิปต้องวนได้ ทุกการเคลื่อนไหวจึงต้องเป็น **ฟังก์ชันคาบของ `u` (0..1 ตลอดคลิป)**:

- `saw(u, n)` — เฟส 0..1 ซ้ำ n รอบ (n ต้องเป็นจำนวนเต็ม) ใช้ป้อนท่าทาง
- `wave(u, n)` — ไซน์ที่กลับมาที่เดิมพอดีตรงรอยต่อ

สิ่งที่ "ค่อย ๆ เพิ่มขึ้นแล้วต้องรีเซ็ต" (ระดับน้ำ ทรายในนาฬิกา ระยะทาง) **ห้ามทำเป็นการไต่ระดับ**
ให้ทำเป็น **สภาวะคงที่ที่ต่างกัน** สองฝั่งแทน — ถังซ้ายรั่วตลอด ถังขวาเต็มล้นตลอด
ส่วนโดมิโนใช้ **คลื่นที่วิ่ง** (มุมของแต่ละตัวเป็นฟังก์ชันของ `((p - i/n) mod 1)`) จึงวนได้จริง

## กับดัก (เจอมาแล้วทุกข้อ)

- **`<FigureDefs/>` / `<PropDefs/>` ต้องอยู่ใน `<svg>` ทุกตัวที่วาดตัวละครหรือ prop** —
  gradient เป็น paint server ที่ resolve ทั้งเอกสาร จึงรอดได้จนกว่า element ที่ถือมันจะ unmount
  แล้วทุกอย่างที่ทาด้วย `url(#…)` จะหายเงียบ ๆ เหลือแต่ชิ้นที่ใช้สีทึบ
- **ท่าที่ทุกชิ้นอยู่ในแนวเดียวกันจะกลายเป็นแท่งเดียว** — ท่าบินต้องกางขาเป็น V และงอเข่าข้างหนึ่ง
- **ท่าที่ rig side-view นี้ทำไม่ได้**: มือไพล่หลังหัว · กอดอก · เท้าพาดโต๊ะ
- **`delayRender` ของฟอนต์ต้องตั้ง timeout สูง (120000)** + `--concurrency=2`
- **ห้าม `Math.random()` ใน prop** — ใช้ jitter จาก index เช่น `((i*37) % 11) - 5`
- **บน Windows ต้องเรียก `npx.cmd`** ไม่ใช่ `npx` เวลาใช้ `execFileSync` ไม่งั้น ENOENT
- **ครอสเฟดตัวละครสองก๊อปปี้เพื่อซ่อนรอยต่อ = เห็นเป็นคนสองคน** สู้ปล่อยให้มีจังหวะว่างสั้น ๆ ดีกว่า
