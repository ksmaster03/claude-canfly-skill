# ชุด G · Craft Skills — สกิลจากงานจริง

23 สกิลที่ใช้ทำงานจริงทุกวันกับ **Claude Code** ต่างจากชุดอื่นในคลังนี้ตรงที่ชุดนี้ไม่ได้เขียนขึ้นจากเทมเพลต แต่ตกผลึกจากงานที่ทำเสร็จแล้วจริง ๆ — ทุกหัวข้อ "Gotchas" ในไฟล์คือสิ่งที่เคยพังมาก่อน

> สกิลกลุ่มนี้เขียนสำหรับ **Claude Code** โดยเฉพาะ (ใช้ Bash/Edit/Agent tools) ไม่ใช่ prompt template ที่ก๊อปไปวางในแชทได้เลย

---

## ติดตั้ง

```bash
git clone https://github.com/<your-github-user>/claude-canfly-skill.git
cp -r claude-canfly-skill/craft-skills/* ~/.claude/skills/
```

เรียกใช้ด้วย `/<ชื่อสกิล>` ใน Claude Code เช่น `/debug-mantra`, `/scrutinize`

ถ้าอยากลงเฉพาะบางตัว ก๊อปแค่โฟลเดอร์นั้นก็พอ — แต่ละสกิลเป็นอิสระต่อกัน (ยกเว้นที่ระบุไว้ในตาราง)

## รายการสกิล

### พัฒนาซอฟต์แวร์ · วิธีทำงาน

| สกิล | ทำอะไร |
| --- | --- |
| `debug-mantra` | วินัยดีบั๊ก 4 ข้อ — reproduce → ไล่เส้นทางที่พัง → **พยายามหักล้างสมมติฐานตัวเอง** → cross-check ทุกเบาะแส ห้ามเสนอ fix ก่อนครบ 4 ขั้น |
| `scrutinize` | รีวิวแบบคนนอก ตั้งคำถามกับ "เจตนา" ก่อนว่ามีทางที่ง่ายกว่านี้ไหม แล้วค่อยไล่โค้ดจริง (ไม่ใช่แค่ diff) ว่าทำตามที่อ้างจริงหรือเปล่า |
| `post-mortem` | เขียนบันทึกบั๊กฉบับทางการ — root cause, กลไกที่พัง, การแก้, การพิสูจน์, และ **ทำไมมันหลุดมาได้** |
| `management-talk` | แปลงเนื้อหาสาย engineer ให้ผู้บริหารอ่านรู้เรื่อง แยกรูปแบบตามช่องทาง (JIRA / Slack / standup / อีเมล / วาระประชุม) |
| `teamagent` | ทำงานเป็นทีม 3 โมเดล — Opus วางแผน+ตัดสิน, Sonnet ลุยงานหนัก, Haiku งานเร็ว/ค้นหา แล้วสังเคราะห์กลับ |
| `recall` | ค้นความจำเก่าด้วย Grep + Read แทนการอ่าน MEMORY.md ทั้งไฟล์ (ประหยัด context) |
| `handoff` | จบงาน — บันทึกความจำ + push ขึ้น GitHub พร้อม **security gate กันคีย์หลุด** ทำสองอย่างขนานกันด้วย subagent |

## ตัวแปรที่ต้องตั้งเอง

สกิลกลุ่มวิดีโอ/หนังสืออ้างถึงเครื่องมือภายนอกด้วยชื่อตัวแปร ให้แทนด้วย path ในเครื่องคุณเอง

| ตัวแปร | คืออะไร |
| --- | --- |
| `$VIDEO_USE` | toolchain `video-use` (ใช้โดย `vdocut`) |
| `$CHATGPT_BRIDGE` | ตัวเชื่อม image-gen + Playwright/Chromium (ใช้โดย `ebook`, `vdostory`, `reel-factory`) |
| `$MEDIA` | คลัง BGM/SFX ของคุณ |
| `$GOOGLE_FONTS` | เช็คเอาต์ของ `github.com/google/fonts` (เอาไฟล์ Sarabun) |
| `$NERAMIT` / `$FB_MCP` | toolkit เสริมของผู้เขียน — ไม่มีก็ทำมือตามขั้นตอนในไฟล์ได้ |
| `$WORK` | โฟลเดอร์โปรเจกต์ของคุณ |

**ของที่ไม่ได้รวมมาในนี้** — `video-use`, image-gen bridge, และคลังสื่อ เป็นเครื่องมือแยกต่างหาก สกิลจะบอกวิธีใช้ แต่ไม่ได้แถมตัวเครื่องมือมาให้

## ข้อควรรู้

* สกิลถูกล้าง path เฉพาะเครื่อง ชื่อลูกค้า และ hostname ของ production ออกหมดแล้ว ที่เหลือเป็น placeholder
* ตัวเลขและค่าที่วัดได้ (เช่น LUFS target ใน `reelcut`, ค่าเสียงใน `reel-factory`) มาจากการวัดจริง ไม่ใช่ค่าที่แต่งขึ้น
* `vdomindset` ใช้ตัวละครชื่อ "โกสินทร์" เป็นตัวเอกใน template — เปลี่ยนชื่อ/สี/โลโก้ได้ที่ `src/theme.ts` และ `public/brand/logo.png`
* สกิลที่แตะ production (`aws-deploy`, `handoff`, `ebook`) ออกแบบให้ **ขออนุมัติก่อนเสมอ** อย่าถอดด่านนั้นออก
