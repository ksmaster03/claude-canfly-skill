# data-cleaning-plan

## ตำแหน่งงานที่เกี่ยวข้อง (JobsDB)
Data Analyst / Data Engineer

## งานเดิมที่ AI ทำแทนได้
วางขั้นตอนทำความสะอาดข้อมูลก่อนวิเคราะห์

## ขั้นตอน
1. ตรวจคุณภาพข้อมูล (ขาด/ซ้ำ/ผิดรูปแบบ)
2. เสนอวิธีจัดการแต่ละปัญหา
3. มาตรฐานรูปแบบ (วันที่/หน่วย/ข้อความ)
4. สร้างสคริปต์/ขั้นตอนทำซ้ำได้

## เทมเพลต / ผลลัพธ์
```
ปัญหาที่พบ: .. | วิธีจัดการ: .. | คอลัมน์ที่กระทบ: .. | ขั้นตอน/โค้ด: ..
```

## ⚠️ ส่วนที่ AI ยังแทนไม่ได้ (ต้องใช้คน)
- ตัดสินใจว่าจะตัดหรือเก็บ outlier (รู้บริบท)
- ยืนยันสมมติฐานเรื่องข้อมูลกับเจ้าของระบบ
