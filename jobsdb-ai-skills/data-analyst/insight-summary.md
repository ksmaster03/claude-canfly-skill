# insight-summary

## ตำแหน่งงานที่เกี่ยวข้อง (JobsDB)
Data Analyst / BI

## งานเดิมที่ AI ทำแทนได้
สรุป insight จากผลข้อมูล/แดชบอร์ดเป็นภาษาคน

## ขั้นตอน
1. อ่านตัวเลข + หาแนวโน้ม/ความผิดปกติ
2. สรุปเป็นประเด็นที่ผู้บริหารสนใจ
3. เชื่อมกับผลกระทบธุรกิจ
4. เสนอคำถาม/การทดสอบต่อ

## เทมเพลต / ผลลัพธ์
```
Key findings: 1).. 2).. / สิ่งที่น่ากังวล: .. / ข้อเสนอแนะ: .. / ควรเจาะต่อ: ..
```

## ⚠️ ส่วนที่ AI ยังแทนไม่ได้ (ต้องใช้คน)
- ตัดสินใจเชิงกลยุทธ์จาก insight
- ตีความสาเหตุที่แท้จริง (correlation≠causation)
