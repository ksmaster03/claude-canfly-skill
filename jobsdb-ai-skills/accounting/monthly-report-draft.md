# monthly-report-draft

## ตำแหน่งงานที่เกี่ยวข้อง (JobsDB)
นักบัญชี / Accountant

## งานเดิมที่ AI ทำแทนได้
ร่างรายงานการเงินรายเดือนพร้อมคำอธิบายแนวโน้ม

## ขั้นตอน
1. รับตัวเลขงบรายเดือน (ปัจจุบัน+เดือนก่อน)
2. คำนวณ variance + เปอร์เซ็นต์เปลี่ยนแปลง
3. อธิบายสาเหตุที่เป็นไปได้ของรายการเด่น
4. สรุปประเด็นสำหรับผู้บริหาร

## เทมเพลต / ผลลัพธ์
```
สรุปผู้บริหาร / ตารางเทียบเดือน / variance ที่ต้องอธิบาย / ประเด็นต้องตัดสินใจ
```

## ⚠️ ส่วนที่ AI ยังแทนไม่ได้ (ต้องใช้คน)
- ตีความเชิงธุรกิจว่าทำไมตัวเลขเปลี่ยน (รู้บริบทจริง)
- ตัดสินใจเชิงกลยุทธ์จากรายงาน
