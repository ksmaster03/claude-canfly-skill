# crm-followup-writer

## ตำแหน่งงานที่เกี่ยวข้อง (JobsDB)
Sales / Account Executive

## งานเดิมที่ AI ทำแทนได้
เขียนอีเมล/ข้อความติดตามลูกค้าตาม stage ใน CRM

## ขั้นตอน
1. ดู stage ของดีล + บริบทคุยล่าสุด
2. เลือกจังหวะ/โทนติดตามให้เหมาะ
3. ทวนคุณค่า + เสนอ next step ชัด
4. เตรียมชุดติดตาม 3-4 ครั้งไม่ให้น่ารำคาญ

## เทมเพลต / ผลลัพธ์
```
Follow-up #.. (stage: ..) / ทวนสิ่งที่คุย / คุณค่า / next step + นัด
```

## ⚠️ ส่วนที่ AI ยังแทนไม่ได้ (ต้องใช้คน)
- จับจังหวะความรู้สึกลูกค้าว่าควรดันหรือถอย
- เจรจาเงื่อนไข/ราคา
