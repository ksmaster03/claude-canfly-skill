## โครงแต่ละไฟล์
ลักษณะเด่น · สื่อสารยังไงให้ได้ผล · สิ่งที่ควรเลี่ยง · แรงจูงใจ · การให้ฟีดแบ็ก · การโน้มน้าว/นำเสนอ · เมื่อเกิดความขัดแย้ง · ข้อควรระวัง

## ข้อควรระวัง (สำคัญ)
- ใช้เพื่อ "เข้าใจและร่วมงานกับคนได้ดีขึ้นอย่างเคารพ" ไม่ใช่เพื่อบงการหรือปั่นหัว
- type เป็นแนวโน้ม ไม่ใช่กล่องตายตัว — คนจริงมีหลายมิติ ควรยืนยันด้วยการสังเกต/พูดคุยจริง อย่าเดาเหมารวม
- ราศีไม่มีหลักฐานทางวิทยาศาสตร์ ใช้เป็นบทสนทนา/สร้างความสัมพันธ์เท่านั้น อย่าตัดสินคน
- เครื่องมืออย่าง MBTI/DISC ควรทำแบบประเมินอย่างเป็นทางการเพื่อความแม่นยำ

## แหล่งอ้างอิงเชิงแนวคิด
- MBTI: Myers-Briggs Type Indicator (The Myers & Briggs Foundation)
- Enneagram: The Enneagram Institute (9 types)
- DISC: William Moulton Marston, DISC behavioral model
- CliftonStrengths: Gallup (34 themes / 4 domains)
- ราศี: โหราศาสตร์ตะวันตก (ความเชื่อเชิงวัฒนธรรม)
