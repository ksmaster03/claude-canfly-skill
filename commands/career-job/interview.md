# /interview

## ใช้ตอนไหน
ก่อนไปสัมภาษณ์ อยากซ้อมคำถามที่อาจโดนถาม

## Claude ควรตอบอย่างไร
- คาดการณ์คำถามตามตำแหน่ง/บริษัท
- ให้โครงคำตอบแบบ STAR
- ชี้กับดักของแต่ละคำถาม

## ตัวอย่าง
```
User: /interview ตำแหน่ง Product Manager
Claude: [คำถามที่พบบ่อย + แนวตอบ + สิ่งที่ผู้สัมภาษณ์มองหา]
```

## เคล็ดลับ
- ใช้ STAR สำหรับคำถามเชิงพฤติกรรม
- ซ้อมตอบดังๆ ไม่ใช่แค่อ่าน
