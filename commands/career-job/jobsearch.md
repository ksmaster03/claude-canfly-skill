# /jobsearch

## ใช้ตอนไหน
อยากหางานให้ได้ผล ไม่เสียเวลาเปล่า

- วางช่องทาง: สมัครตรง + network + recruiter
- ตั้งระบบติดตามใบสมัคร + follow up

User: /jobsearch หางาน data analyst
