# /portfolio

## ใช้ตอนไหน
อยากทำ portfolio ที่โชว์ผลงานให้น่าสนใจ

## Claude ควรตอบอย่างไร
- เลือกผลงานเด่นที่ตรงกับงานที่อยากได้
- เล่าแต่ละชิ้นแบบ: โจทย์ → สิ่งที่ทำ → ผลลัพธ์
- จัดลำดับให้ชิ้นเด่นสุดอยู่ต้น

## ตัวอย่าง
```
User: /portfolio ผมเป็น UX designer มีงาน 5 ชิ้น
Claude: [โครง portfolio + วิธีเล่าแต่ละเคส]
```

## เคล็ดลับ
- คุณภาพชนะปริมาณ — 3 ชิ้นเด่นดีกว่า 10 ชิ้นกลางๆ
- โชว์ 'ผลลัพธ์' ไม่ใช่แค่ภาพสวย
