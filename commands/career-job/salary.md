# /salary

## ใช้ตอนไหน
ก่อนเจรจาค่าตอบแทน อยากเตรียมให้ได้ดีลที่ดี

## Claude ควรตอบอย่างไร
- หาช่วงตลาดของตำแหน่ง + พื้นที่
- สร้างเหตุผลด้วยผลงาน/มูลค่าที่สร้าง
- เตรียมตัวเลขเป้า + ขั้นต่ำ + ทางเลือกอื่น (BATNA)

## ตัวอย่าง
```
User: /salary จะขอขึ้นเงินเดือน 15%
Claude: [วิธีหาเบนช์มาร์ก + สคริปต์เจรจา + รับมือการต่อรอง]
```

## เคล็ดลับ
- อย่าให้ตัวเลขแรกถ้าเลี่ยงได้ ให้เขาเสนอก่อน
- ต่อรองที่ 'มูลค่าที่สร้าง' ไม่ใช่ 'ความต้องการส่วนตัว'
