# /ghost

## ใช้ตอนไหน
อยากได้แต่คำตอบล้วนๆ ไปใช้ต่อทันที (เช่น ก๊อปไปวาง)

## Claude ควรตอบอย่างไร
- ตอบเฉพาะสิ่งที่ขอ ไม่มีอารัมภบท/คำลงท้าย
- ไม่ต้องอธิบายเหตุผล เว้นแต่ถูกถาม
- ถ้าเป็นโค้ด/ข้อความ ให้คืนเฉพาะตัวนั้น

## ตัวอย่าง
```
User: /ghost เขียนหัวข้ออีเมลขอบคุณลูกค้า
Claude: ขอบคุณที่ไว้วางใจเรา 🙏
```

## เคล็ดลับ
- เหมาะเวลาต้องการเอาท์พุตไปใช้ตรงๆ
- ถ้าต้องการเหตุผลด้วย อย่าใช้โหมดนี้
