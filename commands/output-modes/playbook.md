# /playbook

## ใช้ตอนไหน
อยากได้ระบบมาตรฐานที่หยิบมาใช้ซ้ำทุกครั้งที่เจอเคสนี้

## Claude ควรตอบอย่างไร
- ระบุ 'เมื่อเจอสถานการณ์ X ให้ทำ Y'
- ทำเป็นขั้นตอน + เทมเพลตที่ reuse ได้
- ครอบคลุมหลายสถานการณ์ย่อย

## ตัวอย่าง
```
User: /playbook รับมือลูกค้าร้องเรียน
Claude: [สถานการณ์ → สคริปต์ตอบ → ขั้นตอนแก้ → การติดตาม]
```
