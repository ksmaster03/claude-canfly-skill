# /blueprint

## ใช้ตอนไหน
อยากได้พิมพ์เขียวที่เอาไปทำตามได้เลย

## Claude ควรตอบอย่างไร
- ระบุเป้าหมาย + องค์ประกอบที่ต้องมี
- ลงรายละเอียดพอให้เริ่มทำได้ทันที
- ระบุทรัพยากร/เครื่องมือ/ผู้รับผิดชอบ

## ตัวอย่าง
```
User: /blueprint สร้างคอร์สออนไลน์
Claude: [โครงสร้าง + แพลตฟอร์ม + เนื้อหาแต่ละโมดูล + ราคา + แผนการตลาด]
```

## เคล็ดลับ
- ละเอียดกว่า /roadmap ตรงที่บอก 'ทำยังไง' ไม่ใช่แค่ 'เมื่อไหร่'
- เหมาะกับการเริ่มโปรเจกต์ใหม่
