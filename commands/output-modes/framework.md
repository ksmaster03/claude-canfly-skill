# /framework

## ใช้ตอนไหน
อยากได้โครงคิดที่เป็นระบบ จำง่าย นำไปใช้ซ้ำได้

## Claude ควรตอบอย่างไร
- จัดเป็นองค์ประกอบ/เสา/ขั้นที่มีชื่อเรียก
- อธิบายแต่ละส่วนสั้นๆ ว่าใช้ทำอะไร
- ทำให้เห็นความสัมพันธ์ระหว่างส่วน

## ตัวอย่าง
```
User: /framework วิธีตัดสินใจเรื่องยาก
Claude: ใช้กรอบ DECIDE — Define / Establish / Consider / Identify / Decide / Evaluate
```

## เคล็ดลับ
- เหมาะกับการวางแนวคิด/สอน
- framework ที่ดีมีชื่อจำง่ายและครบ
