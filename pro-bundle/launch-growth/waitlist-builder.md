# waitlist-builder

## ใช้ตอนไหน
อยากเก็บรายชื่อคนสนใจก่อนของพร้อม

## ขั้นตอน
1. ทำ landing เก็บอีเมล + สื่อ value ชัด
2. ใส่กลไก referral (ลัดคิวถ้าชวนเพื่อน)
3. ส่งอีเมล nurture ระหว่างรอ
4. แบ่ง early access เป็น batch

## เทมเพลต / โครงผลลัพธ์
```
Landing(value+ฟอร์ม) / referral mechanic / อีเมลระหว่างรอ / แผนปล่อย access
```

## เคล็ดลับ
- referral แบบลัดคิวช่วยให้ลิสต์โตเอง
- อย่าปล่อยลิสต์เงียบ — ส่งอัปเดตเรื่อยๆ
