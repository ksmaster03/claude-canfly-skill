# certification-program

## ใช้ตอนไหน
อยากออกใบรับรองที่น่าเชื่อถือ

## ขั้นตอน
1. กำหนด competency ที่ผู้จบต้องมี
2. ออกแบบเกณฑ์ประเมิน + ข้อสอบ/โปรเจกต์
3. กำหนดระดับ (pass/distinction)
4. วางระบบ verify + ต่ออายุ

## เทมเพลต / โครงผลลัพธ์
```
Competency / เนื้อหา / วิธีประเมิน / เกณฑ์ผ่าน / ใบรับรอง / verify
```

## เคล็ดลับ
- ใบรับรองมีค่าต่อเมื่อ 'สอบผ่านยากพอ'
- ผูกกับทักษะที่ตลาดต้องการจริง
