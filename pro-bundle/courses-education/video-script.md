# video-script

## ใช้ตอนไหน
ต้องเขียนบทวิดีโอให้เล่าลื่นและคนดูจบ

## ขั้นตอน
1. Hook เปิดบอกว่าดูแล้วได้อะไร
2. วางโครงตามจุดประสงค์ (สอน/ขาย/เล่าเรื่อง)
3. เขียนแบบพูด ประโยคสั้น มีจังหวะ
4. ใส่ B-roll/ข้อความบนจอ + CTA จบ

## เทมเพลต / โครงผลลัพธ์
```
[Hook] / [เนื้อหาเป็นช่วง] / [CTA]
คอลัมน์: บทพูด | ภาพ/ข้อความบนจอ
```

## เคล็ดลับ
- เขียนให้ 'ฟังรู้เรื่อง' ไม่ใช่ 'อ่านสวย'
- ตัดทุกประโยคที่ไม่ดันเรื่องไปข้างหน้า
