# pricing-strategy

## ใช้ตอนไหน
ต้องตัดสินใจว่าจะตั้งราคาสินค้า/บริการเท่าไหร่

## ขั้นตอน
1. เลือกฐานตั้งราคา (ต้นทุน/คู่แข่ง/คุณค่า)
2. ออกแบบ tier (good-better-best) ถ้าเหมาะ
3. ใช้จิตวิทยาราคา (anchor, 9-ending, bundle)
4. ทดสอบ + ดูผลต่อ margin และ conversion

## เทมเพลต / โครงผลลัพธ์
```
ฐานราคา / โครง tier / anchor+เทคนิคจิตวิทยา / แผนทดสอบราคา
```

## เคล็ดลับ
- ตั้งราคาจาก 'คุณค่าที่ลูกค้าได้' ไม่ใช่แค่ต้นทุน+%
- 3 tier ช่วยให้คนเลือกตัวกลาง
