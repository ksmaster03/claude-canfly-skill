# unit-economics

## ใช้ตอนไหน
อยากรู้ว่าขายต่อหน่วยแล้วคุ้มจริงไหม

## ขั้นตอน
1. คำนวณรายได้-ต้นทุนต่อหน่วย (contribution margin)
2. หา CAC (ต้นทุนได้ลูกค้า 1 คน)
3. หา LTV + อัตรา LTV:CAC
4. ดู payback period

## เทมเพลต / โครงผลลัพธ์
```
ราคา/หน่วย - ต้นทุน/หน่วย = margin / CAC / LTV / LTV:CAC / payback
```

## เคล็ดลับ
- LTV:CAC < 3 มักไม่ยั่งยืน
- payback ยิ่งสั้นยิ่งสเกลได้เร็ว
