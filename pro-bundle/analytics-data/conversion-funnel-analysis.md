# conversion-funnel-analysis

## ใช้ตอนไหน
อยากรู้ว่าคนหลุดออกจากกรวยตรงไหน

## ขั้นตอน
1. แมป stage ของ funnel + ตัวเลขแต่ละชั้น
2. คำนวณ conversion/drop-off แต่ละขั้น
3. ระบุขั้นที่หลุดเยอะสุด (จุดรั่ว)
4. ตั้งสมมติฐานสาเหตุ + แนวทางทดสอบ

## เทมเพลต / โครงผลลัพธ์
```
Stage | เข้า | ออก | %ผ่าน | จุดรั่ว / สมมติฐานสาเหตุ / แผนแก้
```

## เคล็ดลับ
- แก้จุดรั่วใหญ่สุดก่อน ได้ผลเร็วสุด
- ดูทั้งตัวเลข + พฤติกรรมจริง (session recording)
