# data-dashboard

## ใช้ตอนไหน
อยากทำแดชบอร์ดให้เห็นภาพธุรกิจ

## ขั้นตอน
1. เลือก KPI ที่ขับการตัดสินใจ (ไม่ใช่ทุกตัวเลข)
2. จัดลำดับ: ภาพรวมบนสุด → เจาะลึกล่าง
3. เลือกชนิดกราฟให้ตรงข้อมูล
4. ใส่เป้าเทียบ + ช่วงเวลา

## เทมเพลต / โครงผลลัพธ์
```
KPI หลัก(บนสุด) / กราฟแนวโน้ม / breakdown / เทียบเป้า / ช่วงเวลา/ฟิลเตอร์
```

## เคล็ดลับ
- น้อยแต่ตรง > เยอะแต่รก
- ทุก metric ต้องตอบว่า 'แล้วทำอะไรต่อ'
