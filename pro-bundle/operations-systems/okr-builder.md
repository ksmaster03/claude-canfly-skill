# okr-builder

## ใช้ตอนไหน
ต้องวางเป้าหมายทีม/บริษัทแบบวัดผล

## ขั้นตอน
1. ตั้ง Objective ที่สร้างแรงบันดาลใจ + ชัด
2. กำหนด 3-5 Key Results ที่เป็นตัวเลข
3. แยก KR (ผลลัพธ์) ออกจาก task (กิจกรรม)
4. กำหนดเจ้าภาพ + รอบ check-in

## เทมเพลต / โครงผลลัพธ์
```
Objective: .. / KR1: [ตัวเลข] / KR2: .. / KR3: .. / เจ้าภาพ / รอบติดตาม
```

## เคล็ดลับ
- KR ต้องเป็น 'ผลลัพธ์ที่วัดได้' ไม่ใช่ 'สิ่งที่จะทำ'
- ตั้งให้ท้าทาย ~70% สำเร็จถือว่าดี
