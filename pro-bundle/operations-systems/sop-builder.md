# sop-builder

## ใช้ตอนไหน
ต้องทำคู่มือกระบวนการงานให้เป็นมาตรฐาน

## ขั้นตอน
1. ระบุขอบเขต + ผู้รับผิดชอบ + เมื่อไหร่ใช้
2. เขียนขั้นตอนเรียง 1-2-3 ทำตามได้จริง
3. ใส่จุดตรวจสอบ/เกณฑ์คุณภาพแต่ละขั้น
4. เพิ่มกรณีปัญหาที่พบบ่อย + วิธีแก้

## เทมเพลต / โครงผลลัพธ์
```
ชื่อ SOP / ผู้รับผิดชอบ / เมื่อไหร่ใช้ / ขั้นตอน 1..n / จุดตรวจ / ปัญหาที่พบบ่อย
```

## เคล็ดลับ
- เขียนให้คนเพิ่งเข้างานทำตามได้ ไม่ใช้ศัพท์ลัด
- ใส่ภาพ/ตัวอย่างประกอบจะชัดขึ้นมาก
