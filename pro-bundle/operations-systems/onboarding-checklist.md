# onboarding-checklist

## ใช้ตอนไหน
ต้องต้อนรับพนักงาน/ลูกค้าใหม่ให้เป็นระบบ

## ขั้นตอน
1. แบ่งช่วง: ก่อนวันแรก / วันแรก / สัปดาห์แรก / 30-60-90 วัน
2. ระบุสิ่งที่ต้องเตรียม + ผู้รับผิดชอบ
3. ใส่เป้าหมายความสำเร็จแต่ละช่วง
4. มีจุด check-in + เก็บ feedback

## เทมเพลต / โครงผลลัพธ์
```
ก่อนวันแรก[ ] / วันแรก[ ] / สัปดาห์1[ ] / 30-60-90 / ผู้รับผิดชอบ / เป้าหมาย
```

## เคล็ดลับ
- onboarding ดี = อยู่นาน/ใช้งานต่อ
- กำหนด 'ความสำเร็จช่วงแรก' ให้เห็นคุณค่าไว
