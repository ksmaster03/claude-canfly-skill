# seo-audit

## ใช้ตอนไหน
อยากรู้ว่าเว็บมีปัญหา SEO ตรงไหนบ้าง

## ขั้นตอน
1. ตรวจ technical: speed, mobile, index, sitemap
2. ตรวจ on-page: title, meta, heading, internal link
3. ตรวจ content: thin/duplicate/ช่องว่าง
4. จัดลำดับแก้ตาม impact vs effort

## เทมเพลต / โครงผลลัพธ์
```
Technical: .. / On-page: .. / Content: .. / Backlink: ..
ตารางแก้: ปัญหา|impact|effort|ลำดับ
```

## เคล็ดลับ
- แก้ปัญหา index/speed ก่อน มันกระทบทั้งเว็บ
- เน้น quick win impact สูง effort ต่ำก่อน
