# local-seo-plan

## ใช้ตอนไหน
ธุรกิจมีหน้าร้าน อยากให้คนใกล้ๆ เจอ

## ขั้นตอน
1. ทำ/ปรับ Google Business Profile ให้ครบ
2. สม่ำเสมอ NAP (ชื่อ-ที่อยู่-เบอร์) ทุกที่
3. เก็บรีวิว + ตอบรีวิว
4. ทำคอนเทนต์/แลนดิ้งตามพื้นที่

## เทมเพลต / โครงผลลัพธ์
```
GBP checklist / NAP consistency / กลยุทธ์รีวิว / local content / citations
```

## เคล็ดลับ
- รีวิวจำนวน+ความสดใหม่มีผลต่ออันดับ Maps มาก
- ตอบรีวิวทุกอัน ทั้งดีและร้าย
