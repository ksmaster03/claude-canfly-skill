# featured-snippet-optimizer

## ใช้ตอนไหน
อยากให้บทความขึ้นกล่องตอบบนสุดของ Google

## ขั้นตอน
1. หาคำถามที่ทริกเกอร์ snippet
2. ตอบคำถามตรงๆ กระชับ 40-60 คำ ไว้ต้นย่อหน้า
3. จัดรูปแบบตามชนิด (paragraph/list/table)
4. ใส่ H2 เป็นคำถามตรงกับ query

## เทมเพลต / โครงผลลัพธ์
```
คำถามเป้าหมาย / คำตอบกระชับ(40-60คำ) / รูปแบบ(list/table) / H2=คำถาม
```

## เคล็ดลับ
- ตอบให้ Google ก๊อปไปวางได้เลย กระชับและครบ
- ตาราง/ลิสต์คว้า snippet ง่ายสำหรับบางคำถาม
