# black-friday-emails

## ใช้ตอนไหน
ต้องทำชุดอีเมลโปรช่วงเทศกาลขายใหญ่

## ขั้นตอน
1. วางไทม์ไลน์: teaser → เปิดขาย → ย้ำ → วันสุดท้าย
2. สร้าง urgency + scarcity จริง
3. แบ่งกลุ่มผู้รับ (VIP ได้ก่อน)
4. เตรียมอีเมล 'last chance' ปิดแคมเปญ

## เทมเพลต / โครงผลลัพธ์
```
T-3: teaser / Day0: เปิด / Day+1: best seller / สุดท้าย: last chance
```

## เคล็ดลับ
- ส่งหลายฉบับช่วงพีคได้ คนคาดหวังโปรอยู่แล้ว
- subject line สั้น มีตัวเลขส่วนลด
