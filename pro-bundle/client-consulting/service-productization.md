# service-productization

## ใช้ตอนไหน
อยากเลิกขายแบบ custom ทุกครั้ง ทำเป็นแพ็กเกจ

## ขั้นตอน
1. ระบุงานที่ทำซ้ำบ่อย → จับเป็นแพ็กเกจ
2. กำหนด scope/ราคา/ระยะเวลาตายตัว
3. ทำ process มาตรฐาน + เทมเพลต
4. ออกแบบ 3 tier ให้ลูกค้าเลือก

## เทมเพลต / โครงผลลัพธ์
```
แพ็กเกจ: Basic/Pro/Premium / scope แต่ละชั้น / ราคา / กระบวนการมาตรฐาน
```

## เคล็ดลับ
- productize = ขายซ้ำได้โดยไม่ต้องคิดใหม่ทุกครั้ง
- เริ่มจากงานที่ทำบ่อยและทำกำไรดีสุด
