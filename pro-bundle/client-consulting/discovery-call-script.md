# discovery-call-script

## ใช้ตอนไหน
ต้องคุยรอบแรกกับลูกค้าที่ปรึกษา/บริการ

## ขั้นตอน
1. เปิดสร้าง rapport + ตั้งวาระ
2. ถามเจาะปัญหา/เป้าหมาย/งบ/timeline
3. สรุปสิ่งที่ได้ยิน + ยืนยันความเข้าใจ
4. เสนอ next step ชัดเจน

## เทมเพลต / โครงผลลัพธ์
```
เปิด/วาระ / คำถามค้นปัญหา(SPIN) / สรุปทวน / next step + ส่ง proposal
```

## เคล็ดลับ
- ฟังมากกว่าพูด (80/20)
- คุณสมบัติลูกค้า (budget/authority) ก่อนเสนอราคา
