# scope-of-work

## ใช้ตอนไหน
ต้องระบุขอบเขตงานกับลูกค้า/ฟรีแลนซ์

## ขั้นตอน
1. ระบุ deliverables ชัดเจน + ที่ไม่รวม
2. กำหนด milestone + timeline
3. ระบุจำนวนรอบแก้ + ค่าใช้จ่ายเพิ่ม
4. เงื่อนไขชำระเงินผูกกับ milestone

## เทมเพลต / โครงผลลัพธ์
```
วัตถุประสงค์ / Deliverables / นอกขอบเขต / Timeline+milestone / รอบแก้ / ราคา&งวด
```

## เคล็ดลับ
- 'สิ่งที่ไม่รวม' สำคัญพอๆ กับสิ่งที่รวม
- ผูกการจ่ายเงินกับ milestone ลดความเสี่ยง
