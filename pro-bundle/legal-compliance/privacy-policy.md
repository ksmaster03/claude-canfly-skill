# privacy-policy

## ใช้ตอนไหน
ต้องมีหน้านโยบายความเป็นส่วนตัว

## ขั้นตอน
1. ระบุข้อมูลที่เก็บ + วัตถุประสงค์
2. อธิบายการใช้/แชร์/เก็บรักษา
3. แจ้งสิทธิผู้ใช้ + วิธีใช้สิทธิ
4. ใส่ cookie + ช่องทางติดต่อ DPO

## เทมเพลต / โครงผลลัพธ์
```
ข้อมูลที่เก็บ / วัตถุประสงค์ / การแชร์ / ระยะเก็บ / สิทธิผู้ใช้ / cookie / ติดต่อ
```

## เคล็ดลับ
- ⚠️ ปรับให้ตรงการเก็บข้อมูลจริงของคุณ + ทนายตรวจ
- เขียนให้คนทั่วไปอ่านเข้าใจ ไม่ใช่แค่ภาษากฎหมาย
