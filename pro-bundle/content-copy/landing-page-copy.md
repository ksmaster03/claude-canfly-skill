# landing-page-copy

## ใช้ตอนไหน
ต้องทำหน้าขาย/หน้าเก็บลีดให้ conversion สูง

## ขั้นตอน
1. Headline สื่อ value ใน 5 วินาที
2. เรียง: ปัญหา → ทางออก → ประโยชน์ → หลักฐาน → CTA
3. ใช้ bullet ที่เน้น benefit ไม่ใช่ feature
4. ใส่ social proof + ลด friction ปุ่ม CTA

## เทมเพลต / โครงผลลัพธ์
```
Headline / Subheadline / ปัญหา / ทางออก / ประโยชน์(bullet) / proof / CTA / FAQ
```

## เคล็ดลับ
- หนึ่งหน้า หนึ่งเป้าหมาย หนึ่ง CTA
- พูดภาษาลูกค้า ไม่ใช่ภาษาบริษัท
