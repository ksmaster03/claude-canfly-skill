# tiktok-script

## ใช้ตอนไหน
ต้องทำคลิปสั้นที่คน watch จนจบ

## ขั้นตอน
1. Hook 3 วินาทีแรกต้องสะดุด
2. เล่าเป็นจังหวะเร็ว ตัดน้ำทิ้ง
3. ใส่ pattern interrupt กันคนเลื่อนหนี
4. ปิดด้วย CTA/ค้างให้อยากดูซ้ำ

## เทมเพลต / โครงผลลัพธ์
```
[0-3s Hook] / [เนื้อหาเป็นช็อต] / [CTA]
กำกับภาพ + ข้อความบนจอแต่ละช็อต
```

## เคล็ดลับ
- retention 3 วินาทีแรกชี้ขาด
- เขียนแบบพูด ไม่ใช่แบบอ่าน
