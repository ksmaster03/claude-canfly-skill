# product-description

## ใช้ตอนไหน
ต้องเขียนรายละเอียดสินค้าให้คนกดซื้อ

## ขั้นตอน
1. เปิดด้วยประโยคขายที่ชูจุดเด่นสุด
2. แปลง feature เป็น benefit ที่ลูกค้าได้
3. ใส่สเปก/ขนาด/วิธีใช้ให้ครบ ลดคำถาม
4. ปิดด้วยเหตุผลให้ซื้อตอนนี้

## เทมเพลต / โครงผลลัพธ์
```
[ประโยคขายเปิด] / จุดเด่น(benefit) / สเปก / วิธีใช้ / การรับประกัน
```

## เคล็ดลับ
- ลูกค้าซื้อ 'ผลลัพธ์' ไม่ใช่ 'คุณสมบัติ'
- ใส่คีย์เวิร์ดที่คนเสิร์ชหาสินค้านี้
