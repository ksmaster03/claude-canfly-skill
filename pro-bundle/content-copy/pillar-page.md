# pillar-page

## ใช้ตอนไหน
ต้องทำหน้าเสาหลักเชื่อมบทความย่อยเพื่อ SEO

## ขั้นตอน
1. กำหนดหัวข้อหลักให้กว้างพอครอบ subtopic
2. วางสารบัญ + ลิงก์ไปบทความย่อย (cluster)
3. เขียนแต่ละส่วนให้ครบแต่กระชับ
4. ใส่ internal link สองทาง pillar<->cluster

## เทมเพลต / โครงผลลัพธ์
```
หัวข้อหลัก / สารบัญ / ## ส่วนที่ 1.. (ลิงก์บทความลึก) / ส่วนที่ 2..
```

## เคล็ดลับ
- pillar ตอบ 'ภาพรวม', cluster ตอบ 'เจาะลึก'
- อัปเดตหน้านี้สม่ำเสมอ มันคือหน้าเรือธง SEO
