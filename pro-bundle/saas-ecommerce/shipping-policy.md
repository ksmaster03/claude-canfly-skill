# shipping-policy

## ใช้ตอนไหน
ต้องมีหน้านโยบายจัดส่ง/คืนของ

## ขั้นตอน
1. ระบุวิธีส่ง/ระยะเวลา/ค่าส่งแต่ละพื้นที่
2. เงื่อนไขส่งฟรี (ถ้ามี)
3. นโยบายคืน/เปลี่ยน + ระยะเวลา
4. ขั้นตอนเคลมของเสีย/สูญหาย

## เทมเพลต / โครงผลลัพธ์
```
วิธีส่ง&เวลา / ค่าส่ง / ส่งฟรีเมื่อ / คืน-เปลี่ยน / เคลม / ติดต่อ
```

## เคล็ดลับ
- นโยบายคืนที่ชัดและใจดี เพิ่มความมั่นใจซื้อ
- เขียนให้ครบ ลดคำถามแชตซ้ำๆ
