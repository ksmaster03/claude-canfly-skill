# feature-roadmap

## ใช้ตอนไหน
ต้องวางแผนพัฒนาฟีเจอร์ว่าทำอะไรก่อนหลัง

## ขั้นตอน
1. รวบรวม feature requests + ปัญหาผู้ใช้
2. จัดลำดับด้วย framework (RICE/value-effort)
3. จัดกลุ่มเป็น now/next/later
4. เชื่อมแต่ละฟีเจอร์กับเป้าหมายธุรกิจ

## เทมเพลต / โครงผลลัพธ์
```
Now / Next / Later / แต่ละฟีเจอร์: คุณค่า|effort|เป้าที่หนุน
```

## เคล็ดลับ
- roadmap คือ 'ทิศทาง' ไม่ใช่สัญญาวันส่ง
- ยึดปัญหาผู้ใช้ ไม่ใช่ความอยากได้ฟีเจอร์
