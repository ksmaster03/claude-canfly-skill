# checkout-optimization

## ใช้ตอนไหน
คนถึงหน้าจ่ายเงินแล้วหลุดเยอะ

## ขั้นตอน
1. ลดขั้นตอน/ฟิลด์ให้น้อยสุด
2. แสดงค่าส่ง/รวมทั้งหมดแต่เนิ่นๆ
3. ใส่ guest checkout + วิธีจ่ายหลากหลาย
4. เพิ่ม trust signal + progress bar

## เทมเพลต / โครงผลลัพธ์
```
จำนวนขั้นตอน / ฟิลด์ที่ตัดได้ / วิธีจ่าย / guest checkout / trust / mobile
```

## เคล็ดลับ
- บังคับสมัครสมาชิก = สาเหตุทิ้งตะกร้าอันดับต้น
- ค่าส่งเซอร์ไพรส์ตอนท้าย ทำคนหนี
