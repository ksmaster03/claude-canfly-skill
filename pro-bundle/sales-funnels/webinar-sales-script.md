# webinar-sales-script

## ใช้ตอนไหน
ต้องจัด webinar แล้วปิดการขายตอนจบ

## ขั้นตอน
1. เปิดด้วยสัญญาว่าจะได้อะไร + สร้างความน่าเชื่อถือ
2. ให้เนื้อหาคุณค่าจริง 3 ก้อนหลัก
3. เปลี่ยนเข้าสู่ข้อเสนอแบบธรรมชาติ
4. ปิดด้วย stack คุณค่า + urgency + Q&A

## เทมเพลต / โครงผลลัพธ์
```
เปิด(promise) / เนื้อหา3ก้อน / transition / ข้อเสนอ+โบนัส / urgency / Q&A
```

## เคล็ดลับ
- ให้คุณค่าจริงก่อน คนถึงเชื่อตอนขาย
- เตรียมตอบ objection ไว้ในช่วง Q&A
