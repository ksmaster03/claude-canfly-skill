# personal-brand-strategy

## ใช้ตอนไหน
อยากสร้างตัวตนออนไลน์ให้คนจดจำ

## ขั้นตอน
1. นิยาม positioning: เก่งเรื่องอะไร เพื่อใคร ต่างยังไง
2. กำหนด 3-4 เสาคอนเทนต์
3. กำหนดน้ำเสียง + เรื่องราวส่วนตัว
4. เลือกแพลตฟอร์มหลัก + จังหวะลง

## เทมเพลต / โครงผลลัพธ์
```
Positioning(1ประโยค) / กลุ่มเป้าหมาย / เสาคอนเทนต์ / น้ำเสียง / แพลตฟอร์มหลัก
```

## เคล็ดลับ
- เจาะจงชนะกว้างเสมอ — 'เก่งทุกอย่าง' = ไม่จำ
- ความสม่ำเสมอสร้างแบรนด์ ไม่ใช่ไวรัลครั้งเดียว
