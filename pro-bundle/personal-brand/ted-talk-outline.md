# ted-talk-outline

## ใช้ตอนไหน
ต้องเตรียมพูดบนเวที/นำเสนอที่ทรงพลัง

## ขั้นตอน
1. ตกผลึกเป็น 'หนึ่งไอเดียใหญ่' (through-line)
2. เปิดด้วยเรื่อง/คำถามที่ตรึงคนฟัง
3. วางองก์: hook → เดินทาง → epiphany → call
4. ปิดด้วยประโยคที่คนจำกลับบ้าน

## เทมเพลต / โครงผลลัพธ์
```
Big idea(1ประโยค) / Hook / โครงเล่า / จุดพลิกความคิด / ปิดทรงพลัง
```

## เคล็ดลับ
- หนึ่ง talk หนึ่งไอเดีย อย่ายัดหลายเรื่อง
- เล่าเรื่องเชื่อมไอเดีย คนจำเรื่องมากกว่าข้อมูล
