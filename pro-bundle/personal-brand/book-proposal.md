# book-proposal

## ใช้ตอนไหน
อยากเขียนหนังสือและเสนอให้ตีพิมพ์

## ขั้นตอน
1. สรุปแก่นหนังสือ + ทำไมตอนนี้
2. ระบุกลุ่มผู้อ่าน + ตลาด + หนังสือเทียบเคียง
3. ทำสารบัญ + สรุปแต่ละบท
4. เขียน author platform + ตัวอย่างบท

## เทมเพลต / โครงผลลัพธ์
```
Concept / กลุ่มผู้อ่าน&ตลาด / comparable titles / สารบัญ / author platform / ตัวอย่างบท
```

## เคล็ดลับ
- สำนักพิมพ์ดู 'ตลาด + ฐานผู้ติดตาม' พอๆ กับเนื้อหา
- หนังสือเทียบเคียงช่วยให้เห็นช่องว่างของเรา
