# facebook-ad-campaign

## ใช้ตอนไหน
ต้องยิงแอด Meta ให้คุ้มงบ

## ขั้นตอน
1. เลือก objective ตรงเป้า (leads/sales/traffic)
2. วาง audience: cold/warm/hot + lookalike
3. เขียน ad copy + เลือกมุมภาพ 3 แบบทดสอบ
4. ตั้งงบ + โครงสร้าง CBO + เกณฑ์ตัดสินผล

## เทมเพลต / โครงผลลัพธ์
```
Objective / Audiences / Ad copy x3 / Creative angle / งบ+KPI(CPA,ROAS)
```

## เคล็ดลับ
- ทดสอบทีละตัวแปร อย่าเปลี่ยนหลายอย่างพร้อมกัน
- creative คือ 80% ของผล ไม่ใช่ targeting
