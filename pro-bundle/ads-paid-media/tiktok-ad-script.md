# tiktok-ad-script

## ใช้ตอนไหน
ต้องทำ TikTok Ads ที่ไม่โดนเลื่อนผ่าน

## ขั้นตอน
1. เปิดเหมือนคลิปทั่วไป (native) ไม่เหมือนโฆษณา
2. Hook ปัญหา/ผลลัพธ์ใน 3 วินาที
3. โชว์สินค้าแก้ปัญหาแบบ UGC
4. CTA ชัดเจนปลายคลิป

## เทมเพลต / โครงผลลัพธ์
```
[Hook native] / ปัญหา / สินค้าแก้ / proof / CTA
รูปแบบ: UGC/รีวิว/before-after
```

## เคล็ดลับ
- ยิ่งดู 'ไม่เหมือนแอด' ยิ่งได้ผล
- ใช้สไตล์ creator จริง อย่าดูโปรดักชันเกิน
