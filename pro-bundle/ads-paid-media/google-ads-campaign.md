# google-ads-campaign

## ใช้ตอนไหน
ต้องยิงแอด Google ให้ได้ลีด/ยอดคุ้ม

## ขั้นตอน
1. จัดกลุ่มคีย์เวิร์ดตาม intent
2. เขียน RSA headline/description หลายชุด
3. ตั้ง negative keywords กันงบรั่ว
4. วาง conversion tracking + เป้า CPA

## เทมเพลต / โครงผลลัพธ์
```
Campaign type / Ad groups(keyword) / RSA / Negatives / Bidding+CPA เป้า
```

## เคล็ดลับ
- negative keyword สำคัญพอๆ กับคีย์เวิร์ดหลัก
- ดู search terms report ทุกสัปดาห์
