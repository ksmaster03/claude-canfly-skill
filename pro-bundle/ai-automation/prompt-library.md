# prompt-library

## ใช้ตอนไหน
อยากให้ทีมใช้ AI ได้ผลสม่ำเสมอ

## ขั้นตอน
1. รวบรวมงานที่ใช้ AI บ่อย
2. เขียน prompt แม่แบบ + ช่องตัวแปร [..]
3. ใส่ตัวอย่าง input/output ที่ดี
4. จัดหมวด + เวอร์ชัน + เจ้าของ

## เทมเพลต / โครงผลลัพธ์
```
หมวด / ชื่อ prompt / prompt(มีตัวแปร) / ตัวอย่างผลลัพธ์ / หมายเหตุ
```

## เคล็ดลับ
- prompt ที่ดีระบุบทบาท+บริบท+รูปแบบผลลัพธ์
- ใส่ตัวอย่างช่วยให้ผลคงเส้นคงวา
