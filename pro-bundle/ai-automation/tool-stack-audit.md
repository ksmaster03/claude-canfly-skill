# tool-stack-audit

## ใช้ตอนไหน
อยากรู้ว่าเครื่องมือที่ใช้คุ้มไหม ซ้ำกันไหม

## ขั้นตอน
1. ลิสต์เครื่องมือทั้งหมด + ค่าใช้จ่าย + ผู้ใช้
2. จับกลุ่มตามหน้าที่ หาตัวที่ทับซ้อน
3. ชี้ช่องว่าง (งานที่ยังไม่มีเครื่องมือ)
4. เสนอตัด/รวม/เพิ่ม + ประหยัดเท่าไหร่

## เทมเพลต / โครงผลลัพธ์
```
เครื่องมือ | หน้าที่ | ราคา/เดือน | ผู้ใช้ | ซ้ำกับ? | คำแนะนำ
```

## เคล็ดลับ
- เครื่องมือซ้ำหน้าที่ = จ่ายซ้ำ ตัดได้
- integration ระหว่างเครื่องมือสำคัญกว่าจำนวน
