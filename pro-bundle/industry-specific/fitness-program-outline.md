# fitness-program-outline

## ใช้ตอนไหน
ต้องวางโปรแกรมฝึกให้ลูกค้า/ตัวเอง

## ขั้นตอน
1. ประเมินเป้าหมาย/ระดับ/ข้อจำกัด
2. วางโครงสัปดาห์ (ความถี่/กลุ่มกล้ามเนื้อ)
3. กำหนด progressive overload เป็นเฟส
4. ใส่ warm-up/cooldown + การพัก

## เทมเพลต / โครงผลลัพธ์
```
เป้าหมาย / ระดับ / ตารางสัปดาห์ / เฟส progression / โภชนาการคร่าวๆ / การพัก
```

## เคล็ดลับ
- ⚠️ ปรับตามสุขภาพรายบุคคล แนะนำปรึกษาแพทย์ถ้ามีโรค
- progressive overload คือหัวใจของผลลัพธ์
