# /musicmv — เพลงจริง + MV ที่ตัดตรงคำร้อง

รวมสามสกิลเป็นสายพานเดียว: เขียนเนื้อ → [[sunobridge]] ปั้นไฟล์เพลง → [[vdomindset]] ให้ภาษาภาพ
→ Remotion ประกอบเป็น MV เต็มเพลง

ตัวอย่างที่ทำเสร็จแล้ว: `$PROJECTS/claude-song` — "พิมพ์มาสิ" ร็อคไทย 3:44 / 169.4 BPM / 29 ฉาก
**อ่านโค้ดที่นั่นเป็นตัวอย่างจริงก่อนเริ่มเขียนเอง**

## สายพาน

```
1. lyrics.md (โครง + เหตุผล)  +  suno-lyrics.txt (สะอาด ส่ง Suno)
2. /sunobridge  ->  audio/<take>.mp3  +  aligned-<id>.json
3. downbeat.py  ->  bpm, phase        timeline.py -> timeline.json
4. cp vdomindset/template -> mv/      แล้ววางไฟล์จาก <SKILL_DIR>/template ทับ
5. เขียน scenes.tsx + SCHEDULE ใน Mv.tsx
6. node tools/stills.mjs   -> ตรวจ contact sheet ด้วยตา ทุกฉาก
7. node tools/render-mv.mjs -> out/<ชื่อ>.mp4
```

**ประโยคเปิดของเพลงและแคปชันโพสต์**: คลังฮุก `~/.claude/skills/vidcraft/references/hooks-50.md` ใช้เป็นโจทย์ตั้งบรรทัดแรกของเนื้อเพลง และใช้เขียนแคปชันตอนโพสต์ · "ฮุก" ในคลังหมายถึงประโยคเปิดคลิป ไม่ใช่ท่อนฮุกของเพลง

## ตั้งโปรเจกต์

```bash
cp -r "~/.claude/skills/vdomindset/template" $PROJECTS/<งาน>/mv
cp -r "~/.claude/skills/musicmv/template/." $PROJECTS/<งาน>/mv/
cd $PROJECTS/<งาน>/mv && npm install
mkdir -p public/fonts
cp "$PROJECTS/Fonts_Icon/fonts/ofl/sarabun/Sarabun-Regular.ttf"  public/fonts/
cp "$PROJECTS/Fonts_Icon/fonts/ofl/sarabun/Sarabun-SemiBold.ttf" public/fonts/
rm -rf src/clips src/props/water.tsx      # ตัวอย่างของซีรีส์เดิม ไม่ได้ใช้
cp ../timeline.json src/timeline.json
```
แล้วใส่ `BPM`, `SONG_PHASE`, `SONG_S` ที่วัดได้ลง `src/theme.ts`

## สถาปัตยกรรม

- **`src/song.ts`** — อ่าน `timeline.json` แล้วให้ `barsAt(sec)`, `beatPhase(bars, cyclesPerBar, offset)`,
  `beatPulse(bars)`, `lineAt(sec)` · **นาฬิกาของทุกการเคลื่อนไหวคือ "บาร์" ไม่ใช่เฟรม**
- **`src/Mv.tsx`** — `SCHEDULE` = ลิสต์ `{at, scene, half?}` · เลือกฉากตามวินาที · วาดแถบเนื้อร้องทับ
- **`src/scenes.tsx`** — ฉากรับ `{t, u, bars}` เลือกใช้ตามงาน:
  `u` สำหรับสิ่งที่ค่อย ๆ สร้างขึ้นครั้งเดียว · `bars` สำหรับสิ่งที่ต้องตรงบีตแม้ข้ามคัต · `t` สำหรับ ease ธรรมดา
- **`src/props/mv.tsx`** — ชุด prop: `Slab CodeCard Heap PageStack FileGrid Bars TestDots Chip Beam
  Screen Plug Magnifier Clock Camera PhotoChart` ทั้งหมดรับ phase/progress ไม่อ่านเฟรมเอง

## กฎเรื่องเวลา (ที่เสียเวลาไปมากที่สุด)

- **อย่าแบ่งท่อนเท่า ๆ กัน** — เอาเวลาเริ่มของแต่ละฉากจาก `lines[]` ใน timeline.json ตรง ๆ
  ท่อนแร็ปของงานตัวอย่างร้อง 16 บรรทัดใน 32 บาร์ (บรรทัดละ 2 บาร์) การแบ่ง 8 ฉากเท่า ๆ กัน
  ทำให้ภาพตามหลังคำร้องไป 2 ฉากตอนจบท่อน
- **snap เข้าบาร์เฉพาะรอยต่อท่อนใหญ่** · ท่อนที่ร้องถี่ให้ **snap ครึ่งบาร์** (`snapHalf`)
  เพราะ snap เต็มบาร์เหวี่ยงได้ถึง 0.7 วิ ซึ่งขึ้นภาพใหม่ทั้งที่บรรทัดก่อนหน้ายังร้องไม่จบ
- ห้ามเขียนเลขเฟรมดิบ ใช้ `BAR_F(bars)` / `SEC_F(sec)`

## กับดัก (เจอมาแล้วทุกข้อ)

- **`STAGE_H` ตัดภาพเงียบ ๆ** — เทมเพลตซีรีส์ตั้ง 620 ซึ่งพอสำหรับคนยกแขน แต่ MV แขวนออร์บ/กริด/นาฬิกา
  สูงกว่านั้น **ทุกอย่างที่เกิน 620 หายไปโดยไม่มี error** ตั้ง `STAGE_H = HORIZON` ไปเลย
  (มาส์กเงาคิดจาก `fadeHeight/STAGE_H` จึงยังฟรุ้งเท่าเดิม)
- **โซนห้ามวางของ: y ประมาณ 292–340 บนจอ** คือที่อยู่ของ caption หัวฉาก ออร์บที่ halo กว้าง
  (`3.2 × r × scale`) ชนบ่อยมาก · ฉากที่ต้องใช้กริดเต็มความกว้างให้ **ตัด caption ทิ้ง** ไปเลย
  เพราะแถบเนื้อร้องพูดแทนอยู่แล้ว
- **`A delayRender() "font …" was called but not cleared after 118000ms` มักไม่ใช่เรื่องฟอนต์**
  อาการนี้แปลว่า **แท็บเรนเดอร์หมดแรม** แล้ว Remotion รายงาน handle ที่ค้างอยู่เป็นตัวแทน
  จับผิดได้จาก: still เฟรมเดียวกันเรนเดอร์ผ่านสบาย ๆ · จุดที่ตายขยับไปมาเมื่อเปลี่ยนของที่ไม่เกี่ยวกับฟอนต์เลย
  (ของจริงตายที่ 1249 → 1300 → เฟรมแรก ๆ ตามน้ำหนักของแต่ละเฟรม) · **อย่าไปไล่แก้ฟอนต์**
- **ตัวกินแรมคือเลเยอร์เงา** — `Floor` วาดทั้งฉากซ้ำอีกรอบแล้วใส่ CSS blur ทั้งเลเยอร์
  แต่มาส์กทำให้ **เห็นจริงแค่ `REFLECTION.fadeHeight` (150px) ใต้เส้นพื้น** เท่านั้น
  ให้เงาวาดเฉพาะแถบนั้นด้วย `viewBox` ที่เลื่อนลงมา แทนที่จะวาดเต็ม 1080x1010 แล้ว blur ทิ้ง
  (template แก้ไว้แล้ว — เลเยอร์ที่ต้อง blur เล็กลงราว 85% ภาพเหมือนเดิมทุกประการ)
- **ฟอนต์: อย่ารออะไรเลย** — ลองมาแล้ว 3 แบบ ตายหมดทั้งที่ still ผ่าน: `staticFile()` ค้าง ·
  data URI + `new FontFace().load()` promise ไม่ settle · ใส่ `Promise.race` กับ `setTimeout 5000`
  ก็ยังตาย เพราะ **แท็บที่ Remotion เปิดใหม่อยู่นอกจอ Chromium แช่แข็ง timer ของมัน** ตัวจับเวลาไม่ยิงเลย
  ของที่ผ่านคือ `tools/embed-fonts.py` → **ฉีด CSS `@font-face` ที่พกไบต์มาเอง แล้วตัด `delayRender`
  ทิ้งทั้งหมด** บังคับให้โหลดด้วย probe ที่อ่าน `offsetWidth` แบบ synchronous (fonts.ts ใน template
  ทำให้แล้ว) · ตรวจด้วย still หนึ่งใบว่าวรรณยุกต์ไทยยังลอยถูกตำแหน่ง ไม่กลายเป็นกล่อง
- **ความเร็ว**: ถ้าฉากหนัก `--concurrency=2` อาจกินหลายชั่วโมง · `--concurrency=4
  --image-format=jpeg --jpeg-quality=95` เร็วกว่ามาก แต่ต้องแก้เลเยอร์เงาให้เบาก่อน ไม่งั้นแรมไม่พอ
- **`--concurrency=2` เท่านั้น** — 4 ทำให้เรนเดอร์เต็มความยาวล้ม ทั้งที่ช่วง 60 เฟรมผ่าน
  (แต่ละ worker ถือ canvas 1080x1920 + ฟอนต์)
- **อย่า pipe log ของ remotion ผ่าน `tail` ตอนรัน background** — บรรทัดหัวข้อความ error โดนตัดทิ้ง
  เหลือแต่ stack ที่อ่านไม่ได้ความ ให้ redirect ลงไฟล์เต็มแล้วค่อย grep
- **บน Windows ห้าม spawn `npx`** — bare `npx` = ENOENT, `npx.cmd` = EINVAL ให้เรียก
  `node node_modules/@remotion/cli/remotion-cli.js` ตรง ๆ
- `<FigureDefs/>` + `<PropDefs/>` ต้องอยู่ใน `<svg>` **ทุกตัว** ไม่งั้น gradient หายตอนคัตฉาก
- `delayRender` ของฟอนต์ตั้ง `timeoutInMilliseconds: 120000`
- ห้าม `Math.random()` ใน prop ใช้ jitter จาก index
- **cd ให้ถูกก่อนเสมอ** — background task เริ่มที่ cwd อื่น เคยได้ MODULE_NOT_FOUND มาแล้ว

## วิธีตรวจงาน

`node tools/stills.mjs` เรนเดอร์ still กลางฉากทุกฉากแล้วต่อเป็น contact sheet แผ่นละ 6 ภาพ
**เปิดดูด้วย Read tool ทุกแผ่น** — ปัญหาที่เห็นได้เฉพาะจากภาพจริง: คนยืนซ้อน prop, ท่าคอลลิเนียร์
กลายเป็นแท่ง, ข้อความชนกัน, ของหายเพราะโดนตัด และที่สำคัญที่สุดคือ **เนื้อร้องใต้ภาพตรงกับฉากไหม**
(แถบเนื้อร้องในภาพนิ่งคือตัวจับผิดจังหวะที่ดีที่สุด)

## เรนเดอร์และใส่เพลง

```bash
node tools/render-mv.mjs          # เรนเดอร์เป็นช่วง ๆ -> ต่อกัน -> ใส่เพลง
```
**เรนเดอร์ทีเดียวยาว ๆ ไม่รอด** — แท็บของ Remotion ตายราวเฟรม 1,200 (ของจริงล้ม 2 รอบที่ 1249 และ 1300)
โดยโผล่มาเป็น error ของ delayRender ฟอนต์ ทั้งที่ still เฟรมเดียวกันเรนเดอร์ผ่านสบาย ๆ
เพราะเลเยอร์เงาคือ **การวาดทั้งฉากซ้ำอีกรอบผ่าน CSS blur** ต้นทุนต่อเฟรมจึงสูงและมีอะไรสะสมไปเรื่อย ๆ
`render-mv.mjs` จึงเรนเดอร์ทีละ 1,000 เฟรมให้ได้เบราว์เซอร์ใหม่ทุกช่วง แล้วต่อด้วย
`ffmpeg -f concat -c copy` (ทุกช่วงออกจาก encoder เดียวกัน ต่อได้โดยไม่ต้อง encode ใหม่) ·
สคริปต์ข้ามช่วงที่มีไฟล์แล้ว ล้มกลางทางก็รันซ้ำต่อได้ · เหตุผลเดียวกันนี้ทำให้ควรตั้ง `STAGE_H`
ให้ **พอดีกับของที่สูงที่สุดที่วาดจริง** ไม่ใช่ยัดเต็มเฟรม

เสียงใส่ที่ offset 0 **ห้าม `-ss`** เพราะภาพล็อกกับเพลงตั้งแต่วินาทีแรกแล้ว ·
Suno master มาให้แล้ว **ห้าม loudnorm ซ้ำ**

## ฟอร์แมตนี้ต่างจาก /vdomindset ตรงไหน

vdomindset เป็นรีล 6–9 วินาที **ห้ามคัต ต้องวนลูป** ซึ่งบังคับให้ทุกการเคลื่อนไหวเป็นฟังก์ชันคาบ
MV ไม่ต้อง — **คัตได้ (บนดาวน์บีต) และ "ค่อย ๆ สร้างขึ้น" ได้** ซึ่งเป็นวิธีหลักที่ฉากจะเล่าว่า
"แล้วก็เกิดสิ่งนี้ขึ้น" · สิ่งที่ยกมาทั้งดุ้นคือภาษาภาพ: เส้นพื้นเดียว พื้นมันสะท้อนเงา props สีเหล็ก
และสีสงวนไว้ให้เฉพาะสองสิ่งที่ต้องการให้เทียบกัน
