# ระบบการเคลื่อนไหว v2 (ตัวเลขที่ใช้จริงใน MODEL WARS)

ผู้ใช้ดูคลิปเทียบก่อน/หลังแล้วอนุมัติชุดนี้ 29/09/2026 · ที่มา: งานค้นคว้า (GDC talks, frame data เกมต่อสู้, Netflix style guide)

## ท่าโจมตี: ช้า → เร็ว → ค้าง
| ช่วง | เวลา | วิธี |
|---|---|---|
| เงื้อ (anticipation) | ระดับ 1/2/3 = 0.18 / 0.28 / 0.40 วิ | easeOutCubic เข้าท่าเงื้อเร็ว แล้วค้างแบบสั่นเล็กน้อย (moving hold) |
| ออกหมัด | 2 เฟรม (0.034 วิ) | เส้นตรงจากท่าเงื้อไปท่าออกหมัด + smear |
| ค้างตอนโดน (hitstop) | 0.133 / 0.2 / 0.25 วิ (SFV 8/12/15f) · ปะทะสุดท้าย 0.5 วิ | คนตีค้าง ขยับนิดเดียว · คนโดนค้างนานกว่า 0.05 วิ |
| เด้งกลับ | 0.25 วิ | lean + มุมแขน บวก `7°·e^(-12v)·sin(30v)` |
| คืนท่า | 0.35 วิ | easeInOutCubic กลับท่ายืน |

- ท่าที่ระยะห่างเกิน: ตัวละคร **พุ่งเข้าหา** ระหว่างเงื้อ แล้วกลับที่เดิมหลังเด้งกลับ
- คนโดน: เข้าท่าเจ็บภายใน 4 เฟรม (Sakurai) · สั่นแนวนอน `A·lv·(1-u/H)·sign(sin(16πu))` แล้วลดลง · หลัง hitstop กระเด็น easeOutExpo 0.35 วิ ระยะ 4/9/18 หน่วยตามระดับ แล้วค่อยๆ คืนที่
- **ท่าตัวละครวาด 12 ภาพ/วิ** (`floor(t*12)/12`) ยกเว้นช่วง ±0.05 วิ รอบเฟรมสัมผัส · เอฟเฟกต์และกล้องยังลื่น 60 เฟรม
  ⚠ ผู้ใช้เคยบ่นภาพกระตุก (สาเหตุตอนนั้นคือการเลื่อนฉากแบบปัดเข้าช่อง) · ข้อนี้อนุมัติแล้ว แต่ถ้าทำงานใหม่ให้ทำคลิปทดสอบให้ดูก่อนเสมอ

## กล้องสั่นแบบ trauma (Eiserloh GDC 2016)
- trauma += 0.2 / 0.34 / 0.55 ต่อฮิต (ระดับ 1/2/3) · ลดลงเส้นตรง 1.3/วิ · เหตุการณ์ย่อย +0.06
- `shake = min(1,trauma)^2` · เลื่อนสูงสุด 34 px · หมุนสูงสุด 4° · noise แบบผลรวม sin 3 ความถี่ (ไม่ใช้สุ่มล้วน)

## เฟรมกระแทก (ฮิตระดับ 3)
- เฟรมที่ 1 (1/24 วิ): พื้นขาว + เงาดำตันของคู่ต่อสู้ + รัศมีสามเหลี่ยม 16 แฉกจากจุดโดน
- เฟรมที่ 2 (1/24 วิ): สลับสี (พื้นดำ เงาขาว) · แล้วกลับภาพปกติ
- ตามด้วยเส้นโฟกัส (集中線) พุ่งเข้าจุดโดน 0.45 วิ
- smear ตอนออกหมัด: ภาพซ้อน 2 ชั้น (alpha 0.16, 0.32) + หลอดความเร็วจากตำแหน่งหมัด 0.05 วิก่อน

## ความอ่านง่าย
- **คู่หลักคู่เดียว** ในช่วง [สัมผัส − เงื้อ − 0.15, สัมผัส + hitstop + 0.9] · ตัวอื่น `saturate(0.3) brightness(0.62)`
- เลือกเหตุการณ์ที่ได้ท่าเต็ม: ห่างกันอย่างน้อย 0.9 วิ (คน) / 1.25 วิ (หุ่นยักษ์) · ที่เหลือเป็นตัวนับ + ลูกพลังเล็กๆ ในเลเยอร์ซีด
- ป้ายชื่อ: Netflix ไทย 17 ตัว/วิ ไม่นับสระบน-ล่าง-วรรณยุกต์ (U+0E31, U+0E34–0E3A, U+0E47–0E4E) · ขั้นต่ำ 0.83 วิ (+0.35 วิ ตอนเด้งเข้า) · 2 ช่องซ้าย/ขวาตามฝั่งคนตี · รอคิวเกิน 0.35 วิ → ไปเป็นตัวนับ

## มุมกล้องอัตโนมัติ (ตัดแข็ง ไม่มี smoothing)
- ต้นช่วง: ภาพกว้างที่เห็นทุกตัว
- ก่อนท่าเต็มทุกท่า: ภาพกลางที่คู่ต่อสู้ (zoom = 320 / (ระยะห่าง + 60))
- หลังฮิตหนักถ้ามีช่องว่าง > 1.2 วิ: โคลสอัปหน้าคนโดน 0.75 วิ แล้วกลับภาพกว้าง
- ช็อตสั้นสุด 0.6 วิ · push-in 3–6% ระหว่างช็อต
- repeat cut (เล่นหมัดซ้ำจากมุมใกล้) ทำได้ แต่เวลาฉากจะเลื่อน ต้องแปลงเวลาเหตุการณ์ทั้งหมดหลังจุดนั้น

## เสียง
- หมัด: หัวเสียง Kenney `impactPunch_*` + เบส sine 150→55 Hz + หาง noise LPF 1.5 kHz · saturation `tanh`
- หุ่นยักษ์: `impactMetal_heavy` + `impactPlate_heavy` + ซับ 90→35 Hz + brown noise
- whoosh เริ่มตอนเงื้อ พีคตอนออกหมัด · ducking เพลงตามข้างบน
