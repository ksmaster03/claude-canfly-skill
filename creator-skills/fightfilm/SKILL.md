# /fightfilm: หนังแอนิเมชันต่อสู้จากโค้ด ผูกข้อมูล ล็อกเพลง

ต้นแบบที่ทำเสร็จแล้ว: **MODEL WARS** (3:02, 8 ค่าย AI แข่งออกโมเดล)
อ่าน `README.md` ของ repo นั้นก่อนเขียนโค้ดใหม่ ใช้ต่อยอดได้เกือบทั้งหมด

สิ่งที่ได้: MP4 1920x1080 60fps พร้อมเพลงและเสียงประกอบ, ทุกฉากคำนวณจาก `draw(t)` ที่กระโดดไปเวลาไหนก็ได้ (deterministic)

## ลำดับงาน

### 1. พลอทและข้อมูล (ถามผู้ใช้ได้ไม่เกิน 3 ข้อ)
- เสนอแนวคิดหลัก + ตารางตัวละคร + โครง 3 องก์ก่อน แล้วถามเฉพาะสิ่งที่เปลี่ยนงาน: ความยาว/รูปแบบ, บทบาทของฝ่ายที่อ่อนไหว, ตอนจบ
- **หนึ่งเหตุการณ์ในข้อมูล = หนึ่งท่าโจมตี** · เหตุการณ์ใหญ่ = ท่าเต็ม · เหตุการณ์ย่อย = ตัวนับ "+N"
- ข้อมูลหลังวันตัดความรู้ของโมเดล ให้ส่ง subagent ค้นเว็บยืนยัน พร้อมระดับความมั่นใจ (high/medium/low) และแหล่งที่มา · ตัวเลขเรื่องจริงในพลอทต้องยืนยันก่อนขึ้นจอ
- ช่วงคาดการณ์: ติด "?" ท้ายชื่อทุกตัว + ป้าย "คาดการณ์" + หมายเหตุท้ายเรื่อง

### 2. เพลง
- Suno ผ่าน [[sunobridge]] ใช้ `--instrumental` (เว้นเนื้อร้องว่าง) · ห้ามใส่ชื่อศิลปินใน style ให้บรรยายองค์ประกอบแทน
- หาขอบท่อน: `python scripts/secana.py <song>` (BPM + timbre novelty + ช่วงเบา) แล้วยืนยันด้วยพลังงานเบสทุก 0.1 วิ ตรงจุดสำคัญ
- **เลือกเทคจากโครงเพลงที่วัดได้ ไม่ใช่เดา** แล้ววางฉากตามจุดเปลี่ยน: ดนตรีเข้าเต็ม = ฉากเปิดตัว, เบรก/เบสหาย = ความนิ่งก่อนพายุ, ดนตรีกลับมา = แปลงร่าง, เบสหายกะทันหัน = ระเบิด
- ทุกหมัดต้องตกบนบีต: `snap(t) = phase + ceil((t-phase)/beat)*beat`

### 3. เอนจิน (ดูต้นแบบใน repo)
- `index.html` มี canvas + ฟอนต์ Noto Sans Thai + `window.READY` · ไฟล์ฉากตั้ง `window.draw(t)`, `window.TEND`, `window.SFX`, `window.DUCK`
- ตัวละคร = โครงกระดูก (สะโพก คอ หัว แขนขา 2 ท่อน) มุมสัมบูรณ์ · วาดเป็นเส้นหนามีขอบดำ · หุ่นยักษ์ใช้โครงเดิมใส่กล่องเกราะ
- ฉากเล่าเรื่องเขียนเป็นฟังก์ชันแยก · ฉากต่อสู้ใช้เครื่องยนต์กลางตัวเดียว (ดู `film2.js`) ที่รับ cast, ตำแหน่ง, เหตุการณ์ แล้วสร้างท่า มุมกล้อง ป้ายชื่อเอง
- ระบบการเคลื่อนไหว v2: ดูตัวเลขทั้งหมดใน `references/motion-rules.md`

### 4. เสียง
- เสียงหมัด/โลหะใช้ของจริง Kenney Impact Sounds (CC0) ซ้อนเบสสังเคราะห์และหาง noise · ฉากเล่าเรื่องใช้เสียงสังเคราะห์ numpy ได้
- ลดเพลง -6 dB ใต้ฮิตหนัก, -10 dB ระเบิดใหญ่ (attack 5 ms, release 400 ms) · วางหัวเสียงตรงเฟรมที่หมัดสัมผัส
- ต้นแบบ: `sfx4.py` (ทั้งเรื่อง) ใน repo · ห้ามใช้ BBC Sound Effects · Sonniss GDC ใช้ได้แต่ห้ามเอาไปเทรน AI

### 5. เรนเดอร์และตรวจ
- `PAGE=x.html OUT=part.mp4 F0=<frame> F1=<frame> python scripts/render.py full` · ภาพนิ่ง: `python scripts/render.py preview <t...>`
- แบ่งเรนเดอร์ขนานหลายก้อน **ตัดที่รอยตัดฉากเท่านั้น** (กล้องแบบ smoothing มี state) แล้ว `ffmpeg -f concat -c copy`
- ดูภาพตัวอย่างก่อนเรนเดอร์เต็มทุกครั้ง (เรียงเป็น contact sheet ด้วย PIL)
- ตรวจ: จำนวนเฟรมครบ, timestamp ต่อเนื่องที่รอยต่อ, `ebur128` ได้ -14 LUFS และ true peak ≤ -1.5 dBTP, เปิดเฟรมที่ดูแปลกดูจริงก่อนสรุป
- สิ่งที่ส่งให้ผู้ใช้เลือกปรับ: ทำคลิปทดสอบ 20 วิ + วิดีโอเทียบก่อน/หลัง ก่อนเรนเดอร์ทั้งเรื่องใหม่

## รีลแนวตั้งแบบโมชันกราฟิก (ตัวหนังสือ ไม่มีฉากต่อสู้)
ใช้เอนจินเดียวกัน (`draw(t)` + `render.py` ด้วย `VW=1080 VH=1920`) แต่กฎจังหวะคนละชุด อ่าน `references/motion-graphics.md` ก่อนเขียน
- ช็อตสั้น 0.25–1.5 วิ บนตารางบีต · 1 ช็อต 1 คำ · เปลี่ยนสีพื้นทุกช็อต · ของเลื่อนออกก่อนตัด
- คำเด้งทีละคำ ห่าง 0.10–0.13 วิ เกินขนาดจริง 9% แล้วนิ่งใน 0.2 วิ (ต้นแบบ `fx()` ใน `$PROJECTS/ai-week-reel/fxlib.js` เด้งทีละกลุ่มอักษร ยังไม่ได้ปรับเป็นทีละคำ)
- ฟังก์ชันจังหวะพร้อมใช้: `scripts/motionlib.js` (`ML.pop`, `ML.expoOut/expoIn`, `ML.stagger`, `ML.life`) คัดลอกไปไว้ข้าง `reel.html` แล้วใส่ `<script src>` · คำไทยส่งเป็น array ที่แบ่งเอง
- เสียง: ทุกจุดตัดมีหัวเสียงบนเฟรมเดียวกัน + ติ๊กรับทุกคำที่เด้ง · จุดลงหนักใช้ riser → เงียบ 0.15–0.4 วิ → boom
  สังเคราะห์ด้วย `python scripts/sfxsynth.py mix events.json sfx.wav <ยาว>` แล้วผสมกับเพลงเหมือนเดิม
- ข้อมูลจริงที่คนต้องอ่าน (ตัวเลข วันที่ ชื่อหน่วยงาน) ยังต้องค้างตามกฎ 17 ตัว/วิ ตัดถี่ได้เฉพาะช็อตคำเดียว
- ช็อตแรก 1–3 ช็อตคือฮุก: หยิบแม่แบบจากคลัง `~/.claude/skills/vidcraft/references/hooks-50.md` แล้วย่อเหลือคำสำคัญ 3–6 คำให้เข้ากฎ 1 ช็อต 1 คำ (เช่นข้อ 23 "3 เลเวลของ [เรื่องนี้]" กลายเป็น 3 ช็อต) · ประโยคเต็มเก็บไว้ใช้เป็นแคปชันโพสต์

## ศึกษาคลิปต้นแบบ
ผู้ใช้ส่งลิงก์คลิปมาให้ดูเป็นแนว: `python scripts/refstudy.py <URL หรือไฟล์> <โฟลเดอร์>` (ต้องมี yt-dlp)
ได้จุดตัดภาพ ความยาวช็อต หัวเสียง ระยะเสียงกับจุดตัด riser ช่วงเงียบ ภาพย่อ และสเปกโตรแกรม
แล้วไล่ดูทีละเฟรมเฉพาะช่วงที่อยากรู้จังหวะ (`ffmpeg -ss <t> -frames:v 15` + วัดกรอบของพิกเซลตัวหนังสือ)
เก็บ **ตัวเลขจังหวะ** มาใช้ ไม่ลอกภาพ ตัวละคร หรือเสียงของเจ้าของคลิป

## กฎเนื้อหา
- บริษัทจริง: ใช้สีประจำ + มาสคอตที่ออกแบบเอง **ไม่ใช้โลโก้จริง** · ตัวละครดัง (Goku ฯลฯ) ห้ามลอก ใช้ "สไตล์" ได้
- คนจริง: วาดเป็นการ์ตูนล้อเลียนเท่านั้น + ข้อความ "ภาพล้อเลียน" บนจอ · ห้ามทำภาพเหมือนจริง
- ฝ่ายที่อ่อนไหวเชิงชาติ/กลุ่มคน: วาดเป็นหุ่น/ยาน ไม่วาดเป็นคน และไม่ทำให้เป็นตัวร้ายตรงๆ
- มุมล่างทุกฉากต่อสู้: "ตัวละครสมมติ · อิงวันออกรุ่นจริง"
