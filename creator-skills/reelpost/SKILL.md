# /reelpost: อัปคลิปและตั้งเวลาโพสต์ YouTube + Facebook

ใช้จริงครั้งแรกแบบครบสาย 17 ต.ค. 2569 กับคลิป `$WORK/tmp\usb-ai-reel` (ตั้งเวลา 12:00 แล้วขึ้นจริงตามเวลา)
ก่อนหน้านั้นโพสต์มือทีละขั้นกับคลิป Phoenix, LP 4 คลิป, Tesla และ Vector DB

## ทางหลัก: reel-bridge (ตั้งแต่ 18 ต.ค. 2569)

ไม่ต้องใช้ claude-in-chrome และไม่ต้องทำไฟล์ HEVC ต่ำกว่า 10 MB ใช้สคริปต์ Playwright ที่ `$PROJECTS/reel-bridge` (อ่าน README ของมัน)
```bash
cd $PROJECTS/reel-bridge
node yt-upload.mjs <proj> --schedule "YYYY-MM-DD HH:MM"    # หรือ --now
node fb-upload.mjs <proj> --schedule "YYYY-MM-DD HH:MM"    # หรือ --now
```
- ยังทำขั้น 0 (เช็กตารางและแนะนำเวลา) เหมือนเดิม และโพสต์เฉพาะเมื่อผู้ใช้สั่ง
- ถ้าสคริปต์ล้ม ดู `shots/*-fail.png` ก่อน ถ้าล้มหลังกดปุ่มสุดท้าย ห้ามรันซ้ำจนกว่าจะเช็กใน Studio/Business Suite
- เซสชันหลุด: `node login.mjs` ให้ผู้ใช้ล็อกอินเอง
- ใช้จริงครั้งแรก 19 ต.ค. 2569 (Waiting for the End): ผู้ใช้สั่ง "โพสต์ YouTube ก่อนแต่ยังไม่เผยแพร่" → `yt-upload.mjs --private` แล้วผู้ใช้ตั้งเวลาเองใน Studio จากนั้นสั่ง "ปล่อย Facebook เวลาเดียวกัน" → อ่านเวลาจากหน้าแก้ไขวิดีโอ (เช็กว่าเขตเวลาเป็น GMT+0700) แล้ว `fb-upload.mjs --schedule` เวลาเดียวกัน
- หลังโพสต์ทุกครั้ง เช็กผลจริงในหน้าเว็บ ไม่เชื่อแค่ JSON ของสคริปต์: รอบแรก YouTube บันทึกเป็น Unlisted ทั้งที่เลือก Private (แก้มือแล้ว และสคริปต์ตรวจซ้ำให้แล้ว) ส่วน Facebook สคริปต์ประกาศเสร็จตอนยังขึ้น "กำลังกำหนดเวลาโพสต์ของคุณ" ดูรายการได้ด้วย `debug/fb-find.mjs` และ `debug/yt-row.mjs "<ชื่อ>"`
- 19 ต.ค. 2569 (Numb) `yt-upload.mjs --schedule` ค้างเป็น Draft สองรอบ เพราะหลังกด Schedule ขึ้นกล่อง "We're still checking your content" ที่ต้องกด Got it แก้สคริปต์ให้กดแล้ว (รอบที่สามขึ้น "กล่องตรวจเนื้อหา: กด Got it" และสถานะจริง Scheduled) ถ้ายังค้าง Draft ให้ลบด้วย `yt-delete-draft.mjs "<ชื่อ>"` แล้วอัปใหม่
- อ่านวันเวลาโพสต์ที่ตั้งไว้บน Facebook: สคริปต์อ่านข้อความไม่ได้ ใช้ภาพหน้าจอ `business.facebook.com/latest/posts/scheduled_posts` แบบเต็มหน้า (viewport 1600x2400) แทน
- ขั้นตอนผ่านเบราว์เซอร์ด้านล่างเก็บไว้เป็นทางสำรอง

## ก่อนเริ่ม

- **การโพสต์คือการเผยแพร่สู่สาธารณะ** ทำเมื่อผู้ใช้สั่งในเทิร์นนั้นเท่านั้น ถามวันเวลาถ้าไม่ได้บอก ("พรุ่งนี้" ให้นับจากเวลาที่ผู้ใช้พิมพ์ ถ้าเลยเที่ยงคืนระหว่างทำงานให้บอกวันที่ชัด ๆ)
- คลิปที่โพสต์แล้วไม่ตามแก้ (ผู้ใช้สั่ง 16 ต.ค. 2569) จึงต้องผ่านขั้นตรวจของสกิลที่ทำคลิปให้ครบก่อน โดยเฉพาะคำที่ถอดเสียงไม่ตรงบทต้องแก้แล้ว
- ต้องมีในโฟลเดอร์โปรเจกต์: คลิปเสร็จ, `cover.jpg` (สกิล `/clipcover`), `youtube.txt` (TITLE + DESCRIPTION), `caption.txt` (Facebook)
- บอกผู้ใช้ทุกครั้งว่ายังไม่มีใครฟังเสียง และถ้าเสียงพากย์มาจาก Lumina เครดิตฟรีห้ามใช้เชิงพาณิชย์ ขณะที่เพจ Facebook เปิดการสร้างรายได้ไว้เป็นค่าของเพจ

## 0. เช็กตารางและแนะนำวันเวลา (ทุกครั้ง ผู้ใช้สั่ง 17 ต.ค. 2569)

ทำก่อนอัปทุกครั้ง แม้ผู้ใช้บอกเวลามาแล้ว ถ้าชนกับคลิปอื่นให้เตือนและเสนอเวลาอื่น แล้วทำตามที่ผู้ใช้ยืนยัน
1. YouTube: เปิด `https://studio.youtube.com/channel/<YOUR_CHANNEL_ID>/videos/short` แล้วอ่านแถว
   `[...document.querySelectorAll('ytcp-video-row')].map(r=>['#video-title','.tablecell-visibility','.tablecell-date','.tablecell-views'].map(s=>r.querySelector(s)?.innerText.trim()))`
   แถวที่ visibility เป็น "Scheduled" คือคลิปที่ตั้งเวลาไว้ (หน้านี้บอกแค่วันที่ เวลาดูจากความจำของโปรเจกต์)
2. Facebook: `https://business.facebook.com/latest/posts/scheduled_posts` แถวที่มีวันเวลา และ `published_posts` ดูว่าวันนี้ลงไปแล้วกี่คลิป
3. แนะนำ: วันละ 1 คลิป ห่างจากคลิปก่อนหน้าอย่างน้อยราว 20 ชั่วโมง ช่วง 19:00 ถึง 20:30
   - ที่มา (17 ต.ค. 2569): YT Analytics > Audience > "When your viewers are on YouTube" เข้มสุด 18:00 ถึง 21:00 ทุกวัน
   - 15 ต.ค. ลงคลิป LP 4 คลิปภายใน 1.5 ชั่วโมง FB reach ต่างกัน 89 ถึง 10,649 และ YT 66 ถึง 1,634 แพลตฟอร์มดันทีละคลิป
   - FB มีปุ่ม "เวลาที่ใช้งาน" ในช่องกำหนดเวลา ใช้ดูช่วงที่ผู้ติดตามออนไลน์ (ยังไม่ได้เปิดดู)
4. รายงานเป็นตารางสั้น: คลิปที่ตั้งเวลาไว้แล้ว · ช่องว่างที่แนะนำ · เหตุผล

## 1. ทำไฟล์อัป

```bash
python <skill_dir>/scripts/make_upload.py <proj>/<ชื่อ>_9x16.mp4 <proj>/cover.jpg   # run_in_background
```
ได้ `<ชื่อ>_youtube.mp4` (ปกเป็นเฟรมแรก 0.5 วิ), `<ชื่อ>_youtube_hevc.mp4`, `<ชื่อ>_fb_hevc.mp4`
- `file_upload` ของ claude-in-chrome รับรวมไม่เกิน 10 MB ต่อครั้ง สคริปต์คำนวณบิตเรตตามความยาวให้ไฟล์ราว 9.3 MiB แล้วเช็กขนาดจริง (คลิป 127 วิได้ 497k)
- HEVC ช้า คลิป 2 นาทีใช้ราว 15 นาที อย่าทำงานใน Chrome ระหว่างเข้ารหัส CPU เต็มแล้วหน้า YouTube ค้าง
- ระหว่างรอ เตรียมข้อความ `youtube.txt` กับ `caption.txt`

## 2. YouTube Shorts

1. `tabs_context_mcp` แล้วเปิด `https://www.youtube.com/upload` เช็กชื่อช่องว่าเป็น "โกสินทร์ต้องบินได้"
2. `find` หา file input ในหน้าต่าง Upload videos แล้ว `file_upload` ไฟล์ `_youtube_hevc.mp4`
3. รัน `scripts/yt_details.js` ใน `javascript_tool` (แทน TITLE กับ DESC ก่อน) ต้องได้ `titleOk: true` และ radio ที่ติ๊กครบสามตัว
   - ช่องตั้งค่าเริ่มต้นไว้เป็นชื่อ "Kosin Finsure 「Official Music」" ต้องแทนทุกครั้ง ต่อบรรทัด "สนับสนุนผลงาน" กับลิงก์ join ไว้ท้ายคำอธิบาย
4. ปก: `find` หา file input ใต้ Thumbnail แล้ว `file_upload` ไฟล์ `cover.jpg`
5. Next ไปหน้า Ad suitability: ติ๊ก "None of the above" (เฉพาะเมื่อคลิปไม่มีเนื้อหาหมวดใดจริง ๆ) แล้วกด Submit rating
6. Next ผ่าน Video elements และ Initial check ไปหน้า Visibility
7. เปิดหัวข้อ Schedule:
   - **กด Time zone แล้วเลือก "(GMT+0700) Local Time" ก่อน** ค่าเริ่มต้นไม่ใช่เวลาไทย วันที่ขึ้นเป็นของวันก่อน
   - พอเปลี่ยนเขตเวลาแล้วปฏิทินจะเลื่อนวันเอง ต้องเลือกวันใหม่
   - เวลาเลือกจากรายการ (`find` หา "12:00 PM")
   - ซูมดูว่าได้ "วันที่ · เวลา · (GMT+0700)" ครบ แล้วกด Schedule → Got it
8. เก็บลิงก์ shorts จากกล่อง "Video scheduled" (ข้อความ "Your video will be set to public on ...")

## 3. Facebook Reels

1. เปิด `https://business.facebook.com/latest/reels_composer`
2. "โพสต์ไปที่" เลือกทั้งเพจและ IG kosinbindai ไว้ เปิดเมนูแล้วเอา IG ออก ให้เหลือเพจโกสินทร์ต้องบินได้
3. วิดีโอ: รัน `scripts/capture_file_input.js` (ห้ามคลิกปุ่ม "เพิ่มวิดีโอ" ตรง ๆ จะเปิดหน้าต่างเลือกไฟล์ของระบบ) แล้ว `find` หา file input และ `file_upload` ไฟล์ `_fb_hevc.mp4`
4. ภาพขนาดย่อ: แท็บ "อัพโหลดภาพ" แล้วรันสคริปต์เดิมโดยตั้ง `BUTTON_TEXT` เป็น `/^(อัพโหลดภาพ|อัปโหลดภาพ)$/` แล้วอัป `cover.jpg`
5. คำบรรยาย: คลิกในช่อง "คำอธิบาย" แล้วใช้ `computer` action `type` พิมพ์ทั้ง `caption.txt`
   - **ห้ามใช้ `execCommand('insertText')` หรือยิง paste** ตัวแก้ข้อความทำย่อหน้าแรกหายและเอาแฮชแท็กขึ้นมาแทน แล้วล้างไม่ออก
   - หลังวิดีโอประมวลผลเสร็จ ช่องคำบรรยายอาจหายจากหน้า ให้คลิกขั้น "สร้าง" ด้านบนแล้วจะกลับมา
   - พิมพ์แฮชแท็กท้ายสุดแล้วมีกล่องแนะนำค้าง คลิกที่ว่างปิด อย่ากด Enter
   - เช็กด้วย JS ว่า `innerText` ขึ้นต้นถูก และคำสั่งหรือขีดพิเศษยังอยู่ครบ
6. ถัดไป (แก้ไข) ถัดไป (แชร์):
   - "ตัวเลือกการกำหนดเวลา" กด "กำหนดเวลา" วันที่ถูกตั้งเป็นวันนี้ เขตเวลา Asia/Jakarta (UTC+7 เท่าเวลาไทย)
   - ชั่วโมงกับนาทีเป็น spinbutton: คลิกแล้ว `type` เช่น 12 และ 00 (เป็นแบบ 24 ชั่วโมง)
   - **สวิตช์ "Share to สตอรี่บน Facebook" เปิดเป็นค่าเริ่มต้น** ปิดแล้วเลือก "อย่าแชร์โพสต์นี้" (ไม่ใช่ "หยุดแชร์โพสต์ทั้งหมด" ที่เปลี่ยนค่าของเพจ) แล้ว Confirm
   - ไม่แตะสวิตช์สร้างรายได้ของเพจ
   - กด "กำหนดเวลา" ต้องขึ้นกล่อง "กำหนดเวลาคลิป Reels แล้ว"
7. ตรวจที่ `https://business.facebook.com/latest/posts/scheduled_posts` ว่ามีโพสต์พร้อมวันเวลาถูกต้อง

## 4. หลังโพสต์

- ปิดแท็บที่เปิดเอง
- บันทึกลิงก์ YouTube วันเวลา และค่าที่ใช้ลงความจำของโปรเจกต์ ใส่ว่า "โพสต์แล้ว ห้ามตามแก้"
- หลังถึงเวลา เช็กว่า YouTube ขึ้นจริงด้วย `curl "https://www.youtube.com/oembed?url=<ลิงก์ shorts>&format=json"` (200 พร้อมชื่อคลิปคือเป็นสาธารณะแล้ว)
- ลิงก์ Facebook /reel/<content_id> จากหน้าจัดการมักเปิดไม่ได้ ต้องหาลิงก์จริงจากหน้าเพจ
