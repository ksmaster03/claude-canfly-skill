## 3. อัดจอ

1. `node login.mjs` ให้ผู้ใช้ล็อกอิน
2. `node probe.mjs` หา URL จริงก่อน เดาไม่ได้ เช่น Scheduled อยู่ที่ `claude.ai/scheduled-task` ส่วน `/scheduled` ขึ้น 404
3. แก้ขั้นตอนใน `record.mjs` แล้วรัน วิดีโอจะอยู่ใน `rec/video/*.webm` และ event ใน `rec/events.json`
4. หาเฟรมสเลทสีแดงในวิดีโอ แล้วตั้ง `SLATE_OFFSET` = เวลา event slate ลบเวลาเฟรมแดง

กับดัก:
- Playwright **ไม่อัดเคอร์เซอร์** Remotion วาดให้เองจาก event
- `text=ชื่อ` ไปจับชื่อแชทใน sidebar ได้ ถ้าเจอให้แก้พิกัดใน `FIX` ของ `retime.py`
- ห้ามผสม css กับ `text=` ใน selector เดียวกัน Playwright จะ parse error
- dropdown ที่กดเลือกไม่ติดจะเปิดค้าง แล้วบังฉากถัดไป ให้ใช้ภาพช่วงก่อนเมนูเปิด

## 4. เบลอข้อมูลส่วนตัว (ทำก่อนขั้นอื่นทุกครั้ง)


## 5. พากย์เสียง Gemini

```bash
python tts_line.py <id> script/line_<id>.txt <beat>    # ทีละประโยค เว้นคำขอละ 25 วิ
```

- คีย์อ่านจาก ไฟล์ที่ตั้งใน env `GEMINI_KEY_FILE` ในหน่วยความจำ **ห้ามพิมพ์ค่าคีย์ออกมา** (auto mode บล็อก) ตอนนี้ใช้ได้ป้าย `Gemini VO1`
- Gemini คืน PCM ดิบ 24k ต้องห่อ header wav เอง
- **รวมหลายประโยคในคำขอเดียวไม่น่าเชื่อถือ** มี 2 จาก 3 ครั้งที่อ่านจบประโยคแรกแล้วเงียบยาว 45 วิ ถ้าจำเป็นต้องรวม ต้องมีตัวตรวจว่าอ่านครบก่อนตัด
- ตัดหัวท้ายด้วย `silenceremove` เกณฑ์ตายตัว −40 dB ห้ามใช้เกณฑ์เปอร์เซ็นไทล์ (พังเมื่อไฟล์มีความเงียบยาว)
- ย่อช่องเงียบกลางประโยคที่ยาวกว่า 0.5 วิ ให้เหลือ 0.34 วิ (Gemini หยุดกลางประโยคได้ถึง 2.9 วิ)
- **ตัดก้อนด้วยช่องเงียบที่ยาวที่สุดใช้ไม่ได้** ต้องใช้ whisper เทียบตัวอักษรสะสม (`resplit.py`)

**ตรวจทุกไฟล์ด้วยการถอดเสียง** ถ้าคำไหนเพี้ยน ให้ทำ control test ด้วย edge-tts อ่านประโยคเดียวกัน
ถ้า whisper ฟัง edge-tts ถูก แปลว่า Gemini อ่านผิดจริง ต้องเปลี่ยนคำ ถ้าฟังผิดทั้งคู่ แปลว่าแค่ whisper ฟังพลาด

## 6. ไทม์ไลน์

```bash
python timeline.py && python retime.py
```

- `GROUPS` = (ประโยค, วินาทีเริ่ม, วินาทีจบของภาพต้นฉบับ) ช่วงภาพนิ่งยืดได้ ช่วงพิมพ์หรือคลิกให้ใกล้ความเร็วเดิม
- ภาพต้องคลุมช่องหายใจท้ายกลุ่มด้วย (`span = need + GAP`) ไม่งั้นภาพจะสั้นกว่าเสียง
- ช่วงที่ยืมภาพซ้ำจากที่อื่นใส่ใน `REUSED` **ไม่งั้น mark จากตอนอัดจะไปโผล่ผิดช่วง**
- `EXTRA` เพิ่ม mark ตามเวลาประโยค มี 2 ชนิดพิเศษ
  - `type="cam"` เลื่อนกล้องอย่างเดียว ใช้กับช่วงภาพรวม (กรอบใหญ่ทำให้มืดทั้งจอ)
  - `chip="..."` ป้ายบอกที่มาของภาพ เช่น "ภาพจากแบบสำเร็จรูป ไม่ใช่งานที่เราสร้าง"
- `CTA_CLICK_OFFSET` = เวลาที่คำว่า "ติดตาม" เริ่มในประโยคปิด หาจาก whisper word_timestamps
  **ภาษาไทยแตกเป็นทีละตัวอักษร** ต้องต่อกลับเป็นข้อความก่อนค้นหา

## 7. ภาพ (Remotion)

ทิศทางที่ผ่านรีวิวแล้ว: พื้นครีม `#F3EEE4` · หมึก `#1E1A15` · รอง `#5A5147` · สีเน้นส้มดินเผา `#B24F2C` (สีเดียว) · การ์ด `#FFFDF8`
ฟอนต์หัวข้อ Trirong Bold · เนื้อหา Sarabun · หัวคลิปสูง 236 px · กล่องหน้าจอ 720x640

- **ห้ามพื้นไล่น้ำเงินไปม่วง** prom-design ห้ามทุกกรณี และเป็นสีที่ลอกจากเพจต้นฉบับ
- **ต้องซูมเข้าจุดที่พูด** ย่อทั้งจอ 1440 ลงกรอบ 720 จะอ่านไม่ออกบนมือถือ ระดับซูม: กว้างไม่เกิน 160 px ซูม 2.5 · ไม่เกิน 360 px ซูม 2.0 · ไม่เกิน 700 px ซูม 1.3 · กว้างกว่านั้นซูม 1.12
- ของกว้าง (ฟอร์ม dialog) ซูมเกิน 1.5 ป้ายด้านซ้ายจะโดนตัด
- กล้องไหลเข้าต่อเนื่องระหว่างค้างเป้า **ต้องเกิน 1 px/เฟรม** (`0.012 × วินาที`) ไม่งั้นตัววิเคราะห์ยังนับว่าภาพนิ่ง
- การ์ดที่ขยายตัวเรื่อย ๆ ต้องมีเพดาน (`min(0.025, ...)`) ไม่งั้นล้นขอบ
- **ซับไทย**: แยกคำตามช่องว่างในบท แต่ละคำใส่ `whiteSpace: nowrap` แล้ว **วางช่องว่างไว้นอก span**
  ถ้าไม่ทำ เบราว์เซอร์จะหั่นคำกลางคำ เช่น "กี่ / โมง" (`word-break: keep-all` ใช้กับไทยไม่ได้)
  ถ้าเอาช่องว่างไว้ใน span จะไม่ขึ้นบรรทัดใหม่เลย
- คำที่ยังไม่ถึงคิวใช้สี `#8A8177` ห้ามจางด้วย opacity 0.32 (วัดได้ 1.52:1 อ่านไม่ออก)
- ฉากปิดซ่อนซับ เพราะข้อความบนการ์ดซ้ำกัน ผู้ใช้ติเรื่องซับซ้ำมาแล้ว

```bash
cp script/timeline.json src/timeline.json && cp rec/screen_retimed.mp4 public/screen.mp4
npx remotion still src/index.ts Reel out/chk.png --frame=<N>          # เช็คภาพนิ่งก่อนเรนเดอร์เต็มเสมอ
npx remotion render src/index.ts Reel out/video_only.mp4 --codec=h264 --crf=18 --muted
```

**อย่าวางไฟล์ซับ `.srt` ชื่อเดียวกับคลิปไว้ข้างกัน** เครื่องเล่นจะโหลดขึ้นมาเอง ผู้ใช้จะเห็นซับสองชุด

## 8. เสียง

```bash
python sound.py && python finalize.py
```

| ชั้น | ค่า |
|---|---|
| VO | คอมเพรสแบบนุ่ม (RMS 15 ms, 3:1) ให้ระดับแต่ละก้อนเสมอกัน |
| SFX | สังเคราะห์เอง วางตอน**กราฟิกขึ้น** ไม่ใช่ตอนคัต · pop ตอนกรอบขึ้น −21 dB · click ตอนกด −12 dB · เสียงพิมพ์ช่วง type · riser + whoosh ก่อนการ์ด · click + chime ตอนกดติดตาม |
| BGM | `$MEDIA\bgm` วนต่อตรงรอยบาร์ (ค่า `bar_s` จาก `catalog.json`) ครอสเฟด 2 บาร์ · ตอนพูดเบากว่าเสียงพากย์ 21 dB · ช่วงเงียบเบากว่า 12 dB · เฟดท้าย 2.4 วิ |

กับดักที่วัดแล้ว:
- `-ac 1` ของ ffmpeg downmix โดยไม่ลดเกน พีคทะลุ +3.4 dBFS ต้องยุบเป็นโมโนใน numpy หรือใช้ `pan`
- `alimiter` บนเครื่องนี้ไม่จำกัดพีคเลย ใช้ลิมิตเตอร์ที่เขียนเองใน `sound.py`
- ลิมิตเตอร์ต้อง**ตรวจพีคบนสัญญาณขยาย 4 เท่า** ไม่งั้น wav ผ่านแต่หลัง AAC พีคขึ้นไป −1.2 dBTP
- **หยุดไล่เกนเมื่อความดังเข้าช่วง ±1 LU** ถ้าไล่ให้ถึง −14 เป๊ะ ลิมิตเตอร์จะกดเฉลี่ย 14 dB จนเสียงบี้
- `-v error` ปิด log ของ ebur128 ต้องใช้ `-hide_banner` · ต้องอ่านค่าจากบล็อก `Summary:` เท่านั้น
