# ชุด H · Creator Skills: สกิลสายครีเอเตอร์จากงานจริง

สกิล Claude Code 44 ตัวสำหรับทำคอนเทนต์ครบสาย ตั้งแต่ศึกษาคลิปของคนอื่น เขียนบท พากย์เสียง ตัดต่อ ทำปก โพสต์ขึ้นแพลตฟอร์ม ไปจนถึงทำหนังสือและขอ ISBN
ทุกตัวสรุปมาจากงานที่ทำเสร็จและปล่อยจริงช่วง ต.ค. ถึง พ.ย. 2569 หัวข้อ "กับดัก" ในแต่ละไฟล์คือจุดที่เคยพังจริง

> สกิลกลุ่มนี้เขียนสำหรับ **Claude Code** (ใช้ Bash, Edit และ Agent tools) ไม่ใช่ prompt ที่ก๊อปไปวางในแชท

## ติดตั้ง

```bash
git clone https://github.com/<your-github-user>/claude-canfly-skill.git
cp -r claude-canfly-skill/creator-skills/* ~/.claude/skills/
```

เรียกใช้ด้วย `/<ชื่อสกิล>` เช่น `/msinterview` หรือ `/clipcover`

## ตัวแปรที่ต้องตั้งเอง

path ในเครื่องผู้เขียนถูกแทนด้วยชื่อตัวแปร ให้แทนด้วย path ในเครื่องของคุณ

| ตัวแปร | คืออะไร |
| --- | --- |
| `$WORK` | โฟลเดอร์งานคลิป |
| `$PROJECTS` | โฟลเดอร์ที่เก็บเครื่องมือเสริม เช่น `reel-bridge` (ตัวอัปโหลด) `chatgpt-bridge` `suno-bridge` `lumina-bridge` |
| `$MEDIA` | คลังเพลงประกอบและ SFX |
| `$FFMPEG_BIN` | โฟลเดอร์ `bin` ของ ffmpeg |
| `$PANYA_URL` | URL เซิร์ฟเวอร์ panya ของคุณ |
| `GEMINI_KEY_FILE` | ไฟล์คีย์ Gemini TTS (ใช้โดย `techaireel`) |
| `<YOUR_CHANNEL_ID>` · `<YOUR_REF_CODE>` | ID ช่อง YouTube และรหัสแนะนำของคุณ |

**ไม่ได้รวมมาในนี้:** ตัวเชื่อมเบราว์เซอร์ (reel-bridge, chatgpt-bridge, suno-bridge, lumina-bridge) และคลังสื่อเป็นเครื่องมือแยก สกิลจะบอกว่าต้องเตรียมอะไร

## ข้อควรรู้

* ล้าง path ในเครื่อง ข้อมูลติดต่อ ID บัญชี และ hostname ส่วนตัวออกแล้ว สกิลที่ผูกกับงานลูกค้าหรือบริษัทไม่ได้รวมมา
* สกิลที่โพสต์ขึ้นแพลตฟอร์ม (`reelpost`, `song-release`) ออกแบบให้ทำเมื่อผู้ใช้สั่งเท่านั้น อย่าถอดด่านนั้นออก
* คลิปแปลเพลงใช้ภาพนิ่งจาก MV ทางการและเนื้อร้องสั้น ๆ เพื่อแปลและวิจารณ์ ช่วยลดความเสี่ยงลิขสิทธิ์แต่ไม่เป็นศูนย์ ตรวจเงื่อนไขของแต่ละแพลตฟอร์มเอง
* เครดิตฟรีของบริการ TTS บางเจ้าห้ามใช้เชิงพาณิชย์ อ่านเงื่อนไขก่อนใช้กับช่องที่สร้างรายได้
* ฟอนต์ Kanit และ Trirong ที่แถมมาเป็นสัญญาอนุญาต SIL OFL
