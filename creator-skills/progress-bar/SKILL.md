# /progress-bar แถบความคืบหน้าสีไล่เหลืองไปเขียว

ผู้ใช้ขอไว้เมื่อ 7 ต.ค. 2569 ว่าเวลาทำงานให้มีแถบความคืบหน้า สีไล่จากเหลืองไปเขียว

## หน้าตา

แถบยาว 10 ช่อง ช่องที่ทำแล้วไล่สีตามตำแหน่ง ครึ่งแรกเหลือง ครึ่งหลังเขียว ช่องที่ยังไม่ถึงเป็นสีขาว

```
🟨🟨🟨🟨🟨🟩⬜⬜⬜⬜ 60% · ขั้น 3/5 · เรนเดอร์ภาพ
```

ตามด้วยเปอร์เซ็นต์ ลำดับขั้น และชื่อขั้นที่กำลังทำ คั่นด้วยจุดกลาง

## สร้างแถบ

ใช้สคริปต์นี้เพื่อให้หน้าตาเหมือนกันทุกครั้ง แล้ววางผลลัพธ์เป็นบรรทัดแรกของข้อความสถานะ

```bash
python "~/.claude/skills/progress-bar/bar.py" <ขั้นที่เสร็จแล้ว> <จำนวนขั้นทั้งหมด> --label-file <ไฟล์ข้อความชื่อขั้น>
```

ชื่อขั้นเป็นภาษาไทยให้ส่งผ่านไฟล์ (`--label-file`) เพราะ Git Bash กลืนอักขระไทยใน argument
ถ้าไม่อยากเรียกสคริปต์ ประกอบเองได้ตามกติกา: `filled = round(10 * done / total)` ช่องที่ 1 ถึง 5 ใช้ 🟨 ช่องที่ 6 ถึง 10 ใช้ 🟩 ที่เหลือใช้ ⬜

## ใช้เมื่อไร

- งานที่มี 3 ขั้นขึ้นไป งานที่รันเบื้องหลัง หรืองานที่ส่ง subagent หลายตัว
- แสดงตอนเริ่มงาน (0%) พร้อมรายการขั้น ทุกครั้งที่ส่งข้อความสถานะ และตอนจบ (100%)
- ไม่ต้องแสดงกับคำถามที่ตอบได้ในข้อความเดียว หรืองานขั้นเดียว

## กติกาความถูกต้อง

- เปอร์เซ็นต์ต้องมาจากขั้นที่ **เสร็จและตรวจแล้วจริง** หารด้วยจำนวนขั้นทั้งหมด ห้ามประมาณจากความรู้สึก
- ขั้นที่รันอยู่แต่ยังไม่เสร็จ ไม่นับเป็นเสร็จ ให้บอกเป็นชื่อขั้นที่กำลังทำแทน
- ถ้าจำนวนขั้นเปลี่ยนกลางทาง (เจองานเพิ่ม หรือขั้นไหนถูกตัด) ให้บอกผู้ใช้หนึ่งบรรทัดว่าเปลี่ยนจากกี่ขั้นเป็นกี่ขั้น เพราะแถบจะถอยหรือกระโดด
- ขั้นที่ล้มเหลวหรือถูกพักรอผู้ใช้ ไม่นับเป็นเสร็จ และห้ามขึ้น 100% จนกว่าทุกขั้นจะเสร็จหรือผู้ใช้สั่งตัดขั้นนั้น
- แถบไม่แทนเนื้อหารายงาน ยังต้องบอกผลและสิ่งที่ตรวจแล้วตามปกติ

## ข้อจำกัด

ข้อความในแชตเป็น markdown ใส่สีตัวอักษรไม่ได้ จึงใช้อีโมจิสี่เหลี่ยมสองสี การไล่สีจึงมีสองระดับ (เหลืองแล้วเขียว) ไม่ใช่การไล่เฉดต่อเนื่อง
ห้ามใช้แถบนี้ในเอกสาร หน้าเว็บ หรือสื่อที่ทำให้คนอื่น ใช้เฉพาะข้อความสถานะถึงผู้ใช้
