## ลำดับงาน

1. **ค้นข้อมูลเพลงจากแหล่งจริง** (Wikipedia ของเพลง บทสัมภาษณ์) จดลิงก์ไว้ใส่คำบรรยาย ปีอัลบั้ม ชื่อเดิม ผู้กำกับ MV สิ่งที่ศิลปินพูดถึงเพลง ห้ามแต่ง ถ้าคำพูดของศิลปินหาแหล่งยืนยันได้แค่ทางอ้อม ให้ใช้คำว่า "เคยเล่าว่า" และบอกผู้ใช้
   - **ยืนยันเนื้อร้องทุกท่อนที่จะยก** จากซับของ Lyric Video ทางการของวง (`python -m yt_dlp --skip-download --write-auto-subs --sub-langs "en.*" --sub-format vtt <url>`) ยกเฉพาะท่อนที่ซับตรง ท่อนที่ซับถอดไม่ชัดไม่ใช้ (คลิป Waiting for the End 19 ต.ค. 2569 ตัดท่อน "trade this life for something new" ออกเพราะยืนยันไม่ได้) เว็บเนื้อเพลงมักโหลดไม่ขึ้นใน WebFetch
2. **หา MV ทางการ** `python -m yt_dlp --flat-playlist --print "%(id)s | %(channel)s | %(title)s" "ytsearch5:<เพลง> Official Music Video <ศิลปิน>"` เลือกช่องของศิลปินเอง แล้ว `python -m yt_dlp -f "bv*[height<=1080][ext=mp4]+ba[ext=m4a]/b[ext=mp4]" -o "mv.%(ext)s" <url>` ลง `<proj>/src` ทำ contact sheet `ffmpeg -i <video> -vf "fps=1/3,scale=240:-1,tile=10x7" -frames:v 1 sheet.jpg`
3. **เขียน `clip.json`** ตามหัวข้อ "clip.json" ฉากละหนึ่งคนพูด บรรทัดถามสั้น บรรทัดตอบไม่เกินราว 14 วินาที (ราว 140 ตัวอักษร) รวมราว 1,500 ตัวอักษรได้ราว 160 วินาที
4. **เขียนบท Lumina ทีละบรรทัด** `python <skill_dir>/scripts/make_vo_lines.py <proj>` แล้วตรวจ `python ~/.claude/skills/lumina-script/scripts/lint.py <ไฟล์>` ทุกไฟล์
5. **ตั้งชื่อเสียง** เขียนไฟล์ UTF-8 `<proj>/voice/L.txt` = `ลินดา` และ `<proj>/voice/K.txt` = `โกสินทร์3` (เขียนด้วย Write หรือ python ห้ามส่งไทยผ่าน argument ของ Git Bash) ทดสอบชื่อด้วย `--dry` ก่อน
6. **สร้างเสียง** ลองบรรทัดแรกก่อน `bash <skill_dir>/scripts/gen_vo.sh <proj> 01` ผ่านแล้วรันที่เหลือเบื้องหลัง `bash <skill_dir>/scripts/gen_vo.sh <proj>` (ราว 100 เครดิตต่อบรรทัด 20 บรรทัดใช้ราว 1,800 เครดิต)

8. **ตรวจคำเพี้ยน** `cat <proj>/vo/lines/*_?.txt > <proj>/vo_lumina.txt` แล้ว `python ~/.claude/skills/lumina-script/scripts/asr_check.py <proj>/vo/voice.wav <proj>/vo_lumina.txt "<ชื่อเพลง,ชื่อคน,...>" <proj>/clip.json`

## clip.json

ตัวอย่างเต็มที่ใช้จริง: `references/example-clip.json`

```json
{ "head": 0.4, "tail": 1.4,
  "show": [["ลีฟเอาท์ออลเดอะเรสต์", "Leave Out All the Rest"], ["เอ็มวี", "MV"]],
  "lines": [
    { "id": 6, "tag": "@อารมณ์=ซาบซึ้ง @ความเร็ว=0.8", "pause": {"1": "500ms"},
      "scene": { "type": "mv", "who": "K", "img": "frames/f04.jpg", "kicker": "ท่อนแรก",
                 "lyric": "When my time comes / Forget the wrong that I've done",
                 "th": "เมื่อถึงเวลาของผม ช่วยลืมเรื่องผิดที่ผมเคยทำ" },
      "say": "*เมื่อถึงเวลาของผม*|*ช่วยลืมเรื่องผิด*|ที่ผมเคยทำ|เหมือนคนกำลังเขียนจดหมาย" } ] }
```

- `who` ต้องอยู่ใน `scene` (ตัวเรนเดอร์ส่งต่อแค่ scene) `L` = ลินดา ป้ายสีชมพู `K` = โกสินทร์ ป้ายสีเหลือง สีเน้นในซับเปลี่ยนตามคนพูด
- `tag` แท็กอารมณ์หน้าบรรทัด `pause` ใส่ `@หยุดพัก` หลังวลีที่ระบุ (นับจาก 0) ดูชื่ออารมณ์ที่ใช้ได้ใน `lumina-script/references/tags.md`
- เส้นอารมณ์ที่ใช้แล้วได้ผล: ลินดา อยากรู้อยากเห็น สงสัย เศร้า คาดหวัง ทึ่ง โศกเศร้า มีความสุข · โกสินทร์ ใจเย็น ครุ่นคิด ซาบซึ้ง เห็นอกเห็นใจ ถวิลหา เชื่อใจ มุ่งมั่น ใส่ `@ความเร็ว=0.8` ตอนแปลท่อนสำคัญและข้อคิด
- **ฉาก `mv`** ช่อง: `img` (ต้องมี), `kicker` ป้ายเล็ก, `head` ข้อความใหญ่ (5 ตัวอักษรหรือน้อยกว่า เช่นปี กลายเป็นตัวเลขยักษ์สีเหลือง), `sub`, `chips` 1 ถึง 2 ป้าย, `lyric` เนื้อร้องอังกฤษ (` / ` ขึ้นบรรทัดใหม่), `th` คำแปลไทย, `points` ข้อคิด 2 ข้อ, `focus` จุดกึ่งกลางครอป 0 ถึง 100
  - ภาพคมกว้าง 1080x610 อยู่ที่ y 310 ถึง 920 ซูมเข้าช้า 4% ต่อฉาก ภาพเดียวกันเบลอเป็นพื้นหลังเต็มจอ ข้อความอยู่ y 980 ถึง 1310 ซับอยู่บน ป้ายคนพูดอยู่ y 92
  - ภาพกว้างเห็นแค่ราว 57% ของความกว้างภาพ MV ต้องตั้ง `focus` ให้คนหรือของสำคัญอยู่กลาง
  - ฉากปิดใช้ `cta` ของเอนจินเดิม (ใส่ `who` ได้)
- บรรทัดถามของลินดาใช้ภาพเดียวกับบรรทัดตอบถัดไป ภาพจะได้ไม่เปลี่ยนถี่เกิน

## โครงบทที่ใช้แล้วได้ผล (20 บรรทัด ราว 160 วินาที)

1. ลินดาเปิด: ฟังแล้วขนลุกแต่แปลไม่ออก → โกสินทร์: อัลบั้ม ปี และที่มาเด่น ๆ (เช่นอยู่ในหนังเรื่องไหน)
2. ชื่อเพลงแปลว่าอะไร → แปลตรงตัว + ความหมายจริง
3. ท่อนแรก → แปล + ภาพเปรียบ
4. ลินดาสะท้อนอารมณ์ → โกสินทร์เล่าสิ่งที่ศิลปินพูดถึงเพลง + ข้อเท็จจริงเล็ก ๆ (ชื่อเดิมของเพลง)
5. ท่อนฮุก → แปล + ความหมาย
6. ท่อนที่ชอบที่สุด → แปล + เชื่อมกับชีวิตคนดู
7. ท่อนที่เข้าใจผิดได้ง่าย → แปล + อธิบายว่าไม่ได้ประชด
8. ทำไม MV เป็นแบบนั้น → สิ่งที่ผู้กำกับพูด
9. (ถ้าศิลปินเสียชีวิตแล้ว) ลินดาพูดถึงอย่างเคารพ → ข้อคิด 2 ข้อ ห้ามพูดถึงวิธีการตาย
   - **ห้ามใส่สายด่วน 1323 หรือเบอร์โทรใด ๆ ทุกคลิป** (ผู้ใช้สั่งย้ำ 19 ต.ค. 2569: "ไม่ต้องโปรโมทให้โทร 1323 หรือเบอร์อะไรทั้งนั้น นี่คือการทำคลิปแปลเพลง") ทั้งในเสียงพากย์ บนจอ ปก และข้อความโพสต์
   - เพลงที่ฟังแล้วหนักหรือไม่สบายใจ หน้าที่ของคลิปคือ**ให้กำลังใจคนฟัง** เช่น โกสินทร์พูดตรง ๆ ว่าถ้าใครรู้สึกแบบในเพลงอยู่ คุณไม่ได้อยู่คนเดียว ค่อย ๆ ไปทีละวัน ใส่ไว้ในบรรทัดข้อคิดหรือบรรทัดปิด ไม่ต้องแยกเป็นฉากประกาศ
10. ลินดาปิด: ท่อนไหนโดนใจ คอมเมนต์ + กดติดตาม
