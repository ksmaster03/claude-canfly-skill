# แท็กทั้งหมดของ Lumina TTS

อ่านจากโค้ดหน้าเว็บและทดสอบสร้างเสียงจริงเมื่อ 11 ต.ค. 2569 ถ้าหน้าเว็บอัปเดต ให้เช็กเมนูแทรกแท็กในช่องข้อความอีกครั้ง

## กฎการเขียนแท็ก
- แท็กต้องมีเว้นวรรคหน้าและหลัง ห้ามติดกับคำหรือแท็กอื่น
- แท็กที่มีค่าเขียน `@ชื่อ=ค่า` ไม่มีเว้นวรรครอบเครื่องหมายเท่ากับ
- ตัวนับของหน้าเว็บไม่นับแท็กเป็นตัวอักษร แต่ให้ถือเพดาน 5,000 รวมแท็กไว้ก่อน
- เขียนแท็กเป็นภาษาไทยหรืออังกฤษก็ได้ หน้าเว็บแปลงให้ก่อนส่ง

## อารมณ์ `@อารมณ์=<ชื่อ>`

| กลุ่ม | ชื่อที่ใช้ได้ |
|---|---|
| กลาง | ปกติ |
| สุข ตื่นเต้น | มีความสุข ตื่นเต้น กระตือรือร้น ปิติยินดี อิ่มเอิบใจ ชัยชนะ |
| ทึ่ง สงสัย | ทึ่ง ประหลาดใจ อยากรู้อยากเห็น คาดหวัง ลึกลับ สงสัย |
| นิ่ง อบอุ่น | พึงพอใจ สงบ เยือกเย็น ใจเย็น ซาบซึ้ง รักใคร่ เชื่อใจ เห็นอกเห็นใจ เจ้าชู้ |
| โกรธ รังเกียจ | โกรธ บ้าคลั่ง เกรี้ยวกราด หงุดหงิด ปั่นป่วน ถูกคุกคาม ขยะแขยง ดูถูก อิจฉา |
| ประชด | ประชดประชัน เสียดสี ล้อเล่น |
| เศร้า | เศร้า หดหู่ โศกเศร้า ผิดหวัง เจ็บปวด รู้สึกผิด ถูกปฏิเสธ ถวิลหา อาลัยอาวรณ์ ขอโทษ |
| หมดแรง ลังเล | เบื่อหน่าย เหนื่อย ลังเล ไม่มั่นคง สับสน ยอมจำนน ห่างเหิน |
| กลัว | วิตกกังวล ตื่นตระหนก ตื่นตกใจ กลัว |
| มั่นคง | ภูมิใจ มั่นใจ ครุ่นคิด มุ่งมั่น |

## เสียงที่ไม่ใช่คำพูด (ไม่มีค่า)

| ไทย | อังกฤษ | เสียงที่ได้ |
|---|---|---|
| `@หัวเราะ` | `@laughter` | เสียงหัวเราะ |
| `@นึกคำ` | `@finding-words` / `@uh` | เอ่อ (ถอดเสียงแล้วได้ยินจริง) |
| `@คิดทบทวน` | `@thinking-pause` / `@um` | อืมม |
| `@ครุ่นคิด` | `@pondering` / `@hmm` | ฮึมม (ถอดเสียงแล้วได้ยินเป็น "อืม") |
| `@นึกออก` | `@realization` / `@ah` | อา |
| `@ประหลาดใจ` | `@surprise` / `@oh` | โอ้ |

ระวังชื่อซ้ำ: `@ประหลาดใจ` คือเสียง "โอ้" ส่วน `@อารมณ์=ประหลาดใจ` คือน้ำเสียง และ `@ครุ่นคิด` คือเสียง "ฮึมม" ส่วน `@อารมณ์=ครุ่นคิด` คือน้ำเสียง ใช้คู่กันได้

## จังหวะและระดับ

| แท็ก | ค่าที่หน้าเว็บให้เลือก | หมายเหตุ |
|---|---|---|
| `@หยุดพัก=` | `200ms` `500ms` `1s` | ค่าอื่นยังไม่ได้ทดสอบ |
| `@ความเร็ว=` | `0.8` `1.0` `1.2` `1.5` | ตั้งกลับ `1.0` เองหลังใช้ |
| `@ระดับเสียง=` | `0.5` `1.0` `1.5` | 0.5 ใกล้เสียงกระซิบ ตั้งกลับ `1.0` เองหลังใช้ |
| `@สะกดคำ=` | ข้อความที่ให้อ่านทีละตัว | สำหรับรหัสหรือเบอร์โทร |

## สิ่งที่ไม่มี
- ไม่มีแท็กหายใจ ถอนหายใจ ไอ กระแอม หรือกระซิบ
- คำว่า "เฮ้อ" "ฮู่ว" "อ่า" "เอ่อ" ที่พิมพ์ลงไปถูกอ่านเป็นคำพูดเต็มเสียง (วัดแล้วดังเท่าคำปกติ) ไม่ใช่เสียงลมหายใจ
