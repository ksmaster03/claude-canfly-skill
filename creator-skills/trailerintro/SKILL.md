# /trailerintro: intro แนวเทรลเลอร์ ตัดตามเสียงตูม

ทำจริงครั้งแรก 18 ถึง 19 ต.ค. 2569
2 รุ่น: intro เพจ และ intro โปรไฟล์บุคคล ยาว 48.8 วิ 1171 เฟรม ผู้ใช้บอกว่า "คลิปออกมาดีเลย"
## ตั้งค่าก่อนใช้

- `NAME` ชื่อ-นามสกุลและตำแหน่งที่จะขึ้นในการ์ดชื่อ (`TEXTS` ใน `intro_template.html` และ `kind: 'title'` ใน `intro_unshatter_template.html` เป็นตัวอย่าง "ชื่อ นามสกุล" / "Your Job Title")
- `BRAND` ชื่อแบรนด์และเว็บไซต์ในการ์ดปิด (`endurl`, `bill`, `wm`) · `CHANNEL` ชื่อเพจ
- ภาพที่แม่แบบเรียกใช้ (`img/portrait.png`, `img/own-product-*.jpg`, `img/client-system-*.jpg`, `img/book-*.jpg`, `img/cert0N.png` ฯลฯ) ไม่ได้แถมมาใน repo ให้วางภาพของคุณเองแล้วแก้รายชื่อใน `SETS` / `STROBE` / `SHOTS`
- `$MEDIA` คลังเพลงและเสียงประกอบ (whoosh) · `$WORK` โฟลเดอร์โปรเจกต์ · `$CHATGPT_BRIDGE` เครื่องมือเจนภาพพื้นหลัง

ต้นแบบที่ผู้ใช้ชี้: คลิปโชว์ชุดเสียง EMINENCE ของ AVA Music Group (เสียงมีลิขสิทธิ์ ดูหัวข้อ "เสียง")

## ลำดับงาน

1. **ดูคลิปอ้างอิงโดยไม่ดาวน์โหลด** เปิด YouTube ใน claude-in-chrome แล้วรัน JS: หยุดวิดีโอ วนตั้ง `currentTime` รอ `seeked` แล้ว `drawImage(video)` ลง canvas เรียงเป็นตาราง 6x4 ซ้อนทับหน้าแล้วถ่ายภาพหน้าจอ canvas ไม่ติด taint (ทดสอบแล้ว) ได้โครงช็อตและข้อความครบในภาพเดียว
2. **เสียง** ตัดสินก่อนลงมือ (ถามผู้ใช้ถ้าไม่ชัด):
   - เพลงที่มีสิทธิ์ใช้ (Suno แพ็ก Pro, ไลเซนส์ที่ซื้อ) โพสต์ได้
   - เสียงจากคลิปคนอื่น ใช้ได้แค่ดูเอง ตั้งชื่อไฟล์ลงท้าย `_PRIVATE` และวาง `อ่านก่อน.txt` บอกว่าห้ามโพสต์ ผู้ใช้เลือกทางนี้ในงานแรก
   - ไฟล์เสียงที่ดาวน์โหลดเก็บในโฟลเดอร์ของมันเอง (`ref/`) รัน python ที่อ่านมันด้วย `-I`
3. **หาจังหวะตูม** `python -I <skill>/scripts/onsets.py ref/ref48.wav hits.json` พิมพ์เวลา + flux + ความดังทุก 0.5 วิ แล้วดู `showspectrumpic` ประกอบ เสียงตูมใหญ่เห็นเป็นแท่งสูงเต็มย่าน ช่วงกลองถี่เห็นเป็นเส้นตั้งชิดกัน
4. **คัดลอกแม่แบบ** `scripts/intro_template.html` เป็น `<proj>/intro.html` และ `scripts/render.py` ไว้ข้างกัน แก้ 4 อย่างใน html:
   - `TOTAL` = ความยาวเสียง
   - `SHOTS` ช็อตเริ่มตรงเวลาตูม ชนิด: `logo` `wave`(v 0-3) `ring`(edgeL/edgeR/center/big) `hall`(ต้องมี `bg/warehouse.png`) `stars` `carousel`(ชุดใน `SETS`) `tilt` `ringPanel` `portrait` `certs` `term`
   - `TEXTS` ข้อความ `a`..`b` วินาที ชั้น `en` (อังกฤษตัวบาง ขยายระยะตัวอักษร) `thS` `thM` `thL` (ไทย ห้ามตั้ง letter-spacing) `url` และ `y` เลื่อนขึ้นลงเป็นพิกเซล
   - `HITS` [เวลา, แรง] ทำแฟลชกับกระแทกกล้อง
5. **พื้นหลังโกดัง** สั่ง `$CHATGPT_BRIDGE`: dark empty industrial warehouse at night, wet concrete floor reflections, empty center, navy/teal grade, no ring, no text, 3:2 ได้ 1536x1024 ใช้กับวงแหวนตั้งพื้นที่มีเงาสะท้อน
6. **ตรวจภาพนิ่งก่อน** `python render.py shots chk 4.0 7.0 ...` ต่อแผ่นด้วย PIL แล้วเปิดดู ดูว่าตัวหนังสือไม่ทับแนวคลื่น ชื่อไม่ล้นวงแหวน
7. **เรนเดอร์ 3 ช่วงพร้อมกัน** (run_in_background) `python render.py 0 390 parts/p0.mp4` / `390 780` / `780 -1` (`-1` = ถึงเฟรมสุดท้าย อ่านจาก `TOTAL` ในหน้า) คลิป 48.8 วิใช้ราว 5 นาที เช็กว่าแต่ละ log มี `done` ไม่มีให้รันช่วงนั้นซ้ำ
8. **ต่อและใส่เสียง** concat แล้ว `ffmpeg -i silent.mp4 -i audio.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k -shortest -movflags +faststart out.mp4`
9. **ตรวจทั้งคลิป** `-vf "fps=1/2,scale=384:-1,tile=5x5"` เปิดดู แล้วบอกตรง ๆ ว่ายังไม่มีใครดูพร้อมฟังเสียง
10. **ส่งให้ผู้ใช้** ไฟล์เต็ม crf16 ราว 125 MB ส่งไม่ได้ บีบ 2-pass `-b:v 3900k` ได้ราว 25 MB แล้วใช้ SendUserFile

## แบบที่ 2: ช่วงเปิดเทรลเลอร์ (สูตร UNSHATTER) `scripts/intro_unshatter_template.html`

ถอดจากเทรลเลอร์ LINKIN PARK: UNSHATTER (ทำรายงานถอดแบบเก็บไว้เป็นไฟล์ teardown.md ในโปรเจกต์) ทำจริง 19 ต.ค. 2569 ได้คลิป intro 40 วิ
ผู้ใช้ขอ "เอาเฉพาะช่วง intro" จึงทำแค่ช่วงเปิด ไม่มีช่วงตกและช่วงเริ่มใหม่ของเทรลเลอร์เต็ม

**โครง 40 วิ (เพลงเริ่มที่ 2.0 วิ ตัดทุกคัตตรงห้องเพลง):**
0 ถึง 2 ชื่อแบรนด์บนดำ เงียบ · 2 ถึง 24 เพลงไต่ การ์ดตัวเลข 3 ใบคั่นภาพผลงาน · 24 เพลงเข้าเต็ม ตัดทุก 0.5 ถึง 1 วิ · 28.5 สโตรบ 1.5 วิ · 30.0 ดำเงียบ 0.5 วิ · 30.5 ชื่อสองบรรทัดตรงเสียงตูม ภาพหลังมืดจนดำใน 1.9 วิ · 35.1 การ์ดปิด (ชื่อไทย + ประโยคชวน + ลิงก์สีแดง + billing block เครดิตเพลง)

**ชนิดช็อตใน `SHOTS`:** `wm` `photo` (Ken Burns `s` `x` `y` + เกรด `GRADE` + `fit:'contain'` สำหรับภาพคนพื้นดำ) `screen` (ภาพหน้าระบบเป็นจอเอียงในห้องมืด ใช้กับภาพ UI สีขาวทุกครั้ง) `panel` (โปสเตอร์/ปก) `trio` (ปกหนังสือ 3 เล่ม) `badges` (ป้ายใบรับรอง) `bokeh` (ไฟเบลอสีแดง) `laser` (เลเซอร์แตกกระจาย) `strobe` (`STROBE` เปลี่ยนภาพทุก 2 เฟรม ย้อมสีสุ่ม) `black`
ช็อตที่มี `dip:true` ภาพหลังจะมืดลงช่วง 0.6 ถึง 0.2 วิสุดท้าย โดยการ์ดยังค้างบนดำ · `fadeTo:[a,b]` ใช้กับภาพหลังชื่อเรื่อง

**ข้อความใน `TEXTS`:** `card` (Archivo กว้าง 125% หนา 700 46px สีเทา #B6B6B7 ตัวอักษรโผล่สุ่มพร้อมเบลอ ใช้ `Intl.Segmenter` ตัดทีละ grapheme ภาษาไทยจึงไม่หลุดสระ) `title` (สองบรรทัด ปรับฟอนต์ให้กว้างเท่ากัน 1285px บรรทัดสองสีแดง #D91B22 มีมาสก์พื้นผิวขูดขีด) `wm` `end` · `LEAKS` แสงรั่วชมพูม่วง · `HITS` แฟลช · แถบดำบนล่าง 21px (1.85:1)

‼ **ช่วง "ดำเงียบ 0.5 วิ" ก่อนชื่อเรื่อง ผู้ใช้เห็นเป็นวิดีโอสะดุด** (ทักมาแล้ว 2 ครั้ง: คลิปงานอีเวนต์หนึ่ง "วินาทีที่ 22 สะดุด" และคลิป AI Transformation 21 ต.ค. 2569 "วินาทีที่ 14-16 มันหยุดแปลกๆ")
ใช้ได้เฉพาะงานที่ผู้ใช้ขอแบบ UNSHATTER ตรง ๆ เท่านั้น ถ้าไม่ได้ขอ ให้ภาพเดิมวิ่งถึงชื่อเรื่อง ตัดด้วยแฟลชกับเสียงตูม และเปิดเพลงต่อเนื่องเส้นเดียว · ก่อนส่ง สแกนเฟรมจริงหาจอมืดและภาพค้าง

**เสียง (โพสต์ได้ ถ้าใช้เพลงที่มีสิทธิ์):** `python build_audio.py audio_plan.json master.wav` ดูตัวอย่าง `scripts/audio_plan_example.json`
- `music` ตัดเพลงเป็นท่อนวางตามเวลา ตัดท่อนแรกจบก่อน downbeat 15 ms ให้ช่วงดำเงียบจริง ท่อนสองเริ่มที่เสียงตูมแรงสุดของเพลง (หาด้วย `onsets.py`)
- `booms` เสียงตูมสังเคราะห์เอง (sub กวาด 70 ถึง 30 Hz + ลมต่ำ + หางรีเวิร์บ) ไม่มีลิขสิทธิ์ใคร · `sfx` whoosh จาก `$MEDIA/sfx`
- loudnorm สองรอบแบบ linear ต้องตั้ง `lra` สูงกว่า LRA ของมิกซ์ (งานแรกใช้ 13) ไม่งั้นสลับเป็นโหมดบีบเสียงเอง
- งานแรกใช้ "Cinematic Symphony of Steel" ของ Jimena Contreras จาก `$MEDIA/bgm` (120 BPM ห้องละ 2 วิ ช่วง 0 ถึง 22 วิไต่จาก -28 ถึง -13 dB ตูมที่ 10.0 / 22.0 / 46.0) ได้ -14.2 LUFS ยอด -1.5 dB

**เรนเดอร์:** `render.py` ตัวเดียวกัน (อ่าน `TOTAL` จากหน้าเอง) 960 เฟรมแบ่ง 3 ช่วง `0 320` / `320 640` / `640 -1` · ส่งไฟล์บีบ 2-pass `-b:v 4900k` ได้ราว 26 MB

**กับดักของแบบนี้:**
- canvas `fx` อยู่ชั้นบนของ `#plate` ห้ามทาพื้นทึบลง `fx` ในช็อตที่ใช้ภาพจาก `#plate` (ฉากจอเอียงเคยมืดหมดเพราะเหตุนี้) ให้ตั้งพื้นเป็น CSS ของ `#plate` แทน
- อย่าอ้าง `const ph` ก่อนประกาศใน `renderAt` (TDZ)
- ภาพเวทีที่มีตัวหนังสือใหญ่ (เช่นป้ายชื่องาน) ครอปให้เห็นแต่ส่วนเวที (`s` 2.0, `y` -30) ก่อนวางการ์ดหรือชื่อเรื่องทับ
- สโตรบที่มีภาพ UI สีขาวจะจ้าเกิน ลดความสว่างสุ่มเหลือ 0.55 ถึง 0.9

ตัวเลขจากเทรลเลอร์ต้นแบบที่ยังไม่ได้ใส่: ช่วงตก (เพลง -40 dB ช็อต 2.7 วิ) และประโยคแบ่งสองการ์ดห่าง 10 วิ ใช้เมื่อทำเทรลเลอร์เต็ม ไม่ใช่แค่ช่วงเปิด

## เนื้อหาโปรไฟล์

- ข้อความต้องมาจากแหล่งที่ผ่านการตรวจแล้ว งานแรกใช้ไฟล์ข้อความโปรไฟล์ที่เจ้าของตรวจแล้ว (ผู้ใช้สั่งให้ใช้ข้อมูลจากคลิปแนะนำตัวบน Fastwork)
- ภาพระบบลูกค้าใช้เฉพาะไฟล์ `*-safe` ที่เบลอแล้ว
- งานที่ยังไม่เกิด (เช่น ขึ้นเวทีในอนาคต) เขียนแค่ชื่องาน ไม่เขียนว่าทำแล้ว
- ลิงก์ที่ใส่หน้าสุดท้าย ยิง `curl -sL -o /dev/null -w '%{http_code}'` ให้ได้ 200 ก่อน

## กับดัก

- `Page.evaluate: NetworkError` ตอนโหลด Google Fonts ทำให้ช่วงเรนเดอร์ล้มทั้งช่วง รันช่วงนั้นซ้ำก็ผ่าน
- ค่า seed ของพื้นหลังดาวต้องเป็นตัวเลข เคยส่งชื่อชุด (`'sys' + 7`) เข้าไปแล้วได้ NaN `createRadialGradient` โยน error
- ข้อความกลางจอทับแนวคลื่น: ขยับ `cy` ของ variant ใน `WV` ให้แนวคลื่นพ้นช่วงกลางจอ (0.34 / 0.80 / 0.74 ใช้ได้)
- ชื่อไทยตัวใหญ่ 120px ล้นวงแหวน `center` ใช้ 92px คู่กับวงแหวน `big`
- ภาพแอปที่เบลอจนเห็นแต่พื้นขาวดูว่างเปล่าในแผงเอียง เลือกภาพที่มีสีและตัวหนังสือชัด
- แม่แบบตั้งชื่อเพจและเนื้อหาของงานแรกไว้ ต้องเปลี่ยน `SETS` `SHOTS` `TEXTS` `TERM` ทุกครั้ง
