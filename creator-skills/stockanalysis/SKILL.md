# วิเคราะห์หุ้น (Stock Analysis)

## ใช้ตอนไหน
ผู้ใช้อยากรู้ว่าหุ้นตัวหนึ่ง "น่าลงทุนไหม / แพงไปหรือยัง / ตอนนี้ควรเข้าหรือรอ" — ทั้งแบบลงทุนระยะยาว (ปัจจัยพื้นฐาน) และแบบดูจังหวะซื้อขาย (ปัจจัยเทคนิค)

⚠️ **ก่อนเริ่มทุกครั้ง**: บอกผู้ใช้ตรง ๆ ว่านี่คือ "กรอบวิเคราะห์" ไม่ใช่คำแนะนำการลงทุนส่วนบุคคล (not personalized investment advice) — ผู้ใช้ตัดสินใจเอง

## ถามผู้ใช้ก่อน
1. **ชื่อหุ้น/ตลาด** — ticker + ตลาด (เช่น PTT ใน SET, AAPL ใน NASDAQ) กันสับสนหุ้นชื่อพ้อง
2. **มุมมอง** — จะถือยาว (นักลงทุน, เน้นพื้นฐาน+มูลค่า) หรือเทรดสั้น (เน้นเทคนิค+จังหวะ) หรือทั้งคู่
3. **ข้อมูลที่มีอยู่แล้ว** — มีงบการเงิน/ราคาย้อนหลังมาให้ไหม หรือให้ค้นเว็บ/ใช้ข้อมูลที่ Claude มี (ต้องระบุวันที่ของข้อมูลเสมอ เพราะราคาหุ้นเปลี่ยนทุกวัน — ห้ามอ้างราคาปัจจุบันโดยไม่เช็คว่าเป็นข้อมูลล่าสุดจริง)
4. **สายธุรกิจที่คุ้นเคยของผู้ใช้** (ถ้ามี) — จะได้เทียบอุตสาหกรรม/คู่แข่งได้ตรงบริบท

## ขั้นตอน

### 1) เข้าใจธุรกิจ+อุตสาหกรรม (เชิงคุณภาพ)
- ทำธุรกิจอะไร รายได้หลักมาจากไหน (segment ไหนใหญ่สุด)
- อยู่ช่วงไหนของวัฏจักรอุตสาหกรรม (โต/อิ่มตัว/ถดถอย) เทียบคู่แข่งหลัก
- moat/ความได้เปรียบแข่งขัน (แบรนด์, ต้นทุนต่ำ, network effect, switching cost, license/สัมปทาน)
- ความเสี่ยงเชิงโครงสร้าง (กฎหมาย/ภาษี/เทคโนโลยี disrupt/ค่าเงิน/ราคาสินค้าโภคภัณฑ์)

### 2) งบการเงิน + อัตราส่วน (เชิงปริมาณ)
คำนวณและอ่านแนวโน้ม **ย้อนหลังอย่างน้อย 3-5 ปี** (ไม่ใช่ดูปีเดียว) ตาม 4 หมวดหลัก — รายละเอียดสูตร/เกณฑ์ดูที่ [references/fundamental-checklist.md](references/fundamental-checklist.md):
- **การเติบโต**: รายได้, กำไรสุทธิ, กำไรต่อหุ้น (EPS) โต/หด กี่ % ต่อปี
- **ความสามารถทำกำไร**: Gross/Operating/Net Margin, ROE, ROA, ROIC เทียบ WACC
- **คุณภาพกำไร**: กระแสเงินสดจากการดำเนินงาน (CFO) เทียบกำไรสุทธิ ต้อง ≥ 1 อย่างสม่ำเสมอ ไม่งั้นกำไร "ไม่เป็นเงินสดจริง"
- **ความแข็งแรงทางการเงิน**: D/E, Current Ratio, Interest Coverage, Piotroski F-Score
- **ปันผล** (ถ้ามี): Dividend Yield, Payout Ratio, ความสม่ำเสมอของการจ่าย

### 3) ประเมินมูลค่า (Valuation)
อย่าใช้วิธีเดียว — ใช้อย่างน้อย 2 วิธีเทียบกันแล้วดูว่าราคาปัจจุบันอยู่ตรงไหนของช่วง fair value (รายละเอียดสูตร/ข้อจำกัดแต่ละวิธีดูที่ [references/valuation-methods.md](references/valuation-methods.md)):
- **Relative valuation** (เร็ว ทำก่อนเสมอ): P/E, P/BV, EV/EBITDA, P/S เทียบคู่แข่งในอุตสาหกรรมเดียวกัน และเทียบค่าเฉลี่ยของหุ้นตัวเองย้อนหลัง 5 ปี
- **DCF** (ถ้าพยากรณ์กระแสเงินสดได้พอสมควร): ระวังผลลัพธ์ไวต่อสมมติฐาน growth/discount rate มาก — ทำ sensitivity 3 ฉาก (base/bull/bear) เสมอ อย่าฟันธงเลขเดียว
- **DDM** (เหมาะกับหุ้นปันผลสม่ำเสมอ เช่น กลุ่ม utility/แบงก์)
- สรุปเป็น "ช่วงมูลค่าที่เหมาะสม" ไม่ใช่ตัวเลขเป๊ะตัวเดียว แล้วเทียบราคาตลาดปัจจุบันว่าถูก/แพง/ยุติธรรม

### 4) เทคนิค + จังหวะ (ถ้าผู้ใช้สนใจเรื่องจังหวะเข้า-ออก)
ใช้เสริมข้อ 1-3 ไม่ใช่ใช้แทน — ปัจจัยพื้นฐานบอกว่า "ควรถือไหม" ส่วนเทคนิคบอกว่า "จังหวะไหนน่าเข้า/ออก" รายละเอียดดูที่ [references/technical-indicators.md](references/technical-indicators.md):
- แนวโน้มหลัก (เทียบ MA50/MA200, golden/death cross) + แนวรับ-แนวต้าน
- โมเมนตัม (RSI, MACD) เช็ค overbought/oversold + divergence
- ปริมาณซื้อขาย (volume) ยืนยันความแข็งแรงของแนวโน้ม — ราคาขึ้นแต่ volume ลดลงคือสัญญาณอ่อนแรง

### 5) เช็คสัญญาณเตือน (Red Flags)
ก่อนสรุปทุกครั้ง ไล่เช็คลิสต์ใน [references/red-flags.md](references/red-flags.md) — ถ้าเจอข้อไหนให้เตือนผู้ใช้เด่นชัดแยกหัวข้อ "⚠️ ข้อควรระวัง" ไม่ใช่ซ่อนในรายละเอียด เช่น กำไรโตแต่ CFO ไม่โต, ลูกหนี้การค้าโตเร็วกว่ายอดขาย, หนี้สินสูงผิดปกติ, รายการกับบุคคล/กิจการที่เกี่ยวข้อง (related party) เยอะผิดปกติ, เปลี่ยนผู้สอบบัญชีบ่อย, งบไตรมาส 4 ดีผิดปกติไม่มีเหตุผลตามฤดูกาล

### 6) สรุปเป็นรายงาน
ใช้เทมเพลตด้านล่าง ปิดท้ายด้วยจุดแข็ง/ความเสี่ยง/สิ่งที่ต้องติดตามต่อ — **ไม่ฟันธงว่า "ซื้อ/ขาย"** ให้สรุปเป็นข้อมูลประกอบการตัดสินใจของผู้ใช้เอง

## เทมเพลตผลลัพธ์
```
📊 [ชื่อหุ้น] ([ticker], ตลาด) — ข้อมูล ณ วันที่ ..

1. ธุรกิจ: ทำอะไร / รายได้หลักจากไหน / จุดแข็งแข่งขัน
2. งบการเงิน (ย้อนหลัง 3-5 ปี):
   - เติบโต: รายได้ ..% / กำไรสุทธิ ..% ต่อปี
   - ทำกำไร: Gross .. / Net Margin .. / ROE .. / ROA ..
   - คุณภาพกำไร: CFO/Net Income = ..
   - หนี้สิน: D/E .. / Interest Coverage ..
   - ปันผล: Yield .. / Payout ..%
3. มูลค่า: P/E .. (เทียบอุตสาหกรรม ..) / P/BV .. / EV-EBITDA .. / DCF ช่วง .. บาท
   → ราคาตลาดปัจจุบัน .. บาท: [ถูก/แพง/ยุติธรรม] เทียบช่วงมูลค่าที่ประเมิน
4. เทคนิค (ถ้าดู): แนวโน้ม .. / แนวรับ-แนวต้าน .. / RSI .. / สัญญาณ ..
5. ⚠️ ข้อควรระวัง: [ระบุ หรือ "ไม่พบสัญญาณเตือนเด่นชัด"]
6. สรุป: จุดแข็ง .. | ความเสี่ยง .. | สิ่งที่ควรติดตามต่อ ..

หมายเหตุ: กรอบวิเคราะห์นี้เพื่อประกอบการตัดสินใจ ไม่ใช่คำแนะนำการลงทุน
```

## เคล็ดลับ
- **ไม่มีข้อมูลจริง = ห้ามเดาตัวเลข** ถ้าผู้ใช้ไม่ได้แนบงบ/ราคา และ Claude ไม่มีเครื่องมือดึงข้อมูลตลาดสด ให้บอกตรง ๆ ว่าตัวเลขที่ใช้มาจากความรู้ทั่วไป/อาจไม่ใช่ปัจจุบัน แนะนำให้เช็คราคาจริงที่ settrade.com (หุ้นไทย) หรือแหล่งข้อมูลตลาดที่เชื่อถือได้ก่อนตัดสินใจ
- **หุ้นไทย (SET/mai)** มีข้อควรรู้เพิ่มเฉพาะ ดูที่ [references/thai-market-notes.md](references/thai-market-notes.md) — 56-1 One Report, งบไตรมาส, NVDR, foreign room, กลุ่มอุตสาหกรรม/หมวดธุรกิจของ SET
- ตัวเลขตัวเดียวไม่มีความหมาย ต้องเทียบ **trend ย้อนหลัง** และ **เทียบคู่แข่ง/ค่าเฉลี่ยอุตสาหกรรม** เสมอ (เหมือน [[financial-statement-analysis]])
- แยกให้ชัดระหว่าง "บริษัทดี" กับ "หุ้นราคาดี" — บริษัทดีมากแต่ราคาแพงเกินพื้นฐานก็ยังเป็นการลงทุนที่แย่ได้
- ถ้าผู้ใช้ถามแบบ mixed (ทั้งพื้นฐาน+เทคนิค) ให้น้ำหนักพื้นฐานตัดสิน "ควรถือไหม" และเทคนิคตัดสิน "จังหวะไหน" ไม่ปนกันจนสับสน
