# เครื่องมือวิเคราะห์เทคนิค (Technical Analysis) — สรุปใช้งานจริง

หลักคิด: ราคาสะท้อนข้อมูลและอารมณ์ตลาด, ราคาเคลื่อนไหวเป็นแนวโน้ม, ประวัติศาสตร์มักซ้ำรอย — ใช้เสริม "จังหวะ" ไม่ใช่ใช้แทนการวิเคราะห์พื้นฐานว่า "ควรถือหุ้นตัวนี้ไหม"

## 1. แนวโน้ม (Trend)
- **Moving Average (MA)**: เส้นค่าเฉลี่ยราคาย้อนหลัง (นิยม MA50, MA200)
  - ราคาอยู่เหนือ MA200 = แนวโน้มใหญ่เป็นขาขึ้น, ต่ำกว่า = ขาลง
  - **Golden Cross**: MA50 ตัดขึ้นเหนือ MA200 = สัญญาณขาขึ้นระยะกลาง-ยาว
  - **Death Cross**: MA50 ตัดลงต่ำกว่า MA200 = สัญญาณขาลง
- **แนวรับ (Support) / แนวต้าน (Resistance)**: ระดับราคาที่เคยเด้งกลับ/ถูกต้านหลายครั้งในอดีต ใช้กำหนดจุดเข้า-stop loss-เป้าหมายกำไร

## 2. โมเมนตัม (Momentum)
- **RSI (Relative Strength Index, 0-100)**: วัดความแรงของการขึ้น/ลงช่วงสั้น
  - > 70 = overbought (ซื้อมากไป อาจปรับฐาน), < 30 = oversold (ขายมากไป อาจเด้ง)
  - **Divergence สำคัญกว่าตัวเลขเฉย ๆ**: ราคาทำ high ใหม่แต่ RSI ทำ high ต่ำกว่าเดิม (bearish divergence) = แนวโน้มขึ้นเริ่มอ่อนแรง
- **MACD (Moving Average Convergence Divergence)**: เส้น MACD ตัด Signal line ขึ้น = สัญญาณซื้อ, ตัดลง = สัญญาณขาย ใช้ยืนยันแนวโน้มร่วมกับ MA

## 3. ปริมาณซื้อขาย (Volume)
- ราคาขึ้น + volume เพิ่ม = แนวโน้มแข็งแรงน่าเชื่อถือ
- ราคาขึ้น + volume ลด = สัญญาณอ่อนแรง อาจเป็นแค่การเด้งชั่วคราว
- Volume พุ่งผิดปกติพร้อมข่าว = จุดที่ควรระวัง/จับตาเป็นพิเศษ

## วิธีใช้ร่วมกัน
1. ดู MA/แนวโน้มใหญ่ก่อนว่าทิศทางหลักเป็นขาขึ้น/ลง/sideway
2. ใช้ RSI/MACD หาจังหวะเข้า-ออกภายในแนวโน้มนั้น (อย่าสวนแนวโน้มใหญ่)
3. ใช้ volume ยืนยันความน่าเชื่อถือของสัญญาณ
4. ใช้แนวรับ-แนวต้านกำหนดจุด stop loss และเป้าหมายทำกำไรที่ชัดเจนก่อนเข้าซื้อทุกครั้ง

## ข้อจำกัดที่ต้องบอกผู้ใช้เสมอ
- เทคนิคอ่านพฤติกรรมราคาในอดีต **ไม่ได้การันตีอนาคต** โดยเฉพาะเมื่อมีข่าว/เหตุการณ์ใหม่กระทบพื้นฐานธุรกิจ
- สัญญาณเทคนิคมีโอกาส false signal เสมอ ควรใช้คู่กับการบริหารความเสี่ยง (position size, stop loss) ไม่ใช่เชื่อสัญญาณเดียวแล้วทุ่มหมดหน้าตัก
