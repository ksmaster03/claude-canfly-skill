# เช็กลิสต์สัญญาณเตือน (Red Flags) ก่อนสรุปผลวิเคราะห์

ไล่เช็คทุกข้อก่อนสรุปรายงาน — ถ้าเจอแม้ 1-2 ข้อ ให้แยกเตือนเด่นชัดในหัวข้อ "⚠️ ข้อควรระวัง" ไม่ใช่ฝังในเนื้อหา

## กำไร/รายได้
- [ ] กำไรสุทธิโตต่อเนื่อง แต่ **กระแสเงินสดจากการดำเนินงาน (CFO) ไม่โตตาม หรือติดลบ** — กำไรอาจไม่ใช่เงินสดจริง
- [ ] **ลูกหนี้การค้าโตเร็วกว่ายอดขายอย่างมีนัยสำคัญ** — อาจเร่งรับรู้รายได้ก่อนเก็บเงินได้จริง
- [ ] **สินค้าคงเหลือโตเร็วกว่ายอดขายมาก** — สินค้าขายไม่ออก/สต็อกกองค้าง
- [ ] กำไรไตรมาส 4 (หรือไตรมาสสุดท้ายของรอบบัญชี) สูงผิดปกติโดยไม่มีเหตุผลตามฤดูกาลรองรับ
- [ ] รายได้/กำไรโตสวนทางอุตสาหกรรมทั้งหมดที่กำลังถดถอย โดยไม่มีคำอธิบายที่สมเหตุสมผล

## งบดุล/หนี้สิน
- [ ] D/E หรือ Debt/Assets สูงผิดปกติเทียบอุตสาหกรรมเดียวกัน (เช่น Debt/Assets > 0.9)
- [ ] Interest Coverage (EBIT/ดอกเบี้ยจ่าย) ต่ำกว่า 2-3 เท่า
- [ ] มีสินทรัพย์ไม่มีตัวตน/ค่าความนิยม (goodwill) สัดส่วนสูงผิดปกติเทียบสินทรัพย์รวม (เสี่ยง impairment ในอนาคต)
- [ ] รายการนอกงบดุล (off-balance sheet) หรือภาระผูกพัน/ค้ำประกันจำนวนมากที่ไม่ชัดเจน

## ธรรมาภิบาล/พฤติกรรมบริษัท
- [ ] **รายการกับบุคคล/กิจการที่เกี่ยวข้องกัน (related party transactions)** มูลค่าสูงหรือถี่ผิดปกติ
- [ ] เปลี่ยนผู้สอบบัญชีบ่อย โดยเฉพาะถ้าเปลี่ยนหลังผู้สอบบัญชีตั้งข้อสังเกต/มีความเห็นแย้งในงบก่อนหน้า
- [ ] ผู้บริหาร/ผู้ถือหุ้นใหญ่ทยอยขายหุ้นออกจำนวนมากต่อเนื่อง ขณะที่ให้ข่าวเชิงบวกกับตลาด
- [ ] ผู้บริหารมีแรงกดดันสูงต้องทำตัวเลขให้ถึงเป้า (เช่น ใกล้ครบกำหนดโบนัส/สัญญากู้ที่มีเงื่อนไขผูกกับผลประกอบการ)
- [ ] แถลงข่าว/สื่อสารกับนักลงทุนดูกีดกันคำถามตรวจสอบ หรือให้ข้อมูลไม่สอดคล้องกันระหว่างช่องทาง

## เปรียบเทียบอุตสาหกรรม
- [ ] อัตราส่วนการเงินหลุดออกจากค่าเฉลี่ยอุตสาหกรรมไปทางที่ดีเกินจริง โดยไม่มีคำอธิบายเชิงกลยุทธ์ที่ชัดเจน (มักเป็นสัญญาณของการตกแต่งตัวเลข มากกว่าการเก่งกว่าคู่แข่งจริง)

## สิ่งที่ควรทำเมื่อเจอ red flag
1. ไม่ด่วนสรุปว่าเป็นการฉ้อโกงเสมอไป — บางกรณีมีคำอธิบายทางธุรกิจที่สมเหตุสมผล (เช่น ขยายสาขาใหม่ทำให้สินค้าคงเหลือโตชั่วคราว)
2. แนะนำผู้ใช้ให้ตรวจสอบ **หมายเหตุประกอบงบการเงิน (notes to financial statements)** และ **รายงานผู้สอบบัญชี** เพิ่มเติม ไม่ใช่ดูแค่ตัวเลขหน้างบหลัก
3. ถ้าพบหลายข้อพร้อมกัน ควรเตือนผู้ใช้ให้ระมัดระวังเป็นพิเศษ และพิจารณาลดน้ำหนักความเชื่อมั่นต่อบริษัทนั้นลง
