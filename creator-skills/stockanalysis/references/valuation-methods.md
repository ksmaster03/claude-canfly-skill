# วิธีประเมินมูลค่าหุ้น (Valuation Methods)

หลักการ: ไม่มีวิธีไหนถูกต้อง 100% — ใช้อย่างน้อย 2 วิธีขึ้นไปแล้วดูว่าให้ผลลัพธ์สอดคล้องกันหรือไม่ ถ้าต่างกันมากให้สงสัยสมมติฐาน ไม่ใช่เชื่อตัวเลขใดตัวเลขหนึ่งทันที

## 1. Relative Valuation (Multiples) — ทำก่อนเสมอ เร็วและเข้าใจง่าย
| Multiple | สูตร | เหมาะกับ | ข้อจำกัด |
|---|---|---|---|
| P/E | ราคาหุ้น / EPS | บริษัทกำไรสม่ำเสมอ | ใช้ไม่ได้ถ้าขาดทุน/กำไรผันผวนมาก |
| P/BV | ราคาหุ้น / มูลค่าทางบัญชีต่อหุ้น | แบงก์, ธุรกิจ asset-heavy | ใช้ไม่ได้ดีกับธุรกิจ asset-light (เช่น software) |
| EV/EBITDA | (Market Cap + หนี้สิน - เงินสด) / EBITDA | เทียบบริษัทโครงสร้างทุน/หนี้ต่างกัน | ไม่รวมค่าใช้จ่ายลงทุน (capex) จริง |
| P/S | ราคาหุ้น / ยอดขายต่อหุ้น | บริษัทยังไม่มีกำไร (growth stage) | ไม่บอกอะไรเรื่องความสามารถทำกำไร |
| PEG | (P/E) / อัตราการเติบโตกำไร (%) | เทียบหุ้นโตเร็วต่างกัน | PEG ≈ 1 ถือว่าราคาสมเหตุสมผลกับการเติบโต, ต่ำกว่า 1 อาจถูก |

**วิธีใช้**: เทียบกับ (1) ค่าเฉลี่ยอุตสาหกรรม/คู่แข่งตรงกลุ่มธุรกิจเดียวกัน (2) ค่าเฉลี่ยของหุ้นตัวเองย้อนหลัง 3-5 ปี (historical multiple) — ถ้า multiple ปัจจุบันสูงกว่าทั้งคู่แข่งและค่าเฉลี่ยตัวเอง ต้องมีเหตุผลรองรับ (เช่น เติบโตเร็วกว่าชัดเจน) ไม่งั้นถือว่าแพง

## 2. Discounted Cash Flow (DCF)
แนวคิด: มูลค่าบริษัท = ผลรวมกระแสเงินสดอิสระ (Free Cash Flow) ในอนาคตทั้งหมด คิดลดกลับเป็นมูลค่าปัจจุบัน

ขั้นตอนคร่าว ๆ:
1. พยากรณ์ Free Cash Flow to Firm (FCFF) หรือ to Equity (FCFE) ล่วงหน้า 5-10 ปี
2. หา Discount Rate — WACC (ถ้าใช้ FCFF) หรือ Cost of Equity จาก CAPM (ถ้าใช้ FCFE)
3. คำนวณ Terminal Value ปีสุดท้าย (Gordon Growth: TV = FCF_n × (1+g) / (r-g))
4. คิดลดทุกกระแสเงินสด + terminal value กลับมาเป็นปัจจุบัน รวมเป็นมูลค่ากิจการ

⚠️ **ข้อจำกัดสำคัญ**: ผลลัพธ์ไวต่อสมมติฐานมาก — เปลี่ยน growth rate หรือ discount rate เพียง 1-2% มูลค่าอาจเปลี่ยนหลายสิบเปอร์เซ็นต์ **ห้ามฟันธงมูลค่าเป็นตัวเลขเดียว** ให้ทำ sensitivity อย่างน้อย 3 ฉาก (bear/base/bull) เสมอ และบอกช่วงราคา ไม่ใช่จุดเดียว

## 3. Dividend Discount Model (DDM)
เหมาะกับบริษัทที่จ่ายปันผลสม่ำเสมอและคาดเดาได้ (เช่น กลุ่มธนาคาร, สาธารณูปโภค, REIT)

**Gordon Growth Model**: มูลค่าหุ้น = D1 / (r - g)
- D1 = เงินปันผลคาดการณ์ปีหน้า
- r = อัตราผลตอบแทนที่ต้องการ (cost of equity)
- g = อัตราการเติบโตปันผลระยะยาว (ต้อง g < r เสมอ ไม่งั้นสูตรใช้ไม่ได้)

ใช้ไม่ได้กับบริษัทที่ไม่จ่ายปันผล หรือจ่ายไม่สม่ำเสมอ

## แนวทางสรุปผล
- นักวิเคราะห์มืออาชีพมักเฉลี่ยผลจาก 3-4 วิธี เพื่อหาช่วง fair value ไม่ใช่ตัวเลขเป๊ะ
- เทียบราคาตลาดปัจจุบันกับช่วง fair value: ต่ำกว่าขอบล่างมาก = อาจถูก (undervalued), สูงกว่าขอบบนมาก = อาจแพง (overvalued), อยู่ในช่วง = ยุติธรรม (fairly valued)
- "หุ้นถูก" ไม่ได้แปลว่า "ควรซื้อทันที" ต้องพิจารณาเหตุผลที่ตลาดให้ราคาต่ำ (อาจมีความเสี่ยงที่ตลาดรู้แต่การวิเคราะห์ยังไม่ครอบคลุม) เสมอ
