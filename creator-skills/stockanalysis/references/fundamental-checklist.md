# เช็กลิสต์ปัจจัยพื้นฐาน — สูตร + เกณฑ์อ่านค่า

## 1. การเติบโต (Growth)
| ตัวชี้วัด | สูตร | อ่านผล |
|---|---|---|
| Revenue Growth YoY | (รายได้ปีนี้ - ปีก่อน) / ปีก่อน | โตต่อเนื่อง 3-5 ปี ดีกว่าโตกระชากปีเดียว |
| Net Income Growth | (กำไรสุทธิปีนี้ - ปีก่อน) / ปีก่อน | ควรโตสอดคล้อง/เร็วกว่ารายได้ (แปลว่าคุมต้นทุนได้ดีขึ้น) |
| EPS Growth | เทียบ EPS ย้อนหลัง | ระวัง EPS โตเพราะซื้อหุ้นคืนลด share count ไม่ใช่ธุรกิจโตจริง |

## 2. ความสามารถทำกำไร (Profitability)
| ตัวชี้วัด | สูตร | เกณฑ์คร่าว ๆ |
|---|---|---|
| Gross Margin | กำไรขั้นต้น / รายได้ | เทียบคู่แข่งในอุตสาหกรรมเดียวกันเท่านั้น (ธุรกิจต่างประเภทเทียบกันไม่ได้) |
| Operating Margin | กำไรจากการดำเนินงาน / รายได้ | แนวโน้มขึ้นแปลว่า operating leverage ดีขึ้น |
| Net Margin | กำไรสุทธิ / รายได้ | |
| ROE (Return on Equity) | กำไรสุทธิ / ส่วนของผู้ถือหุ้นเฉลี่ย | ค่าเฉลี่ยตลาดสากลระยะยาว ~15-20% แต่ต้องดูว่า ROE สูงเพราะกำไรดีจริง หรือเพราะกู้เยอะ (leverage) — แตก ROE ด้วย DuPont: ROE = Net Margin × Asset Turnover × Financial Leverage |
| ROA | กำไรสุทธิ / สินทรัพย์รวมเฉลี่ย | ดีสำหรับเทียบธุรกิจที่ capital-intensive ต่างกัน |
| ROIC vs WACC | NOPAT / Invested Capital เทียบต้นทุนเงินทุนถัวเฉลี่ย | ROIC > WACC ต่อเนื่อง = ธุรกิจสร้างมูลค่าเพิ่มจริง (economic value added) |

## 3. คุณภาพกำไร (Earnings Quality) — สำคัญมาก มักถูกมองข้าม
- **CFO / Net Income ratio**: กระแสเงินสดจากการดำเนินงานหารกำไรสุทธิ ควร ≥ 1 ต่อเนื่องหลายปี ถ้าต่ำกว่า 1 เรื้อรัง = กำไรบัญชีไม่แปลงเป็นเงินสดจริง (สัญญาณอันตราย)
- **Accruals ratio**: (กำไรสุทธิ - CFO) / สินทรัพย์รวม ยิ่งสูงยิ่งเสี่ยงกำไรถูกปรับแต่ง
- เทียบการเติบโตของ **ลูกหนี้การค้า** กับ **ยอดขาย** — ลูกหนี้โตเร็วกว่ายอดขายมาก = อาจเร่งรับรู้รายได้ก่อนเก็บเงินจริง
- เทียบการเติบโตของ **สินค้าคงเหลือ** กับ **ยอดขาย** — สินค้าคงเหลือโตเร็วกว่ามาก = ขายไม่ออก/สต็อกล้น

## 4. ความแข็งแรงทางการเงิน (Financial Strength)
| ตัวชี้วัด | สูตร | เกณฑ์ |
|---|---|---|
| Current Ratio | สินทรัพย์หมุนเวียน / หนี้สินหมุนเวียน | > 1 พอมีสภาพคล่องระยะสั้น, ธุรกิจ capital-intensive อาจต่ำกว่านี้ได้ปกติ |
| Quick Ratio | (สินทรัพย์หมุนเวียน - สินค้าคงเหลือ) / หนี้สินหมุนเวียน | เข้มกว่า current ratio |
| D/E (Debt to Equity) | หนี้สินรวม / ส่วนของผู้ถือหุ้น | เทียบอุตสาหกรรม (แบงก์/อสังหาฯ สูงเป็นปกติ, เทคโนโลยีควรต่ำ) |
| Debt/Assets | หนี้สินรวม / สินทรัพย์รวม | > 0.7-0.8 ถือว่าสูง ต้องดูความสามารถชำระคืนประกอบ |
| Interest Coverage | EBIT / ดอกเบี้ยจ่าย | < 2-3 เท่า เริ่มน่ากังวลเรื่องความสามารถจ่ายดอกเบี้ย |

## 5. Piotroski F-Score (คัดกรองคุณภาพเชิงปริมาณ 9 ข้อ ให้ 1 คะแนนต่อข้อที่ผ่าน)
**Profitability (4 ข้อ):** ROA เป็นบวก, CFO เป็นบวก, ROA ปีนี้ > ปีก่อน, CFO > Net Income
**Leverage/Liquidity (3 ข้อ):** D/E ปีนี้ < ปีก่อน, Current Ratio ปีนี้ > ปีก่อน, ไม่มีการออกหุ้นเพิ่มทุนใหม่ในปีนี้
**Efficiency (2 ข้อ):** Gross Margin ปีนี้ > ปีก่อน, Asset Turnover ปีนี้ > ปีก่อน
→ รวมคะแนน: **8-9 = แข็งแรงมาก, 5-7 = ปานกลาง, 0-4 = อ่อนแอ ควรระวัง**

## 6. ปันผล (ถ้ามี)
- **Dividend Yield** = เงินปันผลต่อหุ้น / ราคาหุ้น
- **Payout Ratio** = เงินปันผลจ่าย / กำไรสุทธิ — สูงเกิน 80-100% ต่อเนื่องอาจจ่ายไม่ยั่งยืนถ้ากำไรไม่โตตาม
- ดูความสม่ำเสมอ: จ่ายต่อเนื่องกี่ปีติด, เคยลด/งดจ่ายช่วงวิกฤตไหม

## ข้อควรระวังทั่วไป
- อัตราส่วนเดี่ยว "ไม่มีความหมาย" ถ้าไม่เทียบ (ก) แนวโน้มของบริษัทเองย้อนหลัง (ข) ค่าเฉลี่ยคู่แข่ง/อุตสาหกรรมเดียวกัน
- ธุรกิจต่างอุตสาหกรรมมีเกณฑ์ปกติต่างกันมาก (เช่น แบงก์ D/E สูงเป็นปกติ, ธุรกิจ software D/E ต่ำเป็นปกติ) — อย่าใช้เกณฑ์เดียวตัดสินทุกอุตสาหกรรม
