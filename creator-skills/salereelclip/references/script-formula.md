# สูตรบทคลิปขาย (ใช้ก่อนเขียน clip.json ทุกครั้ง)

ที่มา: วัดจากคลิปต้นแบบใน `teardown-7elements.md` แล้วเรียบเรียงใหม่เป็นขั้นตอนเขียนบท

## โครง 6 ช่วงกับงบเวลา (คลิป 45 ถึง 60 วิ)

| ช่วง | ทำอะไร | งบเวลา (ต้นแบบ) | ฉากที่ใช้ใน clip.json |
|---|---|---|---|
| Hook | บอกผลลัพธ์ที่คนดูอยากได้ หรือปัญหาที่เขาเจอทุกวัน ในประโยคเดียว | 2–3.5 วิ (2.2) | `split` + `pre`/`kw`/`post` + แผง `proof` ที่โชว์หลักฐาน |
| Setup | สัญญาว่าจะได้อะไรเป็นข้อ ๆ ("มี N อย่าง") | 3.5–4.5 วิ (4.3) | `num` + `numKeep` + แผง `diagram` สรุปทุกข้อในภาพเดียว |
| Body | N ข้อ (5–7) ข้อละ 3.5–5 วิ เลข → คีย์เวิร์ด → ประโยคเดียวว่าทำไม | 55–70% ของคลิป | ข้อละฉาก: `num` + วลี `#คีย์เวิร์ด` + แผงคนละชนิด |
| พักหายใจ | ทุก 2–3 ข้อ แทรกฉากเต็มจอไม่มีแผง 2–3 วิ ประโยคชวนฟังต่อ | 2–3 วิ ต่อครั้ง | `frame: "wide"` ไม่มีแผง |
| Rehook | ความเจ็บ: ถ้ายังไม่ทำ จะเสียอะไร | 4–5 วิ (4.8) | `wide` + `kwColor: "red"` + วลี `#คำเจ็บ` (มี boom อัตโนมัติ) |
| Payoff | ข้อเสนอ: ใครอยากได้ผลแบบนี้ทั้งหมด มีให้ในสินค้านี้ | 5–7 วิ (6.5) | `frame: "offer"` + แผง `funnel` / `grid` / `image` |
| CTA | การ์ดสินค้า + สิ่งเดียวที่ให้ทำ | 3.5–4.5 วิ (3.9) | `frame: "card"` |

ต้นแบบใช้เวลาให้ความรู้ 72% ขาย 19% ถ้าสัดส่วนขายเกิน 35% คลิปจะกลายเป็นโฆษณาที่คนปัดทิ้ง

## 7 ข้อที่ต้องมีในคลิปขาย (เช็กก่อนเรนเดอร์)

1. **อารมณ์และโทน** เลือกสีหลัก 2–3 สี แสง และฉากให้เหมือนกันทุกคลิปของแบรนด์ คนจะจำได้ก่อนเห็นชื่อ (ใน clip.json คือ `theme`)
2. **ข้อความฮุกบนจอ** วินาทีแรกต้องมีคำบนจอที่บอกว่าคลิปนี้เรื่องอะไร คนดูไม่เปิดเสียงก็ต้องรู้
3. **ภาพประกอบทุกช่วง** ทุกข้อมีภาพของตัวเองในแผงบน ห้ามมีข้อที่มีแต่หน้าคนพูด ภาพที่ดีที่สุดคือผลงานจริง ภาพหน้าจอจริง ตัวเลขจริง
4. **คุณค่าที่คนดูได้กลับไป** เขียนให้ได้ก่อนเขียนบทว่า ดูจบแล้วคนดูทำอะไรได้มากขึ้น ถ้าตอบไม่ได้ อย่าเพิ่งเขียน
5. **รูปแบบนำเสนอ** ใช้ format เดิมซ้ำ (เลขข้อ คีย์เวิร์ด แผงภาพ) และหัวข้อเดียวต่อคลิป ไม่หลุดออกนอกเรื่อง
6. **โครงบท** Hook, Setup, Body, Rehook, Payoff, CTA ตามตารางข้างบน
7. **CTA เดียว** บอกชัดว่าให้ทำอะไร (คอมเมนต์คำเดียว / กดลิงก์ / ทักแชต) ต้นแบบมีสอง CTA ซ้อนกัน อย่าทำตาม

## เขียน say ให้ตัดต่อได้

- คั่นวลีด้วย `|` วลีละ 1–4 คำ ตามจังหวะพูด วลีคือซับหนึ่งจังหวะ
- `#คำ` = วลีนี้กลายเป็นคีย์เวิร์ดตัวใหญ่ (ซับเล็กหายไป) ใช้กับชื่อข้อ หรือคำที่ต้องการให้กระแทก
- `~คำ` = พูดแต่ไม่ขึ้นจอ ใช้กับเลขข้อ ("~หนึ่ง") เพราะเลขตัวใหญ่ขึ้นแทนแล้ว
- `*คำ*` = ซับวลีนี้เป็นสีส้มตัวหนา
- คำอังกฤษเขียนเป็นคำอ่านไทยใน `say` แล้วแปลงกลับด้วย `show` (`["เคพีไอ", "KPI"]`)
- 1 ฉาก = 1 ความคิด ฉากยาวเกิน 6 วิ ให้แตกฉาก

## ประโยคเปิด

เทียบกับคลังฮุกของคุณ (ถ้ามี เช่นไฟล์รวมฮุกที่เก็บไว้ข้าง `/vidcraft`) แล้วเสนอผู้ใช้ 3 ตัวเลือก ต้นแบบใช้ฮุกแบบเงื่อนไข "ถ้าจะ [ผลลัพธ์] ..." ตามด้วยตัวเลขข้อทันที

## ข้อห้ามด้านเนื้อหา

- ตัวเลขผลลัพธ์ ยอดขาย ROI เปอร์เซ็นต์ ต้องมาจากผู้ใช้หรือเอกสารจริง ห้ามแต่ง ถ้าไม่มี ให้เขียนเป็นสิ่งที่สินค้าทำได้แทน
- ของแถม โปรโมชัน ราคา เงื่อนไข ในการ์ด CTA ต้องให้ผู้ใช้ยืนยันก่อนเรนเดอร์จริงทุกครั้ง
- ห้ามลอกบท ภาพ หรือแบรนด์ของคลิปต้นแบบ ใช้ได้แค่โครงและวิธีคิด
