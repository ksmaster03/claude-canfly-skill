# /salereelclip: คลิปขายแบบสอนเป็นข้อแล้วพาไปขาย

สคริปต์อยู่ที่ `~/.claude/skills/salereelclip/scripts` (ต่อไปเรียก `<S>`) ไม่ต้องก๊อปไปโปรเจกต์
โปรเจกต์หนึ่งคือโฟลเดอร์หนึ่งที่มี `clip.json` เก็บไว้ใต้ `$WORK` (เช่น `$WORK/<ชื่องาน>`)
แสดงแถบความคืบหน้าตามสกิล `progress-bar` ทุกครั้งที่รายงานสถานะ

อ่านก่อนเริ่มงานแรกของแต่ละวัน:
- `references/script-formula.md` โครงบท 6 ช่วง งบเวลา และ 7 ข้อที่ต้องมี
- `references/teardown-7elements.md` ตัวเลขที่วัดจากต้นแบบ
- `references/example-clip.json` คลิปตัวอย่างขายระบบจองคิวท่ารถ (ชื่อสมมติ) ที่เรนเดอร์ผ่านแล้ว

## ถามผู้ใช้ก่อนเขียนบท (ข้ามข้อที่รู้แล้ว)

1. ขายอะไร ให้ใคร ราคาหรือข้อเสนอคืออะไร และ CTA เดียวที่ต้องการ (คอมเมนต์คำ / ลิงก์ / ทักแชต)
2. มีหลักฐานอะไรบ้าง: ภาพหน้าจอ ผลงาน ยอดวิว รีวิว ตัวเลขจริง (ห้ามแต่งตัวเลขเอง)
3. **คนพูดมาจากไหน** ดูตาราง "สองโหมด"
4. **เสียงมาจากไหน** ดูหัวข้อ "เสียง" คลิปขายคือเชิงพาณิชย์ ต้องบอกเรื่องสิทธิ์ทุกครั้ง

## สองโหมด

| โหมด | เมื่อไร | `bg` ใน clip.json |
|---|---|---|
| A-roll (แนะนำ ตรงต้นแบบ) | ผู้ใช้อัดตัวเองพูดตามบท ถือมือถือแนวตั้ง | `{"type":"aroll","dir":"aroll/frames","fps":30,"count":N}` และ `"head": 0, "tail": 0.3` |
| ภาพตัดพื้น | ไม่มีฟุตเทจ ใช้รูปคนพื้นใส + เสียงพากย์ | `{"type":"cutout","src":"img/presenter.png"}` ใช้รูปของผู้ใช้เอง (เช่น 900x900 พื้นใส) วางไว้ที่ `<proj>/img/presenter.png` |

**คำแนะนำการอัด A-roll ให้ผู้ใช้:** มือถือแนวตั้งระดับสายตา หน้าอยู่กลางจอค่อนล่าง เหลือที่ว่างเหนือหัวราว 35% (แผงครีมจะทับตรงนั้น) แสงอุ่นจากด้านข้าง ห้องมีของตกแต่งโทนเดียวกับแบรนด์ อ่านบทจาก `vo.txt` ต่อเนื่องเทคเดียว พูดผิดให้เว้นสองวินาทีแล้วพูดประโยคนั้นใหม่ (ตัดออกตอนเขียน `say`)

## ลำดับงาน

1. **บท** เขียน `clip.json` ตาม `references/script-formula.md` เสนอฮุก 3 ตัวเลือกจากคลังฮุกก่อน
2. **ซ้อมภาพ** `python <S>/sr_preview.py <proj> 11` ได้ `timeline.json` (กะเวลาจากตัวอักษร) และ `vo.txt` (บทพูดล้วน ฉากละบรรทัด)
   แล้ว `python <S>/sr_render.py <proj> shots <proj>/chk <เวลาที่มันพิมพ์> --guides` ต่อแผ่นด้วย `ffmpeg -i s%02d.jpg -vf "scale=360:-1,tile=6x2"` เปิดดูว่าไม่ล้น ไม่ทับหน้า ไม่ตกเขต UI สีฟ้า
3. **เสียง**
   - A-roll: `python <S>/sr_aroll.py <video> <proj>` ตัดเงียบ (เหลือช่อง 90 ms) แตกเฟรม และถอดเสียงลง `<proj>/asr.json` แล้วแก้ `say` ให้ตรงคำพูดจริงตาม `aroll/transcript.txt` ใส่ `bg` ตามที่มันพิมพ์
   - พากย์: สร้างเสียงตามหัวข้อ "เสียง" จากบทใน `vo.txt`
4. **จับเวลา** `python ~/.claude/skills/explainreel/scripts/align.py <proj> <voice>` (ใช้ตัวเดียวกับ /explainreel) ต้องได้ ratio เกิน 0.8 และ unmatched ใกล้ 0 เปลี่ยนไฟล์เสียงต้องลบ `asr.json` ก่อน ยกเว้นไฟล์ที่ `sr_aroll.py` เพิ่งเขียน
   - A-roll: voice คือ `<proj>/aroll/voice.wav`
5. **ภาพตรวจรอบสอง** แบบข้อ 2 ที่เวลาจริงจาก `timeline.json`
6. **เสียงรวม** `python <S>/sr_mix.py <proj> <voice>` ได้ `master.wav` −14 LUFS true peak ≤ −1.5 dBTP SFX ทุ้มต่ำ 3 ก้อนอัตโนมัติ ไม่มีเพลง (ตามต้นแบบ)
7. **เรนเดอร์** `python <S>/sr_render.py <proj> full <proj>/silent.mp4 3` (สั่ง `run_in_background` คลิป 42 วิ ภาพตัดพื้นใช้ราว 2 นาที)
8. **ประกบ** `python <S>/sr_mix.py <proj> <voice> --mux <proj>/silent.mp4 <proj>/<ชื่อ>.mp4`
9. **ตรวจไฟล์จริง** รัน `python ~/.claude/skills/reelcut/scripts/reelcut_analyze.py <out.mp4> --work <scratchpad>` เทียบกับตาราง "เป้า" ดึงเฟรม 8 ถึง 10 จุดเปิดดู
10. **ปก** ทำด้วยสกิล `/clipcover` ทุกครั้ง ไม่ต้องรอผู้ใช้ขอ

## clip.json

```json
{ "head": 0.4, "tail": 1.0,
  "bg": { "type": "cutout", "src": "img/presenter.png" },
  "theme": { "orange": "#E2582B", "cream": "#F1EBDD" },
  "show": [["เคพีไอ", "KPI"]],
  "lines": [
    { "id": 1, "scene": { "frame": "split", "pre": "ถ้าคลังของคุณ", "kw": "รถยังต่อคิวยาว", "post": "หน้าท่า*ทุกเช้า*",
        "panel": { "type": "proof", "items": [{ "img": "img/a.jpg", "chip": "จดมือ", "play": false }] } },
      "say": "ถ้าคลังสินค้าของคุณ|ยังมีรถต่อคิวยาว|หน้าท่าทุกเช้า" } ] }
```

**`say`:** คั่นวลีด้วย `|` · `#คำ` สลับเป็นคีย์เวิร์ดใหญ่ · `~คำ` พูดแต่ไม่ขึ้นจอ · `*คำ*` ซับสีส้ม · เขียนเป็นคำอ่าน แล้วแปลงกลับด้วย `show`

**ช่องของ `scene`:**

| ช่อง | ความหมาย |
|---|---|
| `frame` | `split` (แผงครีมบน 780 px คนเลื่อนลง ดีฟอลต์เมื่อมี `panel`) · `close` (เต็มจอ ดีฟอลต์) · `wide` (เต็มจอ คนเล็กลง ใช้พักหายใจและฉากเจ็บ) · `offer` (พื้นไล่ขาวไปส้ม แผงสูง 1150 คนอยู่ล่าง) · `card` (การ์ดปิด) |
| `kw` | คีย์เวิร์ดตั้งต้นของฉาก (หรือใช้วลี `#` ใน say ให้ขึ้นตรงคำพูด) · `kwColor`: `red` / `white` · `kwSize` ดีฟอลต์ 150 ย่อเองถ้ากว้างเกิน 960 |
| `pre` / `post` | บรรทัดเล็กเหนือ/ใต้คีย์เวิร์ด (แบบชื่อเปิดของต้นแบบ) มี `post` แล้วซับวิ่งจะซ่อน |
| `num` | เลขข้อตัวใหญ่สีขาวขึ้นต้นฉากราว 0.75 วิ · `numKeep: true` = เลขส้มติดหน้าคีย์เวิร์ดค้างทั้งฉาก (ฉาก Setup) |
| `panel` | แผงภาพด้านบน ดูตารางถัดไป · `panelH` ความสูงแผง · `panelStill` ไม่เล่นเข้า |
| `card` | ฉากการ์ด: `brand` `logo` `title[]` `accent` (บรรทัดสีส้ม) `photo` `bonusTitle` `bonuses[{img,label}]` (`/` ในป้าย = ขึ้นบรรทัด) `under[]` `cta` (`*คำ*` เป็นสีส้ม) |
| `sfx` | `thump` / `boom` / `tick` / `none` ทับค่าอัตโนมัติ |
| `subs: false` | ซ่อนซับวิ่งทั้งฉาก |

**ชนิดแผง (`panel.type`)** ทุกชนิดใส่ `title` ได้ (`*คำ*` เป็นสีส้มในชนิด `text`):

| ชนิด | ช่อง | ใช้เมื่อ |
|---|---|---|
| `proof` | `items[{img, chip, play}]` สูงสุด 3 ใบแนวตั้ง | หลักฐานตอนฮุก: คลิปเก่า+ยอดวิว ผลงาน รีวิว |
| `diagram` | `img`, `labels[]` สูงสุด 7 (บน แล้วสลับขวาซ้าย), `w` `h` | ฉาก Setup สรุปทุกข้อ |
| `swatch` | `title`, `colors[]`, `img`, `imgTitle` | เรื่องสี/โทน |
| `shot` | `img`, `box:[x,y,w,h]` (สัดส่วน 0–1 ของภาพ), `chip`, `play`, `fit` | ชี้จุดสำคัญในภาพหน้าจอด้วยกรอบแดง |
| `mindmap` | `center`, `items[4]` | ประโยชน์หลายด้าน |
| `bars` | `rows[{label, color, w, icon:"loop"}]` | โครง/ขั้นตอน/เทียบระดับ |
| `image` | `img`, `w`, `h`, `fit` | ภาพเดียวเต็มแผง |
| `funnel` | `tiers[3]{side, chip, head, sub, color}` | กลยุทธ์ ฉากข้อเสนอ |
| `grid` | `cols[3]{head, img, pos}` | สินค้าหลายส่วน หลายหมวด |
| `checklist` | `items[]` | สิ่งที่ได้ / สิ่งที่รวมในแพ็กเกจ |
| `compare` | `left{img,label,pos}`, `right{...}` | ก่อน/หลัง |
| `text` | `lines[]`, `size` | ประโยคเด็ดในแผง |

ต้องการชนิดแผงใหม่หรือธีมอื่น: ก๊อป `<S>/engine.html` ไปไว้ใน `<proj>/engine.html` แล้วแก้ที่นั่น ตัวเรนเดอร์หยิบฉบับของโปรเจกต์ก่อน

## รายงาน

- ผมฟังเสียงไม่ได้ บอกทุกครั้งว่าน้ำเสียงและ SFX ยังไม่มีใครฟัง
- ให้ path เต็มของคลิปบรรทัดของตัวเอง พร้อมความยาว ความดัง และสิ่งที่ต่างจากที่ขอ
- ข้อความขายในการ์ด (ของแถม ราคา CTA) บอกว่าเป็นของตัวอย่าง ถ้าผู้ใช้ยังไม่ได้ยืนยัน

## กับดัก

- ข้อความไทยห้ามส่งผ่าน argument ของ Git Bash เขียนไฟล์ด้วย Write หรือ python
- ภาพตัดพื้นวางยึดขอบล่าง ถ้ารูปตัดที่อก คีย์เวิร์ดที่ `--capY` 1500 จะทับอก ถ้ารูปตัดสูงกว่านั้นให้ปรับ `theme.capY` หรือ `bg.width` / `bg.lift` รายโหมดเฟรม
- A-roll ที่มีกราฟิกฝังมาแล้ว (คลิปที่ตัดต่อเสร็จ) จะซ้อนกับแผงและคีย์เวิร์ด ใช้ได้แต่ฟุตเทจดิบ
- ฉาก `offer` ของ A-roll ใช้ภาพจางขอบบนแทนการตัดพื้น ถ้าอยากได้คนตัดพื้นจริงแบบต้นแบบ รัน `python <S>/sr_aroll.py --cut <proj> <t0> <t1>` (ครั้งแรกดาวน์โหลดโมเดล rembg ราว 170 MB) แล้วใส่ `cut` ที่มันพิมพ์ลงใน `bg`
- `align.py` ไม่รู้จักช่อง `hold` (ใช้ได้แค่ตอนซ้อม) ฉากการ์ดยาวตามเสียงพูดบวก `tail`
- ฟอนต์ Kanit (OFL) ตัวเรนเดอร์ฉีดให้เองจาก `assets/fonts` ฟอนต์ไม่ได้แถมมาใน repo ดาวน์โหลด Kanit (OFL) จาก Google Fonts มาวางที่ `assets/fonts/` (ไฟล์ `Kanit-Regular.ttf`, `Kanit-Medium.ttf`, `Kanit-SemiBold.ttf`, `Kanit-Bold.ttf`, `Kanit-ExtraBold.ttf`, `Kanit-Italic.ttf`) ห้ามใส่ letter-spacing กับข้อความไทย
- งานเบื้องหลังเกิน 10 นาทีถูกตัด คลิปยาวให้เพิ่ม jobs ของ `full`
