## ทำฉบับของเรา (‼ ยังไม่เคยรันจริง ทั้งหัวข้อนี้)

ใช้เครื่องมือที่มีอยู่แล้ว ไม่มีฟุตเทจคนพูด จึงแทนครึ่งล่างด้วยการ์ดหรือเสียงโกสินทร์อย่างเดียว

1. **เลือก repo จริง** แต่ละตัวต้องผ่าน:
   `gh api repos/<owner>/<name> --jq '[.full_name,.stargazers_count,.license.spdx_id,.pushed_at,.archived,.description]|@tsv'`
   - pushed_at ไม่เกิน 3 เดือน, archived = false
   - license: MIT/Apache ใช้คำว่า "ฟรี" ได้ · AGPL หรือ NOASSERTION (มีส่วน enterprise) พูดว่า "ฟรีถ้าติดตั้งเอง" · ไม่มี license ห้ามพูดว่า open source
   - ตัวเลขเงิน: ดูราคาแผนจริงจากหน้า pricing ของแอปเสียเงินวันที่ทำ ห้ามลอกตัวเลขจากคลิปต้นทาง
   - เคลมแบบ "646 ภาษา" "200 โมเดล" ต้องตรงกับ README ถ้าใช้ API เสียเงินของคนอื่น (เช่นตัวรวมโมเดลภาพ) ต้องบอกว่า "ไม่ต้องสมัครรายเดือน แต่จ่ายตามใช้"
2. **ภาพหน้าจอ** ใช้ Playwright เปิดหน้า GitHub ของ repo + หน้าเว็บจริง จับภาพ 1280x800 (ภาพแอปเสียเงินใช้หน้าแรกเว็บของเขาเอง เป็นการอ้างอิงเทียบ ไม่ใช้โลโก้ปลอม)
3. **บท** ไทย ประโยคเดียวต่อ repo: "<ชื่อ> คือ <แอปเสียเงิน> ฉบับฟรี <ทำอะไรได้ 1 อย่าง>" รวมไม่เกิน 60 วิ เปิดด้วยเงินที่ประหยัดได้ต่อปี ปิดด้วย "ตัวที่ดีที่สุดเก็บไว้ท้าย" + ชวนคอมเมนต์
4. **เสียง** โกสินทร์3 ผ่าน `/lumina-script` (x1.08) หรือ edge-tts ถ้าเครดิต Lumina ไม่พอ
5. **ภาพเคลื่อนไหว** ใช้เอนจิน `/explainreel` (ฉาก `cards`, `num`, `stamp`, `strike`) ใส่สีป้ายเลขต่างกันต่อ repo ซับกล่องขาวขอบดำ
6. **ลิงก์** ใส่ลิงก์ GitHub ทุกตัวในคำบรรยายตรง ๆ (เราไม่มีระบบ DM อัตโนมัติ อย่าเขียน "คอมเมนต์ 7 แล้วจะส่งให้" ถ้าไม่ได้ตอบจริง)
7. ปกด้วย `/clipcover`, โพสต์ด้วย `/reelpost` ตามกฎเดิม

## กับดัก

- yt-dlp โหลดลิงก์ `facebook.com/share/r/...` ได้ตรง ๆ ไม่ต้องล็อกอิน
- ffmpeg ต้องใส่ PATH ของ winget ก่อน (ดู `/msinterview` กับดัก)
- ชื่อ repo ที่ whisper ถอดผิด: "Chatwood" = Chatwoot, "Open Whisper" = OpenWhispr, "App Flowey" = AppFlowy, "Open Higgs Field" = open-higgsfield ให้ยืนยันจากภาพในคลิป ไม่ใช่จากเสียง
