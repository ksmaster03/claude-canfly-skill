# โปสเตอร์งานอบรม + โครงร่างหลักสูตร

สกิลนี้สกัดมาจากงานจริง: โปสเตอร์อบรม AI ให้หน่วยงานราชการแห่งหนึ่ง (วิทยากร 2 คน + เจ้าภาพ 1 คน)
ซึ่งผ่านมา 5 เวอร์ชันกว่าผู้ใช้จะพอใจ กฎทุกข้อด้านล่างมาจากสิ่งที่พังจริงระหว่างทาง
`template/poster-45.html` เป็นโครงเปล่า (ข้อความทุกช่องเป็นตัวอย่างให้แทนที่)

## ตั้งค่าก่อนใช้

- `$CHATGPT_BRIDGE` = โฟลเดอร์ chatgpt-bridge (ใช้เจนฉากหลัง/โลโก้ และให้ `render.mjs` ยืม playwright)
- ชื่อไฟล์ในเทมเพลต: `host-logo.png` (โลโก้ผู้จัด) · `badge.png` (ตราเจ้าภาพ) · `p-speaker1.png`, `p-speaker2.png`, `p-sponsor.png` (รูปคนตัดพื้น) · `bg.png` (ฉากหลัง)
- ฟอนต์ไม่ได้แถมมาใน repo ดาวน์โหลด Prompt (OFL) จาก Google Fonts มาวางที่ `fonts/Prompt-*.ttf` ข้างไฟล์ html

## หลักใหญ่: แยกงานสามชั้น ห้ามให้ AI ทำทั้งใบ

| ชั้น | ใครทำ | เหตุผล |
|---|---|---|
| ฉากหลัง (ไม่มีคน ไม่มีตัวหนังสือ) | chatgpt-bridge `chatgpt-img.mjs` | ให้ AI ทำเฉพาะสิ่งที่มันเก่ง |
| คนจริง | รูปถ่ายจริง → `scripts/cutout.py` | ให้ GPT วาดคนจากรูปอ้างอิง **หน้าเปลี่ยนเป็นคนอื่นทุกครั้ง** ใช้กับคนจริงที่มีชื่อกำกับไม่ได้ |
| ตัวหนังสือไทย โลโก้ ไอคอน | HTML + Chromium (`scripts/render.mjs`) | โปสเตอร์ที่ AI วาดไทยเองมีคำผิดเงียบ ๆ ("แม่นย่า", "เชี่ยวขาญ", ตัวอักษรกลายเป็น ?) และ **QR ปลอมที่สแกนไม่ได้** |

ห้ามวาดข้อความไทยด้วย PIL / ffmpeg drawtext (สระลอย) และห้ามให้ GPT แก้โปสเตอร์ทั้งใบถ้ามีคนจริงอยู่ในภาพ

## ขั้นตอน

### 1. เก็บข้อเท็จจริงก่อน (ถามได้ แต่ถามเฉพาะที่เดาไม่ได้)
ชื่อ-ยศวิทยากรสะกดตรงตัว, ตำแหน่งใต้ชื่อ, บทบาท (วิทยากร / สนับสนุนโดย), วันที่+เวลา, ห้อง, เบอร์, ลิงก์ QR
- **ชื่อคนไทยห้ามเดา** งานจริงเจอชื่อเดียวกันสะกดต่างกันสองแบบ และผู้ใช้เองพิมพ์ชื่อสลับกันคนละรอบ
  → ถามยืนยันเมื่อสะกดไม่ตรงกันสองแหล่ง ป้ายชื่อบนเครื่องแบบในรูปจริงเป็นหลักฐานที่ดี
- วันไทยต้องตรงวันในสัปดาห์: `python -c "import datetime;print(datetime.date(2026,9,24).strftime('%A'))"`
- ไม่มีข้อมูล → ใช้แบบย่อ (เช่น "ห้องประชุมหน่วยงาน") หรือตัดบรรทัดทิ้ง **ห้ามทิ้งจุดไข่ปลา / 038-xxxxxxx ไว้บนงานส่ง**
- ไม่มีลิงก์ QR → ตัด QR ออก ห้ามใส่ QR ตกแต่ง ถ้ามีลิงก์ ให้สร้างด้วย `segno` แล้วทดสอบอ่านด้วย `zxingcpp` ก่อนส่ง

### 2. ตรวจโปสเตอร์เดิม (ถ้ามี)
รูปที่แปะในแชตไม่มีไฟล์ให้ใช้ต่อ ให้ดึง base64 จาก session jsonl
(`~/.claude/projects/<slug>/<session>.jsonl` → `message.content[].type=="image"`) หรือขอให้ผู้ใช้วางไฟล์
ซูม 5-8 เท่าทีละส่วนก่อนสรุปว่าคำไหนผิด (ที่ 832px ตัว ข/ช และ ำ/่า แยกไม่ออกถ้าไม่ซูม) และทดสอบ QR ด้วย zxingcpp
(ทดสอบตัวอ่านกับ QR จริงขนาดเท่ากันก่อน ถ้าตัวอ่านอ่านของจริงได้แต่อ่านของบนโปสเตอร์ไม่ได้ = QR ปลอม)

### 3. โลโก้ (ถ้าโลโก้เดิมจมพื้น)
`chatgpt-edit.mjs "@prompt.txt" <สัญลักษณ์จริง.png> out.png` สั่ง wordmark สีขาว + สัญลักษณ์สีเดิม บน **pure solid black #000000**
แล้ว `python scripts/logo_alpha.py out.png logo-white.png` ได้พื้นใสที่ขอบเนียน สะกดชื่อแบรนด์ให้ GPT ทีละตัวอักษรใน prompt

### 4. ฉากหลัง
`node chatgpt-img.mjs "<prompt>" scene.png` (ภาษาอังกฤษล้วน ส่งตรงได้) โครง prompt ที่ได้ผล:
"NO PEOPLE in the upper 75% ... ABSOLUTELY NO TEXT, NO LETTERS, NO LOGOS, NO BADGES, NO SIGNS" + ระบุโซนว่างที่จะวางข้อความ
(ซ้าย 45% ว่าง, แถบบน 12% ว่าง) + องค์ประกอบธีม (ฉากและสัญลักษณ์ที่เข้ากับธีมงาน เช่น ไฟสีแบรนด์ สมองกลโฮโลแกรม)
ก่อนรัน bridge: `powershell -File "$CHATGPT_BRIDGE/kill-chatgpt-chrome.ps1"` และรันทีละภาพ ห้ามสองลูปพร้อมกัน

### 5. ตัดรูปคนจริง
```
python scripts/cutout.py police.jpeg p-police.png --fill-body                          # ชุดขาวบนพื้นอ่อน
python scripts/cutout.py avatar.jpeg p-x.png --remove-green --upscale 2 --fade-from 0.64 # รูป LinkedIn #OPENTOWORK
python scripts/cutout.py photo.png p-y.png                                              # ทั่วไป
```
เปิดไฟล์ `*-check.png` (พื้นเขียว) ดูรอยตัดทุกครั้ง ขอบกรอบรูปเดิมที่ตัดตรง ๆ ให้ไล่ด้วย CSS mask (ข้อ 6)

### 6. ประกอบใน HTML
เริ่มจาก `template/poster-45.html` (4:5, 1080×1350) คัดลอกไปโฟลเดอร์งานพร้อม `bg.png`, `p-*.png`, `badge.png`, `tt-logo.png`, `fonts/`
- **ฟอนต์ที่ติดตั้งแบบรายผู้ใช้บน Windows อยู่ในโฟลเดอร์ Fonts ของ LocalAppData ไม่ใช่โฟลเดอร์ Fonts ของระบบ** ให้ก๊อป `Prompt-*.ttf` มาไว้ `fonts/` ข้าง html
  ถ้าโหลดไม่ขึ้น Chromium จะใช้ฟอนต์สำรองเงียบ ๆ และเลย์เอาต์จะพังตอนแก้ (Prompt กว้างกว่ามาก)
- **ห้ามคนซ้อนกัน** (ผู้ใช้เคยติ) จัดเคียงกันหรือแนวทแยง: ผู้สนับสนุน/เจ้าภาพตัวใหญ่ขวาบน วิทยากรเคียงกันซ้ายล่าง แต่ละคนมีการ์ดชื่อใต้ตัว
  คำนวณจากกรอบที่มองเห็น: `ขอบขวา = left + scale × bbox_right` ต้องไม่เกินขอบซ้ายของอีกคน ขนาดหน้าให้ใกล้กัน (face px = scale × ความกว้างหน้าในรูป)
- ขอบกรอบรูปเดิมที่เป็นเส้นตรง: `mask-image: linear-gradient(180deg,#000 62%,transparent 84%), linear-gradient(90deg,transparent 1%,#000 9%); mask-composite: intersect;` หรือเลื่อนรูปให้ขอบชนขอบโปสเตอร์
- **ตัวหนังสือต้องใหญ่ (มันคือโปสเตอร์)** ขั้นต่ำที่ผู้ใช้รับได้บน 1080 px: หัวเรื่อง 88, ชื่อวิทยากร 24-28, เนื้อหา/หัวข้อ 20, ข้อมูลวันเวลา 22, ป้ายเล็ก 17
  ถ้าจัตุรัส 1:1 ใส่ไม่พอ ให้ขยับเป็น 4:5 (Facebook แสดงใหญ่สุด ใกล้โปสเตอร์พิมพ์) ดีกว่าย่อตัวหนังสือ
- ไม่ใส่ letter-spacing กับข้อความไทย (อังกฤษได้) · ไอคอนเป็น SVG เส้น ห้าม emoji · ข้อความยาวตัดบรรทัดเองด้วย `<br>` ที่จุดความหมาย
- สไตล์ที่ผ่าน: พื้นกรมท่า `#06122b`, แดง `#e3262e`, ฟ้าเรือง `#59b4ff`, หัวเรื่อง skewX(-7deg) ExtraBold, กล่องโปร่ง `rgba(8,24,60,.78)` ขอบ `rgba(120,170,255,.35)`

### 7. เรนเดอร์ + ตรวจ (ต้องผ่านทั้งหมดก่อนบอกว่าเสร็จ)
```
node scripts/render.mjs poster.html out.png 2 1350 --check "ชื่อ1|ชื่อ2|วันที่" --boxes ".spk1,.spk2,.topics,.info,.slogan"
```
1. `fonts` ต้อง `loaded` ทุกตัว
2. `--check` ทุกคำต้อง `OK` (ใส่ชื่อคน ยศ ตำแหน่ง วันที่ และคำที่เคยผิด)
3. `--boxes` ไล่ดูว่า bottom ของกล่องบนน้อยกว่า top ของกล่องล่าง (เว้น ≥ 15 px)
4. เปิดภาพดูทั้งใบ แล้ว crop ซูมการ์ดชื่อ/หัวเรื่องจากไฟล์ 2x ดูสระ-วรรณยุกต์
5. ส่งไฟล์เป็นชื่อเวอร์ชันใหม่ทุกครั้ง (`-v5-4x5.png`) ไม่เขียนทับต้นฉบับของผู้ใช้

### 8. โครงร่างหลักสูตร
ใช้สกิล `human-docx` (ย่อหน้าแบบคนเขียน ไม่มี emoji/กล่องสี ตารางเฉพาะกำหนดการ) 
- เวลา "เรียน N ชม. เริ่ม 9 จบ X" → รวมนาทีในตารางให้ได้ N×60 พอดี (พักกลางวันไม่นับ พักเบรกนับ) แล้วบอกผู้ใช้ว่ารวมได้เท่าไร
- เรียงหัวข้อตามโปสเตอร์ ใช้ข้อมูลสมมติใน workshop ทุกกิจกรรม ผูกตัวอย่างกับพื้นที่จริง
- ชื่อ/บทบาทคนต้องตรงกับโปสเตอร์ทุกครั้งที่โปสเตอร์เปลี่ยน (เปลี่ยนวิทยากร → แก้ outline ด้วย)
- แปลง PDF ด้วย Word COM (`SaveAs2(path, 17)`) แล้วตรวจข้อความด้วย `fitz` (PyMuPDF)

## กับดักที่เจอจริง
- `chatgpt-edit` รอบที่สองในลูปเดียวกันอาจค้าง/exit 127 เมื่อถูก kill ระหว่างทาง ให้เช็กไฟล์ผลลัพธ์ ไม่ใช่ exit code
- Git Bash ส่ง prompt ภาษาไทยทาง argument ไม่ได้ ใช้ `"@prompt.txt"`
- เครื่องไม่มี OpenCV ใช้ numpy/PIL/scipy แทน · rembg ต้องติดตั้งเพิ่ม (`pip install "rembg[cpu]"`)
- Python heredoc ที่มี path แบบ Windows → `	` กลายเป็นแท็บ ใช้ `/` ใน path เสมอ
