# /vibe-ui-sources: 5 เว็บแก้หน้าเว็บ AI ที่เหมือนกันหมด

ที่มา: รีล DevKub (FB, 52 วิ, 42K views, 841 reactions, ศึกษา 8 พ.ย. 2569) ไฟล์ `$WORK\_study\fb-1DWPHXMUgX\`
แก่นของคลิป: **"AI เขียนโค้ดเก่ง แต่รสนิยมต้องมาจากคุณ"** ส่งของอ้างอิงจริงให้ AI แทนการสั่งว่า "ทำให้สวย"

## 5 แหล่ง (ตามลำดับการใช้)

| ขั้น | เว็บ | ใช้ทำอะไร | ส่งอะไรให้ AI |
|---|---|---|---|
| 1 หาไอเดีย | godly.website | รวมเว็บสวย ๆ (ส่วนใหญ่เป็นเว็บแอนิเมชันจัด) ดู mood ก่อนเริ่ม | ลิงก์/ภาพหน้าจอเว็บที่ชอบ + บอกว่าชอบอะไร (ตัวอักษร, จังหวะ, แอนิเมชัน) |
| 2 ดูหน้าจอจริง | mobbin.com | คลังภาพหน้าจอแอปและเว็บจริง (คำบรรยายคลิปบอก 600,000 ภาพ) ดูว่าเขาจัด layout, onboarding, pricing, dashboard อย่างไร | ภาพหน้าจอ flow เดียวกับที่จะทำ |
| 3 ก๊อปให้ AI | 21st.dev | คอมโพเนนต์ React + Tailwind (คลิปบอกหลักหมื่น) มีปุ่ม **Copy prompt** วางให้ AI เขียนต่อได้เลย | prompt ที่ก๊อปมา + บอกว่าจะวางตรงไหน |
| 4 ฐานของ UI | ui.shadcn.com | ชุดคอมโพเนนต์ฟรีที่ AI หลายตัวใช้เป็นค่าเริ่มต้น | สั่งให้ใช้ shadcn เป็นฐานแล้วปรับธีม (สาเหตุที่เว็บ AI เหมือนกันก็คือทุกคนใช้ฐานนี้แบบไม่ปรับ) |
| 5 เลือกโทนสี | coolors.co | สุ่มชุดสี กด Space Bar สุ่มใหม่ ล็อกสีที่ชอบ | รหัสสี hex 5 ตัว + บอกบทบาท (พื้น, ตัวอักษร, เน้น) |

## ลำดับงานเมื่อผู้ใช้ให้ทำหน้าเว็บ

1. ถามหรือหาเว็บอ้างอิง 1 ถึง 3 เว็บ (Godly) และหน้าจอแอปแนวเดียวกัน (Mobbin) ถ้าผู้ใช้ไม่มี ให้เสนอทิศทาง 2 แบบพร้อมเหตุผล
2. แตกหน้าเป็นส่วน (เมนู, ฮีโร่, การ์ด, หน้าแอป, ท้ายเว็บ) แล้วจับคู่แต่ละส่วนกับแหล่ง: ฮีโร่จาก Godly, การ์ด/ปุ่มจาก 21st.dev, ฐานทั้งหมด shadcn
3. ตั้ง design tokens ก่อนเขียนหน้า: ชุดสีจาก Coolors (5 สี กำหนดบทบาท), ฟอนต์, radius, spacing ใส่เป็นตัวแปร CSS / theme ของ shadcn
4. เขียนหน้าโดยใช้คอมโพเนนต์จริงจาก 21st.dev/shadcn ไม่สร้างทุกอย่างจากศูนย์
5. ตรวจด้วยสกิลที่มีในเครื่อง: `/impeccable` หรือ `/taste-skill` (กันหน้าตา AI), `/better-colors` (contrast), `/better-interface`

prompt ตั้งต้นที่ส่งให้ AI (ปรับค่าในวงเล็บ):
```
ทำหน้า (landing page ของ X) ด้วย Next.js + Tailwind + shadcn/ui
mood อ้างอิง: (ลิงก์ Godly) ชอบ (ตัวอักษรใหญ่ ช่องว่างเยอะ แอนิเมชันตอนเลื่อน)
layout อ้างอิง: (ภาพจาก Mobbin)
ชุดสี: พื้น #0d1b2a ตัวอักษร #e0e1dd เน้น #ffb703 รอง #8ecae6 เส้น #415a77
ใช้คอมโพเนนต์นี้เป็นฮีโร่: (prompt จาก 21st.dev)
ห้ามใช้ค่าเริ่มต้นของ shadcn ตรง ๆ ให้ปรับ radius ฟอนต์ และสีตาม token ข้างบน
```

## รูปแบบคลิปต้นทาง (ถ้าจะทำคลิปแนวนี้)

- พื้นดำแบบเทอร์มินัล มุมจอมีป้ายเล็ก `01 / HOOK`, `02 / GODLY` ... บอกฉาก โลโก้ช่องกลางบน
- หัวข้อขั้นตอนตัวขาวหนา ("1 หาไอเดีย") ใต้นั้นเป็นการ์ดหน้าต่างเบราว์เซอร์ (จุดสามสี + URL) อัดหน้าเว็บจริง
- มาสคอตการ์ตูนมุมล่างซ้ายพร้อมแถบเสียงขยับ ซับคำสำคัญตัวใหญ่ข้างมาสคอต มีขีดสีเขียวใต้คำ
- เปิดด้วยปม "ให้ AI ทำเว็บแล้วหน้าตาเหมือนกันหมดใช่ไหม" + ภาพเว็บประกอบจาก 5 ชิ้น นับ 0/5 → 3/5 → 5/5 ตามแหล่งที่เติม
- ปิด: ประโยคจำ 1 บรรทัด → CTA ตัวอักษรในกล่อง `V I B E` "คอมเมนต์คำนี้รับลิสต์ทางแชท" → ปุ่ม "ติดตาม" กลายเป็น "ติดตามแล้ว ✓"
- 5 ข้อใน 52 วิ ข้อละประมาณ 7 วิ

## ข้อควรรู้

- จำนวนภาพ/คอมโพเนนต์ (600,000 / 10,000–12,000) มาจากคลิปและคำบรรยาย ยังไม่ได้ตรวจกับเว็บจริง
- Mobbin ดูเต็มต้องสมัครแบบเสียเงิน Godly, 21st.dev (บางคอมโพเนนต์), shadcn/ui, Coolors ใช้ฟรีได้
- คอมโพเนนต์จาก 21st.dev มาจากผู้เขียนหลายคน เช็ก license ก่อนใช้ในงานลูกค้า
