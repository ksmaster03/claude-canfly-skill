# /darkui-repo-reel: รีลจอมืด "N repo ฟรี" ไม่ต้องพากย์

ที่มา: ศึกษารีลทั้ง 25 คลิปของเพจ Altair AI (9 พ.ย. 2569) ดู `$WORK\_study\fbreels-100092880740003\STUDY.md`
คลิปแบบคนพูดหน้ากล้องของเพจนั้นได้ 13 ถึง 154 วิว พอเปลี่ยนเป็นแบบนี้ได้ 2 พัน ถึง 2.7 หมื่น (สูงสุด "94 Claude plugins จากทีม Boris Cherny")

## ทำไมได้ผล

- **ภาพเป็นแค่ตัวดึงสายตา** วนลูปสวย ๆ 15 ถึง 35 วิ คนดูซ้ำ แล้วไปอ่านแคปชัน ความรู้จริงทั้งหมดอยู่ในแคปชัน
- **บรรทัดแรกของแคปชันคือทุกอย่าง**: คำแรง + ชื่อคนหรือบริษัทที่คนรู้จัก (Anthropic, Boris Cherny, CEO YC, CEO Obsidian) + "ฟรี" + "คนส่วนใหญ่ยังไม่รู้"
  - ในยุคเดียวกัน คลิปภาพแบบเดียวกันแต่ hook เป็นรายการเฉย ๆ ไม่มีชื่อคนดัง ได้แค่ 65 ถึง 166 วิว
- **ตัวเลขชัด**: จำนวนชิ้น, ดาวรวม, "เอเจนซีคิด $300 ถึง 1,500 ต่อชิ้น ที่นี่ $0"
- **ใส่ลิงก์ในแคปชันเลย** ไม่ต้อง "คอมเมนต์แล้วจะ DM ให้" (เพจนั้นทำแบบ DM แล้วไม่ได้ผล และเราไม่มีระบบ DM อัตโนมัติ)

## ขั้นตอน

1. **หาหัวข้อ**: ข่าวหรือรายการ repo ที่กำลังมาในฝั่งอังกฤษ (เพจ Altair, X, รายการที่ /page-study เก็บไว้) เลือกที่มีชื่อคนหรือบริษัทดังเป็นเจ้าของ 5 ถึง 10 ชิ้น
2. **เขียน `data.json`** ในโฟลเดอร์งาน `$WORK\<ชื่องาน>\` (ตัวอย่างที่รันผ่านแล้ว: `$WORK\darkui-test\data.json`)
   ```json
   {
     "tag": "CLAUDE + OBSIDIAN",              // ป้ายเล็กมุมซ้ายบน ภาษาอังกฤษตัวใหญ่
     "title": "5 เครื่องมือจาก CEO Obsidian",   // บนจอ ยาวเกินจะย่อตัวอักษรเอง (ไม่ต่ำกว่า 44px)
     "subtitle": "แจกฟรีบน GitHub ให้ Claude ใช้ Obsidian เป็น",
     "hook": "บรรทัดแรกของแคปชัน: คำแรง + ชื่อคนดัง + ฟรี + คนส่วนใหญ่ยังไม่รู้",
     "lead": "(ไม่บังคับ) ย่อหน้าสั้นใต้ hook เช่น ตัวเลขรวม",
     "accent": "#b18cff",
     "items": [
       {"repo": "owner/name", "name": "ชื่อสั้นในรายการ", "label": "(ไม่บังคับ) ชื่อบนการ์ด",
        "line": "บนจอ ไม่เกิน ~30 ตัวอักษร", "why": "ในแคปชัน ประโยคเดียวว่าช่วยอะไร"}
     ],
     "howto": ["ขั้น 1", "ขั้น 2", "ขั้น 3"],
     "outro": "ลิงก์ครบทุกตัวอยู่ในแคปชัน 👇", "outro2": "กดบันทึกไว้ก่อนหาไม่เจอ",
     "per": 2.6, "intro": 3, "outro_sec": 3.2, "seed": 7
   }
   ```
   ไฟล์ JSON จริงห้ามมีคอมเมนต์ `//` (ในตัวอย่างใส่ไว้อธิบายเท่านั้น) item ที่ไม่ใช่ repo ให้ใส่ `"url"` แทน `"repo"`
3. **ตรวจกับ GitHub จริง** เติมดาว ลิงก์ และเขียน `caption.txt`:
   `node ~/.claude/skills/darkui-repo-reel/scripts/verify.mjs data.json`
   - ✓ ผ่าน · ⚠ archived, ไม่อัปเดตเกิน 3 เดือน, ไม่มี license (ห้ามเรียกว่า open source หรือ "ฟรี" แบบเหมารวม) · ‼ ไม่พบ ต้องแก้ก่อน (exit 1)
   - ดาวในจอกับแคปชันใช้ค่าที่สคริปต์ดึงมาเท่านั้น **ห้ามลอกตัวเลขจากโพสต์ต้นทาง** ตัวเลขอื่นในโพสต์ต้นทาง เช่น ราคาเอเจนซี หรือคำสั่งที่อ้างว่ามาจากเอกสาร ให้ตรวจก่อน ตรวจไม่ได้ให้ตัดทิ้ง
4. **ตรวจเลย์เอาต์ด้วยเฟรมเดียว** แล้วเปิดดูภาพทุกครั้ง:
   `node ~/.claude/skills/darkui-repo-reel/scripts/render.mjs data.json . --still 6`
   ดูว่าชื่อบนการ์ดไม่ล้น ภาษาไทยไม่ลอย และรายการไม่ทับลายน้ำ
5. **เรนเดอร์วิดีโอ** (1080x1920, 30fps, ราว 1 นาทีต่อคลิป 20 วิ):
   `node ~/.claude/skills/darkui-repo-reel/scripts/render.mjs data.json . [--bgm "<ไฟล์ใน $MEDIA\bgm>"]`
   ได้ `reel.mp4` เพลงค่าเริ่มต้นคือ `Deep Space Sector 9 - Ezra Lipp.mp3` เบาลง 6 dB มีเฟดเข้าและออก
   ตรวจด้วย contact sheet: `ffmpeg -i reel.mp4 -vf "fps=12/<วินาที>,scale=270:-1,tile=6x2" -frames:v 1 sheet.jpg`
6. **แคปชัน**: อ่าน `caption.txt` แล้วเกลาเป็นภาษาคน (ใช้ /humanizer ได้) จากนั้นทำปกด้วย `/clipcover` (หรือใช้เฟรมการ์ดใบแรก) แล้วโพสต์ด้วย `/reelpost` เมื่อผู้ใช้สั่งเท่านั้น

## โครงภาพ (template/scene.html วาดด้วย canvas ตามเวลา t ทุกเฟรมได้ผลเหมือนเดิม)

| ช่วง | ภาพ |
|---|---|
| 0 ถึง intro (3 วิ) | หัวข้อพิมพ์ทีละตัว โหนดค่อย ๆ ปรากฏ รายการเทอร์มินัลไล่ขึ้น |
| ทีละรายการ (`per` วิ) | กลุ่มโหนดของรายการนั้นสว่าง พัลส์วิ่งตามเส้น การ์ดเลขสี + ชื่อ + บรรทัดเดียว แถวในรายการขึ้น ▶ ตัวที่ผ่านไปแล้วขึ้น ✓ ตัวนับมุมขวาบน |
| ปิด (`outro_sec`) | การ์ด "ลิงก์ครบทุกตัวอยู่ในแคปชัน 👇" |
| ตลอด | ลายน้ำ "โกสินทร์ต้องบินได้ \| ติดตามไว้ ไม่ตกข่าว AI" (`watermark` เปลี่ยนได้) |

อยากได้ภาพแบบอื่น เช่น dashboard หรือ flow chart แบบคลิป "Haiku + Opus advisor" ให้เพิ่มฉากใหม่ใน scene.html โดยยังวาดจาก `draw(t)` เหมือนเดิม แล้วเลือกฉากด้วยฟิลด์ใน data.json

## กับดัก

- render.mjs ยืม Playwright จาก `$PROJECTS/reel-bridge` (createRequire) ถ้าย้ายโฟลเดอร์นั้นต้องแก้บรรทัด require
- ฟอนต์ Kanit ติดตั้งใน user fonts แล้ว Chromium หาเจอจากชื่อ ถ้าเครื่องใหม่ไม่มี หัวข้อจะเป็น Leelawadee
- toDataURL แบบ jpeg 0.92 ไฟล์ราว 5 MB ต่อ 20 วิ อยู่ในเกณฑ์ 10 MB ของ /reelpost
- FB เอาแถบแคปชันและปุ่มทับขอบล่างราว 300px กับขอบขวา อย่าย้ายข้อมูลสำคัญลงไปต่ำกว่าบรรทัดรายการ
- โหนดสุ่มด้วย `seed` ถ้าทำหลายคลิปติดกัน ให้เปลี่ยน seed และ accent ไม่ให้หน้าตาซ้ำ
