# /newsreel: คลิปเล่าข่าวแนวตั้งจากภาพฟรี

ถอดแบบจากคลิปเล่าข่าวของเพจ Chimlang (12 ต.ค. 2026 ยาว 12 นาที) ตัวเลขที่วัดได้และวิธีพูดอยู่ใน `references/speech-style.md` **อ่านไฟล์นั้นก่อนเขียนบททุกครั้ง**
ใช้เครื่องยนต์ร่วมกับ `/explainreel` (`align.py` `mix.py` `render_range.py`) และเขียนบทเสียงตาม `/lumina-script`
โปรเจกต์หนึ่งคือโฟลเดอร์หนึ่งที่มี `clip.json` ด้านล่าง `<nr>` = `<skill_dir>/scripts` และ `<ex>` = `~/.claude/skills/explainreel/scripts`

## ลำดับงาน

1. **ถามความยาว** ถ้าผู้ใช้ไม่บอก ใช้ 90 ถึง 180 วินาที (900 ถึง 1,800 ตัวอักษรพูด)
2. **ค้นข่าวจากแหล่งต้นทางอย่างน้อย 2 สำนัก** จดลิงก์ ชื่อสำนัก วันเวลา ตัวเลข และคำพูดตรงตัว ห้ามแต่งตัวเลขหรือคำพูด เรื่องที่ยังไม่มีข้อพิสูจน์ต้องเขียนว่ายังไม่มีหลักฐาน
3. **เขียน `clip.json`** ตามโครงเล่าใน `references/speech-style.md` ตัวอย่างเต็มอยู่ที่ `references/example-clip.json` บรรทัดสุดท้ายต้องเป็นฉาก `cta`
4. **หาภาพ** เขียน `queries.txt` แล้ว `python <nr>/find_images.py <proj> <proj>/queries.txt 4` เปิด `img/_sheet_<slug>.jpg` ดูทุกแผ่นแล้วเลือกเอง ผลค้นมั่วบ่อย ห้ามใช้ภาพโดยไม่ดู
5. **ตรวจ** `python <nr>/prep.py <proj>` ต้องไม่มี ERROR (ตัวนี้เติมเครดิตภาพ วาง `scenes.html` และเขียน `vo_plain.txt` ให้ด้วย)
6. **ดูภาพก่อนใช้เครดิตเสียง** `python <nr>/draft_timeline.py <proj>` แล้ว `python <ex>/render_range.py <proj> shots <proj>/chk <เวลา...>` เปิดดูว่าหน้าคนไม่โดนตัด ซับไม่ทับจุดสำคัญ
7. **เสียงพากย์** ตามหัวข้อ "เสียงพากย์"
8. **จับเวลา** `python <ex>/align.py <proj> <proj>/voice.mp3` ต้องได้ ratio เกิน 0.8
   ก่อนจับเวลา ตรวจคำที่ออกเสียงเพี้ยนด้วย `asr_check.py` แล้วแก้ให้จบตามขั้น 5 ของ `/explainreel` ห้ามส่งงานโดยแค่แนบตารางคำให้ผู้ใช้ไปฟังเอง (ผู้ใช้สั่ง 17 ต.ค. 2569)
9. **เสียงรวม** `python <ex>/mix.py <proj> <proj>/voice.mp3 14 <เพลง>` เพลงเลือกแนวนิ่ง ตึง ไม่มีเสียงร้อง จาก `$MEDIA\bgm` หรือสั่ง Suno ตาม `/explainreel`
   ถ้าโควตา Suno หมดและ `$MEDIA\bgm` ไม่มีเพลงที่เข้าโทน ใช้ YouTube Audio Library ใน Studio ของผู้ใช้ได้ วิธีและตัวตรวจว่าไม่มีเสียงร้องอยู่ใน `~/.claude/skills/vidcraft/references/reel-lessons.md` ข้อ 6
10. **เรนเดอร์** แบ่ง 3 ช่วงเฟรมด้วย `render_range.py <proj> <f0> <f1> <out.mp4>` รันเบื้องหลังพร้อมกัน แล้ว concat และประกบ `master.wav` ตามขั้น 9 ถึง 10 ของ `/explainreel`
11. **ทำปกเตรียมไว้** ตามสกิล `/clipcover`: เขียน `<proj>/cover.json` แล้ว `python ~/.claude/skills/clipcover/scripts/make_cover.py <proj>` ไม่ต้องรอผู้ใช้ขอ
12. **ตรวจไฟล์จริงแล้วรายงาน** ตามหัวข้อ "รายงาน" พร้อม path ของปก

## clip.json

```json
{ "head": 0.4, "tail": 1.4,
  "show": [["แปดสิบสี่เปอร์เซ็นต์", "84%"]],
  "lines": [
    { "id": 1, "scene": { "type": "photo", "img": "img/vote_1.jpg", "chip": "แพ้แล้วหลุดปากเอง", "tag": "NEWS FILE #0001", "brand": "โกสินทร์ต้องบินได้" },
      "say": "คนที่พูดมาทั้งปี|ว่าอีกฝ่ายมีพรรคหนุน|*กลับหลุดปากเอง*" } ] }
```

- `say` และ `show` ใช้กติกาเดียวกับ `/explainreel`: เขียนคำอ่าน คั่นวลีด้วย `|` ครอบวลีเด่นด้วย `*...*` ตัวเลขเขียนเป็นคำแล้วแปลงกลับด้วย `show`
- ตัวเลขในซับ ป้าย และแถบข้อมูลเป็นสีเหลืองเอง ไม่ต้องทำอะไร
- `tag` และ `brand` ใส่ที่บรรทัดแรกบรรทัดเดียว ใช้ทั้งคลิป

| ฉาก | ช่อง | ใช้เมื่อ |
|---|---|---|
| `photo` | `img` (ไฟล์เดียวหรือรายการ แบ่งเวลาเท่ากัน) · `chip` ป้ายกรอบเหลือง · `info` แถบดำ 1 ถึง 2 บรรทัด · `pos` top/center/bottom · `credit` | เกือบทุกบรรทัด |
| `stamp` | `text` | ตราแดงเอียงบนพื้นดำ คำไม่เกิน 12 ตัวอักษร ใช้ 2 ถึง 3 ครั้งในช่วงเปิด และตอนเปลี่ยนตอน |
| `cta` | `head` `a` `b` `name` | บรรทัดสุดท้าย ปุ่มกดไลก์กับกดติดตามเด้งทีละปุ่ม |

**จังหวะภาพ:** ช็อตเฉลี่ยราว 5 วินาที บรรทัดที่พูดเกิน 7 วินาทีให้ใส่ `img` เป็นรายการ 2 ถึง 3 ภาพ `chip` ใช้กับ 20 วินาทีแรกและจุดเปลี่ยนเรื่อง `info` ใช้ตอนแนะนำคน วันที่ หรือตัวเลขหลัก
**โครงสองความเร็ว (วัดจากคลิป 2.16 ล้านวิว):** ช่วงเล่าช็อตละราว 5 วินาที ช่วงสรุปหรือไล่รายการช็อตละ 0.6 ถึง 1.5 วินาทีตามจังหวะเพลง และเพลงเข้าเต็มตรงนั้น · ป้ายชื่อคน (`info`) ขึ้นตอนคนโผล่ครั้งแรกครั้งเดียว
**ซับ:** วลีละ 2 ถึง 5 คำ ไม่เกิน 26 ตัวอักษร บรรทัดเดียว ตัดตามความหมาย

## ภาพ

- `queries.txt` บรรทัดละ `slug | คำค้น | แหล่ง` คำค้นภาษาอังกฤษที่เจาะจง (ชื่อคน ชื่อสถานที่ ชื่อหน่วยงาน) ได้ผลดีกว่าคำไทย
- ตัวหาภาพรับเฉพาะ CC0, CC BY, CC BY-SA และสาธารณสมบัติ เก็บเครดิตไว้ใน `credits.json` และขึ้นเครดิตมุมล่างซ้ายของภาพเอง
- **ห้ามเอาภาพจากเว็บข่าว Google Images หรือโซเชียลมาใช้** ถ้าไม่มีภาพเสรีของบุคคลในข่าว ให้ใช้ภาพสถานที่ หน่วยงาน หรือสิ่งของที่เกี่ยว แล้วบอกผู้ใช้ว่าไม่มีภาพบุคคล
- ภาพคนที่ไม่เกี่ยวกับข่าว ห้ามวางคู่กับประโยคกล่าวหา คนดูจะเข้าใจว่าเป็นคนในข่าว

## เสียงพากย์

1. เอา `vo_plain.txt` มาใส่แท็กตาม `/lumina-script` ได้ `vo_lumina.txt` ถ้อยคำต้องตรงกับ `say` ต่างได้แค่แท็กและคำเอ่อ โทนเล่าข่าว: อารมณ์หลักสุขุม ใส่แท็กอารมณ์น้อยกว่าคลิปทั่วไป ไม่ใช้หัวเราะ `@หยุดพัก` ไม่เกิน 500ms
2. รัน `python ~/.claude/skills/lumina-script/scripts/lint.py <proj>/vo_lumina.txt`
3. เปิดแท็บ `https://luminatts.vercel.app/` ใน Chrome ที่ผู้ใช้ล็อกอิน **เลือกเสียง "โกสินทร์3" แล้วถ่ายภาพหน้าจอยืนยันชื่อเสียงก่อนกดสร้าง** ถ้าไม่เจอชื่อนี้ให้หยุดถามผู้ใช้ ห้ามใช้เสียงอื่นแทนเอง
4. ส่งบทด้วย `lumina_bridge.py` กับ `lumina_page.js` ตาม `/lumina-script` บันทึกเป็น `<proj>/voice.mp3`
5. บทเกิน 4,600 ตัวอักษร (รวมแท็ก) แบ่งสร้างเป็นสองไฟล์แล้วต่อด้วย ffmpeg concat ก่อนจับเวลา
6. บอกผู้ใช้ทุกครั้ง: เครดิตฟรีของ Lumina ใช้กับงานไม่เชิงพาณิชย์ และข้อตกลงห้ามบอต

ระดับเสียง: `mix.py` ปรับเป็น -14 LUFS และจำกัดยอดที่ -1.5 dB ให้แล้ว (ต้นแบบยอดเกิน 0 dBFS อย่าทำตาม)

## รายงาน

- path เต็มของคลิปในบรรทัดของตัวเอง ความยาว ความดัง จำนวนช็อต
- ลิงก์แหล่งข่าวทุกแห่ง และรายการเครดิตภาพจาก `credits.json` สำหรับวางใต้โพสต์
- บอกตรง ๆ ว่ายังไม่มีใครฟังเสียง และรายงานคำที่แก้คำสะกดไปแล้ว พร้อมจุดที่เหลือซึ่งเป็นแค่การสะกดต่างของตัวถอดเสียง
- ถ้าใช้ภาพแทนเพราะหาภาพบุคคลในข่าวไม่ได้ ให้บอกว่าบรรทัดไหน
- เขียน `caption.txt` กับ `youtube.txt` ไว้รอ ผู้ใช้สั่งโพสต์หรือตั้งเวลาเมื่อไรใช้สกิล `/reelpost` (เพิ่ม 17 ต.ค. 2569)

## กับดัก

- ข้อความไทยห้ามส่งผ่าน argument ของ Git Bash เขียน `queries.txt` และ `clip.json` ด้วย Write
- รัน python ที่พิมพ์ไทยต้องตั้ง `PYTHONIOENCODING=utf-8` ไม่งั้นพังที่ cp1252
- `prep.py` คัดลอกแม่แบบทับ `<proj>/scenes.html` ทุกครั้ง ถ้าจะแก้ธีมให้แก้ที่ `<nr>/news.html` หรือแก้หลังรัน prep ครั้งสุดท้าย
- ภาพแนวนอนถูกครอปเป็นหน้าต่างเกือบจัตุรัส (1080x1300) หน้าคนที่อยู่ริมภาพจะหลุด ใช้ `pos` หรือเลือกภาพอื่น
- ต้นแบบมีคลิปเสียงสัมภาษณ์แทรก 17% ของเวลา สกิลนี้ไม่ทำ เพราะคลิปข่าวต้นทางมีลิขสิทธิ์ ให้เล่าคำพูดแทนและบอกชื่อสำนักที่รายงาน
- เพลงตื่นเต้นแบบกลองรัว: สั่ง Suno ด้วย `--instrumental --styles "military marching snare drum rolls, army field drum cadence, relentless rolling snares, deep war drums, percussion only, no melody, no vocals"` แล้วผสมที่เบากว่าเสียงพากย์ 12 dB (ใช้จริงกับคลิป ArtCraft 12 ต.ค. 2026)
- บทที่ได้เสียงยาวเกิน 90 วินาที `lumina_page.js` จะรอไม่ทัน ให้กด GENERATE แล้วปล่อยให้หน้าเว็บ POST ไฟล์กลับเองเบื้องหลัง แล้วรอไฟล์ `voice.mp3` จากฝั่งเครื่อง
- Wikimedia ตอบ 429 เมื่อโหลดภาพติดกันราว 80 ไฟล์ แบ่ง `queries.txt` เป็นรอบละไม่เกิน 15 คำค้น
- URL thumbnail ของ Wikimedia มี query string ต่อท้าย ถ้าตัดนามสกุลจาก URL จะได้ชื่อไฟล์เพี้ยน ดูชนิดไฟล์จาก magic bytes
- เสียงโคลนออกเสียงชื่อฝรั่งที่สะกดเป็นไทยเพี้ยนได้ (เชสเตอร์ ได้ยินเป็น ชัตเตอร์) ใส่ชื่อเหล่านี้ในตารางคำที่ต้องให้ผู้ใช้ฟังเสมอ


## กฎความเร็วเสียงโกสินทร์3 (ผู้ใช้สั่ง 21 ต.ค. 2569)
เสียง "โกสินทร์3" ทุกคลิปต้อง**เร็วขึ้น 8%** หลังได้ไฟล์จาก Lumina ให้เร่งด้วย ffmpeg `-af atempo=1.08` (เสียงไม่แหลม) ก่อน align และ mix ไม่ใช้แท็ก `@ความเร็ว=0.8` เสียงอื่น (เช่น ลินดา) คงความเร็วเดิม
เหตุผล: คนดูบ่นว่าพูดช้า ผู้ใช้ฟังเทียบ 1.00 / 1.08 / 1.15 แล้วเลือก 1.15 ก่อน จากนั้นเปลี่ยนเป็น 1.08 (เร็วขึ้น 8%) วันเดียวกัน
ตัวอย่าง: `ffmpeg -i vo.mp3 -af atempo=1.08 vo_fast.wav` แล้วใช้ไฟล์เร่งแล้วในขั้นต่อไปทั้งหมด (ตรวจคำเพี้ยนด้วยไฟล์ที่เร่งแล้ว)
