# วิธีพูดและวิธีตัดของคลิปเล่าข่าวต้นแบบ

วัดจากคลิป "สาวไส้กันเอง 'ลุงพนัส' หลุดปากแฉ" เพจ Chimlang เผยแพร่ 12 ต.ค. 2026 ยาว 727.7 วินาที
ไฟล์ที่วัดเป็นไฟล์จากเฟซบุ๊ก (AV1 + HE-AAC) ไม่ใช่มาสเตอร์ บทถอดด้วย faster-whisper รุ่น small จึงสะกดเพี้ยนบางคำ

## ตัวเลขที่วัดได้

| เรื่อง | ค่า |
|---|---|
| เสียงบรรยาย | ราว 566 วินาที (78%) |
| คลิปเสียงสัมภาษณ์แทรก | 5 ช่วง รวมราว 124 วินาที (17%) ยาว 3, 6, 30, 28 และ 57 วินาที |
| ความเร็วพูด | 7.7 พยัญชนะต่อวินาที |
| ความยาวประโยค | กลาง 2.9 วินาที (ช่วง 2.0 ถึง 3.8) |
| ช่องว่างระหว่างประโยค | 45% ต่อกันไม่เว้น ที่เหลือเว้นกลาง 0.32 วินาที ไม่มีช่องเงียบเกิน 1 วินาที |
| ระดับเสียงพูด | กลาง 147 Hz ช่วงกว้าง 16.7 เซมิโทน (รวมเสียงคนในคลิปแทรก) |
| ช็อตภาพ | 147 ช็อต เฉลี่ย 5.2 วินาที ตัดฉับทั้งหมด |
| สีภาพ | มืดและซีด ความสว่างกลาง 57 จาก 255 พิกเซลดำสนิท 22% ความอิ่มสีเฉลี่ย 0.21 |
| ความดัง | -14.2 LUFS, LRA 2.4 LU, ยอด +0.2 dBFS (เกิน ไม่ควรทำตาม) |

เพลงประกอบ: ยังไม่ได้ชี้ขาดว่ามีหรือไม่ เพราะตัวแยกสเต็มเสียงถูก Application Control ของเครื่องบล็อก

| 20 ถึง 36 วิ | บอกว่าเป็นใคร พร้อมตำแหน่งและตัวเลขประจำตัว | "คนพูดคือลุงพนัส ผู้นำแรงงานที่นั่งเก้าอี้บอร์ดมาแปดสมัย" |

| ราว 80% | เฉลยปมที่ทิ้งไว้ ไล่ลำดับคำพูดเต็ม | "ถึงเวลาแกะท่อนเต็ม" |

| ปิด | สกิลนี้เพิ่ม: ชวนกดไลก์ กดติดตาม (ต้นแบบไม่มี) | |

## เครื่องมือการพูดที่ต้องมีในบท

1. **อ้างสำนักข่าวด้วยชื่อทุกครั้งที่ให้ข้อเท็จจริง** "มติชนรายงานว่า" "ไทยพีบีเอสรายงานว่า" ใช้คำกริยา "รายงาน" ไม่ใช้ "ว่ากันว่า"
2. **พูดกับคนดูตรง ๆ** "คุณผู้ชมนึกภาพตามนะครับ" "ลองวางตัวเลขเทียบกันดู" "คุณผู้ชมอาจสงสัยว่าเกี่ยวตรงไหน" ต้นแบบใช้ราวนาทีละครั้ง
3. **คำเปลี่ยนตอนสั้น ๆ แบบภาษาพูด** "เอาล่ะ กลับเข้าเรื่อง" "โอเค มาดูตัวเลขกันชัด ๆ" "อ้าว" "โอ้โห"
4. **ตัวเลขต้องมีตัวเทียบ** ไม่พูดเลขเดี่ยว "เจ็ดแสนกว่ากับหนึ่งหมื่นแปดพัน ห่างกันเกือบสี่สิบเท่า"
5. **ยกคอมเมนต์ของคนอ่านมาเป็นเสียงที่สอง** "ใต้โพสต์มีคนพิมพ์ว่า" "อีกคนคอมเมนต์ว่า" ยกทั้งฝั่งตำหนิและฝั่งเห็นใจ
6. **ดึงมาที่คนธรรมดา** "ลองนึกถึงพนักงานโรงงานสักคน โดนหักเงินสมทบทุกเดือนมาสิบปี"
7. **ให้ความเป็นธรรมกับคนที่ถูกพาดพิง** บอกคำปฏิเสธของเขา และบอกว่ายังไม่มีหลักฐาน ต้นแบบทำ 2 ครั้ง กลางเรื่องและก่อนจบ
8. **ความเห็นของผู้เล่าแยกจากข้อเท็จจริง** ขึ้นต้นว่า "ถ้าให้เดานะครับ" "มองอีกมุม"
9. **ประโยคสั้น** 2 ถึง 4 วินาที สลับกับประโยคสั้นมาก ("คำถามนี้ไม่ได้ถามเล่น ๆ" "แล้วนี่คืออะไร") พูดต่อเนื่อง ไม่เว้นนาน
10. ลงท้าย "ครับ" "นะครับ" เป็นระยะ ไม่ทุกประโยค

## ภาพและซับ

- พื้นมืด ภาพข่าวอยู่ในหน้าต่างกลางจอ ซูมช้า มุมจอมีขีดกรอบ มุมซ้ายบนมีเลขแฟ้ม
- 10 วินาทีแรกสลับภาพกับตราแดงบนพื้นดำ ("หลุดปากคาจอ" "เจ้าตัวรีบปัด") และป้ายกรอบเหลือง ("แพ้แล้วหลุดปากเอง" "สาวไส้กันเอง?")
- แถบดำสองบรรทัดตอนแนะนำคนหรือวันที่ ("'ลุงพนัส' บอร์ด / ประกันสังคม 8 สมัย") ตัวเลขสีเหลือง
- ซับทีละวลี 2 ถึง 5 คำ บรรทัดเดียว ตัวขาวหนาขอบดำ กลางจอค่อนล่าง (ราว 75% ของความสูง) ตัดฉับ ตัวเลขสีเหลือง
