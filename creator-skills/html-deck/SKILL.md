# html-deck

สไลด์ HTML ไฟล์เดียวที่เปิดด้วยเบราว์เซอร์ มีการเคลื่อนไหว และมี PDF คู่กันสำหรับส่งหรือพิมพ์
ทุกขั้นด้านล่างรันจริงแล้วในงานข้อเสนอ 14 หน้า (ต.ค. 2569) ตัวอย่างที่ทำงานได้อยู่ใน repo ส่วนตัว
`<โปรเจกต์ deck เดิมของคุณ>/deck/` (`deck.tpl.html`, `build.py`, `qa.py`) ให้เปิดดูโครงก่อนเขียนใหม่ แต่ห้ามคัดลอกเนื้อหาลูกค้าออกมา

## ใช้เมื่อไร
ผู้ใช้ขอสไลด์ "เป็น html" หรืออยากได้ motion ถ้าขอไฟล์ .pptx ให้ใช้สกิล pptx หรือ ppt-master แทน

## ก่อนเริ่ม ถามให้จบในครั้งเดียว
ตัวเลขเชิงพาณิชย์ (ราคา จำนวนผู้ใช้ รวมอะไรบ้าง) และชื่อผู้เสนอ ถามผู้ใช้ก่อน อย่าเดา แล้วระบุในสรุปว่าอะไรคือสิ่งที่ใส่เอง

## โครงไฟล์
- `deck.tpl.html` เทมเพลตที่มีตัวแทน `{{LOGO}}` `{{S1}}` `{{P_COVER}}` สำหรับภาพ
- `build.py` แทนที่ตัวแทนด้วย base64 เขียน HTML พิมพ์ PDF แล้ววัดทุกสไลด์
- `qa.py` ทดสอบการใช้งานและอ่านข้อความจาก PDF

## กติกาของหน้า (ผิดแล้วเสียเวลาทุกข้อ)
1. เวทีขนาดคงที่ `1280x720` แล้วย่อด้วย `transform:scale()` ตามจอ
   **ต้องวางเวทีด้วย `position:absolute;left:50%;top:50%;margin:-360px 0 0 -640px`**
   ถ้าใช้ grid `place-items:center` เวทีที่ใหญ่กว่าจอจะไม่ถูกจัดกลาง แล้วล้นจอบนมือถือ
2. สไลด์เป็น `display:flex;flex-direction:column` และลูกทุกตัว `flex:none` ไม่งั้นตารางหรือแผนภาพจะถูกบีบจนแถวสุดท้ายหาย
3. จัดเนื้อหาให้เต็มหน้าด้วยสคริปต์: ใส่ `margin-top:auto` ให้บล็อกเนื้อหาตัวแรก และ `margin-bottom:auto` ให้ตัวสุดท้าย (ข้าม eyebrow, h2, lead, footer)
4. ขนาดตัวอักษรบนเวที 1280px: หัวเรื่อง 44px เนื้อหา 19px ขึ้นไป ป้ายกำกับ 16px ขึ้นไป footer 13px (เทียบเท่า 14pt, 12pt, 10pt บนสไลด์ 13.33 นิ้ว)
   ถ้าไม่พอดี ให้ตัดคำ อย่าย่อฟอนต์
5. ห้าม letter-spacing บนข้อความไทย ห้าม emoji ห้ามขีดยาว
6. motion: สไลด์ที่เปิดอยู่ได้คลาส `on` องค์ประกอบที่มี `data-a` เลื่อนเข้าด้วย `transition-delay` ที่สคริปต์ตั้งให้ทีละ 85ms
   เส้นใน SVG วาดด้วย `stroke-dashoffset` ตัวเลขนับขึ้นด้วย `requestAnimationFrame`
   **ข้อความเริ่มต้นใน HTML ต้องเป็นค่าสุดท้ายเสมอ** เพราะ PDF จับภาพสถานะนิ่ง
7. ภาพในกริดที่ต้องสูงเท่าการ์ดข้าง ๆ ให้ใส่ `position:absolute;inset:0` ที่ `<img>` ไม่งั้นความสูงจริงของภาพจะดันแถวจนล้นหน้า

## PDF
```css
@page{size:1280px 720px;margin:0}
@media print{
  .ui{display:none!important}
  .stage{position:static;margin:0;transform:none!important;height:auto;overflow:visible}
  .slide{position:relative;opacity:1!important;visibility:visible!important;transform:none!important;height:720px;break-after:page}
  [data-a]{opacity:1!important;transform:none!important}
  *{animation:none!important;transition:none!important}
}
```
```python
pg.emulate_media(media='print')
pg.pdf(path=pdf_out, width='1280px', height='720px', print_background=True, margin={'top':'0','right':'0','bottom':'0','left':'0'})
```
- ผลคือหน้า 960x540pt ตัวอักษรเป็นข้อความจริง ค้นหาได้ สระไม่ลอย
- ปุ่มดาวน์โหลดเป็น `<a href="ชื่อไฟล์.pdf" download>` ชี้ไฟล์ที่วางคู่กัน สองไฟล์ต้องส่งและอัปโหลดคู่กันเสมอ
- แก้ HTML แล้วต้องสร้าง PDF ใหม่ทุกครั้ง

## ตัวตรวจใน build.py (รันทุกครั้ง)
เปิดทีละสไลด์ รอ motion จบ แล้ววัด: มีองค์ประกอบใดเลยขอบสไลด์หรือไม่ ขอบล่างของเนื้อหาอยู่ที่กี่ px (เกิน 665 จะชน footer) และมีตัวอักษรเล็กกว่า 16px หรือไม่ จากนั้นถ่ายภาพทุกหน้ามาเรียงเป็นแผ่นแล้ว **เปิดดูด้วยตา** ตัวเลขผ่านไม่ได้แปลว่าสวย

## qa.py ควรครอบคลุม
ปุ่มลูกศรและปุ่มบนจอ · hash ในที่อยู่ · มีสไลด์เดียวที่มองเห็น · motion ไปถึงสถานะสุดท้าย · พอดีจอ 390x844, 844x390, 768x1024, 1920x1080 · `prefers-reduced-motion` · PDF มีจำนวนหน้าถูก อัตราส่วน 16:9 และอ่านข้อความไทยกับตัวเลขสำคัญออกมาได้

## ภาพถ่ายจาก Unsplash
- `unsplash.com/napi/search/photos` ตอบ 401 ใช้ไม่ได้ ให้เปิดหน้า `https://unsplash.com/s/photos/<คำค้น>?license=free&orientation=landscape` ด้วย Playwright แล้วเก็บ `img[src*="images.unsplash.com/photo-"]` ใน `figure a[href^="/photos/"]`
- ดาวน์โหลดด้วย `<raw>?w=..&h=..&fit=crop&crop=entropy&q=68&fm=jpg` แล้วฝังเป็น base64
- ทำแผ่นรวมภาพผู้สมัครแล้วเปิดดูก่อนเลือก **อ่านชื่อหน้าต้นทางด้วย** เคยเลือกภาพ "server room" ที่จริงเป็นตู้ล็อกเกอร์
- เลือกภาพที่ไม่เห็นหน้าคน ใส่หมายเหตุว่าเป็นภาพจากคลังภาพ ไม่ใช่สถานที่จริงของลูกค้า และเก็บ `credits.json`

## บทเรียนจากเด็คเกมมารยาท (16 ต.ค. 2569 รันจริงแล้ว)
- `prefers-reduced-motion` ต้องใส่ `transition-delay:0s!important` ด้วย ไม่ใช่แค่ `transition-duration` เพราะสคริปต์ตั้ง delay ทีละองค์ประกอบแบบ inline ไว้ องค์ประกอบท้าย ๆ จึงยังซ่อนอยู่ตอนตรวจ (qa ข้อ reduced-motion แดงเพราะเรื่องนี้)
- `pdftotext` แทรกช่องว่างระหว่างอักษรไทยบางตัว ตัดช่องว่างกับขึ้นบรรทัดออกก่อนค้นคำ (`.replace(' ', '').replace('\n', '')`) แล้วเทียบกับคำที่ไม่มีช่องว่าง · ลองฟอนต์ไทยของ Google 11 ตัวแล้ว pypdf ทำสระหายเหมือนกันทุกตัว ปัญหาอยู่ที่ตัวอ่าน ไม่ใช่ฟอนต์
- ไม่มีตัวเรนเดอร์ PDF เป็นภาพ (ไม่มี pdftoppm, fitz ถูกบล็อก) ให้เปิด PDF ใน Chrome แบบมีหน้าต่าง (`headless=False`, `goto("file:///...pdf")`) แล้วถ่ายภาพหน้าจอ ใช้ดูว่าสระไม่ลอยและพื้นหลังพิมพ์ติด
- **เผยแพร่เป็น Artifact ด้วย** ให้ build ทำไฟล์ที่สองจากเทมเพลตเดียวกัน: ไม่มี `<!doctype>` `<html>` `<head>` `<body>` (หน้าเว็บห่อให้เอง) เอา `<title>` กับ `<style>` ไว้บนสุด ถอดทั้งปุ่ม PDF **และโค้ดที่สั่งดาวน์โหลดหรือ `print()`** (ครอบด้วยคอมเมนต์ `<!--PDF-->...<!--/PDF-->` กับ `/*PDF*/.../*/PDF*/` แล้วตัดด้วย regex) เพราะตัวแสดงหน้าเว็บสั่งดาวน์โหลดหรือพิมพ์ไม่ได้ และการเผยแพร่จะเตือนถ้ายังมีโค้ดพวกนี้ · เด็คโทนมืดอย่างเดียวให้ตั้ง `color-scheme:dark` บน `:root` กับสีพื้นของ body ให้ชัด

## กับดักของเครื่องนี้
- heredoc ยาวใน Git Bash พังและกินเครื่องหมาย `\` ให้เขียนสคริปต์ด้วยเครื่องมือ Write แล้วสั่ง `python ไฟล์.py`
- แก้เทมเพลตด้วยสคริปต์ `rep(old, new)` ที่ `assert s.count(old) == 1` ก่อนแทนที่ทุกครั้ง จะรู้ทันทีเมื่อข้อความไม่ตรง
- repo ที่เก็บ HTML ซึ่งต้องตรงกับเว็บทุกไบต์ ให้ใส่ `.gitattributes` เป็น `* -text`
