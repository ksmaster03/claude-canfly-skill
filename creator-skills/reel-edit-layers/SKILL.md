# /reel-edit-layers: 5 ชั้นการตัดต่อรีล

ที่มา: รีล "Raw vs Edited" ของ Kien Nguyen (Kienobi) บน Facebook ยาว 13 วิ ได้ราว 41K วิว 1.2K รีแอคชัน
ผู้ใช้ส่งมาให้ศึกษา แล้วสั่งให้บันทึกเป็นสกิล (25 ต.ค. 2569)
ไฟล์ที่ศึกษาอยู่ที่ `$WORK\study\fb-1CuDhnqNUX\` (v.mp4, v.info.json, sheet2.jpg, trio.jpg)

หัวใจของคลิปนั้น: ฟุตเทจเดิมทุกเฟรม ต่างกันแค่การตัดต่อ และการตัดต่อคือสิ่งที่ทำให้คนดูจนจบแล้วส่งต่อ

## 5 ชั้น (เรียงจากคุ้มสุด ถ้าเวลาน้อยให้ทำ 2 ชั้นแรกก่อน)

| # | ชั้น | ทำอะไร | ทำไม |
|---|---|---|---|
| 1 | Raw | คนพูดหรือภาพเฉย ๆ | ไอเดียดีแค่ไหน ภาพนิ่งก็โดนเลื่อนผ่าน |
| 2 | Captions | ตัวหนังสือใหญ่ทีละคำหรือทีละวลี เน้นคำสำคัญด้วยฟอนต์หรือสีต่าง | คนจำนวนมากดูแบบปิดเสียง และตาจะได้มีอะไรตาม |
| 3 | Zoom in & out | ซูมเข้ากระชากสั้น ๆ ตรงคำสำคัญ แล้วคลาย | ภาพไม่ใช่ช็อตนิ่งยาวช็อตเดียว |
| 4 | Graphics | พูดถึงตัวเลข แอป หรือสิ่งของ ให้ขึ้นภาพสิ่งนั้น (เช่นแจ้งเตือน Instagram, เช็กลิสต์) | เห็นแล้วเข้าใจเร็วกว่าฟัง |
| 5 | BGM & SFX | เพลงเบาคลอใต้เสียงพูด และเสียงเอฟเฟกต์ทุกครั้งที่ตัดภาพหรือมีอะไรโผล่ | เพลงสร้างอารมณ์ เอฟเฟกต์ทำให้จังหวะตัดมีน้ำหนัก เพลงต้องเบาพอที่จะไม่สู้กับเสียงพูด |

เทคนิคของคลิปต้นทางที่หยิบมาใช้ได้:
- ฟอร์แมต "วนคลิปเดิม เพิ่มทีละชั้น" พร้อมแถบไทม์ไลน์สีด้านล่างบอกว่าอยู่ชั้นไหน คลิปสั้นจึงวนดูซ้ำได้
- ประโยคฮุกประโยคเดียวในวินาทีแรก ("Never post another reel without fixing this")
- คำบรรยายอธิบายทีละชั้นแบบมีเลขข้อ ปิดด้วยการ**ขอให้แชร์ให้คนที่ต้องฟัง** ไม่ใช่แค่ขอไลก์

## ใช้ตรวจคลิป (ทำก่อนเรนเดอร์จริง)

ไล่ถามทีละชั้นกับภาพตรวจ (`chk_sheet.jpg`) และไฟล์มิกซ์:
1. 3 วินาทีแรกมีปมหรือข้อความใหญ่ที่หยุดนิ้วไหม
2. ซับอ่านได้ไหมตอนปิดเสียง ล้นขอบไหม และคำสำคัญเด่นกว่าคำอื่นไหม
3. มีภาพนิ่งเกิน 3–4 วินาทีโดยไม่มีอะไรขยับไหม ถ้ามี ใส่ซูมกระชากหรือกราฟิก
4. ทุกตัวเลขหรือชื่อที่พูด มีบนจอไหม
5. เพลงเบากว่าเสียงพูดพอไหม (msinterview ใช้ลดใต้เสียงพูด 12 dB) และมีเสียงเอฟเฟกต์ตรงจังหวะตัดไหม
6. คำบรรยายมีประโยคชวนแชร์ที่เฉพาะกับคลิปนั้นไหม

## สถานะในคลิปแปลเพลง /msinterview (25 ต.ค. 2569)

| ชั้น | มีแล้ว | ยังขาด |
|---|---|---|
| Captions | ซับทีละวลี, การ์ดเนื้อร้องอังกฤษ + ไทย, ซับยาวตัดขึ้นสองบรรทัด | ไม่ขาด |
| Zoom | ภาพ MV ซูมเข้าช้า 4% ต่อฉาก | ซูมกระชากตรงคำที่บทครอบ `*...*` |
| Graphics | ป้ายคนพูด ตัวเลขยักษ์ ป้าย kicker และ chips | ไอคอนหรือภาพของสิ่งที่พูดถึง (ไม่บังคับ) |
| BGM | เพลงบรรเลง Suno ใต้เสียงพูด | ไม่ขาด |
| SFX | ไม่มีเลย | ยังขาดทั้งชั้น |

## วิธีเพิ่มชั้นที่ขาด ‼ ยังไม่เคยรันจริง เป็นแผน

1. **SFX ในขั้นมิกซ์**
   - อ่านเวลาเริ่มของแต่ละฉากจาก `timeline.json`
   - วางเสียงวูบสั้น ๆ ตรงจุดเปลี่ยนฉาก เสียงป๊อปตรงการ์ดเนื้อร้องหรือตัวเลขยักษ์ และเสียงติ๊งตรงฉากให้คะแนน (รูปแบบ A และ C)
   - ระดับเสียงราว -24 ถึง -20 dB ใต้เสียงพูด ห้ามทับคำพูดแรง ๆ
   - ใช้ไฟล์เสียง CC0 เท่านั้น จดที่มาไว้ในโฟลเดอร์ sfx
   - ทำเป็นสคริปต์เสริมหลัง `mix.py` / `mix_intro.py`
2. **ซูมกระชากใน `scenes.html`**
   - ตอนซับวลีที่มี `*` ขึ้น ให้ภาพ MV ซูมเพิ่มราว 8% ใน 0.15 วิ แล้วคลายกลับใน 0.4 วิ
   - แก้ที่สกิลแล้วก๊อปลงโปรเจกต์
3. **คำบรรยายชวนแชร์**
   - ท้าย `caption.txt` / `youtube.txt` ใส่ประโยคแบบ "แชร์ให้เพื่อนที่ร้องเพลงนี้ได้แต่ไม่รู้ความหมาย"
   - ปรับให้เฉพาะเพลง
4. ทำกับคลิปใหม่ก่อน 1 คลิป แล้วส่งให้ผู้ใช้ดูเทียบกับแบบเดิม ห้ามแก้คลิปที่โพสต์หรือตั้งเวลาไว้แล้ว

ไอเดียคลิปจากฟอร์แมตนี้: "คลิปเดียวกัน ดิบ vs ตัดต่อ" เบื้องหลังช่องลินดากับโกสินทร์ (เสียง AI ดิบ → ซับ → ภาพ MV → เพลง → เอฟเฟกต์) ยาว 15–20 วิ

## วิธีศึกษารีลจากลิงก์ (รันจริงแล้ว 25 ต.ค. 2569)

```bash
export PATH="$FFMPEG_BIN:$PATH"
mkdir -p $WORK/study/<id> && cd $WORK/study/<id>
python -m yt_dlp -o "v.%(ext)s" --write-info-json "<ลิงก์ FB share/r/...>"   # ลิงก์แชร์ของ FB โหลดได้ตรง ๆ
# v.info.json มี title (ยอดวิว/รีแอคชัน) กับ description (คำบรรยายเต็ม)
ffmpeg -v error -y -i v.mp4 -vf "fps=2,scale=200:-1,tile=9x3" -frames:v 1 sheet2.jpg   # ภาพตัวอย่างทุก 0.5 วิ
ffmpeg -v error -y -ss <วิ> -i v.mp4 -frames:v 1 f<วิ>.jpg                                 # ภาพเต็มของจังหวะที่สนใจ
```

ถอดเสียง:
- คลิปภาษาอังกฤษใช้ faster-whisper `small` แบบไม่ระบุภาษา
- คลิปไทยใช้ `~/.claude/skills/explainreel/scripts/asr_para.py`

รายงานกลับผู้ใช้เป็นภาษาไทย ให้ครบ 4 เรื่อง:
1. คลิปทำอะไร
2. ทำไมคนดูหรือแชร์
3. เทียบกับคลิปของเรา
4. สิ่งที่หยิบมาใช้ได้ เรียงตามความคุ้ม
