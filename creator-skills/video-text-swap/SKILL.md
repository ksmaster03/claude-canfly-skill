# /video-text-swap

รันจริงแล้ว 31 ต.ค. 2569: เปลี่ยนป้าย `NAT · THE MASTERMIND` เป็น `NATHAN · THE MASTERMIND` ในคลิป 45 วินาที 1920x1080 ต้นแบบที่ทำงานได้อยู่ที่ `scripts/patch_clip_name.example.py`

## ใช้เมื่อไร

- ไม่มีไฟล์โปรเจกต์ตัดต่อ เหลือแต่ mp4
- ตัวอักษรใหม่ทุกตัวมีอยู่แล้วในภาพช่วงนั้น เช่น H จาก THE, A และ N จาก NAT
- ตัวอักษรเล็ก เส้นบาง สีเดียว บนพื้นมืดที่ลายน้อย

ไม่ใช่งานของสกิลนี้: ต้องใช้ตัวอักษรที่ไม่มีในภาพ · พื้นหลังสว่างหรือลายแน่น · อักษรไทยที่มีสระและวรรณยุกต์ซ้อน ‼ ยังไม่เคยรันจริง

ต้องมี ffmpeg, python, numpy, scipy, PIL

## ขั้นตอน

1. **ดูก่อนว่าคุ้มจะแก้ไหม** ตัดเฟรมเป็นตาราง แล้วไล่ทั้งคลิปว่าข้อความอยู่ที่ไหนบ้าง ถอดเสียงด้วยว่ามีคนพูดคำนั้นไหม เสียงแก้ด้วยวิธีนี้ไม่ได้
   ```bash
   ffmpeg -v error -y -t 12 -i in.mp4 -vf "fps=2,scale=480:-1,tile=4x6" -frames:v 1 sheet.jpg
   ```
2. **อ่านตำแหน่งจากเฟรมดิบ** แปลงเป็น yuv420p อ่านระนาบ Y ด้วย numpy แล้วหา
   - ช่วงเฟรมที่ข้อความมองเห็น รวมตอนเฟดเข้าและออก
   - แถวบนล่าง ซึ่งเปลี่ยนตามเฟรมถ้าข้อความเลื่อน เผื่อกรอบให้ครอบทุกตำแหน่ง
   - ขอบซ้ายขวาของแต่ละตัว จากการนับพิกเซลรายคอลัมน์ แล้วคำนวณระยะห่างต่อตัว
3. **กำหนดตารางย้ายตัวอักษร** `(x เริ่ม, x จบ, เลื่อนกี่พิกเซล)` **ค่าเลื่อนต้องเป็นเลขคู่** เพราะระนาบสีละเอียดแค่ครึ่งเดียว
4. **ทำรอบตัวอย่างก่อน** แก้ค่าที่ส่วนบนของสคริปต์ แล้วรัน `--preview` เทียบต้นฉบับกับที่แก้หลายเฟรม รวมตอนเฟดด้วย
5. **ซูมและเร่งความสว่างเป็นสองเท่าแล้วดูด้วยตา** คราบสีมองไม่เห็นในภาพปกติ แต่เห็นบนจอใหญ่
6. รันเต็ม แล้วเขียนไฟล์ใหม่ อย่าทับต้นฉบับ

## หลักการในสคริปต์

- ทำงานบน raw yuv420p จาก pipe เฟรมนอกช่วงผ่านตรง ๆ จึงไม่มีการแปลงสี ถ้าผ่าน PNG สีจะกระโดดตรงรอยต่อ
- พื้นหลัง Y ประเมินด้วย `grey_opening` ขนาด 9x9 ลบเส้นบางออกเหลือพื้น
- ความทึบ `alpha = (Y - พื้น - 5) / (สีตัวอักษร - พื้น - 5)` จึงรวมการเฟดมาแล้ว ทำให้จังหวะเข้าออกตรงทุกเฟรม
- คิด alpha เฉพาะในกล่องตัวอักษร ฝุ่นในฉากจะได้ไม่ติดมา
- ลบของเดิมด้วยพื้นที่ประเมิน แล้ววาดตัวอักษรใหม่ด้วยสีที่อ่านจากเฟรมสว่างที่สุด

## กับดัก

- **คราบสีแดงที่ตำแหน่งตัวอักษรเดิม** เกิดเพราะสีเลอะออกนอกเส้น ตัวกรอง median ยังเห็นสีตัวอักษรอยู่ ต้องขยายหน้ากากกว้าง 15 พิกเซล แล้วเฉลี่ยสีพื้นหลังแบบถ่วงน้ำหนักที่ไม่นับบริเวณนั้น
- ไฟล์ใหญ่ขึ้น คลิปต้นแบบจาก 84 MB เป็น 121 MB ที่ `-crf 15 -preset slow` เช็กเพดานของปลายทางด้วย เช่น GitHub 100 MB
- ใส่ tag สีให้ตรงต้นฉบับทั้งฝั่งเข้าและฝั่งออกของ encoder

## ยืนยันผล

```bash
ffprobe -v error -count_packets -show_entries stream=codec_name,nb_read_packets,pix_fmt,color_space new.mp4
ffmpeg -v error -i old.mp4 -map 0:a -c copy -f md5 -     # เทียบกับ new.mp4 ต้องตรงกัน
ffmpeg -v error -i old.mp4 -i new.mp4 -lavfi "[0:v][1:v]psnr=stats_file=psnr.log" -f null -
```

จำนวนแพ็กเก็ตต้องเท่าเดิม · MD5 เสียงต้องตรงกัน · PSNR นอกช่วงแก้ควรเกิน 44 dB และห้ามตกเฉพาะบางเฟรม · ต้องเล่นใน Chrome จริงแล้ว seek มาที่จุดแก้ได้

`stats_file` รับ path ที่มีเครื่องหมาย `:` ไม่ได้ ให้รันจากโฟลเดอร์นั้นแล้วใช้ชื่อไฟล์เปล่า
