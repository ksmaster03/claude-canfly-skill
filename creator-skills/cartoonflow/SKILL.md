# /cartoonflow: ภาพ flow การ์ตูน + Markdown แชร์

ทำจริง 18 ต.ค. 2569: ภาพอธิบายการทำคลิปสั้น 10 ขั้น ที่ `$WORK/tmp\reel-process-guide\` (flow.png 1080x5239, ภาพการ์ตูน 11 ภาพ, ไฟล์ .md, โพสต์ FB)

## ลำดับงาน

1. **แบ่งขั้น** 6 ถึง 10 ขั้น ขั้นละหนึ่งภาพ + ภาพเปิด (hero)
2. **เขียน prompt ทีละไฟล์** `img/<id>.json` = `[{"id":"<id>","prompt":"..."}]` ดูตัวอย่าง `scripts/prompt_example.json`
   - ทุก prompt มีบล็อกสไตล์เดียวกัน + คำบรรยายตัวละครซ้ำตัวอักษรเดิม (งานแรก: หนุ่มไทยผมดำสั้นแว่นกลมเสื้อกรมท่า + หุ่นยนต์กลมขาวหน้าจอส้ม)
   - ปิดท้ายทุก prompt: `Absolutely no text, no letters, no words, no numbers, no logos, no watermarks anywhere in the image. Square 1:1 aspect ratio image.`
3. **เจนทีละภาพ** แก้รายการ ID ใน `scripts/gen_example.sh` แล้วรันเบื้องหลัง ข้ามภาพที่มีแล้ว ลองซ้ำ 3 รอบ ปิด Chrome ของ bridge ก่อนทุกภาพ (`kill-chatgpt-chrome.ps1` + sleep 3) ภาพละราว 50 ถึง 110 วิ ได้ 1254x1254
4. **เปิดดูทุกภาพ** ว่าตรง prompt และไม่มีตัวอักษร ID สลับกันได้ ภาพไหนผิดลบแล้วรัน gen ซ้ำ
5. **โปสเตอร์** คัดลอก `scripts/flow_template.html` เป็น `flow.html` แก้หัวเรื่องและอาร์เรย์ `S` (id ภาพ, หัวข้อ, คำอธิบายสองบรรทัด, ป้าย) แล้ว `python scripts/render.py` (วางไว้ข้าง flow.html) ได้ `flow.png` และภาพย่อ `img/web/*.jpg` 800px สำหรับ Markdown
6. **ตรวจโปสเตอร์** ตัดเป็น 4 ท่อนด้วย PIL แล้วเปิดดูทีละท่อน: สระไม่ลอย ข้อความไม่ล้นการ์ด การ์ดสลับซ้ายขวาข้อความชิดเท่ากัน
7. **Markdown** อ้าง `flow.png` และ `img/web/<id>.jpg` เป็น path สัมพัทธ์ grep ว่าไม่มี path ในเครื่อง โทเคน หรือข้อมูลบัญชี บอกผู้ใช้ว่าต้องส่งทั้งโฟลเดอร์

## กับดัก

- ห้ามให้ AI วาดตัวไทยในภาพ ให้วางทีหลังด้วย Chromium เท่านั้น (PIL วาดไทยไม่ได้บนเครื่องนี้)
- การ์ดที่กลับด้าน (`row-reverse`) ข้อความลอยห่างขอบ ต้องตั้ง `.txt { flex:1 }`
- คำอธิบายเชิงเทคนิค (เช่น "ตัวหนังสือไทยไม่ลอย") คนทั่วไปไม่เข้าใจ เขียนให้ชัดว่าหมายถึงอะไร
- โปสเตอร์ยาว 5,000px โพสต์ Facebook ได้ แต่ Instagram ครอปเหลือส่วนบน
- ข้อความโพสต์ที่เผยแพร่: ตัดชื่อบริการที่เงื่อนไขห้ามเชิงพาณิชย์หรือห้ามบอตออก แล้วบอกผู้ใช้ว่าทำไม
