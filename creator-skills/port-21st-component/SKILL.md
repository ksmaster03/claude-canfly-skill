# /port-21st-component แปลง component React ลงเว็บที่ไม่ใช่ React

ใช้เมื่อ prompt สั่งให้ลง shadcn, Tailwind, TypeScript แต่เว็บปลายทางไม่มี `package.json` หรือเป็น HTML ที่เจนจากสคริปต์
ถ้าเว็บเป็น React + Tailwind อยู่แล้ว ไม่ต้องใช้สกิลนี้ ทำตาม prompt ได้เลย

ผ่านการใช้จริงกับเว็บ static ที่เจนจากสคริปต์: hero-section-6, glass-folder-cards, curtain-split-hero

## 1. ตัดสินใจเรื่อง stack ก่อน

เว็บเจนจาก `index.html` เดียวและ AEO พึ่ง HTML ดิบ การย้ายไป Next.js คือรื้อทั้งเว็บ ให้แปลงดีไซน์เป็น HTML/CSS/JS ล้วน แล้วบอกผู้ใช้เป็นการตัดสินใจ ไม่ต้องถาม

ก่อนแก้ให้อ่าน: โทเคนสีและธีม, ระบบสลับภาษา, ตัวเจนหน้า, รายการไฟล์ที่สคริปต์ deploy อัปขึ้น (ไฟล์ชนิดใหม่อาจไม่ถูกอัป)

## 2. ตารางแปลง

| ของเดิม | แปลงเป็น |
|---|---|
| framer-motion entrance | `@keyframes` + `animation-delay` |
| `useSpring`, `useTransform` | `requestAnimationFrame` กับ `p += (target - p) * 0.12` แล้วคำนวณสูตรเดิมของต้นแบบ |
| `next/image` | `<img loading="lazy" decoding="async">` พร้อม width height |
| `dark:` ของ Tailwind | ตัวเลือกธีมของเว็บ เช่น `html[data-theme="dark"]` |
| สี Tailwind | โทเคนของเว็บ เปลี่ยนสีหลักของต้นแบบเป็นสีแบรนด์ |
| canvas วาดตอนรันไทม์ | รันอัลกอริทึมเดิมใน Chrome ครั้งเดียว บันทึก `toDataURL('image/webp')` แล้วใช้เป็นภาพ |
| navbar ในตัว component | ตัดออกถ้าเว็บมี header อยู่แล้ว |
| ฟังก์ชันของแอป (ปุ่มเพิ่มไฟล์, เมนู) | ตัดออกถ้าไม่มีความหมายบนเว็บแนะนำบริษัท แล้วบอกผู้ใช้ |

## 3. ภาพและข้อมูล

- ห้ามใช้ภาพจาก `cdn.21st.dev` หรือ stock ตามที่ prompt บอก ใช้ของจริงของลูกค้า เช่น ปกหนังสือ ภาพงานจริง
- ถ้าต้องวาดจอ dashboard ให้ใช้ inline SVG กับโทเคนธีม สลับธีมและภาษาได้เอง ตัวเลขสมมติต้องมีป้าย "ข้อมูลตัวอย่าง" บนจอ
- เลือกที่วางจากรูปทรงของ component เช่น การ์ดแนวตั้ง 2:3 เหมาะกับปกหนังสือ อย่าวางตามหน้าตัวอย่าง
- ตัวเลขที่อ้างบนหน้าต้องตรวจจากแหล่งจริงก่อนใส่

## 4. พฤติกรรมที่ต้องเปลี่ยน

- **อย่าดักล้อเมาส์** (`wheel` + `preventDefault`) ใช้ระยะเลื่อนหน้าคำนวณ progress แทน
- **อย่าใช้ margin ติดลบวางของทับ** จะพังที่บางความกว้าง ให้ของที่จางลงจบที่ขอบล่างของกล่องตัวเอง แล้ววางเนื้อหาถัดไปบนพื้นทึบ
- **อย่าตั้งขนาดตายตัวบนจอแคบ** ใช้ `clamp()` กับ `vw`
- `prefers-reduced-motion`: แสดงสถานะจบทันที

## 5. เนื้อหาต้องไม่หาย

- ถ้า component ซ่อนเนื้อหา ให้เก็บข้อความไว้ใน HTML ดิบเสมอ ย้ายการ์ดเดิมไปไว้ในแผงที่เปิดได้ ไม่เขียนข้อความใหม่
- ใส่ `<script>document.documentElement.classList.add('js')</script>` ใน head กฎที่ซ่อนเนื้อหาต้องขึ้นต้น `html.js` ไม่มี JS ต้องเห็นเนื้อหาครบ
- จอแคบให้แผงอยู่ใต้ปุ่มที่กด: เรียง DOM เป็น ปุ่ม แผง ปุ่ม แผง แล้วใช้ grid จัดแผงลงแถวสองบนจอกว้าง
- ป้ายที่อ่านด้วย screen reader ใช้ระบบแปลภาษาเดิม (ใส่ใน `<span class="sr-only" data-th>`) ไม่ใช้ `aria-label` ภาษาเดียว

## 6. วิธีแก้ไฟล์

เขียนสคริปต์ Python แก้ไฟล์ แต่ละจุดใช้ฟังก์ชันที่ `assert src.count(old) == 1` อ่านต้นฉบับจาก `git show HEAD:<ไฟล์>` หรือสำเนาใน scratchpad เสมอ เพื่อรันซ้ำได้
นับข้อความแปลไทยก่อนและหลังแล้ว assert ว่าไม่มีอะไรหาย

## 7. ตรวจผล

1. ถ่ายครบ ธีม 2 × ภาษา 2 × จอ 1440 และ 390 แล้ว **ดูภาพด้วยตา**
2. ตรวจทุกความกว้าง รวมขอบ breakpoint และโหมดปิด JS:
   ```
   node "$HOME\.claude\skills\port-21st-component\scripts\verify-widths.cjs" <base-url> /,/th/ <ตัวเลือกที่ต้องซ่อนเมื่อไม่มี JS> <โฟลเดอร์ภาพ>
   ```
   ‼ รันจาก PowerShell เท่านั้น Git Bash แปลง `/,/th/` เป็น path ของ Windows และถ้าใส่ `MSYS_NO_PATHCONV=1` กัน `node` ก็หาไฟล์จาก `~` ไม่เจอ
3. ทดสอบกดจริง: ปุ่ม คีย์บอร์ด Enter Space Esc, ปุ่มสลับภาษาและธีมหลังโหลดหน้า, ลิงก์ทุกอันตอบ 200 และเลื่อนล้อเมาส์บน component แล้วหน้าต้องเลื่อน
4. grep ข้อความเต็มในไฟล์ HTML ที่เจนแล้วทั้งสองภาษา

ขั้น deploy ทำเมื่อผู้ใช้สั่งในเทิร์นนั้นเท่านั้น และตรวจซ้ำบนโดเมนจริงหลัง deploy

## กับดักที่เจอจริง

- **ฟอนต์ไม่โหลดเงียบ ๆ:** หน้าทดสอบจาก `file://` ดึงฟอนต์จาก http ไม่ได้ ตกเป็น serif ต้อง `page.goto` เข้า origin ของเว็บก่อนแล้วค่อย `setContent`
- **ฟอนต์ไทยบนหน้าทดสอบ:** ใช้ `document.fonts.check()` ยืนยันก่อนตัดสินหน้าตา
- **จอ 390 ผ่านไม่ได้แปลว่า 320 ผ่าน:** เจอมือถือทับปุ่ม 11px และหัวข้อตก 3 บรรทัดที่ 320 เท่านั้น
- **ขอบ breakpoint:** header ล้น 90px ที่ 901 ทั้งที่ 1024 ผ่าน
- **ข้อความเส้นขอบเล็ก ๆ:** `-webkit-text-stroke` ที่ 22px เบลอบนจอ 1x ต้องดูภาพที่ `deviceScaleFactor: 1` และเพิ่มขนาดหรือลดเส้น ฟอนต์ variable อาจมีรอยเส้นซ้อน ให้ขยายดูที่ 150px ก่อนใช้
- **ลบ keyframes:** grep ก่อนลบ ชื่อ `fadeUp` ถูกใช้ที่หมวดอื่นด้วย
- **lxml กับ SVG:** แปลงชื่อเป็นตัวเล็ก (`viewbox`, `clippath`) เบราว์เซอร์แก้กลับให้เอง ไม่ใช่บั๊ก
- **escape ใน heredoc:** แก้สคริปต์ Python ผ่าน Python อีกชั้น `\n` กลายเป็นขึ้นบรรทัดจริง ใช้ Edit แทน
- **ภาพเต็มหมวดที่มี header fixed:** ภาพ `locator.screenshot` จะมี header ลอยกลางภาพ ไม่ใช่บั๊กของหน้า
- **Playwright:** ถ้า browser รุ่นไม่ตรง ใช้ `chromium.launch({ channel: 'chrome' })`

## รายงาน

บอกผู้ใช้เป็นการตัดสินใจ: แปลงเป็น stack อะไร, ตัดอะไรออกจากต้นแบบและเพราะอะไร, วางที่ไหน, ตรวจอะไรแล้ว, ตัวเลขไหนเป็นข้อมูลสมมติ, browser ไหนยังไม่ได้ลอง
