# /disk-archive: คืนพื้นที่โดยไม่ลบงาน

ไดรฟ์งานเต็มซ้ำหลายรอบ วิธีนี้ใช้จริงแล้วครั้งหนึ่ง จากเหลือ 0.3 GB เป็น 20.8 GB

## ลำดับงาน

1. **วัดทุกไดรฟ์ก่อน** `Get-PSDrive -PSProvider FileSystem` · ‼ ไดรฟ์สำรองเป็น SSD USB ที่ไม่ได้เสียบตลอด (ในตัวอย่างนี้คือ E:) ถ้าไม่มีไดรฟ์นั้น ให้บอกผู้ใช้ก่อน เพราะงานที่ย้ายไปแล้วก็เปิดไม่ได้เช่นกัน
2. **วัดขนาดโฟลเดอร์แบบเร็ว** (ปลายทางเป็น NUL ใช้ไม่ได้ อ่านบรรทัด `Bytes :`)
   ```powershell
   robocopy <dir> "$env:TEMP\__robo_dummy_nonexist" /L /S /NJH /BYTES /NFL /NDL /XJ /MT:16
   ```
3. **แยกกลุ่ม** แล้วถามผู้ใช้ด้วย AskUserQuestion แบบเลือกหลายข้อ พร้อมขนาดแต่ละกลุ่ม
   - แคชที่สร้างใหม่ได้: `<โฟลเดอร์ npm cache>`, `bun pm cache rm` (รันในโฟลเดอร์ที่มี package.json), `pip cache purge`
   - โปรเจกต์คลิปที่เสร็จแล้ว และไฟล์ชั่วคราวที่งานโพสต์ไปแล้ว ดูสถานะจากบันทึกของแต่ละงาน คลิปที่ยังตั้งเวลาโพสต์อยู่ห้ามย้าย
   - checkpoint ระหว่างฝึกโมเดล (ไฟล์ `G_*.pth`, `D_*.pth` ใน `logs`) เก็บโมเดลสุดท้าย `.pth` กับ `.index` ที่ยังใช้งานไว้
4. **ห้ามแตะ:** โฟลเดอร์เครื่องมือที่ยังใช้งานอยู่ทั้งโฟลเดอร์ · โปรไฟล์เบราว์เซอร์ที่ล็อกอินค้าง (เช่น `pw-*-profile`) · `AppData\Roaming\npm` · Docker volume (เป็นข้อมูล) · งานที่บันทึกระบุว่ายังต้องทำต่อ หรือมีกำหนดส่ง
5. **ย้าย** เขียนรายการงานด้วยเครื่องมือ Write (‼ heredoc ของ Git Bash กินแบ็กสแลชใน JSON) แล้วรันเบื้องหลัง
   ```json
   [{"src":"D:\\work\\proj-a","dst":"E:\\archive\\D-work\\proj-a","files":[]},
    {"src":"D:\\work\\trainer\\logs","dst":"E:\\archive\\trainer-checkpoints\\logs","files":["G_*.pth","D_*.pth"]}]
   ```
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File <skill_dir>/scripts/move_to_archive.ps1 -Jobs jobs.json
   ```
   `files` ว่าง = ย้ายทั้งโฟลเดอร์ · ใส่ mask = ย้ายเฉพาะไฟล์นั้น โฟลเดอร์เดิมอยู่ครบ · สคริปต์หยุดทันทีถ้าไดรฟ์ปลายทางไม่มี robocopy คืนค่า 8 ขึ้นไป หรือขนาดปลายทางน้อยกว่าต้นทาง · log เขียนข้างไฟล์ jobs จบด้วย `MOVEDONE`
   รุ่นนี้ทดสอบกับโฟลเดอร์จำลองบน D: ครบ 4 กรณี (ไดรฟ์ปลายทางหาย · ย้ายทั้งโฟลเดอร์ · ย้ายตาม mask · ต้นทางไม่มี) ส่วนการย้ายจริง 20 GB ไป E: ใช้รุ่นก่อนหน้าที่เขียนรายการงานไว้ในสคริปต์ ‼ รุ่นรับ `-Jobs` ยังไม่เคยย้ายไป E: จริง รอบแรกให้ลองกับโฟลเดอร์เล็กก่อน
6. **จดที่อยู่ใหม่** เพิ่มบรรทัด `**ย้ายไฟล์ <วันที่>:** <path ใหม่>` ในบันทึกของทุกโปรเจกต์ที่ย้าย และสรุปรอบนี้ไว้ที่เดียว ไม่งั้นเซสชันหน้าจะหาไม่เจอ
7. **Docker** เช็ก `docker system df` ก่อน คุ้มเมื่อ build cache หรือ image ค้างเกิน 10 GB เท่านั้น การบีบ vhdx ต้องใช้สิทธิ์ admin และปิด WSL (ห้ามใส่ `-Wait` ตอน RunAs) · เปิด Docker แล้วต้องปิดกลับถ้าเดิมปิดอยู่ · ห้าม prune volume
8. **ตรวจ** `Get-PSDrive` เทียบก่อนและหลัง · เปิดดู path ปลายทางจริง · รายงานตัวเลขที่วัดได้ และบอกสิ่งที่ยังไม่แตะพร้อมขนาด

## กับดัก

- `Get-ChildItem -LiteralPath ... -Include` ไม่กรองไฟล์ ใช้ `Where-Object { $_.Name -match ... }`
- robocopy คืนค่า 0 ถึง 7 คือสำเร็จ แต่เครื่องมือ PowerShell จะแจ้ง exit 1 ถ้าปล่อยค่านี้ค้าง สคริปต์จึงจบด้วย `exit 0`
- ใส่ `/XJ` เสมอ โฟลเดอร์ที่เป็น junction ไปไดรฟ์อื่น ถ้าตามเข้าไปจะนับซ้ำ
- C: เต็มคนละสาเหตุกับ D: ก้อนใหญ่คือ `pagefile.sys` ซึ่งลดต้องใช้สิทธิ์ admin ให้ถามผู้ใช้ อย่าแตะเอง
