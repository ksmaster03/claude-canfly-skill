# /clipcover: ปกคลิปแนวตั้งแบบหยุดนิ้ว

ผู้ใช้สั่งเมื่อ 13 ต.ค. 2026: เวลาทำคลิป ให้เตรียมปกไว้รอเลย สกิลทำคลิปทุกตัวจึงต้องจบด้วยขั้นนี้ แล้วส่ง path ของปกไปพร้อมคลิป
ปกต้นแบบสองใบที่ผู้ใช้เห็นแล้ว: `$WORK/tmp/artcraft-news/cover.jpg` (ภาพเดียว) และ `$WORK/tmp/creator-reel/cover.jpg` (แบ่งเฉียงสองภาพ)

## ลำดับงาน

1. **เลือกภาพ 1 ถึง 2 ภาพ** จากโฟลเดอร์ `img/` ของโปรเจกต์คลิป (ภาพที่มีใน `credits.json` อยู่แล้ว) ภาพต้องอ่านออกในครึ่งวินาที มีวัตถุเดียวเด่น ๆ หน้าคน หน้าหุ่นยนต์ อาคารที่มีโลโก้ หรือสถานที่ที่คนจำได้
2. **เขียน `<proj>/cover.json`** ตามหัวข้อ "ข้อความบนปก"
3. **เรนเดอร์** `python <skill_dir>/scripts/make_cover.py <proj>` ต้องขึ้นว่า "อยู่ในเขตปลอดภัย 4:5"
4. **เปิดดู `cover_preview.jpg` และ `cover_4x5.jpg`** ทุกครั้ง เช็กว่าหน้าหรือวัตถุหลักไม่โดนตราแดงทับ คำใหญ่อ่านออกเมื่อย่อเหลือขนาดนิ้วโป้ง และไม่มีคำโดนตัด
5. **รายงาน** path เต็มของ `cover.jpg` ในบรรทัดของตัวเอง พร้อมบอกว่าข้อความบนปกตรงกับเนื้อคลิปตรงไหน

## cover.json

```json
{ "layout": "split",
  "img": ["img/robot_2.jpg", "img/temple_2.jpg"],
  "pos": ["42% 18%", "62% 50%"],
  "tag": "FILM FILE #0002", "brand": "โกสินทร์ต้องบินได้",
  "stamp": "ทั้งโลกแบน AI",
  "a": "หนังฮอลลีวูดให้ AI หนีมา",
  "b": "อยู่ไทย?",
  "c": "ถ่ายในไทยจริง",
  "chip": "The Creator · ไทยจะเป็นฐาน AI ไหม" }
```

| ช่อง | คืออะไร | ข้อจำกัด |
|---|---|---|
| `layout` | `single` ภาพเดียวเต็มครึ่งบน · `split` สองภาพแบ่งเฉียงด้วยเส้นเหลือง ใช้เมื่อเรื่องคือสองสิ่งมาชนกัน | |
| `img` `pos` | ภาพและจุดโฟกัส (`background-position`) | `split`: ภาพซ้ายเห็นแค่ครึ่งซ้าย ให้วัตถุอยู่ซ้าย ภาพขวาให้อยู่ขวา |
| `stamp` | ตราแดงเอียง คือปมหรือคำถามของเรื่อง | ไม่เกิน 14 ตัวอักษร |
| `a` | บรรทัดนำ ตัวขาว | ไม่เกิน 24 ตัวอักษร |
| `b` | **คำใหญ่สีเหลือง** คือคำที่ทำให้หยุดนิ้ว | 1 ถึง 2 คำ ไม่เกิน 12 ตัวอักษร |
| `c` | บรรทัดรอง ตัวขาวใหญ่ | ไม่เกิน 14 ตัวอักษร |
| `chip` | ป้ายกรอบเหลือง ชื่อเรื่องและประเด็น | ไม่เกิน 34 ตัวอักษร |
| `tag` `brand` | ใช้ค่าเดียวกับในคลิป | |
| `credit` | ไม่ใส่ จะเติมจาก `credits.json` ให้ | |
| `top` | ตำแหน่งบนของก้อนข้อความเป็นพิกเซล ดีฟอลต์ 722 | ปรับเมื่อตัวตรวจบอกว่าหลุดเขต |

ตัวเลขใน `a` `c` `chip` เป็นสีเหลืองเอง บรรทัดที่กว้างเกินถูกย่อให้พอดีเอง

## ข้อความบนปก

- อ่าน `a` `b` `c` ต่อกันต้องเป็นประโยคเดียวที่เข้าใจได้โดยไม่ต้องดูคลิป ("ใช้ AI เขียนใหม่ทั้งชุด / แจกฟรี / 12 แอป")
- `b` เลือกจากสิ่งที่คนดูได้ เสีย หรือสงสัย ไม่ใช่ชื่อเรื่อง ชื่อเรื่องไปอยู่ที่ `chip`
- `stamp` กับ `b` ต้องดึงกัน ตัวหนึ่งตั้งปม อีกตัวตอบหรือพลิก ("แกะโค้ดจริงหรือ?" กับ "แจกฟรี")
- **ทุกคำบนปกต้องเป็นจริงตามเนื้อคลิป** เรื่องที่ยังไม่ยืนยันให้ตั้งเป็นคำถาม ห้ามใช้คำอย่าง "ทำนายไว้แล้ว" "ช็อกทั้งโลก" ที่คลิปไม่ได้พิสูจน์ (รอบแรกของปก The Creator เขียนว่า "หนังทำนายไว้แล้ว" แล้วต้องแก้เป็น "ถ่ายในไทยจริง")
- ไม่ใช้อีโมจิ ไม่ใช้ขีดยาว ไม่ใส่ letter-spacing กับข้อความไทย

## ภาพ

- ใช้ภาพเสรีที่มีเครดิตเท่านั้น (CC0, CC BY, CC BY-SA, สาธารณสมบัติ) ห้ามใช้ภาพจากหนัง เว็บข่าว หรือโซเชียล
- ภาพที่ใช้สื่อความหมายแต่ไม่ใช่ของจริงในเรื่อง (เช่น วัดพระแก้วแทนความเป็นไทย) ต้องบอกผู้ใช้ตอนรายงาน
- ถ้าโปรเจกต์ไม่มีภาพที่เด่นพอ หาเพิ่มด้วย `find_images.py` ของ `/newsreel` คำค้นละ 4 ภาพ
- **วาดภาพประกอบเองด้วย HTML/SVG** เหมาะกับเรื่องเทคนิคที่ไม่มีภาพเสรีเด่น ๆ หรือเมื่อ chatgpt-bridge ถูกอีกเซสชันใช้อยู่ (ใช้จริงกับคลิป AI ในแฟลชไดรฟ์ 17 ต.ค. 2569: แฟลชไดรฟ์ ฟอง "AI" สัญลักษณ์ไม่มีเน็ต)
  - ก๊อป `references/cover_art_example.html` เป็น `<proj>/cover_art.html` แก้ภาพ แล้ว `python <skill_dir>/scripts/art_to_png.py <proj>/cover_art.html <proj>/img/cover_bg.png` (1080x1130)
  - วางวัตถุหลักช่วง y ราว 250 ถึง 750 ของภาพ: ส่วนบนสุดโดนครอป 4:5 ส่วนล่างโดนเงาไล่และตราแดงทับ (รอบแรกฟอง "AI" อยู่ y 170 แล้วโดนครอปหัวในแบบ 4:5 ต้องเลื่อน viewBox ลง 110 px)
  - ใส่ `"credit": ""` ใน cover.json เพราะไม่มีเจ้าของภาพ
  - ตัวอักษรในภาพวาดใช้แค่คำอังกฤษสั้น ๆ (เช่น AI) ข้อความไทยให้อยู่ในช่องของ cover.json

## กับดัก

- ปกเรนเดอร์ด้วย Chromium เท่านั้น ห้ามวาดตัวอักษรไทยด้วย PIL หรือ ffmpeg `drawtext` (สระลอย)
- หน้าโปรไฟล์ของ Instagram และ Facebook ครอปเป็น 4:5 หรือ 1:1 ตรงกลาง ข้อความต้องอยู่ในช่วง y 285 ถึง 1635 ตัวตรวจใน `make_cover.py` เช็กให้
- YouTube Shorts ใช้เฟรมจากคลิปเป็นปก อัปภาพเองไม่ได้ในบางบัญชี ตั้งแต่คลิป Phoenix (15 ต.ค. 2569) ผู้ใช้ใช้วิธีแทรกปกเป็นเฟรมแรก 0.5 วินาทีในฉบับ YouTube และอัปปกเองด้วยทุกคลิป `reelpost/scripts/make_upload.py` ทำให้แล้ว ไฟล์คลิปหลักไม่ต้องแทรก
- `make_cover.py` รับชื่อไฟล์ config เป็นอาร์กิวเมนต์ที่สอง ใช้ทำหลายแบบให้เลือก (`cover_a.json` `cover_b.json`) โดยไม่ทับกัน
