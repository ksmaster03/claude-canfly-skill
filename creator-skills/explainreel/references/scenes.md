# ชนิดฉากของ scenes.html

พื้นที่ฉาก 1080x1000 อยู่ใต้ซับ ข้อความทุกช่องย่อฟอนต์เองเมื่อยาวเกินกรอบ แต่สั้นไว้ดีกว่า
ช่องที่ขึ้นต้นด้วย ? ไม่ใส่ก็ได้

| type | ช่อง | ใช้ตอนไหน |
|---|---|---|
| `title` | `a` บรรทัดขาว, `b` บรรทัดสีเน้น, `?c` บรรทัดเล็ก | เปิดเรื่อง หรือสรุปสองบรรทัด |
| `stamp` | `a` สีเน้น, `b` ขาว | ข้อสรุปแบบตราประทับ |
| `num` | `top`, `n` ตัวเลขใหญ่, `unit` | ตัวเลขสำคัญ |
| `rule` | `n` เลขข้อ, `title` (เว้นวรรคแรกขึ้นบรรทัดใหม่), `chips` 2 ถึง 3 ป้าย | ข้อที่มีรายละเอียดย่อย · ป้าย 3 ใบต้องให้ `title` อยู่บรรทัดเดียว (ใช้ ` ` แทนเว้นวรรค) ไม่งั้นป้ายใบที่สามล้นการ์ด |
| `list` | `head`, `items` 2 ถึง 4 ข้อ | รายการติ๊กถูก |
| `cards` | `items` 2 ใบ `{icon,label}`, `foot` | เทียบสองอย่าง icon: doc check user hand wave chat clock site robot search gear |
| `flow` | `steps` 3 ขั้น, `?good` true ให้ขั้นสุดท้ายเป็นสีเขียว | ลำดับขั้น |
| `chat` | `bubbles` 1 ถึง 2 ฟอง, `foot`, `?heart` | คำถามหรือคำขอของคน |
| `strike` | `items` 2 ถึง 3 บรรทัดที่จะถูกขีดฆ่า, `foot`, `?soft` | ของเดิมที่ถูกแทน |
| `warn` | `a`, `b` | คำเตือน มีเสียงทุ้ม |
| `formula` | `parts` 2 ถึง 3 ส่วน, `result` | ก บวก ข เท่ากับ ค |
| `loop` | `nodes` 3 จุด, `note` | วงจรวนซ้ำ |
| `cmds` | `group` ป้ายหัว, `items` 1 ถึง 2 ใบ `{c,d}` (c คำสั่งอังกฤษ ขึ้นต้นด้วย $ ให้เอง, d คำอธิบายไทย) | คำสั่งเทอร์มินัลสั้น |
| `term` | `?title`, `lines` 1 ถึง 3 บรรทัด `{t,?c}` (c: mut grn acc red ink, `{n}` ใน t เป็นตัวนับ 1 ถึง 3), `foot`, `?foot2` | หน้าจอเทอร์มินัล คำสั่งยาว โครงไฟล์ |
| `shot` | `img` path ในโปรเจกต์ (กว้างไม่เกิน 1020 สูงไม่เกิน 360), `foot` | ภาพหน้าจอจริงในกรอบเหลือง ครอปเฉพาะส่วนที่ต้องโชว์ ขยายให้ตัวหนังสืออ่านได้บนมือถือ และตัดข้อมูลส่วนตัวออก (ใช้จริงกับคลิปเครดิต Claude 15 ต.ค. 2569) |
| `phone` | `caller`, `bubble`, `q` | สายเรียกเข้า |
| `cta` | `a`, `b` สีเน้น, `?c`, `?d` ป้ายเหนือลูกศร (ดีฟอลต์ "ปุ่มติดตามอยู่ตรงนี้") | ฉากปิด ลูกศรชี้ลงมุมล่างซ้ายที่ปุ่มติดตามของ Facebook Reels และ YouTube Shorts |
| `videocall` `ad` `profile` `sms` | ดูในโค้ด | ชุดคลิปกลโกง |
| `graph` `island` `map` | เนื้อหาฝังตายตัวจากคลิปเก่า | อย่าใช้กับเรื่องใหม่ ให้เขียนชนิดใหม่ใน scenes.html ของโปรเจกต์ |

ธีมสีอยู่บรรทัด `:root` ของ scenes.html: `--bg` พื้น, `--acc` เหลืองเน้น, `--red` สีเน้นรอง, `--grn` เขียว
ป้ายมุมล่างซ้ายคือ "บรรยายโดย โกสินทร์ต้องบินได้" (ผู้ใช้สั่งเปลี่ยนจากป้ายเสียง AI เมื่อ 15 ต.ค. 2569) ซ่อนเองตอนฉาก `cta`
