# /brandpost: ทำโพสต์ตรงแบรนด์ด้วยเครื่องมือในเครื่อง

ลูปการทำงาน: **Brand DNA → คิดหัวข้อ → สร้างงาน → วางแผน → ส่งมอบ** ภาพมาจาก chatgpt-bridge (บัญชี ChatGPT Plus ของผู้ใช้)
และตัวหนังสือไทยวางทีหลังด้วย HTML + Chromium ไม่ให้ AI วาดตัวไทยเอง

```
SK=~/.claude/skills/brandpost          # สกิลนี้
WS=$WORK/brandpost                     # ที่เก็บงาน แยกโฟลเดอร์ต่อแบรนด์
BRIDGE=$CHATGPT_BRIDGE                 # ตัวยิงภาพ (image-gen + Playwright/Chromium bridge)
```

## กฎเหล็ก

1. **ข้อเท็จจริงมาจาก `brand.json` เท่านั้น** ราคา โปร ส่วนลด เบอร์ ไอดีไลน์ เวลาเปิด สาขา รางวัล ที่ผู้ใช้ไม่ได้บอก ห้ามใส่ทั้งในภาพและแคปชัน
   (AI ต้องไม่แต่งตัวเลขหรือราคาที่ผู้ใช้ไม่ได้บอก และไม่เดาเบอร์หรือไลน์ให้)
2. **ห้าม AI วาดตัวหนังสือในภาพ** พรอมต์ทุกตัวปิดท้ายด้วยข้อห้ามตัวอักษร ข้อความไทยวางด้วย `render_post.py` เท่านั้น
   ห้ามวาดไทยด้วย PIL / ffmpeg drawtext / pdf-lib (สระลอย)
3. **สินค้าที่มีรูปจริงต้องยิงแบบมีรูปอ้างอิง (`ref`)** แล้วเปิดเทียบกับรูปจริงทุกภาพ ไม่มีรูปให้บอกผู้ใช้ว่า "หน้าตาสินค้าในภาพเป็นภาพที่ AI นึกเอง"
4. **คนจริง (พรีเซ็นเตอร์ เจ้าของร้าน) ห้ามให้ AI วาดจากรูปอ้างอิง** หน้าเปลี่ยนเป็นคนอื่นทุกครั้ง ใช้รูปจริงตัดพื้น (`~/.claude/skills/training-poster/scripts/cutout.py`) วางเป็นชั้น `person`
5. **ไม่โพสต์ ไม่ตั้งเวลา ไม่ส่ง LINE OA เอง** ส่งมอบเป็นโฟลเดอร์ไฟล์ โพสต์เมื่อผู้ใช้สั่งในเทิร์นนั้นเท่านั้น
6. **ภาษา**: ห้ามขีดยาว (em dash) และขีดกลาง (en dash) ทั้งในแคปชัน ข้อความบนภาพ และไฟล์ที่ส่งมอบ ใช้คำที่คนจบ ม.6 อ่านรู้เรื่องทันที ไม่ใช่ภาษาแปล
   emoji ในแคปชันใช้ตามน้ำเสียงใน `dna.md` แบรนด์ B2B/องค์กรใหญ่ไม่ใส่
7. **chatgpt-bridge รันทีละลูปเดียว** ลูปที่สองจะ kill เบราว์เซอร์ของลูปแรก

## ขั้น 0 เตรียม

- เช็กที่ว่างของไดรฟ์ที่เก็บ `$WORK` ถ้าต่ำกว่า 1 GB ถามผู้ใช้ก่อนว่าจะเก็บงานที่ไหน
- แบรนด์มีโฟลเดอร์แล้ว (`$WS/<slug>/brand.json`) อ่าน `brand.json` + `dna.md` แล้วข้ามขั้น 1 ได้
- งานที่ต้องใช้ภาพ: ถ้า bridge ขึ้น `not authenticated` เอเจนต์ล็อกอินแทนไม่ได้ ให้ผู้ใช้รัน `node login-helper.mjs` ใน `$BRIDGE` เอง

## ขั้น 1 Brand DNA

ทำตาม `reference/brand-dna.md` (โครง `brand.json` ทุกช่อง + โครง `dna.md`) ตัวอย่างเต็ม `templates/brand.example.json`
ชิ้นตัวอย่างที่ผ่านครบสายแล้ว (2 พ.ย. 2569): `templates/example-post.json` + `example-bg.jpg` (ภาพดิบจาก bridge) → `example-post.jpg` + `example-caption.txt`

1. ถาม 3 ข้อ: ชื่อแบรนด์ · หมวดธุรกิจ · เล่าว่าขายอะไรให้ใคร พร้อมขอรูปสินค้า โลโก้ ป้ายเมนู/ราคา (ถ้ามี) ช่องทางสั่งซื้อจริง
   ผู้ใช้อยากกรอกละเอียดให้เดิน 5 ขั้นตามตาราง
2. เติมที่เหลือเอง (กลุ่มลูกค้า ความต้องการ น้ำเสียง สไตล์ภาพจาก 14 แบบใน `reference/styles.json` สีหลัก รอง เน้น)
   อ่านราคาจากรูปป้ายได้ อ่านไม่ชัดให้เว้นว่างและบอกว่าเว้นตรงไหน สินค้าที่เดาเองติด `"guessed": true` ไม่ใส่ราคา
3. แสดงร่างเป็นตารางสั้นให้ผู้ใช้ตรวจ แก้จนผ่าน แล้วเขียน `brand.json`
4. เขียน `dna.md` (แนวทางคอนเทนต์ คำขวัญ หลักยึด บุคลิก · Content Pillars 4 หมวด · น้ำเสียง · ภาพ · ข้อห้าม)
5. คัดลอกรูปเข้า `assets/` (`logo.png`, `products/<sku>-1.jpg` ไม่เกิน 3 มุมต่อสินค้า)

## ขั้น 3 สร้างงาน

| ชนิด | ชื่อเรียก | ภาพ AI | ไฟล์ที่ได้ |
|---|---|---|---|
| แคปชันล้วน | เฉพาะแคปชัน | 0 | `caption.txt` |
| รูปเดี่ยว | รูปเดี่ยว | 1 | `post.png` + `caption.txt` |
| อัลบั้ม 2 ถึง 6 สไลด์ | อัลบั้มโพสต์ | เท่าจำนวนสไลด์ | `slide-1.png` ... + `caption.txt` |
| โพสต์จากรูปผู้ใช้ | โพสต์เอง | 0 | `caption.txt` (+ ข้อความบนรูปถ้าขอ ใช้รูปผู้ใช้เป็น `bg`) |
| แต่งรูปสินค้า | แต่งรูปสินค้า | 1 (มี ref) | `<id>.png` สไตล์จาก `enhance` 11 แบบ |
| ชุดรูปร้านค้าออนไลน์ | Shopee / Lazada | 1 ถึง 10 (มี ref) | `sku-1.png` ... ลำดับ ปก → วิธีใช้ → บรรยากาศ → ดีเทลใกล้ ขนาด 1:1 |
| คลิป | วิดีโอโฆษณา / คลิป TikTok | ใช้สกิลอื่น | `/explainreel` (motion + เสียงพากย์) · `/reel-factory` · Kling สำหรับคลิปสินค้าไม่มีเสียงพูด ห้ามใช้รูปหน้าคนจริงเป็นภาพตั้งต้นของโมเดลวิดีโอ |

โฟลเดอร์ต่อชิ้น `$WS/<slug>/posts/<YYYY-MM-DD>-<id>-<คำสั้น>/` ขั้นตอนของชิ้นที่มีภาพ

1. **`images.json`** เขียนฉากเป็นภาษาอังกฤษ (`subject`) ระบุ `aspect` `text_zone` `ref` `mode` (`post` / `enhance` / `sku` + `shot`)
   ```json
   [{ "id": "p01", "subject": "a glass of iced latte on a wooden cafe counter by the window, morning steam from a hot cup behind",
      "aspect": "4:5", "text_zone": "bottom", "ref": "../../assets/products/coffee-1.jpg" }]
   ```
   `text_zone` ต้องตรงกับ `layout` ที่จะใช้: bottom/card → `bottom` · top → `top` · left → `left` · none → `none`
2. ประกอบพรอมต์ (สไตล์ สีแบรนด์ พื้นที่ว่างวางข้อความ ข้อห้ามตัวอักษร คำสั่งคงหน้าตาสินค้า)
   ```bash
   python $SK/scripts/prompt.py images.json jobs --brand ../../brand.json
   ```
3. ยิงภาพ (รันเบื้องหลัง ภาพละราว 1 ถึง 2 นาที รอจนเห็น `ALLDONE`)
   ```bash
   bash $SK/scripts/gen_images.sh jobs img
   ```
4. **เปิดดูทุกภาพ** ตรงพรอมต์ไหม · สินค้าเหมือนรูปจริงไหม · มีตัวอักษรที่ AI แอบวาดไหม · ภาพสลับ id ไหม (bridge เคยคืนภาพของงานก่อนหน้า)
   ภาพไหนไม่ผ่านลบไฟล์แล้วรันข้อ 3 ซ้ำ (สคริปต์ข้ามภาพที่มีแล้ว)
5. **`post.json`** (อัลบั้มใช้ `slide-1.json` ... ทีละสไลด์) แล้วเรนเดอร์ ต้องขึ้น "ผ่าน" ทุกชิ้น
   ```json
   { "size": "4:5", "bg": "img/p01.png", "layout": "bottom", "eyebrow": "เมนูใหม่ต้นหนาว",
     "headline": "ลาเต้ดอยช้าง\nคั่วเองทุกเช้า", "sub": "หอมกลิ่นคั่วใหม่ ดื่มแล้วอุ่นไปถึงใจ", "cta": "แวะมาชิมที่ร้าน" }
   ```
   ```bash
   python $SK/scripts/render_post.py post.json --brand ../../brand.json
   ```
   ช่องที่ใช้ได้: `size` (1:1 4:5 2:3 9:16 5:4 3:2) · `bg` · `bg_position` · `layout` (bottom top left card none) · `logo` (ไม่ใส่ = ใช้โลโก้แบรนด์, `false` = ไม่มี) ·
   `logo_chip` · `eyebrow` · `headline` · `sub` · `bullets[]` · `price` · `cta` · `slide` ("2/4") · `person` · `theme` · `out`
   สีและฟอนต์มาจาก `brand.json` อัตโนมัติ ตัวเรนเดอร์ย่อตัวอักษรเองจนพอดีกรอบ ถ้ายังล้นจะขึ้น "ไม่ผ่าน" และคืน exit 1 ให้ตัดข้อความ
6. เปิดดู PNG ซูมตรงข้อความ: สระไม่ลอย ไม่ตัดกลางคำ ข้อความไม่ทับจุดสำคัญของภาพ
7. เขียน `caption.txt` ตามสูตรใน `reference/caption-and-plan.md` นับตัวอักษรไม่เกิน 2,200 แยก `caption_line.txt` / `caption_tiktok.txt` ถ้ามีช่องทางนั้น
8. เพิ่มแถวใน `$WS/<slug>/posts.csv` (`id,date,type,topic,folder,status,created`) สถานะเริ่ม `draft`

ข้อความบนภาพสั้นกว่าแคปชันเสมอ พาดหัว 4 ถึง 9 คำ ใช้ `\n` กำหนดจุดขึ้นบรรทัด และเว้นวรรคระหว่างวลีใน sub/bullets
เพราะตัวเรนเดอร์ตัดบรรทัดเฉพาะตรงเว้นวรรค (กันตัดกลางคำ เช่น "ลาเต้ดอย / ช้าง")

## ขั้น 4 แผนทั้งสัปดาห์หรือทั้งเดือน

ทำตาม `reference/caption-and-plan.md` หัวข้อ "แผนหลายโพสต์"
- ถามน้ำหนักเป้าหมาย 5 ตัว (ค่าเริ่มตัวละ 20%) ช่วงเวลา (1 สัปดาห์ 3 โพสต์ / 2 สัปดาห์ 7 / 1 เดือน 20) ช่องทาง สินค้าที่จะดัน
- แจกจำนวนโพสต์ตามน้ำหนัก วางวันกระจาย เวลา 11:00 หรือ 18:00 โพสต์ขายใกล้วันเงินเดือนออกหรือวันโปรใหญ่ **ห้ามโพสต์ขายในวันที่ติด "ไม่ควรโพสต์ขาย"**
- เขียน `posts/<YYYY-MM>-plan/plan.md` + `plan.csv` ให้ผู้ใช้ตรวจก่อน แล้วค่อยสร้างงาน
- ทั้งชุด: รวม `images.json` ของทุกโพสต์ไว้ในไฟล์เดียว ยิงลูปเดียว แล้วแยกเรนเดอร์ทีละโพสต์ บอกผู้ใช้ก่อนเริ่มว่าจะยิงกี่ภาพ ใช้เวลาราวเท่าไร

## ส่งมอบ

- ตารางสรุป: ชิ้นไหน ชนิดอะไร ไฟล์อยู่ไหน วันเวลาที่แนะนำให้โพสต์
- บอกตรง ๆ ว่าอะไรเป็นภาพที่ AI นึกเอง (ไม่มีรูปสินค้าจริง) และอะไรที่เว้นว่างเพราะผู้ใช้ไม่ได้ให้ข้อมูล
- ปิดท้ายเสมอ: AI อาจผิดได้ ตรวจก่อนเผยแพร่ ผู้โพสต์รับผิดชอบเนื้อหาเอง
- ถามว่าจะโพสต์ไหม ถ้าสั่งโพสต์ค่อยทำในเทิร์นนั้น ข้อควรรู้ LINE OA: ส่งเข้าแชตผู้ติดตามทุกคน ลบไม่ได้ กินโควตา ส่งวิดีโอไม่ได้

## กับดัก

- **bridge ล้ม `Target page, context or browser has been closed`** มักเพราะ chrome เก่าค้างถือ profile `chatgpt-data` สคริปต์ kill ให้ก่อนทุกภาพแล้ว
  ถ้ายังล้มซ้ำ อย่าวนแก้นาน ส่งงานส่วนที่ไม่ต้องใช้ภาพก่อน แล้วค่อยกลับมาทำภาพ
- **งานมี ref ขึ้น `no image` ทั้งที่ภาพเจนแล้ว** สคริปต์ลอง `recover.mjs` ให้อัตโนมัติ ภาพที่กู้มาอาจเป็นภาพผิดชิ้น ต้องเปิดเทียบทุกครั้ง
- หลัง TaskStop ลูปเบื้องหลัง เช็กว่าไม่มี `bash.exe` ของ `gen_images.sh` ค้าง (`Get-CimInstance Win32_Process | ? CommandLine -like '*gen_images*'`) ก่อนเริ่มลูปใหม่
- ChatGPT คืนภาพได้ไม่กี่สัดส่วน (เคยได้ 1254x1254 และ 1086x1448) สัดส่วนที่ต้องการจริงได้จากการครอปใน `render_post.py` (`object-fit: cover`) จึงวางของสำคัญไว้กลางภาพ
- ขึ้นบรรทัดในข้อความ JSON ต้องเขียน `\n` ห้ามขึ้นบรรทัดจริง (ตัวเรนเดอร์จะบอกชื่อไฟล์ที่เสีย)
- ฟอนต์ไม่ได้แถมมาใน repo ดาวน์โหลด Kanit, Prompt, Sarabun (OFL) จาก Google Fonts มาวางที่ `assets/fonts/<ชื่อ>-Regular/Medium/SemiBold/Bold.ttf` (4 น้ำหนักต่อฟอนต์) ฟอนต์อื่นก็ใช้วิธีเดียวกัน
- ห้ามใส่ letter-spacing กับข้อความไทย
