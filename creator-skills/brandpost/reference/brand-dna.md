# Brand DNA: ไฟล์ตัวตนแบรนด์ที่ทุกโพสต์อ้างอิง

ตัวช่วยสร้างแบรนด์ 5 ขั้น เก็บเป็นไฟล์สองไฟล์ในโฟลเดอร์แบรนด์

```
<workspace>/<brand-slug>/
  brand.json      ข้อมูลดิบที่ผู้ใช้บอก (ข้อเท็จจริง แก้ได้)
  dna.md          พิมพ์เขียวที่ Claude เขียนจาก brand.json (แนวทาง บุคลิก pillars)
  assets/         logo.png, presenter-*.png, products/<sku>-1.jpg ...
  posts/          งานแต่ละชิ้น (ดู SKILL.md)
  posts.csv       คลังคอนเทนต์
```

ตัวอย่างเต็มอยู่ที่ `templates/brand.example.json`

## brand.json

| ช่อง | มาจากขั้นไหน | หมายเหตุ |
|---|---|---|
| `name` | 1 | บังคับ |
| `industry` / `subindustry` | 1 | ข้อความอิสระ เช่น คาเฟ่ เครื่องสำอาง ร้านอาหาร |
| `sells` | 1 | `product` / `service` / `both` บริการเน้นบรรยากาศและผลลัพธ์ สินค้าเน้นหน้าตาแพ็กเกจให้ตรงจริง |
| `goals` | 1 | หลายข้อได้ จากชุด: followers, awareness, sales, community, launch |
| `price_range` | 1 | ข้อความตามที่ผู้ใช้บอก ห้ามเดา |
| `platforms` | 1 | facebook, instagram, tiktok, line_oa |
| `usp` | 1 | จุดเด่นแบรนด์ |
| `audience.who` / `audience.needs` | 2 | 1 ถึง 2 ประโยค |
| `voice` | 2 | หลายข้อได้: thai, english, thai_eng_mixed, genz_slang, professional, friendly_casual |
| `logo` | 3 | path ใน assets หรือ null |
| `presenters[]` | 3 | สูงสุด 3 คน `{name, photo, note}` ใช้กับภาพนิ่งเท่านั้น |
| `products[]` | 3 | `{sku, name, price, detail, order_channel, photos[]}` รูปสูงสุด 3 มุม |
| `order_channels` | 3 | ช่องทางสั่งซื้อรวมของร้าน (LINE, เบอร์, ลิงก์) ใส่เฉพาะที่ผู้ใช้ให้มา |
| `visual.style` | 4 | หนึ่งในคีย์ `post` ของ `styles.json` |
| `visual.colors` | 4 | `{primary, secondary, accent}` เป็นรหัสสี |
| `visual.font` | ใหม่ | `Kanit` / `Prompt` / `Sarabun` (ตัวที่สกิลฝังไว้) |
| `visual.custom` | 4 | "สไตล์ของคุณ" ข้อความอังกฤษสั้น ๆ ต่อท้ายพรอมต์ภาพ |
| `facts_locked` | ใหม่ | รายการข้อเท็จจริงที่แคปชันอ้างได้ (ราคา โปร เวลาเปิด) ทุกตัวต้องมาจากผู้ใช้ |

## สองทางเข้า

**แบบรวดเร็ว** (ค่าเริ่ม) ถาม 3 ข้อแล้วเติมที่เหลือเอง
1. ชื่อแบรนด์
2. หมวดธุรกิจ
3. "เล่าให้ฟังหน่อยว่าขายอะไร ให้ใคร" + รูปร้าน เมนู ป้ายราคา สูงสุด 4 รูป (ถ้ามี)

จากนั้นเติม audience, voice, usp, goals, style, สีเอง แล้ว **แสดงร่างให้ผู้ใช้ตรวจก่อนเขียน dna.md**
ราคา เบอร์ ไลน์ เวลาเปิด ที่ผู้ใช้ไม่ได้บอก ให้เว้นว่าง ห้ามเดา อ่านป้ายเมนูไม่ชัดให้เว้นและบอกว่าเว้นตรงไหน
สินค้าที่เดาจากคำเล่า (เช่น "ร้านกาแฟ" → กาแฟ เค้ก) ใส่ได้แต่ติด `"guessed": true` และไม่ใส่ราคา

**แบบละเอียด** เดินครบ 5 ขั้นตามตารางข้างบน ถามเป็นชุดละขั้น ใช้เมื่อผู้ใช้มีข้อมูลพร้อมหรือขอเอง

## dna.md (พิมพ์เขียว)

เขียนเป็นภาษาไทย ยาวไม่เกินหนึ่งหน้า โครงตามด้านล่าง

```markdown
# Brand DNA: <ชื่อแบรนด์>
สร้างเมื่อ <วันที่>

## แนวทางคอนเทนต์
"<คำขวัญหนึ่งบรรทัด>"
<ย่อหน้าวางตำแหน่ง: แบรนด์ช่วยใคร ด้วยอะไร ต่างจากร้านอื่นตรงไหน>
หลักยึด: <หนึ่งวลีที่ใช้ตัดสินทุกโพสต์ เช่น Practical over Technical / ของจริงไม่ปรุงแต่ง>
บุคลิก: <เปรียบเป็นคนหนึ่งคน เช่น "เพื่อนบาริสต้าที่จำเมนูประจำของคุณได้"> · <ทำอะไร> · <ไม่ทำอะไร>

## Content Pillars
1. <ชื่อหมวด> ทำอะไร เพื่ออะไร (ผูกกับเป้าหมายข้อไหน)
2. ...
3. ...
4. ...

## น้ำเสียง
- ภาษา: <ตาม voice>
- คำที่ใช้ / คำที่เลี่ยง
- emoji: <ใช้มากน้อยแค่ไหน>
- ปิดท้ายด้วย: <ช่องทางสั่งซื้อจริงจาก brand.json หรือ "ไม่ระบุช่องทาง">

## ภาพ
- สไตล์: <visual.style> + <visual.custom>
- สี: หลัก <hex> รอง <hex> เน้น <hex>
- ของที่ต้องเหมือนจริงเสมอ: <สินค้า/แพ็กเกจที่มีรูป>

## ห้าม
- ข้อเท็จจริงที่ไม่มีใน facts_locked (ราคา โปร ส่วนลด เบอร์ ไลน์ จำนวนสาขา รางวัล)
- คำโฆษณาเกินจริง / คำที่กฎหมายห้ามตามหมวด (อาหารเสริม เครื่องสำอาง คลินิก การเงิน ต้องระวังคำว่า รักษา หาย การันตี)
```

Pillars 4 หมวดเลือกให้ครอบเป้าหมายใน `goals` อย่างน้อยหมวดละเป้าหมาย สูตรตั้งต้นที่ใช้ได้กับร้านส่วนใหญ่:
ขาย/โปร · เล่าสินค้าและเบื้องหลัง · ความรู้ที่ลูกค้าเอาไปใช้ได้ · ชุมชนและเสียงลูกค้า
แก้ dna.md ทุกครั้งที่ brand.json เปลี่ยน และบันทึกวันที่ไว้หัวไฟล์
