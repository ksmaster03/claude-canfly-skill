# /nlt-isbn : ขอเลข ISBN จากหอสมุดแห่งชาติ

เป็นขั้น 9-15 ของสกิล [[ebook]] (ฟอนต์ Kanit → ปก v3 → ISBN → ส่งสำเนา → ขึ้นร้าน) ดูตารางลำดับงานในสกิล ebook หัวข้อ "9-15 หลัง build"
สคริปต์เพิ่ม: `to_kanit.py` (แปลงฟอนต์ทั้งเล่ม) · `front_cover.py` (ปก v3 ค่าเริ่มต้นตาม `cover_style` ใน book.json) · `back_cover.py` + `ean13.py` (ปกหลังบาร์โค้ด)

ทำจริงครั้งแรกเมื่อ 30/09/2569 กับเล่ม "หัวมันตัน ก็วาดออกมาสิ" ในนามบริษัทของผู้เขียน ได้คำร้องเลขที่ 372387
ระบบนี้เป็น ASP.NET MVC รุ่นเก่า (Version 1.0.0.111) มี jQuery datepicker, dropdown แบบ cascade และ modal ใช้ Playwright ต่อเข้า Chrome จริงทาง CDP (พอร์ต 9333)

- สคริปต์: `scripts/nlt_isbn.py` (ขับหน้าเว็บ) · `scripts/build_isbn_docs.py` (สร้างไฟล์แนบ)
- ตัวอย่างข้อมูลเล่ม: `templates/book.json` (ค่าจริงของเล่มแรก)
- ประวัติบัญชีและคำร้องที่ยื่นไปแล้ว: memory `project_nlt_isbn_account`

## กติกา

- **สมัครสมาชิกกับยื่นคำร้องเป็นการส่งข้อมูลจริงถึงหน่วยงานรัฐ** ทำเมื่อผู้ใช้สั่งในเทิร์นนั้นเท่านั้น
  `fill` และ `attach` ยังเป็นแค่ "ร่าง" ส่วน `submit` คือการส่งจริง
- เงื่อนไขข้อ 2 ของระบบ: ถ้ากรอกข้อมูลเท็จ เขายกเลิกสมาชิกได้ **ห้ามเดาข้อมูลส่วนตัวหรือข้อมูลบริษัท** ต้องดึงจากเอกสารจริง
  (บัตรประชาชน / หนังสือรับรองบริษัท ใน `<your-project>/gen_spec.py`) หรือถามผู้ใช้ ช่องที่ไม่บังคับและไม่มีในเอกสาร ให้เว้นว่าง
- ล็อกอินต้องให้ผู้ใช้ทำเอง เพราะมี reCAPTCHA ห้ามพิมพ์รหัสผ่านซ้ำในแชท ถ้าผู้ใช้เคยส่งรหัสในแชท ให้เตือนเปลี่ยน
- ข้อความไทยทั้งหมดส่งผ่านไฟล์ `.py` หรือ `.json` ที่เป็น UTF-8 อย่าส่งผ่าน argument ของ Git Bash เพราะอักษรไทยจะถูกกลืน

## ขั้นตอน

### 0. เปิดเบราว์เซอร์
```bash
python ~/.claude/skills/nlt-isbn/scripts/nlt_isbn.py chrome    # โปรไฟล์ถาวรที่ %LOCALAPPDATA%\nlt-eservice-profile
python ~/.claude/skills/nlt-isbn/scripts/nlt_isbn.py status    # ล็อกอินหรือยัง + รายการคำร้อง
```

### 1. สมัครสมาชิก (ครั้งแรกครั้งเดียว บัญชีมีอายุ 1 ปี)
หน้า `/Account/Register` ไม่มี captcha ตอนสมัคร แต่ต้อง**รอเจ้าหน้าที่อนุมัติ** ซึ่งจะแจ้งผลทางอีเมล
เลือก เอกชน → นิติบุคคล → ขอบริการ ISBN → บริษัทจำกัด ช่องบังคับของแบบนิติบุคคลมีดังนี้
- บัญชี: username (6-20 ตัวอักษร) และรหัสผ่าน
- ผู้ติดต่อ: คำนำหน้า ชื่อ นามสกุล เลขบัตรประชาชน และอีเมล
- บริษัท: ชื่อสำนักพิมพ์ และชื่อนิติบุคคลตามหนังสือรับรอง
- เจ้าของ: วันเกิด อาชีพ (เลือก "นักธุรกิจ") วันออกบัตร วันหมดอายุบัตร และเพศ
- ที่อยู่และติดต่อ: เลขที่ จังหวัด อำเภอ ตำบล รหัสไปรษณีย์ และเบอร์โทร
- **ไฟล์ยืนยันตัวตน** (บังคับ): ใช้ `สำเนาบัตรประชาชนกรรมการ_..._stamp.pdf` ไฟล์ต้องไม่เกินราว 5 MB

ถ้าขอแค่ ISBN อย่างเดียว ฟอร์มจะซ่อนช่องสัญชาติกับเชื้อชาติไว้ ช่องเลขทะเบียนนิติบุคคลกับเลขผู้เสียภาษีใช้เลข 13 หลักเดียวกันได้
วันที่ทุกช่องต้องเป็น `dd/mm/พ.ศ.` ถ้าวันเกิดถูก ช่องอายุจะคำนวณออกมาถูก (เช่น 23/08/2526 ได้ 43 ปี)

### 2. เตรียมข้อมูลเล่ม
คัดลอก `templates/book.json` ไปไว้ที่ `<โปรเจกต์เล่ม>/isbn/book.json` แล้วแก้ค่า
- `cover_pages` = เลขหน้าของปกและปกในใน PDF · `toc_pages` = เลขหน้าสารบัญ (เปิด PDF ดูก่อน อย่าเดา)
- `abstract` = ใช้คำอธิบายหน้าร้านได้ (ในโปรเจกต์ ebook อยู่ในตัวแปร `DESC` ของ `make-upload-sql.py`)
- ผู้แต่งให้ใช้ชื่อจริง ส่วนนามปากกาจะไปขึ้นในหน้าลิขสิทธิ์เอง
- วันเข้าโรงพิมพ์กับวันเผยแพร่: ถ้าเล่มขึ้นร้านไปแล้ว ให้ใส่วันที่ขึ้นร้านจริง

### 3. สร้างไฟล์แนบ
```bash
python ~/.claude/skills/nlt-isbn/scripts/build_isbn_docs.py <book>/isbn/book.json
```
คำสั่งนี้สร้าง 3 ไฟล์ตามช่องแนบของระบบ
1. **ปกและปกใน**
2. **หน้าลิขสิทธิ์ + สารบัญ + หนังสือรับรองบริษัท** (ช่องบังคับ)
3. **เรื่องย่อ**

หน้าลิขสิทธิ์ทำตามแบบในคู่มือหอสมุด หน้า 40-41 ส่วนที่ต้องมีคือ ชื่อหนังสือ ผู้จัดพิมพ์ และบรรทัด "ISBN" ที่เว้นว่างไว้
**ต้องเปิดภาพหน้าลิขสิทธิ์ดูก่อนแนบทุกครั้ง** ใช้ `channel='chrome'` เพื่อให้ตัดคำไทยถูก
ถ้าบรรทัดขึ้นใหม่ตรงรอยต่อคำประสม เช่น ลูก/ศร หรือ มือ/ถือ ถือว่าปกติ

### 4. กรอกคำร้อง → แนบไฟล์ → ยื่น
```bash
python ~/.claude/skills/nlt-isbn/scripts/nlt_isbn.py fill   <book>/isbn/book.json --dry   # ทดสอบกรอก ไม่บันทึกอะไร
python ~/.claude/skills/nlt-isbn/scripts/nlt_isbn.py fill   <book>/isbn/book.json   # จบที่หน้า EditFiles (ร่าง)
python ~/.claude/skills/nlt-isbn/scripts/nlt_isbn.py attach <book>/isbn/book.json   # ห้าม reload ระหว่างนี้
python ~/.claude/skills/nlt-isbn/scripts/nlt_isbn.py submit                         # ส่งจริง ต้องได้คำสั่ง
python ~/.claude/skills/nlt-isbn/scripts/nlt_isbn.py status                         # ต้องเห็นสถานะ "ขอ"
```
อ่านผลที่สคริปต์พิมพ์ออกมาทุกขั้น `fill` ต้องจบที่ URL `/ISBNReq/EditFiles/<id>` และ `submit` ต้องได้เลขที่คำร้องกับเวลาส่ง
เลขในหน้า Preview (เช่น 374267) เป็นรหัสภายในของระบบ **ไม่ใช่เลขที่คำร้อง** เลขที่คำร้องจริงอยู่ในหน้า Final หรือหน้า list (เช่น 372387)

### 5. หลังได้เลข ISBN
```bash
python ~/.claude/skills/nlt-isbn/scripts/apply_isbn.py <book.json>              # เตรียมโครง ช่อง ISBN ว่าง (ห้ามขึ้นร้าน)
python ~/.claude/skills/nlt-isbn/scripts/apply_isbn.py <book.json> 978-616-...  # ใส่เลขจริง
```
- ผลลัพธ์อยู่ที่ `<โฟลเดอร์ book.json>/out/` ไฟล์ต้นฉบับใน `dist/` ไม่ถูกแก้
- **PDF**: แทรกหน้าลิขสิทธิ์ก่อนหน้าสารบัญ สคริปต์จะบันทึกไฟล์ เปิดใหม่ แล้วตรวจว่าลิงก์ในสารบัญยังพาไปหน้าเปิดบทเดิม
  ‼ ถ้าเช็กลิงก์ก่อนบันทึก จะเห็นเลขหน้าเก่าและดูเหมือนเพี้ยน ทั้งที่ไฟล์จริงถูกต้อง
- **EPUB**: เพิ่ม `text/copyright.xhtml` ต่อจาก title_page ใน spine ถ้าใส่เลขมา จะใส่ `<dc:identifier id="isbn">urn:isbn:...</dc:identifier>` ด้วย
  โดยยังเก็บ uuid เดิมไว้เป็น unique-identifier
- หลังได้เลข มีงานต่อ 3 ขั้น
  1. อัปไฟล์ใน `out/` ทับบนร้าน ต้องได้คำสั่งอัปในเทิร์นนั้น
  2. ส่งสำเนาตาม พ.ร.บ.จดแจ้งการพิมพ์ มาตรา 8-9 ภายใน 30 วันนับจากวันเผยแพร่
     `python nlt_isbn.py deposit <book.json> <editId>` จะส่ง `out/<pdf>` ที่หน้า `/ISBNReqElect/Edit/<editId>`
     (editId ใช้เลขเดียวกับคำร้อง) สคริปต์ตรวจก่อนส่งว่าในเล่มมีบรรทัด "ISBN (e-book) <เลข>" และเลขตรงกับหน้าส่ง
     ส่งสำเร็จแล้วรายการในหน้า `/ISBNReqElect/listclient` จะเปลี่ยนจาก "ยังไม่ได้ส่ง" เป็น "รอตรวจสอบ"
  3. บันทึกเลขลง memory และ `_requests.csv`
- **ใส่เลขจริงแล้วได้เพิ่ม**: ปกหน้าแบบใหม่ (`front_cover.py` พื้นเข้ม รูปผู้เขียน ป้ายราคาเฉพาะเล่มขาย) แทนหน้า 1 ของ PDF และรูปปกใน EPUB
  + ปกหลังท้ายเล่ม (`back_cover.py` + `ean13.py`) มีบาร์โค้ด EAN-13 ที่สคริปต์สแกนตรวจด้วย `zxing-cpp` ทุกครั้ง
  ภาพศิลป์ใช้ `images/cover-plain.jpg` ของโปรเจกต์ ถ้าไม่มีจะใช้ปกเดิมแล้วครอปส่วนล่าง (`cover_art_pos` ปรับได้)
- หน้าลิขสิทธิ์ใช้ชื่อรองตามที่กรอกในคำร้อง (มาจากชื่อบนร้าน) ซึ่งอาจต่างจากชื่อรองในปกในของเล่ม

ถ้าเจ้าหน้าที่ส่งคำร้องกลับให้แก้ ในรายการคำร้องจะมีไอคอนซองจดหมาย ให้กดอ่านก่อน แล้วกด "แก้ไข" ไล่ขั้นไปจนถึงขั้นที่ 4 อีกรอบ

## ยื่นหลายเล่ม
ชุดที่เตรียมไว้ทั้งร้านอยู่ที่ `$PROJECTS/isbn-requests\<slug>\` (ดู README.md และ `_summary.csv` ในโฟลเดอร์นั้น)
- รายชื่อเล่มดึงจาก `https://myweekend.fun/api/ebooks?limit=200` ต้องใส่ `limit` เพราะค่าเริ่มต้นได้แค่ 50 รายการ ตัดรายการที่ `type` เป็น template หรือ game ออก
- เล่มฟรี (`price` 0) สคริปต์จะติ๊ก "ไม่มีราคาจำหน่าย (Free Copy)" ให้เอง
- ยื่นทีละเล่มแล้วอ่านผลที่สคริปต์พิมพ์ทุกครั้ง อย่ายิงรวดเดียวทั้งชุด ถ้าเล่มแรกโดนตีกลับ จะได้แก้ทุกเล่มก่อน
- ทุกเล่มที่ได้เลขแล้ว ต้องส่งสำเนาภายใน 30 วัน ถ้ายื่นหลายเล่มพร้อมกัน ภาระส่งสำเนาจะมาพร้อมกันด้วย

## กติกาจากเจ้าหน้าที่ (feedback จริง ต.ค. 2569) ‼ บางข้อทับคู่มือเล่มเก่า
เจ้าหน้าที่ 2 คนส่งคำร้องกลับมาด้วยเหตุผลชุดเดียวกัน ทั้งหมดนี้แก้ไว้ในสคริปต์แล้ว
1. **วันเผยแพร่ (ข้อ 16) ห้ามเป็นวันย้อนหลัง** รวมถึงเดือนและปีในบรรทัด "พิมพ์ครั้งที่" ของหน้าลิขสิทธิ์ด้วย
   ถ้าเล่มขึ้นร้านไปแล้ว ให้ใช้วันที่ฉบับที่มี ISBN จะขึ้นร้าน ซึ่งต้องเป็นวันในอนาคต เผื่อเวลาอนุมัติราว 2 สัปดาห์
   วันขึ้นร้านครั้งแรกเก็บไว้ใน `_review.first_store_date` ของ book.json
2. **ข้อ 8 โรงพิมพ์ของ e-book ต้องเว้นว่างทุกช่อง** และจังหวัด อำเภอ ตำบล ให้เลือก "-- กรุณาเลือก --"
   (คู่มือหน้า 43 บอกให้ใส่ "-" แต่เจ้าหน้าที่ตีกลับ)
3. **ข้อ 12 ลักษณะการพิมพ์** ต้องเลือก "อื่นๆ" ให้ติดจริง สคริปต์ assert ค่านี้ไว้แล้ว
4. **หนังสือรับรองบริษัทต้องเป็นไฟล์แยก** (`4-dbd-certificate.pdf` อยู่ในช่องที่ 2) ถ้ารวมไว้ท้ายไฟล์หน้าลิขสิทธิ์ เจ้าหน้าที่จะหาไม่เจอ
5. **หน้าลิขสิทธิ์ต้องเขียน "ISBN (e-book)"** แทน "ISBN" และเขียน **"จัดทำโดย"** แทน "จัดพิมพ์โดย"
6. **หลังเจ้าหน้าที่ลงทะเบียนบริษัทให้แล้ว** (ระบบจะให้รหัสองค์กรและเลขนำหน้า ISBN ของสำนักพิมพ์)
   ต้องเลือก "นิติบุคคล" แล้วกด "ค้นหาสำนักพิมพ์" ด้วยคำสั้น ๆ จากชื่อบริษัท ห้ามพิมพ์ชื่อเอง
   สคริปต์ทำให้เองเมื่อ book.json มี `publisher.nlt_org_search` จากนั้นระบบจะเติมที่อยู่ไทย/อังกฤษจากทะเบียนให้
7. **ช่องจำนวนที่จัดพิมพ์ (ข้อ 12) ของ e-book ต้องเว้นว่าง** ไม่ใช่ใส่ 0

### แก้คำร้องที่ถูกตีกลับ
```bash
python nlt_isbn.py status                       # ทุกหน้า: เลขที่คำร้อง | editId | สถานะ  (บันทึกไว้ที่ status.json)
python nlt_isbn.py fix <book.json> <editId>     # เปิด /isbnreq/Edit/<editId> แก้ฟอร์มตาม book.json แล้วไปขั้นแนบไฟล์
python nlt_isbn.py attach <book.json>           # ลบไฟล์เก่าทุกช่องก่อน แล้วแนบชุดใหม่
python nlt_isbn.py submit                       # ส่งกลับ สถานะจะกลับเป็น "ขอ"
```

อ่านข้อความจากเจ้าหน้าที่ได้จากปุ่ม "ดู" (`.button-show-message`) ในแต่ละแถว ข้อความจะเปิดขึ้นเป็น modal

## กับดักที่เจอมาแล้ว

| อาการ | สาเหตุ / ทางแก้ |
|---|---|
| ช่อง "ผู้รับผิดชอบจัดการพิมพ์" พิมพ์ไม่ได้ | ถ้าเลือกนิติบุคคล ช่องนี้เป็น readonly และให้เลือกได้เฉพาะสำนักพิมพ์ที่อยู่ในทะเบียน ถ้าเป็นบริษัทที่ขอครั้งแรก จะหาไม่เจอ ให้ตั้งค่าด้วย JS แล้วแนบหนังสือรับรองบริษัทไปด้วย คู่มือหน้า 43 บอกว่าเจ้าหน้าที่จะลงข้อมูลให้ |
| `select_option(label=...)` ค้าง | ชื่ออำเภอหรือตำบลมีวงเล็บภาษาอังกฤษต่อท้าย เช่น `บางพลี (Bang Phli )` ให้หา value ด้วยการเทียบคำขึ้นต้น แล้วรอ 2-3 วินาทีให้ dropdown ถัดไปโหลด |
| dropdown ภาษาอังกฤษถูก disable | ระบบตั้งค่าตามช่องภาษาไทยเอง ข้ามไปได้เลย |
| กด "ไม่ต้องการ CIP" แล้วค่าไม่เปลี่ยน | ปุ่มนี้มี `confirm()` แต่ Playwright ปฏิเสธ dialog เป็นค่าเริ่มต้น ต้องใส่ `page.on('dialog', d.accept())` |
| ไฟล์ที่แนบไว้หายไป | ไฟล์จะผูกกับคำร้องจริงก็ต่อเมื่อกด "ถัดไป ขั้นตอนบันทึกคำร้อง" ถ้า reload หน้าก่อนหน้านั้น ไฟล์ที่แนบไว้ทั้งหมดจะหาย ให้แนบครบ 3 ช่องในหน้าเดียว (ใช้ `button.manage-upload-file[value=15/16/17]`) |
| e-book ไม่มีโรงพิมพ์ | ~~ใส่ "-"~~ **เว้นว่างทุกช่อง และให้จังหวัด อำเภอ ตำบลเป็น "-- กรุณาเลือก --"** ตามที่เจ้าหน้าที่สั่ง · จำนวนพิมพ์ใส่ 0 · ลักษณะการพิมพ์เลือก "อื่นๆ" |
| ที่อยู่บริษัทไม่มีถนน แต่ช่องถนนบังคับ | ใส่ "-" |
| เล่มฟรีแล้ว `check(usePubAddressForDis)` ค้าง | พอติ๊ก Free Copy ระบบจะซ่อนส่วนผู้จัดจำหน่าย ให้ติ๊กช่องนี้เฉพาะตอนที่ยังมองเห็น |
| `page.screenshot(full_page=True)` ค้างในหน้าคำร้อง | หน้ามี `<option>` เกือบหมื่นตัว ให้อ่านค่าด้วย `evaluate` แทนการถ่ายภาพ |
| วันที่ผิดปี | ทุกช่องใช้ปี พ.ศ. รูปแบบ `dd/mm/yyyy` ให้ตั้งค่าแล้วสั่ง `$(e).trigger('change')` |
