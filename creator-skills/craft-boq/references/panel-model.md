อ้างอิงตอนเขียนโมเดลใน `takeoff_lib.py` — ทุกกฎมีเหตุผลทางช่างกำกับ

## 1. องค์ประกอบมาตรฐานของตู้ 1 ใบ

| ชิ้นส่วน | จำนวน | ขนาด | หมายเหตุ |
|---|---|---|---|
| แผงตั้งข้าง + แผงกั้น | **ช่อง + 1** | สูงตัวตู้ × ลึกตัวตู้ | ปิดผิว 2 หน้า (นอก/ใน) |
| แผงบน + แผงล่าง | **ช่อง × 2** | กว้างช่อง × ลึกตัวตู้ | ถ้าเป็นตู้ยาวชิ้นเดียวให้แตกตามความยาวแผ่นสูงสุด 2440 |
| แผงหลัง | 1 | กว้างรวม × สูงตัวตู้ | ปกติ 6 มม. ปิดผิวขาวด้านใน — **ถ้าแบบไม่ระบุ ต้องเข้า RFI** |
| ชั้นปรับระดับ | ช่อง × จำนวนชั้น | กว้างช่อง × (ลึก − 30) | ร่น 30 มม. ให้พ้นบานและสายไฟ |
| หน้าบาน | ตามรูปด้าน | อ่านจาก FRONT โดยตรง | ปิดขอบ 4 ด้าน |
| ตีนตู้ | หน้า 1 + ข้าง 2 | ยาว/ลึก × สูงตีนตู้ | ปกติร่นเข้า 50–75 มม. |
| คิ้วมือจับในตัว | 1 | กว้างรวม × สูงคิ้ว | เฉพาะตู้ที่ใช้ integrated handle |

## 2. ความสัมพันธ์ของระยะที่ต้องตรวจทุกครั้ง

```
กว้างรวม = แผงข้าง + Σ(บาน) + แผงข้าง
ภายในสุทธิ = กว้างรวม − (แผงข้าง × 2)
ภายในสุทธิ = (กว้างช่อง × จำนวนช่อง) + (หนาแผงกั้น × (ช่อง − 1))
```

**ตัวอย่างจริง** ตู้ยาว 7650 มม. แบบให้บาน 422 มม. × 18 ช่วง
- `25 + 422×18 + 25 = 7646 ≈ 7650` ✓ (422 เป็นค่าปัดจาก 422.2)
- ถ้าบานเป็นคู่ → 9 ช่อง ช่องพิทช์ 844 → `9w + 8×25 = 7600` → `w = 822`
- ⚠ **แบบให้แค่ระยะบาน ไม่ได้ให้ตำแหน่งแผงกั้น** → ตีความแล้วเข้า RFI เสมอ

## 3. กรณีพิเศษที่มักถอดพลาด

### ตู้แยก BODY บน–ล่าง
BOQ เขียน "ตู้บน-ตู้ล่างแยก BODY ออกจากกัน" = **นับแผงบน-ล่างเพิ่มอีก 1 ชุด**
โครงสร้างความสูงมาตรฐาน:
```
สูงรวม = บังตาบน + บานบน + คิ้วมือจับ + บานล่าง + ตีนตู้
2800   =   100    +  1469  +    85     +  1096   +   50     ✓
```

### ตู้ชนหลัง (2 หน้า)
ลึกรวม 900 = ตู้ลึก 450 × 2 → **นับเป็น 2 โครงเต็ม** บาน 2 ชุด ชั้น 2 ชุด
แต่ **ท็อปบนมักเป็นชิ้นเดียวกว้าง 900** — ต้องอ่านหมายเหตุใน BOQ ให้ดี

### ตู้หลายชุดต่อกัน
แบบเขียน "ชุดที่ 1 / ชุดที่ 2" = **โครงแยกกัน** ไม่ใช่โครงเดียวยาว
→ นับแผงข้างซ้ำที่รอยต่อ (2 แผง ไม่ใช่ 1)

### ตู้ช่องเก็บแผ่นตัวอย่าง (pigeonhole)
```
จำนวนช่อง = ช่องต่อแถว × จำนวนแถว          (แบบมักเขียนไว้ในกรอบ เช่น "142×6 = 852 ช่อง")
พิทช์ช่อง = ความกว้างช่อง + ความหนาแผ่นกั้น  (เช่น 50 + 5 = 55 มม.)
ตรวจ: กว้างภายใน ÷ พิทช์ ≈ จำนวนช่องต่อแถว
ชั้นนอน = แถว − 1
แผ่นกั้น ≈ จำนวนช่อง (ปัดขึ้น เผื่อเสียหาย)
```
**ค่าแรงต้องคิดต่อช่อง แยกจาก บาท/ตร.ม.** ไม่งั้นราคาต่ำกว่าความจริงมาก

### เคาน์เตอร์เข้ามุม L
แตกเป็น 2 ท่อนตามผัง แล้วหักพื้นที่ทับซ้อนที่มุม 1 ครั้ง
ท็อปหิน = พื้นที่ท็อป + **ผนังกันเปื้อน (backsplash)** — คนถอดลืมบ่อย

## 4. การนับผิวลามิเนต

- นับ **แยกหน้า** — แผงกั้น 1 แผ่นที่เห็นทั้ง 2 ด้าน = ลามิเนต 2 เท่าของพื้นที่แผ่น
- แผงหลัง แผ่นล่างสุด และด้านที่ชนผนัง = ปิดหน้าเดียว (`fb="-"`)
- ผิวนอกกับผิวในมักคนละรหัส → ต้องแยกคอลัมน์เสมอ ไม่รวมเป็น "ลามิเนต" ก้อนเดียว

## 5. การนับขอบ PVC

| ชิ้นส่วน | ปิดขอบ |
|---|---|
| หน้าบาน / หน้าลิ้นชัก | 4 ด้าน |
| ชั้นวาง | ด้านหน้า 1 ด้าน (ถ้ามองเห็นด้านข้างให้เพิ่ม) |
| แผงตั้ง / แผงบน-ล่าง | เฉพาะด้านที่มองเห็น (ปกติขอบหน้า 1 ด้าน) |
| แผงหลัง | ไม่ปิด |

## 6. ฮาร์ดแวร์

| รายการ | เกณฑ์นับ |
|---|---|
| บานพับ | บานสูง ≤ 1100 มม. = 3 ตัว · > 1100 มม. = 4 ตัว · > 2000 มม. = 5 ตัว |
| ตัวรองชั้นปรับระดับ | 4 ตัว/ชั้น |
| ขาปรับระดับ | 4 ตัว/ช่อง (ตู้ยาวใช้ 4 ตัวต่อโมดูล) |
| กุญแจล็อค | 1 ชุด/ช่องที่ระบุว่าต้องล็อก (อ่านจาก BOQ ไม่ใช่แบบ) |
| รางลิ้นชัก | 1 ชุด/ลิ้นชัก |

## 7. แปลงเป็นแผ่นสั่งซื้อ

```
จำนวนแผ่น = ROUNDUP( พื้นที่สุทธิ × (1 + เผื่อเศษ) ÷ 2.9768 , 0 )     # แผ่น 1220×2440
```
วิธีนี้เป็นการประมาณด้วยพื้นที่ **ไม่ใช่ nesting จริง** — ถ้าชิ้นงานยาวเกิน 2440 หรือกว้างเกิน 1220
ต้องแตกชิ้นก่อน และแจ้งผู้ใช้ว่าจำนวนแผ่นจริงอาจสูงกว่านี้
